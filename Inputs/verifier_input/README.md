# Standalone verifier inputs

Optional target, allowed-support, proof, skeleton, and saved-report files for
`python -m verifiers` belong here. The verifier CLI may also receive files from
another path; this directory is only the conventional ignored workspace.

Do not place gold proofs or API credentials here. See the
[standalone verifier guide](../../Individual%20Pipeline/verifiers/README.md) for
commands and the [output guide](../../Outputs/README.md) for artifacts.
