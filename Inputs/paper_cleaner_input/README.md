# Prepared paper inputs

`Commands/prepare_paper_input.sh` writes source and Paper Cleaner Steps 1-5
artifacts here, grouped by paper ID. A prepared directory normally contains the
flattened source, statement index, dependency evidence, and
`roles/selection.json` used to choose an opaque `stmt-...` target.

Everything except this README and the local ignore rule stays untracked. Paper
source may be subject to third-party redistribution restrictions.

See the [Paper Cleaner guide](../../Individual%20Pipeline/paper_cleaner/README.md)
and [command guide](../../Commands/README.md).
