The file asks a solver to prove the Target (Section 6) using only its
Sections 0-5 plus standard <<field_baseline>> knowledge. Audit five
claims:

1. SELF-CONTAINED — for EVERY non-standard symbol, operator, index set,
   named object and term appearing in the Target and in the granted
   blocks it builds on, verify a definition actually exists in Sections
   0-5. Use the paper to determine what each symbol really means and
   whether the file's version is faithful. Calibrations: (a) an
   instance of parametrized notation counts as defined when the file
   grants the general definition (e.g. $\mathbb{Z}_K$ is covered by a
   granted "$\mathbb{Z}_n := \{0,\dots,n-1\}$"); (b) textbook material
   of the baseline is NOT a gap; (c) a definition that exists in the
   paper but is missing from the file is a fatal issue. Also flag
   dangling \ref/\eqref/\cite (pointing at nothing inside the file)
   and LaTeX commands used but neither standard nor defined in
   Section 0.
2. LEAK-FREE — compare the file against <target_proof>. Flag any
   passage that narrates HOW the Target is proved: proof sketches,
   orderings ("first ... then"), "combine X with Y", "as in the proof
   of", meta-commentary on the argument, or text lifted from the
   proof. The mere PRESENCE of granted statements (Sections 3 and 5)
   is NOT a leak, even when they obviously bear on the Target;
   NARRATION is, and it is fatal even inside a granted block.
3. SUFFICIENT — walk through <target_proof> step by step; every
   pre-existing result / definition / assumption it pulls in must be
   granted in the file (statement-only is enough). Ignore what the
   proof derives itself, and short local steps a strong graduate
   student re-derives in ~3 routine lines from granted material. When
   in doubt whether a step is short, flag it.
4. FAITHFUL — for each granted definition, assumption and result,
   compare the file's wording against the paper's own version. Any
   paraphrase that weakens, strengthens, or shifts scope — changed
   quantifiers, an "all X" condition narrowed to a special case, a
   hypothesis dropped or added, a constant or exponent altered — is a
   fatal issue (kind "other"): the solver would be proving a DIFFERENT
   statement. Verbatim quotes are exempt by construction; scrutinize
   every restatement.
5. SOURCE-IDENTIFIED — every **[Rn]** item in Section 3 must have an explicit
   `Source:` citation key found in <bibliography>, or an unambiguous complete
   named source. A missing, vague, or unresolved source identifier is a fatal
   `other` issue. This check only validates identifiability; the independent
   restricted-web source gate verifies the external statement itself.

severity: "fatal" = the claim is false — the solver is blocked, misled,
