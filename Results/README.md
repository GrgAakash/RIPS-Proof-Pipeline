# Public results

This directory contains deliberately reviewed evaluation artifacts that are
exceptions to the repository's ordinary ignored-output policy.

| Collection | Contents | Claim boundary |
|---|---|---|
| [`brokenarxiv/`](brokenarxiv/README.md) | 43 selected solver-only S0-S6 runs from the June 2026 BrokenArXiv evaluation | prompts and model outputs, not verified proofs |

Public result collections should provide a scope statement, execution dates,
model and settings, artifact layout, accounting method, known irregularities,
and an explicit explanation of what the export does **not** establish.

Raw local runs belong under [`Outputs/`](../Outputs/README.md), not here.
