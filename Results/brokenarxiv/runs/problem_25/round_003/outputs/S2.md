S1 prerequisite stated explicitly: If `M` is Jiang-type and `pi_1(M)` has property `R_infty`, then every self-map `f: M -> M` whose induced map `f_*: pi_1(M) -> pi_1(M)` is an automorphism must satisfy `L(f)=0`.

Apply this to the identity map `id_M: M -> M`. Its induced map on fundamental groups is the identity automorphism:
`(id_M)_* = id_{pi_1(M)}`.

Therefore, by the S1 obstruction,

`L(id_M)=0`.

By the standard Lefschetz number formula for a finite CW complex, hence for a closed manifold,

`L(id_M) = sum_i (-1)^i tr(id: H_i(M;Q) -> H_i(M;Q)) = sum_i (-1)^i b_i(M) = chi(M)`.

Thus

`chi(M)=0`.
