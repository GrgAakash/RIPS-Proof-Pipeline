2. Subproof or failure.

Let `G = pi_1(M)`. By the standard definition from Nielsen fixed point theory, the Reidemeister number `R(f)` is the number of `f_*`-twisted conjugacy classes in `G`, where

`alpha ~ sigma alpha f_*(sigma)^(-1)`.

If `f_*: G -> G` is an automorphism, then property `R_infty` applies directly to `phi = f_*`. Hence the number of `f_*`-twisted conjugacy classes is infinite. Therefore

`R(f) = infinity`.

Now assume also that `M` is Jiang-type. If `L(f) != 0`, the Jiang-type condition gives

`N(f) = R(f)`.

But `N(f)` is a finite nonnegative integer by the standard definition of Nielsen number for a continuous self-map of a compact manifold, while `R(f)=infinity`. This is impossible. Therefore the alternative `L(f) != 0` cannot occur, and so

`L(f) = 0`.
