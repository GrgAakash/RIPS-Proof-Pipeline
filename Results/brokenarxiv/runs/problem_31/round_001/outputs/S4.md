2. Subproof or failure

Let \(P=Q=[0,10]\). These are lattice polytopes. For an integer \(n\ge 0\),
\[
L_P(n)=|[0,10n]\cap \mathbb Z|=10n+1,
\]
and similarly \(L_Q(n)=10n+1\). Thus both are Ehrhart positive.

Write coordinates in \(\mathbb R^3\) as \((X,Y,T)\). By the join definition,
\[
P*Q=\operatorname{conv}\bigl(\{(x,0,1):0\le x\le 10\}\cup \{(0,y,0):0\le y\le 10\}\bigr).
\]
Since the two displayed sets are convex, every point of \(P*Q\) has the form
\[
\lambda(x,0,1)+(1-\lambda)(0,y,0)
\]
with \(0\le \lambda\le 1\), \(0\le x\le 10\), and \(0\le y\le 10\). Hence
\[
P*Q=\{(X,Y,T):0\le T\le 1,\ 0\le X\le 10T,\ 0\le Y\le 10(1-T)\}.
\]
Therefore
\[
n(P*Q)=\{(X,Y,T):0\le T\le n,\ 0\le X\le 10T,\ 0\le Y\le 10(n-T)\}.
\]

For a lattice point \((X,Y,T)\in n(P*Q)\cap \mathbb Z^3\), the coordinate \(T=k\) is an integer with \(0\le k\le n\). For fixed \(k\), the number of possible integer \(X\)-coordinates is \(10k+1\), and the number of possible integer \(Y\)-coordinates is \(10(n-k)+1\). Thus
\[
L_{P*Q}(n)=\sum_{k=0}^n (10k+1)(10(n-k)+1).
\]
Expanding,
\[
(10k+1)(10(n-k)+1)=100k(n-k)+10n+1.
\]
So
\[
L_{P*Q}(n)
=100\sum_{k=0}^n k(n-k)+(10n+1)(n+1).
\]
Using
\[
\sum_{k=0}^n k(n-k)=n\sum_{k=0}^n k-\sum_{k=0}^n k^2
=\frac{n^2(n+1)}2-\frac{n(n+1)(2n+1)}6
=\frac{n(n+1)(n-1)}6,
\]
we get
\[
L_{P*Q}(n)
=\frac{100}{6}n(n+1)(n-1)+(10n+1)(n+1).
\]
Expanding:
\[
L_{P*Q}(n)
=\frac{50}{3}(n^3-n)+10n^2+11n+1
=\frac{50}{3}n^3+10n^2-\frac{17}{3}n+1.
\]
The linear coefficient is \(-17/3<0\). Hence \(P*Q\) is not Ehrhart positive, although \(P\) and \(Q\) are Ehrhart positive. This gives an explicit counterexample to the target theorem.
