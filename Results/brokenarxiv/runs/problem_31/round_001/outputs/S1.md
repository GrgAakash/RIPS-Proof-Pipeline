2. Subproof or failure

Let
\[
J=P*Q=\operatorname{conv}\bigl(\{(x,0_q,1):x\in P\}\cup\{(0_p,y,0):y\in Q\}\bigr).
\]

Every point of the first generating set has last coordinate \(1\), and every point of the second generating set has last coordinate \(0\). Since the last-coordinate projection is affine, every convex combination of such points has last coordinate in the interval \([0,1]\). Hence every point of \(J\) has last coordinate \(t\) with \(0\le t\le 1\).

Now fix an integer \(n\ge 0\), and let \(z\in nJ\cap \mathbb Z^{p+q+1}\). If \(n=0\), then \(nJ=\{0\}\), so the last coordinate of \(z\) is \(0\), which lies between \(0\) and \(n\).

Assume \(n>0\). Then \(z=nw\) for some \(w\in J\). If the last coordinate of \(w\) is \(t\in[0,1]\), then the last coordinate of \(z\) is \(nt\), hence lies in \([0,n]\). Because \(z\) is a lattice point in \(\mathbb Z^{p+q+1}\), its last coordinate is an integer. Therefore it is some integer \(k\) with \(0\le k\le n\).

This proves the assigned slicing setup.
