## 1. Subproblem

Prove: if \(N\trianglelefteq G\) is a normal subgroup of a finite group \(G\), then

\[
k(G)\leq k(N)\,k(G/N).
\]

Status: solved.

## 2. Proof

Let \(\pi:G\to G/N\) be the quotient map.

Every conjugacy class of \(G\) maps under \(\pi\) into a single conjugacy class of \(G/N\), since

\[
\pi(gxg^{-1})=\pi(g)\pi(x)\pi(g)^{-1}.
\]

Thus the conjugacy classes of \(G\) may be grouped according to the conjugacy class of \(G/N\) containing their image.

Fix one conjugacy class \(\overline C\) of \(G/N\), and choose \(x\in G\) with \(xN\in \overline C\). It is enough to show that at most \(k(N)\) conjugacy classes of \(G\) map into \(\overline C\).

The full preimage of \(\overline C\) is

\[
\pi^{-1}(\overline C)=\bigcup_{g\in G} g(xN)g^{-1}.
\]

So every \(G\)-conjugacy class lying above \(\overline C\) contains an element of the coset \(xN\). Therefore it is enough to bound the number of \(G\)-conjugacy classes meeting \(xN\).

Now consider the elements of the coset \(xN\), which have the form \(xn\) with \(n\in N\). If \(n_1,n_2\in N\) are conjugate inside \(N\), say \(n_2=ana^{-1}\) for some \(a\in N\), then the corresponding elements \(xn_1\) and \(xn_2\) need not be conjugate. So we use a slightly different parametrization.

Since \(N\trianglelefteq G\), conjugation by \(x\) defines an automorphism of \(N\). For \(a\in N\),

\[
a(xn)a^{-1}
= x\bigl(x^{-1}ax\bigr)n a^{-1}.
\]

Thus \(N\)-conjugation acts on the coset \(xN\). The number of \(G\)-conjugacy classes meeting \(xN\) is at most the number of \(N\)-orbits on \(xN\).

It remains to show that the number of \(N\)-orbits on \(xN\) is at most \(k(N)\).

The action of \(N\) on \(xN\) by conjugation is equivalent, after identifying \(xN\) with \(N\) by \(xn\leftrightarrow n\), to the twisted conjugation action

\[
a\cdot n=(x^{-1}ax)na^{-1}.
\]

A standard orbit-counting argument gives the number of orbits as

\[
\frac{1}{|N|}\sum_{a\in N} |\{n\in N:(x^{-1}ax)na^{-1}=n\}|.
\]

The fixed-point condition is

\[
(x^{-1}ax)n=na,
\]

equivalently

\[
x^{-1}ax=nan^{-1}.
\]

Thus \(a\) contributes fixed points only when \(a\) and \(x^{-1}ax\) are conjugate in \(N\). Since \(x^{-1}ax\in N\), this condition holds only within the \(N\)-conjugacy class of \(a\). For each \(a\), the number of solutions \(n\in N\) to

\[
x^{-1}ax=nan^{-1}
\]

is either \(0\) or \(|C_N(a)|\). Therefore the orbit count is at most

\[
\frac{1}{|N|}\sum_{a\in N} |C_N(a)|.
\]

But

\[
\sum_{a\in N}|C_N(a)|=k(N)|N|,
\]

because each conjugacy class \(D\subseteq N\) has size \(|N|/|C_N(a)|\), so its total contribution to the sum is

\[
|D|\cdot |C_N(a)|=\frac{|N|}{|C_N(a)|}|C_N(a)|=|N|.
\]

There are \(k(N)\) conjugacy classes in \(N\), hence the sum is \(k(N)|N|\). Therefore the number of \(N\)-orbits on \(xN\) is at most \(k(N)\).

So each conjugacy class of \(G/N\) accounts for at most \(k(N)\) conjugacy classes of \(G\). Since there are \(k(G/N)\) conjugacy classes in \(G/N\),

\[
k(G)\leq k(N)k(G/N).
\]

This proves the claim.
