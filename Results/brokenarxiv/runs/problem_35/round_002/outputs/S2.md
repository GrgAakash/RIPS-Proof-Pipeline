**1. Result**

S2 closes only conditionally. From S1 alone, the solvable-radical reduction reaches an essential lifting gap.

Let `m(G)` be the maximum order of a nilpotent subgroup of `G`. Suppose `G` is a minimal counterexample and `R(G) != 1`. Then `G` has a nontrivial normal elementary abelian subgroup `N <= R(G)`.

By S1,

```text
k(G) <= k(N) k(G/N) = |N| k(G/N),
```

since `N` is abelian. By minimality, `G/N` satisfies the target theorem, so

```text
k(G/N) <= m(G/N).
```

Thus

```text
k(G) <= |N| m(G/N).
```

Therefore S2 is proved if one has the following S3-type lifting statement:

```text
For this N, G contains a nilpotent subgroup P with |P| >= |N| m(G/N).
```

Then `k(G) <= |P|`, contradicting that `G` was a counterexample.

**2. Proof Of The Radical Subgroup Step**

Because `R(G)` is nontrivial and solvable, it contains a nontrivial abelian characteristic subgroup in its derived series. Choose a minimal nontrivial normal subgroup `N` of `G` inside such an abelian normal subgroup.

Then `N` is abelian. If more than one prime divides `|N|`, a Sylow subgroup of `N` is characteristic in `N`, hence normal in `G`, contradicting minimality. So `N` is a `p`-group. The subgroup of elements of order dividing `p` is also characteristic and nontrivial, so by minimality it equals `N`. Hence `N` is elementary abelian.

This supplies the normal elementary abelian subgroup required for the S1 reduction.
