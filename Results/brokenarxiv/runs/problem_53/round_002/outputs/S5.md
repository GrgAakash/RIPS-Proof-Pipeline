2. `S2`: The kinematic condition gives absolutely continuous trajectories
   `t -> X(t,a)`, `t -> X(t,b)` on `[t0,T_*)`, satisfying  
   `d_t X(t,a)=u(t,X(t,a))` and `d_t X(t,b)=u(t,X(t,b))` a.e.

3. `S3`: Under the contradiction assumption `sup_{t<T_*} K(t) < infinity`, plus the needed controlled local graph geometry, there is an integrable local Lipschitz bound along the two trajectories: for a.e. `t in [t0,T_*)`,
   ```text
   |u(t,X(t,a))-u(t,X(t,b))| <= L(t)|X(t,a)-X(t,b)|
   ```
   with
   ```text
   ∫_{t0}^{T_*} L(t) dt < infinity.
   ```
   This is the key continuation/regularity input; S5 does not prove it.

4. `S4`: The distance function
   ```text
   r(t)=|X(t,a)-X(t,b)|
   ```
   obeys the Gronwall lower bound
   ```text
   r(t) >= r(t0) exp(-∫_{t0}^{t} L(s) ds)
   ```
   for all `t in [t0,T_*)`.

Conditional contradiction:

Assume, toward contradiction, that a finite-time self-intersection occurs at `T_*` while curvature remains bounded:
```text
sup_{t<T_*} K(t) < infinity.
```
By the definition of collapse, there are distinct labels `a != b` such that
```text
|X(t,a)-X(t,b)| -> 0 as t -> T_*.
```

Choose `t0 < T_*` as in S1. Then `r(t0)>0`. By S3-S4,
```text
r(t) >= r(t0) exp(-∫_{t0}^{t} L(s) ds).
```
Since `∫_{t0}^{T_*} L(s) ds < infinity`, the right-hand side has a strictly positive uniform lower bound:
```text
r(t) >= r(t0) exp(-∫_{t0}^{T_*} L(s) ds) > 0
```
for every `t in [t0,T_*)`.

Thus `r(t)` cannot tend to zero as `t -> T_*`, contradicting collapse. Therefore, conditional on the stated prerequisites, bounded curvature is impossible. Hence
```text
sup_{t<T_*} K(t)=infinity.
```
