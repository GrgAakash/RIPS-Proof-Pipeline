2. **Derivative**

For
\[
g(a,b)=\frac{a^2+b^2}{(a+b)^2},
\]
\[
\partial_a g(a,b)=\frac{2b(a-b)}{(a+b)^3},\qquad
\partial_b g(a,b)=\frac{2a(b-a)}{(a+b)^3}.
\]

Thus
\[
\partial_xF=2x-\frac{2y(x-y)}{(x+y)^3}-\frac{2z(x-z)}{(x+z)^3},
\]
\[
\partial_yF=2y+\frac{2x(x-y)}{(x+y)^3}-\frac{2z(y-z)}{(y+z)^3}.
\]

\partial_xF-\partial_yF

2(x-y)-\frac{2(x-y)}{(x+y)^2}

4. **Exact Evaluation**

At
\[
x=\frac12,\quad y=\frac7{16},\quad z=\frac1{16},
\]
we have
\[
x-y=\frac1{16},\quad x+y=\frac{15}{16},\quad x-z=\frac7{16},\quad x+z=\frac9{16},
\]
\[
y-z=\frac6{16},\quad y+z=\frac8{16}=\frac12.
\]

So
\[
\partial_xF-\partial_yF
=
\frac18-\frac{32}{225}-\frac{224}{729}+\frac38.
\]

5. **Simplification**

\[
\frac18+\frac38=\frac12,
\]
hence
\[
\partial_xF-\partial_yF
=
\frac12-\frac{32}{225}-\frac{224}{729}.
\]

Using denominator \(36450\),
\[
\frac12=\frac{18225}{36450},\quad
\frac{32}{225}=\frac{5184}{36450},\quad
\frac{224}{729}=\frac{11200}{36450}.
\]

Therefore
\[
\partial_xF-\partial_yF
=
\frac{18225-5184-11200}{36450}
=
\frac{1841}{36450}.
\]

\boxed{\partial_xF-\partial_yF=\frac{1841}{36450}>0}.
