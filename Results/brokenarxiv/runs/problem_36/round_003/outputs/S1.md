2. Subproof or failure

Let `T` be the stopping time, namely the first draw time at which collector 1 has collected all `3` coupon types. For each type `i`, let `A_i(T)` be the number of coupons of type `i` drawn up to and including time `T`.

By definition of `T`, collector 1 has all coupon types at time `T`. Collector 1 only retains the first coupon of each type, so having type `i` at time `T` means that at least one coupon of type `i` has appeared by time `T`. Hence

`A_i(T) >= 1`

for every type `i`.

Now fix a type `i`. The first coupon of type `i` drawn before or at time `T` is retained by collector 1 and is not passed to collector 2. Every later coupon of type `i` is a duplicate for collector 1, so it is passed to collector 2. Therefore the number of type `i` coupons passed to collector 2 by time `T` is exactly `A_i(T) - 1`, since `A_i(T) >= 1`.

Collector 2 retains the first coupon of each type they receive. Thus collector 2 has type `i` at time `T` if and only if collector 2 has received at least one coupon of type `i`, which is equivalent to

`A_i(T) - 1 >= 1`,

or equivalently

`A_i(T) >= 2`.

Therefore collector 2 is missing type `i` at time `T` if and only if collector 2 has not received any coupon of type `i`, which is equivalent to

`A_i(T) - 1 = 0`.

Since `A_i(T) >= 1`, this is equivalent to

`A_i(T) = 1`.

So, at collector 1's completion time, every type has appeared at least once, and collector 2 is missing a type exactly when that type has appeared exactly once.
