2. At time \(T\), collector 1 has seen every type at least once. Collector 2 has received type \(i\) exactly when type \(i\) has appeared at least twice before or at time \(T\), because collector 1 keeps the first coupon of each type and passes later duplicates to collector 2. Therefore collector 2 is missing type \(i\) iff type \(i\) appears exactly once by time \(T\).

3. Fix a distinguished type \(A\) of probability \(a\), with the other two types \(B,C\) of probabilities \(b,c\). Type \(A\) is not a singleton by completion iff before at least one of \(B,C\) first appears, two \(A\)'s have already appeared.

   In the subsequence restricted to \(\{A,B\}\), the event that two \(A\)'s occur before the first \(B\) has probability
   \[
   \frac{a^2}{(a+b)^2}.
   \]
   Similarly, the event that two \(A\)'s occur before the first \(C\) has probability
   \[
   \frac{a^2}{(a+c)^2}.
   \]
   These two events occur simultaneously iff the first two actual draws are both \(A\), which has probability \(a^2\). Hence, by inclusion-exclusion,
   \[
   \mathbb P(A\text{ is singleton at }T)
   =
   1-\frac{a^2}{(a+b)^2}-\frac{a^2}{(a+c)^2}+a^2.
   \]

4. Summing this singleton probability over the three coupon types gives
   \[
   F(x,y,z):=\mathbb E[U_2^3(p)]
   =
   3+x^2+y^2+z^2
   -\frac{x^2+y^2}{(x+y)^2}
   -\frac{x^2+z^2}{(x+z)^2}
   -\frac{y^2+z^2}{(y+z)^2}.
   \]

5. For
   \[
   g(a,b)=\frac{a^2+b^2}{(a+b)^2},
   \]
   direct differentiation gives
   \[
   \partial_a g=\frac{2b(a-b)}{(a+b)^3},
   \qquad
   \partial_b g=\frac{2a(b-a)}{(a+b)^3}.
   \]
   Therefore
   \[
   \partial_xF
   =
   2x-\frac{2y(x-y)}{(x+y)^3}
      -\frac{2z(x-z)}{(x+z)^3},
   \]
   and
   \[
   \partial_yF
   =
   2y+\frac{2x(x-y)}{(x+y)^3}
      -\frac{2z(y-z)}{(y+z)^3}.
   \]
   Hence
   \[
   \partial_xF-\partial_yF
   =
   2(x-y)-\frac{2(x-y)}{(x+y)^2}
   -\frac{2z(x-z)}{(x+z)^3}
   +\frac{2z(y-z)}{(y+z)^3}.
   \]

   (x,y,z)=\left(\frac12,\frac7{16},\frac1{16}\right).

   \[
   \partial_xF-\partial_yF
   =
   \frac12-\frac{32}{225}-\frac{224}{729}
   =
   \frac{18225-5184-11200}{36450}

   \]

   \[
   (x-y)(\partial_xF-\partial_yF)\le 0

   whenever \(x>y\).    \]
   Therefore

   (x-y)(\partial_xF-\partial_yF)>0,
   \]
   contradicting the necessary derivative condition for Schur-concavity.

9. Thus \(F(p)=\mathbb E[U_2^3(p)]\) is not Schur-concave on the probability simplex. Consequently, the target theorem, which asserts Schur-concavity for all \(N\ge2\) and \(j\ge2\), is false as stated.
