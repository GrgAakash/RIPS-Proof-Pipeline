2. Subproof or failure

Let \(X_1,X_2,\ldots\) be the coupon types drawn in discrete time, with
\(\mathbb P(X_n=i)=p_i\). Let
\[
T=\inf\{n:\{X_1,\ldots,X_n\}=\{1,\ldots,N\}\}
\]
be the stopping time for collector 1, whenever this is finite. For a type \(i\), write
\[
C_i(n)=\#\{1\le m\le n:X_m=i\}.
\]

Fix a type \(i\). The passing rule acts independently by type: a coupon of type \(i\) is retained by the first collector in the sibling line who has not yet retained type \(i\). Therefore, after exactly \(m\) total coupons of type \(i\) have appeared, collectors \(1,\ldots,m\) have type \(i\), and collectors \(m+1,m+2,\ldots\) do not.

This is proved by induction on \(m\). For \(m=0\), no collector has type \(i\). If after \(m\) appearances exactly collectors \(1,\ldots,m\) have type \(i\), then the next type-\(i\) coupon is passed by collectors \(1,\ldots,m\), each of whom already has type \(i\), and is retained by collector \(m+1\). Thus after \(m+1\) appearances exactly collectors \(1,\ldots,m+1\) have type \(i\).

Hence, at any discrete time \(n\),
\[
\text{collector }j\text{ has type }i
\quad\Longleftrightarrow\quad
C_i(n)\ge j.
\]
So at the stopping time \(T\),
\[
U_j^N(p)=\sum_{i=1}^N \mathbf 1\{C_i(T)<j\}.
\]
This proves SC1.

Now assume first that \(p_i>0\) for all \(i\), so the stopping time is finite almost surely. Let \((N_i(t))_{t\ge0}\), \(1\le i\le N\), be independent Poisson processes with rates \(p_i\). Their superposition
\[
N_\ast(t)=\sum_{i=1}^N N_i(t)
\]
is a Poisson process of rate \(\sum_i p_i=1\). Conditional on an arrival of the superposed process, the arriving coupon has type \(i\) with probability \(p_i\), independently from arrival to arrival. Therefore the ordered labels of the superposed arrivals have the same law as the iid coupon sequence \((X_n)\).

Let
\[
Y_i=\inf\{t:N_i(t)\ge1\}
\]
be the first arrival time of type \(i\), and let
\[
M=\max_{1\le i\le N}Y_i.
\]
Then \(M\) is the first continuous time at which every type has appeared at least once. Indeed, by time \(M\), every \(Y_i\le M\), so every type has appeared; if \(t<M\), then some \(Y_i>t\), so type \(i\) has not appeared.

Since the Poisson arrival labels reproduce the coupon sequence in law, the count vector at the discrete stopping time \(T\) has the same law as
\[
(N_1(M),\ldots,N_N(M)).
\]
Equivalently,
\[
C_i(T)\stackrel{d}{=}N_i(M)
\]
jointly over all \(i\). Applying SC1 inside this embedded process gives
\[
\text{type }i\text{ is missing from collector }j
\quad\Longleftrightarrow\quad
N_i(M)<j.
\]
Thus
\[
U_j^N(p)\stackrel{d}{=}\sum_{i=1}^N \mathbf 1\{N_i(M)<j\}.
\]
This proves SC2 on the usual stochastic domain \(p_i>0\). If boundary points \(p_i=0\) are included literally, the finite stopping time need not exist; handling those points requires either an explicit infinite-time convention or a later continuity argument.
