1. Target decomposition

target_label:  
Problem 36

target_type:  
Schur-concavity theorem for an expected coupon-collector deficit

main_goal:  
Show, for every `N >= 2` and `j >= 2`, that `E[U_j^N(p)]` is Schur-concave in `p`.

variables_and_parameters:  
`N >= 2`; `j >= 2`; probability vector `p = (p_1, ..., p_N)` in the probability simplex; sibling collectors indexed by positive integers; stopping time when collector 1 first has all `N` types.

conclusion_to_prove:  
`E[U_j^N(p)]` is Schur-concave on the probability simplex, hence maximized at `p = (1/N, ..., 1/N)`.

source_status: provided definition / notation / assumption

tool:  
Schur derivative criterion

source_status: standard background fact

exact_statement_or_fact:  
For a differentiable symmetric function `F` on the simplex interior, Schur-concavity requires  
`(p_a - p_b)(partial_a F - partial_b F) <= 0`  
for every pair of coordinates.

intended_role_in_proof:  
Necessary test for the claimed Schur-concavity in the interior.

intended_role_in_proof:  
This is a direct obstruction to Schur-concavity unless the formula or arithmetic is wrong.

tool:  
Symmetry of expected deficit

source_status: standard background fact

exact_statement_or_fact:

intended_role_in_proof:

source_status: standard background fact

exact_statement_or_fact:
