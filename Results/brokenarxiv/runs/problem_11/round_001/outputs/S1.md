For every nonempty \(S\subseteq V(G)\), prove

\[
d_p(G)\ge 2^{-p}.
\]
Finally, for a vector \(x=(x_v)_{v\in V(G)}\) with \(\sum_v x_v^2=1\), define \(L_t=\{v\in V(G):x_v>t\}\) for \(t>0\), and prove
\[
|L_t|\le t^{-2}
\]
and the trivial bound \(|L_t|\le n\).

declared prerequisite subclaims: none

2. Subproof or failure

By definition,
\[
d_p(G)=\max_{\emptyset\ne T\subseteq V(G)} \frac{e(G[T])}{|T|^p}.
\]
Therefore, for any nonempty \(S\subseteq V(G)\), the particular set \(S\) is one of the sets over which the maximum is taken. Hence
\[
\frac{e(G[S])}{|S|^p}\le d_p(G),
\]
and multiplying by \(|S|^p>0\) gives
\[
e(G[S])\le d_p(G)|S|^p.
\]

Since \(G\) has at least one edge, choose an edge \(uv\in E(G)\). Let \(S=\{u,v\}\). Then \(G[S]\) contains the edge \(uv\), so \(e(G[S])=1\). Hence
\[
d_p(G)\ge \frac{e(G[S])}{|S|^p}=\frac{1}{2^p}=2^{-p}.
\]

Now let \(x=(x_v)_{v\in V(G)}\) satisfy \(\sum_{v\in V(G)}x_v^2=1\), and for \(t>0\) define
\[
L_t=\{v\in V(G):x_v>t\}.
\]
For each \(v\in L_t\), we have \(x_v^2>t^2\). Therefore
\[
t^2|L_t| < \sum_{v\in L_t}x_v^2 \le \sum_{v\in V(G)}x_v^2=1.
\]
Thus \(|L_t|<t^{-2}\), and in particular
\[
|L_t|\le t^{-2}.
\]
Also \(L_t\subseteq V(G)\), so
\[
|L_t|\le |V(G)|=n.
\]
