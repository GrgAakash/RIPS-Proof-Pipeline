Let `D=d_p(G)`, so for every nonempty `S`,
\[
e(S)\le D|S|^p.
\]

It is enough to prove that for every nonnegative unit vector `x`,
\[
x^T A x\le C_p D n^{p-1}.
\]
The spectral radius is attained by a nonnegative Perron vector, componentwise if needed.

First derive a cut estimate. If `U⊆W`, put `a=|U|`, `b=|W|`. The ordered adjacency count
\[
R(U,W)=\sum_{u\in U,w\in W}A_{uw}
\]
satisfies
\[
R(U,W)\le (2+2^p)D a^{p-1}b.
\]
Indeed, `R(U,W)=2e(U)+e(U,W\setminus U)`. The internal part is at most `2Da^p≤2Da^{p-1}b`. For the cross part, if `B=W\setminus U` has size `c≤a`, then
\[
e(U,B)\le e(U\cup B)\le D(2a)^p\le 2^pDa^{p-1}b.
\]
If `c>a`, choose a uniformly random `a`-subset `B'⊆B`; then
\[
(a/c)e(U,B)=\mathbb E e(U,B')\le D(2a)^p,
\]
so again `e(U,B)≤2^pDa^{p-1}c≤2^pDa^{p-1}b`.

Now let
\[
L_t=\{v:x_v\ge t\},\qquad a(t)=|L_t|.
\]
By layer cake,
\[
x^TAx=\int_0^\infty\int_0^\infty R(L_s,L_t)\,ds\,dt.
\]
The level sets are nested. For `s≥t`, `L_s⊆L_t`, so the cut estimate gives
\[
R(L_s,L_t)\le (2+2^p)D\,a(s)^{p-1}a(t).
\]
By symmetry,
\[
x^TAx
\le 2(2+2^p)D
\int_0^\infty a(s)^{p-1}\left(\int_0^s a(t)\,dt\right)ds.
\]

It remains to bound the integral. Since `||x||_2=1`,
\[
\int_0^\infty 2t\,a(t)\,dt=1.
\]
Also `a(t)≤n`, and monotonicity gives `a(t)≤t^{-2}`. Finally,
\[
\int_0^s a(t)\,dt\le ns,\qquad
\int_0^s a(t)\,dt\le \int_0^\infty a(t)\,dt=\|x\|_1\le \sqrt n.
\]
Split at `s_0=n^{-1/2}`. For `s≤s_0`,
\[
\int_0^{s_0} a(s)^{p-1}\int_0^s a(t)dt\,ds
\le \int_0^{s_0} n^{p-1}ns\,ds
=\frac12 n^{p-1}.
\]
For `s≥s_0`,
\[
\int_{s_0}^{\infty} a(s)^{p-1}\int_0^s a(t)dt\,ds
\le \sqrt n\int_{s_0}^{\infty}s^{-2(p-1)}ds
=\frac{n^{p-1}}{2p-3},
\]
using `p>3/2`.

Therefore
\[
\lambda(G)\le x^TAx
\le 2(2+2^p)\left(\frac12+\frac1{2p-3}\right)D n^{p-1}.
\]
