Let \(D=d_p(G)\). Then for every nonempty \(U\subseteq V(G)\),

\[
e(U)\le D|U|^p.
\]

I prove the finite-\(n\) bound

\[
\lambda(G)\le C_pD\sqrt n
\]

for every \(1<p<3/2\).

Define, for \(A\subseteq B\subseteq V(G)\),

\[
\iota(A,B)=\sum_{u\in A,\ v\in B}\mathbf 1_{uv\in E(G)}.
\]

So edges inside \(A\) are counted twice, and edges from \(A\) to \(B\setminus A\) once.

**Cut lemma.** If \(A\subseteq B\), \(a=|A|\), \(b=|B|\), then

\[
\iota(A,B)\le K_p D\, b\, a^{p-1},
\qquad K_p=2+2^p.
\]

If \(A=\varnothing\) this is trivial. If \(b\le 2a\), then

\[
\iota(A,B)\le 2e(B)\le 2Db^p\le 2^pDba^{p-1}.
\]

If \(b>2a\), choose uniformly an \(a\)-element set \(R\subseteq B\setminus A\), and put \(S=A\cup R\). Then \(|S|=2a\), hence \(e(S)\le D(2a)^p\). Taking expectations,

\[
\frac{a}{b-a}e(A,B\setminus A)\le \mathbb E e(S)\le D(2a)^p,
\]

so

\[
e(A,B\setminus A)\le 2^pDba^{p-1}.
\]

Also \(2e(A)\le 2Da^p\le 2Dba^{p-1}\). Thus the cut lemma follows.

Now take any nonnegative vector \(x\) with \(\sum_v x_v^2=1\). Let

\[
L_t=\{v:x_v>t\},\qquad A(t)=|L_t|,\qquad F(s)=\int_0^s A(t)\,dt.
\]

By layer cake,

\[
x^TAx
=
\int_0^\infty\int_0^\infty \iota(L_s,L_t)\,dt\,ds.
\]

By symmetry, restrict to \(s\ge t\). Then \(L_s\subseteq L_t\), so the cut lemma gives

\[
\iota(L_s,L_t)\le K_pD\,A(t)A(s)^{p-1}.
\]

Therefore

\[
x^TAx
\le
2K_pD\int_0^\infty F(s)A(s)^{p-1}\,ds.
\]

Since \(\|x\|_2=1\),

\[
A(s)\le n,\qquad A(s)\le s^{-2},\qquad x_v\le 1.
\]

Set \(r=n^{-1/2}\). For \(0<s\le r\),

\[
F(s)\le ns,\qquad A(s)^{p-1}\le n^{p-1},
\]

so

\[
\int_0^r F(s)A(s)^{p-1}\,ds
\le
\frac12 n^{p-1}
\le
\frac12\sqrt n.
\]

For \(r<s\le 1\),

\[
F(s)\le nr+\int_r^s t^{-2}\,dt\le 2\sqrt n,
\]

and

\[
A(s)^{p-1}\le s^{-2(p-1)}.
\]

Hence, since \(p<3/2\),

\[
\int_r^1 F(s)A(s)^{p-1}\,ds
\le
2\sqrt n\int_r^1 s^{2-2p}\,ds
\le
\frac{2}{3-2p}\sqrt n.
\]

Thus

\[
\int_0^\infty F(s)A(s)^{p-1}\,ds
\le
\left(\frac12+\frac{2}{3-2p}\right)\sqrt n.
\]

So for every unit nonnegative \(x\),

\[
x^TAx
\le
2K_pD\left(\frac12+\frac{2}{3-2p}\right)\sqrt n.
\]

Taking the Rayleigh supremum, and replacing an arbitrary vector by its absolute value if needed,

\[
\lambda(G)\le C_pD\sqrt n,
\]

with

\[
C_p=2(2+2^p)\left(\frac12+\frac{2}{3-2p}\right).
\]
