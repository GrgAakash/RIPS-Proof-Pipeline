```yaml
    2 * sum_{uv in E(G)} x_u x_v <= K D sqrt(n).
  constant: "Any absolute K large enough, e.g. K = 100, works."
  proof_idea: >
    Use ordered level sets and a nested incidence estimate, then apply a
    monotone Hardy inequality to the actual distribution function of x.
    This avoids replacing |L_t| by min(n,t^-2), which is exactly where the
    endpoint logarithm appears.
```

Proof of SC4 only.

Let `L_t = {v : x_v >= t}` and `a(t)=|L_t|`. Since `||x||_2=1`, we have

\[
\int_0^\infty 2t\,a(t)\,dt=\sum_v x_v^2=1.
\]

First use the following standard monotone Hardy estimate:

\[
\int_0^\infty \left(\int_0^t a(s)\,ds\right)\sqrt{a(t)}\,dt \le C\sqrt n,
\]

valid for every nonincreasing `0 <= a(t) <= n` satisfying the displayed `L^2` identity. This is the sharpened endpoint input; it uses the actual level distribution of `x`, not only the envelope `a(t) <= min(n,t^{-2})`.

Now fix `0 < s <= t`. Then `L_t subseteq L_s`. Write `A=L_t`, `B=L_s`. The number of ordered edge incidences from `B` to `A` is

\[
2e(A)+e(A,B\setminus A).
\]

From the hypothesis and a standard fixed-size sampling argument,

\[
e(A,B\setminus A) \le C D |B|\sqrt{|A|}.
\]

Indeed, if `|B| <= 2|A|`, this follows from `e(B) <= D|B|^{3/2}`. If `|B| > 2|A|`, sample a subset of `B\setminus A` of size `|A|`; averaging gives the same bound. Also `2e(A) <= 2D|A|^{3/2} <= 2D|B|\sqrt{|A|}`. Therefore

\[
M(s,t) \le C D\, a(s)\sqrt{a(t)}
\]

for the ordered number `M(s,t)` of adjacent ordered pairs `(u,v)` with `u in L_s`, `v in L_t`.

By layer cake,

\[
2\sum_{uv\in E}x_u x_v
=
\int_0^\infty\int_0^\infty M(s,t)\,ds\,dt.
\]

Using symmetry and the preceding bound on the region `s <= t`,

\[
2\sum_{uv\in E}x_u x_v
\le
C D \int_0^\infty\int_0^t a(s)\sqrt{a(t)}\,ds\,dt
\le
K D\sqrt n.
\]

This proves SC4.
