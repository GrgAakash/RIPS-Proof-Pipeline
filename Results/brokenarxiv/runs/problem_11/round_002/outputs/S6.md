d_{3/2}(G)\le d_p(G)n^{\max\{0,p-3/2\}}.
\]
If one had the endpoint estimate
\[
\lambda(G)\le K\,d_{3/2}(G)\sqrt n,
\]
then
\[
\lambda(G)\le Kd_p(G)n^{1/2+\max\{0,p-3/2\}}

\]
which would imply the target theorem.

[KEY STEP] The blocking point is the missing endpoint estimate: under the hereditary assumption \(e(G[S])\le D|S|^{3/2}\), one still needs a valid proof that
\[
2\sum_{uv\in E(G)}x_ux_v\le K D\sqrt n
\]
for every nonnegative unit vector \(x\).

The supplied S3 proof does not establish this. Its asserted monotone Hardy estimate is false. Let \(L=\log N\), and define a nonincreasing function \(q\) on \([0,\infty)\) by taking \(q_0(u)=1/2\) on \((0,1/2]\), \(q_0(u)=1/(2L)\) on \((1/2,1]\), \(q_0(u)=1/(2Lu)\) on \((1,e^L]\), and \(q_0(u)=0\) afterward; normalize \(q=q_0/\int q_0\). \[
\int_0^\infty\left(\int_0^t a(s)\,ds\right)\sqrt{a(t)}\,dt
\ge c\sqrt{N\log N},
\]
not \(O(\sqrt N)\). Therefore S3’s analytic endpoint argument cannot complete the proof.
