1. Target decomposition

target_label:
Spectral radius versus hereditary p-density bound.

target_type:
Asymptotic upper bound for graphs.

main_goal:
Reduce the statement for all `1 < p <= 2` to the endpoint `p = 3/2`, then prove a uniform endpoint Rayleigh-form inequality.

variables_and_parameters:
`p` with `1 < p <= 2`; `n`; an `n`-vertex graph `G` with at least one edge; `lambda(G)`; `d_p(G)`.

conclusion_to_prove:
There is a constant `C_p > 0`, depending only on `p`, such that
`lambda(G) <= (C_p + o(1)) d_p(G) n^{max{1/2, p-1}}`
as `n -> infinity`.

2. Available tools

tool:
Rayleigh variational characterization.

source_status:
standard background fact.

exact_statement_or_fact:
For a graph adjacency matrix `A`,
`lambda(G) = max_{||x||_2=1} x^T A x`, and for a nonnegative Perron vector,
`x^T A x = 2 sum_{uv in E(G)} x_u x_v`.

intended_role_in_proof:
Convert the spectral-radius bound into a weighted edge-sum estimate.

tool:
Perron-Frobenius nonnegative eigenvector.

source_status:
standard background fact.

exact_statement_or_fact:
A nonnegative symmetric adjacency matrix has a nonnegative eigenvector attaining the spectral radius.

intended_role_in_proof:
Allows the Rayleigh maximizer to be assumed nonnegative.

tool:
Endpoint hereditary-density comparison.

source_status:
proved inside the current proof.

exact_statement_or_fact:
For `D = d_{3/2}(G)`, if `e(G[S]) <= D |S|^{3/2}` for every nonempty `S`, then
`lambda(G) <= K D sqrt(n)`
for an absolute constant `K`.

intended_role_in_proof:
This is the central endpoint estimate from which all `p` follow.

tool:
Density monotonicity between `d_p` and `d_{3/2}`.

source_status:
provided definition / notation / assumption.

exact_statement_or_fact:
For every nonempty `S`,
`e(S)/|S|^{3/2} = (e(S)/|S|^p) |S|^{p-3/2}`.
Thus
`d_{3/2}(G) <= d_p(G)` if `p <= 3/2`, and
`d_{3/2}(G) <= d_p(G) n^{p-3/2}` if `p >= 3/2`.

intended_role_in_proof:
Transfers the endpoint estimate to the full range `1 < p <= 2`.

tool:
Guidance item 1.

source_status:
additional guidance item.

exact_statement_or_fact:
The endpoint `p = 3/2` cannot be proved from only `|L_t| <= min(n,t^{-2})` in the max-min level-set integral; one needs a sharper integral formulation, structural coupling between level sets, or a different Rayleigh-form estimate avoiding the endpoint logarithm.

intended_role_in_proof:
Warns the final proof to avoid the naive level-set argument and to prove the endpoint using a sharper weighted/structural estimate.

4. Hardest step prediction

hardest_step_id:
SC4

hardest_step_description:
Proving the endpoint weighted Rayleigh estimate without losing a logarithmic factor at `p = 3/2`.

risk_if_wrong:
A naive level-set integral gives an endpoint logarithm, which would not imply the stated theorem.

how_final_proof_should_handle_it:
Use a sharper Rayleigh-form argument that couples different coordinate levels, for example by dyadic decomposition together with a structural cross-level estimate derived from `e(S) <= D |S|^{3/2}`. The proof should explicitly show summability at the endpoint and cite guidance item 1 as the reason the naive max-min level-set bound is insufficient.

5. Failure-mode checks

circularity_check:
Do not assume the target theorem or any `p=3/2` spectral theorem externally; SC4 must be proved inside the current proof.

full_theorem_check:
After SC4, verify both regimes separately: `p <= 3/2` gives exponent `1/2`, and `p >= 3/2` gives exponent `p-1`.

source_check:
No allowed supporting statements are provided beyond definitions. Only standard spectral facts and internally proved subclaims may be used.

hypothesis_check:
Use the assumption that `G` has at least one edge only to avoid degenerate density issues; if needed, note the edgeless case is trivial.

notation_check:
Keep `e(G[S])`, `d_p(G)`, `lambda(G)`, and `n` consistent throughout.

standard_background_check:
Explicitly state Rayleigh characterization and Perron-Frobenius when used. Avoid invoking nonstandard matrix or graph inequalities unless they are proved in the final proof.

6. Subproblem assignment table

S1:
Prove SC1 and SC2. Show the comparison between `d_p` and `d_{3/2}`, then explain why the endpoint estimate implies the theorem for all `1 < p <= 2`.

S2:
Prove SC3 using Rayleigh characterization and Perron-Frobenius. Set up the endpoint problem as a bound on `2 sum_{uv} x_u x_v`.

S3:
Prove SC4, the endpoint weighted Rayleigh estimate. This is the main technical subproblem.

S4:
Audit the SC4 proof specifically for the `p=3/2` endpoint. Ensure it does not rely only on `|L_t| <= min(n,t^{-2})` and that no logarithmic loss remains.

S5:
Combine all subclaims into the final theorem statement, define `C_p`, and justify that the non-asymptotic bound implies the stated `(C_p+o(1))` form.
