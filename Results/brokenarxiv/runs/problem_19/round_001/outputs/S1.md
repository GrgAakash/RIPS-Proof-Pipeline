2. Subproof or failure

Let \(G\) be a connected simple undirected graph with vertex set \(V(G)\), \(|V(G)|=n\), edge set \(E(G)\), \(|E(G)|=m\), and adjacency matrix \(A\).

First, prove \(m\ge n-1\). If \(n=0\) this is outside the usual connected-graph setting for the target theorem. Assume \(n\ge 1\). Choose a root vertex \(r\). Since \(G\) is connected, for every vertex \(v\ne r\), there is a path from \(r\) to \(v\). Choose one shortest such path, and let \(p(v)\) be the vertex immediately preceding \(v\) on that path. Then \(\{p(v),v\}\in E(G)\). The \(n-1\) edges \(\{p(v),v\}\), one for each \(v\ne r\), are distinct, because each chosen edge is assigned to its endpoint \(v\ne r\). Hence \(G\) contains at least \(n-1\) edges, so
\[
m\ge n-1.
\]

Therefore
\[
m-\frac n2-\frac12\ge (n-1)-\frac n2-\frac12=\frac{n-3}{2}.
\]
Thus the expression under the square root is automatically nonnegative for every connected simple graph with \(n\ge 3\).

For \(n=1\), a simple graph has no loop, so \(m=0\), and
\[
m-\frac n2-\frac12=0-\frac12-\frac12=-1<0.
\]
Also, \(\lambda_2\) is not defined for a \(1\times 1\) adjacency matrix. For \(n=2\), connectedness forces the unique edge between the two vertices, so \(m=1\), and
\[
m-\frac n2-\frac12=1-1-\frac12=-\frac12<0.
\]
Thus the square-root expression is real automatically exactly in the connected simple graph cases covered by \(n\ge 3\); the cases \(n=1,2\) require separate clarification in any final proof of the theorem.

Now prove the trace identity. Since \(A\) is the adjacency matrix of a simple undirected graph, \(A\) is real symmetric. By the spectral theorem for real symmetric matrices, \(A\) is orthogonally diagonalizable: there is an orthogonal matrix \(Q\) and real eigenvalues \(\lambda_1,\dots,\lambda_n\) such that
\[
A=Q\operatorname{diag}(\lambda_1,\dots,\lambda_n)Q^T.
\]
Hence
\[
A^2=Q\operatorname{diag}(\lambda_1^2,\dots,\lambda_n^2)Q^T.
\]
Using invariance of trace under orthogonal similarity,
\[
\operatorname{tr}(A^2)=\sum_{i=1}^n \lambda_i^2.
\]

It remains to compute \(\operatorname{tr}(A^2)\) combinatorially. For each vertex \(i\),
\[
(A^2)_{ii}=\sum_{j=1}^n A_{ij}A_{ji}.
\]
Because \(G\) is undirected, \(A_{ij}=A_{ji}\), and because \(G\) is simple, \(A_{ij}\in\{0,1\}\). Thus
\[
A_{ij}A_{ji}=A_{ij}^2=A_{ij},
\]
so
\[
(A^2)_{ii}=\sum_{j=1}^n A_{ij}=\deg(i).
\]
Therefore
\[
\operatorname{tr}(A^2)=\sum_{i=1}^n (A^2)_{ii}
=\sum_{i=1}^n \deg(i).
\]
Each edge contributes \(1\) to the degree of each of its two endpoints, so
\[
\sum_{i=1}^n \deg(i)=2m.
\]
Consequently,
\[
\sum_{i=1}^n \lambda_i^2=\operatorname{tr}(A^2)=2m.
\]
