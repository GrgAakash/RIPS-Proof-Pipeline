2. Subproof or failure

Let \(G\) be a connected simple undirected graph with \(n\) vertices and \(m\) edges. Let the adjacency eigenvalues be ordered
\[
\lambda_1\ge \lambda_2\ge \cdots \ge \lambda_n.
\]

First consider the small orders.

If \(n=1\), then the adjacency matrix has only one eigenvalue, so \(\lambda_2(G)\) is not defined. Thus the theorem as literally stated is not meaningful for \(n=1\).

If \(n=2\), connectedness forces \(G=K_2\), so \(m=1\). The expression under the square root is
\[
m-\frac n2-\frac12=1-1-\frac12=-\frac12<0.
\]
Thus the right-hand side is not a real number. Hence the theorem as a real-valued inequality is not meaningful for \(n=2\).

Therefore the final assembly proves the theorem for the meaningful real-valued range \(n\ge 3\). For \(n\ge 3\), S1 gives
\[
m-\frac n2-\frac12\ge 0,
\]
so the square root is real.

Now split by the sign of \(\lambda_2\).

If \(\lambda_2\le 0\), then since \(\sqrt{m-\frac n2-\frac12}\ge 0\), we immediately have
\[
\lambda_2\le 0\le \sqrt{m-\frac n2-\frac12}.
\]
This is exactly the desired inequality.

It remains to handle \(\lambda_2>0\). By prerequisite S3,
\[
\lambda_2^2\le m-\frac{n+1}{2}.
\]
Since
\[
m-\frac{n+1}{2}=m-\frac n2-\frac12,
\]
this says
\[
\lambda_2^2\le m-\frac n2-\frac12.
\]
Both sides are nonnegative: the right-hand side is nonnegative by S1, and \(\lambda_2^2\ge 0\). Because \(\lambda_2>0\), taking square roots gives
\[
\lambda_2\le \sqrt{m-\frac n2-\frac12}.
\]

Thus, conditional on S1-S4, the desired inequality follows for every connected simple graph with \(n\ge 3\). The cases \(n=1,2\) are not valid real-valued instances of the theorem as stated.
