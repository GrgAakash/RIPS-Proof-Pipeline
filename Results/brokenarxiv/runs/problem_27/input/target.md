Problem 27:
Let $W$ be an irreducible Coxeter group. For each fixed integer $k \ge 0$, only finitely many isomorphism types of Bruhat intervals of length $k$ (where the length of an interval $[u,v]$ is defined as $\ell(v) - \ell(u)$ with $\ell$ being the length function on $W$) occur in $W$ if and only if $W$ is a finite Coxeter group.
