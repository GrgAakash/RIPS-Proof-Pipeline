In the infinite irreducible Coxeter group \(I_2(\infty)=\langle s,t\mid s^2=t^2=1\rangle\), for each fixed \(k\ge 0\), all Bruhat intervals of length \(k\) have the same finite-poset isomorphism type. Thus the “only if” direction of the target theorem is false.

Here is the obstruction. The group \(I_2(\infty)\) is irreducible because its Coxeter graph has two vertices connected by an \(\infty\)-edge, and it is infinite because \(st\) has infinite order. By standard Coxeter background for the infinite dihedral group, every nonidentity element has a unique alternating reduced expression, and there are exactly two elements of each positive Coxeter length.

[KEY STEP] By the subword criterion, if \(x,y\in I_2(\infty)\) and \(\ell(x)<\ell(y)\), then \(x\le y\) in Bruhat order, while if \(\ell(x)=\ell(y)\), then \(x\le y\) only when \(x=y\). Indeed, every reduced expression in \(I_2(\infty)\) is alternating in \(s,t\). Any alternating word of smaller positive length occurs as a subword of either alternating word of larger length, so the subword criterion gives \(x\le y\) whenever \(\ell(x)<\ell(y)\). Conversely, Bruhat order is graded by Coxeter length, so comparable elements of equal length are equal.

Therefore, for any interval \([u,v]\) with \(\ell(v)-\ell(u)=k\), the interval has one bottom element \(u\), one top element \(v\), and, for each intermediate rank \(1\le i\le k-1\), exactly two elements of length \(\ell(u)+i\). Every element of a lower intermediate rank is below every element of a higher intermediate rank, and distinct elements of the same rank are incomparable. Hence the poset structure of \([u,v]\) depends only on \(k\), not on \(u\) or \(v\). For \(k=0\), the interval is a singleton; for \(k\ge1\), it has this fixed rank-layered form.

Thus \(I_2(\infty)\) is an infinite irreducible Coxeter group satisfying the fixed-\(k\) finiteness property: for each \(k\), only one Bruhat-interval isomorphism type of length \(k\) occurs.
