2. Subproof or failure

Let \(R=k[u,v]/(uv)\). Write again \(u,v\) for the residue classes of the polynomial variables.

Define a map
\[
\Phi:k[u,v]\to k[u]\times k[v],\qquad F(u,v)\mapsto (F(u,0),F(0,v)).
\]
This is a ring homomorphism. Its kernel consists exactly of the polynomials all of whose monomials are divisible by \(uv\), hence \(\ker\Phi=(uv)\). Therefore \(\Phi\) induces an injective homomorphism
\[
\overline{\Phi}:R\hookrightarrow k[u]\times k[v].
\]
Its image is
\[
S=\{(f(u),g(v))\in k[u]\times k[v]\mid f(0)=g(0)\},
\]
because every pair with equal constant term is represented by \(f(u)+g(v)-f(0)\). Thus we identify \(R\) with \(S\).

Under this identification,
\[
u\mapsto (u,0),\qquad v\mapsto (0,v).
\]
Hence
\[
(u)=\{(u f(u),0): f(u)\in k[u]\},
\]
and
\[
(v)=\{(0,v g(v)): g(v)\in k[v]\}.
\]

First, every nonzero element of \((u)\cup(v)\) is a zero-divisor. Indeed, if \(0\ne a\in(u)\), then \(a=(u f(u),0)\) with \(u f(u)\ne0\), and
\[
a\cdot v=(u f(u),0)(0,v)=(0,0),
\]
while \(v=(0,v)\ne0\). Thus \(a\) is a zero-divisor. Similarly, if \(0\ne b\in(v)\), then \(b\cdot u=0\) with \(u\ne0\), so \(b\) is a zero-divisor.

Conversely, let \(x=(f(u),g(v))\in S\) be a zero-divisor. Then there exists \(0\ne y=(p(u),q(v))\in S\) such that
\[
xy=(f p,g q)=(0,0).
\]
Since \(k[u]\) and \(k[v]\) are integral domains, \(f p=0\) implies \(f=0\) or \(p=0\), and \(g q=0\) implies \(g=0\) or \(q=0\).

Suppose, for contradiction, that both \(f\ne0\) and \(g\ne0\). Then \(p=0\) and \(q=0\), so \(y=(0,0)\), contradicting \(y\ne0\). Therefore \(f=0\) or \(g=0\).

If \(g=0\), then the condition \(f(0)=g(0)\) gives \(f(0)=0\), so \(f(u)=u h(u)\) for some \(h(u)\in k[u]\). Hence
\[
x=(f(u),0)=(u h(u),0)\in(u).
\]
If \(f=0\), similarly \(g(0)=0\), so \(g(v)=v\ell(v)\), and
\[
x=(0,g(v))=(0,v\ell(v))\in(v).
\]
Thus every zero-divisor of \(R\) lies in \((u)\cup(v)\). Removing \(0\), the nonzero zero-divisors are exactly
\[
Z(R)^*=(u)^*\cup(v)^*.
\]
