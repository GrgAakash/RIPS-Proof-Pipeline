2. Subproof or failure

Let \(R=k[u,v]/(uv)\). Write again \(u,v\) for their residue classes in \(R\).

First note the following normal-form fact. Every element of \(R\) can be written uniquely in the form
\[
c+u f(u)+v g(v),
\]
where \(c\in k\), \(f(u)\in k[u]\), and \(g(v)\in k[v]\). Indeed, in the quotient by \((uv)\), every monomial involving both \(u\) and \(v\) vanishes, so every residue class has such a representative. Uniqueness follows because if
\[
c+u f(u)+v g(v)\in (uv)\subseteq k[u,v],
\]
then the left side contains no monomial divisible by both \(u\) and \(v\). Since every nonzero polynomial in \((uv)\) is a sum of monomials each divisible by both variables, all coefficients on the left must be zero.

Now let \(0\ne a\in (u)\). Since \(a\in (u)\), the normal form of \(a\) has no constant term and no \(v\)-part, so
\[
a=u p(u)
\]
for some nonzero \(p(u)\in k[u]\). Let
\[
r=c+u f(u)+v g(v)\in R.
\]
Then, using \(uv=0\),
\[
ra=(c+u f(u)+v g(v))u p(u)
= (c+u f(u))u p(u).
\]
Thus \(ra=0\) in \(R\) iff the polynomial
\[
(c+u f(u))u p(u)\in k[u]
\]
is zero. Since \(k[u]\) is an integral domain and \(u p(u)\ne 0\), this is equivalent to
\[
c+u f(u)=0.
\]
Therefore \(r\in \operatorname{ann}_R(a)\) iff \(r=v g(v)\), i.e. iff \(r\in (v)\). Hence
\[
\operatorname{ann}_R(a)=(v).
\]

The argument for \((v)\) is symmetric. If \(0\ne b\in (v)\), then
\[
b=v q(v)
\]
for some nonzero \(q(v)\in k[v]\). For
\[
r=c+u f(u)+v g(v),
\]
we have
\[
rb=(c+u f(u)+v g(v))v q(v)
= (c+v g(v))v q(v).
\]
Since \(k[v]\) is an integral domain and \(v q(v)\ne 0\), this product is zero in \(R\) iff
\[
c+v g(v)=0.
\]
Thus \(r\in \operatorname{ann}_R(b)\) iff \(r=u f(u)\), i.e. iff \(r\in (u)\). Therefore
\[
\operatorname{ann}_R(b)=(u).
\]

So the assigned subclaim is proved.
