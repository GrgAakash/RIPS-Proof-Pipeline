## 1 Assignment Restatement

Subclaim E: prove a precise W*-bundle approximate-intertwining lemma. Given two W*-bundles over a compact Hausdorff space `U`, coherent finite-stage approximately multiplicative, trace-preserving, `C(U)`-linear maps with uniform `2`-norm inverse errors on dense finite stages extend to genuine mutually inverse W*-bundle morphisms.

## 2 Subproof

Let `A` and `B` be W*-bundles over compact Hausdorff `U`, with traces `τ_A:A→C(U)` and `τ_B:B→C(U)`. Write

```text
||a||_{2,u} = ||τ_A(a*a)||^{1/2},     ||b||_{2,u} = ||τ_B(b*b)||^{1/2}.
```

Assume:

1. `A` and `B` have unit balls complete for `||·||_{2,u}`.
2. There are increasing finite sets `F_n⊂A_1`, `G_n⊂B_1` whose union is `||·||_{2,u}`-dense in the respective unit balls.
3. There are unital contractive maps
   `φ_n:A→B`, `ψ_n:B→A`
   which are `C(U)`-linear, `*`-preserving, and trace-preserving.
4. For every `n`, the maps are `2^{-n}`-multiplicative on the relevant finite sets:

```text
||φ_n(xy)-φ_n(x)φ_n(y)||_{2,u} < 2^{-n}   for x,y∈F_n,
||ψ_n(uv)-ψ_n(u)ψ_n(v)||_{2,u} < 2^{-n}   for u,v∈G_n.
```

5. Coherence/inverse control holds on dense stages:

```text
||ψ_n(φ_n(x))-x||_{2,u} < 2^{-n}   for x∈F_n,
||φ_n(ψ_n(u))-u||_{2,u} < 2^{-n}   for u∈G_n,
```

and, after passing to a subsequence if necessary, the pointwise sequences are Cauchy on dense stages:

```text
(φ_n(x))_n is ||·||_{2,u}-Cauchy for each x∈⋃F_n,
(ψ_n(u))_n is ||·||_{2,u}-Cauchy for each u∈⋃G_n.
```

Then there are mutually inverse W*-bundle morphisms

```text
φ:A→B,     ψ:B→A.
```

### Construction of the Limit Maps

For `x∈⋃F_n`, define

```text
φ(x) = lim_n φ_n(x)
```

in `||·||_{2,u}`. This limit exists because `(φ_n(x))` is Cauchy and the unit ball of `B` is complete. Similarly, for `u∈⋃G_n`, define

```text
ψ(u) = lim_n ψ_n(u).
```

Because each `φ_n` is contractive for the operator norm and trace-preserving, it is contractive for the uniform `2`-norm:

```text
||φ_n(a)-φ_n(a')||_{2,u} ≤ ||a-a'||_{2,u}
```

on the finite-stage domain where the maps are linear and trace-preserving. Hence `φ` is uniformly `2`-norm contractive on `⋃F_n`. Since `⋃F_n` is `2`-norm dense in `A_1`, `φ` extends uniquely to a `2`-norm contractive map `A_1→B_1`. By homogeneity, it extends to all of `A`. The same argument gives `ψ:B→A`.

Thus both limit maps are `2`-norm continuous and contractive.

### Linearity, Unit, Star, Trace, and `C(U)`-Linearity

Each property passes to the limit because it is expressed by a `2`-norm closed condition.

For example, if `x,y∈⋃F_n` and `λ∈C`, then

```text
φ(x+λy)
= lim_n φ_n(x+λy)
= lim_n (φ_n(x)+λφ_n(y))
= φ(x)+λφ(y).
```

By density and continuity, this holds for all `x,y∈A`.

Similarly,

```text
φ(x*) = lim_n φ_n(x*) = lim_n φ_n(x)* = φ(x)*.
```

Since every `φ_n` is unital,

```text
φ(1_A)=1_B.
```

Trace preservation passes to the limit because `τ_B` is `2`-norm continuous:

```text
τ_B(φ(x))
= lim_n τ_B(φ_n(x))
= lim_n τ_A(x)
= τ_A(x).
```

For `f∈C(U)`,

```text
φ(fx)
= lim_n φ_n(fx)
= lim_n fφ_n(x)
= fφ(x),
```

so `φ` is `C(U)`-linear. The same proof applies to `ψ`.

### Multiplication

Let `x,y∈⋃F_n`. For all sufficiently large `n`, `x,y,xy∈F_n`. Hence

```text
||φ_n(xy)-φ_n(x)φ_n(y)||_{2,u} < 2^{-n}.
```

Taking limits in `||·||_{2,u}` gives

```text
φ(xy)=φ(x)φ(y).
```

To justify the product limit, use operator-norm contractivity: the elements remain uniformly bounded by `1`, and multiplication is jointly continuous on bounded sets for the uniform `2`-norm:

```text
||bc-b'c'||_{2,u}
≤ ||(b-b')c||_{2,u}+||b'(c-c')||_{2,u}
≤ ||c||·||b-b'||_{2,u}+||b'||·||c-c'||_{2,u}.
```

By density and `2`-norm continuity on bounded sets, multiplicativity extends to all of `A`. Thus `φ` is a unital `*`-homomorphism. Likewise, `ψ` is a unital `*`-homomorphism.

### Inverse Property

Let `x∈⋃F_n`. For all sufficiently large `n`, `x∈F_n`, so

```text
||ψ_n(φ_n(x))-x||_{2,u}<2^{-n}.
```

Using convergence of `φ_n(x)→φ(x)`, `ψ_n` being contractive, and `ψ_n(u)→ψ(u)` on dense-stage elements, we obtain

```text
ψ(φ(x)) = x.
```

Indeed,

```text
||ψ(φ(x))-x||_{2,u}
≤ ||ψ(φ(x))-ψ_n(φ(x))||_{2,u}
 + ||ψ_n(φ(x))-ψ_n(φ_n(x))||_{2,u}
 + ||ψ_n(φ_n(x))-x||_{2,u},
```

and each term tends to `0`. The first term is controlled first on dense approximants to `φ(x)` in `⋃G_n`, then by contractivity.

Hence `ψ∘φ=id_A` on the dense set `⋃F_n`, and therefore on all of `A` by continuity. Similarly,

```text
φ∘ψ=id_B.
```

Thus `φ` and `ψ` are mutually inverse unital `C(U)`-linear trace-preserving `*`-homomorphisms. They are W*-bundle morphisms.

This proves the approximate-intertwining lemma.
