Problem 33:
Let $d \ge 2$ be an integer, $k \in \{1, \dots, d\}$, and $1 < p < \infty$. Consider the discrete Riesz Transform $R_{\text{dis}}^{(k)}$ on $\ell^p(\mathbb{Z}^d)$ defined by convolution with the kernel $K_k(m) = c_d m_k / |m|^{d+1}$ for $m \in \mathbb{Z}^d \setminus \{0\}$ and $K_k(0)=0$, where $c_d = \Gamma(\frac{d+1}{2}) / \pi^{(d+1)/2}$. There exists a constant $C_p > 0$ depending only on $p$ such that for all dimensions $d \ge 2$, the operator norm is bounded independently of the dimension, satisfying $\|R_{\text{dis}}^{(k)}\|_{\ell^p(\mathbb{Z}^d) \to \ell^p(\mathbb{Z}^d)} \le C_p$.
