**1 Assignment Restatement**

S1 must prove SC1 and SC2 for finitely supported `f` on `Z^d`:

- SC1: For each `n in Z^d`, the full convolution defining `R_dis^(k) f(n)` is pointwise well-defined.
- SC2: The truncated sums
  `T_R f(n) = sum_{0<|m|<=R} c_d m_k / |m|^{d+1} f(n-m)`
  converge pointwise to the full convolution as `R -> infinity`.

**2 Subproof Or Failure**

Let `f` be finitely supported, and write `F = supp(f)`, so `F` is a finite subset of `Z^d`.

For fixed `n in Z^d`, the convolution sum is

```text
R_dis^(k) f(n) = sum_{m in Z^d} K_k(m) f(n-m).
```

The term `f(n-m)` can be nonzero only when `n-m in F`, equivalently when `m in n-F := {n-a : a in F}`. Since `F` is finite, `n-F` is finite. Therefore only finitely many terms in the convolution sum can be nonzero. Also `K_k(0)=0` is explicitly defined, so there is no singular undefined term. Hence the convolution sum is finite at each lattice point `n`, proving SC1.

For SC2, fix `n`. Define

```text
M_n = {m in Z^d : m != 0 and f(n-m) != 0}.
```

As above, `M_n` is finite. If `M_n` is empty, then both the full convolution and every truncated sum are zero at `n`.

Otherwise, let

```text
R_n = max{|m| : m in M_n}.
```

Then for every `R >= R_n`, the truncated sum includes every nonzero term that can contribute to the full convolution at `n`. Therefore

```text
T_R f(n)
= sum_{0<|m|<=R} K_k(m) f(n-m)
= sum_{m in Z^d} K_k(m) f(n-m)
= R_dis^(k) f(n).
```

Thus `T_R f(n)` is eventually equal to the full convolution value, and hence `T_R f(n) -> R_dis^(k) f(n)` pointwise as `R -> infinity`. This proves SC2.
