\[

\]

For finitely supported `f`, SC1 and SC2 give pointwise convergence

\[
T_R f(n)\to R_{\mathrm{dis}}^{(k)}f(n).
\]

SC3 gives

\[
\|T_R f\|_{\ell^p(\mathbb Z^d)}\le C_p\|f\|_{\ell^p(\mathbb Z^d)}
\]

with `C_p` independent of `d,k,R`. Then Fatou yields

\[
\|R_{\mathrm{dis}}^{(k)} f\|_p^p
\le \liminf_{R\to\infty}\|T_R f\|_p^p
\le C_p^p\|f\|_p^p.
\]

Thus

\[
\|R_{\mathrm{dis}}^{(k)} f\|_p\le C_p\|f\|_p
\]

on finitely supported functions. Since finitely supported functions are dense in \(\ell^p(\mathbb Z^d)\) for \(1<p<\infty\), the operator extends uniquely and linearly to all of \(\ell^p\) with the same norm bound.

Linearity is preserved: each `T_R` is a finite convolution operator, the pointwise finite-support limit is linear, and the bounded extension is linear.

The constant remains dimension-free if and only if SC3 is genuinely dimension-free and uses the exact stated `c_d`. No additional dependence on `d`, `k`, or `R` is introduced by Fatou or density.

The only fatal proof obstruction is SC3. If SC3 is missing, circular, or proved by invoking a theorem equivalent to the target dimension-free discrete Riesz bound, then the final proof fails.
