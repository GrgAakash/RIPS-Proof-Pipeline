**2 Subproof Or Failure**

Let `c_00(Z^d)` denote the finitely supported functions. For `1 < p < infinity`, `c_00(Z^d)` is dense in `ell^p(Z^d)`: for any `f in ell^p`, define

`f_N = f * 1_{[-N,N]^d cap Z^d}`.

Then `f_N in c_00(Z^d)` and

`||f - f_N||_p^p = sum_{n notin [-N,N]^d} |f(n)|^p -> 0`

because `sum_n |f(n)|^p < infinity`.

Assume SC4 has established that for finitely supported `g`,

`||R_dis^(k) g||_p <= C_p ||g||_p`

with `C_p` independent of `d` and `k`.

Then `R_dis^(k): c_00(Z^d) -> ell^p(Z^d)` is linear and bounded with respect to the inherited `ell^p` norm. Therefore it extends uniquely to a bounded linear operator

`overline{R_dis^(k)}: ell^p(Z^d) -> ell^p(Z^d)`

as follows: for `f in ell^p`, choose any sequence `f_j in c_00(Z^d)` with `f_j -> f` in `ell^p`, and define

`overline{R_dis^(k)} f = lim_j R_dis^(k) f_j`

in `ell^p`.

This limit exists because

`||R_dis^(k) f_j - R_dis^(k) f_i||_p <= C_p ||f_j - f_i||_p`,

so `{R_dis^(k) f_j}` is Cauchy in `ell^p`. The definition is independent of the approximating sequence: if `g_j -> f`, then

`||R_dis^(k) f_j - R_dis^(k) g_j||_p <= C_p ||f_j - g_j||_p -> 0`.

The extension satisfies

`||overline{R_dis^(k)} f||_p <= C_p ||f||_p`

by passing to the limit from

`||R_dis^(k) f_j||_p <= C_p ||f_j||_p`.

Thus the operator norm on all of `ell^p(Z^d)` is at most `C_p`, with the same dimension-free constant.
