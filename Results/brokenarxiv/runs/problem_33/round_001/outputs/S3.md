## Assignment restatement

Construct the local discretization approximation: start with finitely supported \(f:\mathbb Z^d\to\mathbb C\), embed it into step functions on \(\mathbb R^d\), apply continuous truncated Riesz kernels, average over unit cubes, and prove convergence to a discrete truncated convolution operator.

## Subproof or failure

Let
\[
K(x)=c_d\frac{x_k}{|x|^{d+1}},\qquad x\neq 0,
\]
and let \(Q=[-1/2,1/2)^d\). For \(R>0\), define the discrete radial truncation
\[
D_R f(m)=\sum_{0<|h|\le R}K(h)f(m-h).
\]

Choose \(\delta_R>0\) so that no lattice length \(|h|\), \(h\in\mathbb Z^d\), lies in \((R,R+2\delta_R]\). This is possible because only finitely many lattice points have \(|h|\le R+1\).

For \(N\ge 1\), embed \(f\) by
\[
F_N(x)=\sum_{n\in\mathbb Z^d} f(n)\mathbf 1_{Nn+Q}(x).
\]
For fixed \(0<\varepsilon<1\), define the continuous doubly truncated transform
\[
T_{\varepsilon,\Lambda}G(x)=\int_{\varepsilon<|x-y|\le \Lambda}K(x-y)G(y)\,dy,
\]
and set \(\Lambda_N=N(R+\delta_R)\). Now define the averaged lattice expression
\[
A_{N,R}f(m)
=
N^d\int_Q T_{\varepsilon,\Lambda_N}F_N(Nm+u)\,du.
\]

Expanding over cubes gives
\[
A_{N,R}f(m)=\sum_{n} f(n)a_{N,R}(m-n),
\]
where
\[
a_{N,R}(h)
=
N^d\int_Q\int_Q
K(Nh+u-v)
\mathbf 1_{\{\varepsilon<|Nh+u-v|\le N(R+\delta_R)\}}
\,dv\,du.
\]

If \(h=0\), then \(a_{N,R}(0)=0\): the domain in \((u,v)\) is symmetric under swapping \(u\) and \(v\), while \(K(u-v)=-K(v-u)\).

If \(h\neq 0\), then for all large \(N\), the lower truncation is inactive. Also,
\[
N^dK(Nh+u-v)=K\left(h+\frac{u-v}{N}\right)
\]
by homogeneity of \(K\). Hence, uniformly for \(u,v\in Q\),
\[
N^dK(Nh+u-v)\to K(h).
\]

The upper cutoff stabilizes as follows. If \(|h|\le R\), then for large \(N\),
\[
|h+(u-v)/N|\le R+\delta_R,
\]
so the term is included. If \(|h|>R\), the choice of \(\delta_R\) gives \(|h|\ge R+2\delta_R\), hence for large \(N\),
\[
|h+(u-v)/N|>R+\delta_R,
\]
so the term is excluded. Therefore
\[
a_{N,R}(h)\to \mathbf 1_{\{0<|h|\le R\}}K(h).
\]

Since \(f\) is finitely supported, the sum over \(n\) is finite for each \(m\), so
\[
A_{N,R}f(m)\to D_Rf(m)
\]
pointwise. Moreover, for large \(N\), \(A_{N,R}f\) is supported in a fixed finite enlargement of \(\operatorname{supp}f\), so the convergence also holds in every \(\ell^p(\mathbb Z^d)\), \(1\le p<\infty\).
