Assignment restatement

Show that once a family of truncated discrete Riesz transforms has dimension-free `ell^p` bounds, the full operator follows: first for finitely supported functions by passing the truncation parameter to infinity, then for all of `ell^p(Z^d)` by density. Track that the final constant depends only on `p`.

Subproof or failure

Let

```text
T_N f(n) = sum_{0 < |m| <= N} K_k(m) f(n - m)
```

and assume the preceding truncation step has proved

```text
||T_N f||_{ell^p(Z^d)} <= C_p ||f||_{ell^p(Z^d)}
```

for every `N`, every `d >= 2`, every `k in {1,...,d}`, and every finitely supported `f`, with `C_p` depending only on `p`.

For finitely supported `f`, define the full discrete operator by

```text
R_dis^(k) f(n) = sum_{m in Z^d \ {0}} K_k(m) f(n - m).
```

For each fixed `n`, this sum is finite because `f` has finite support. Also `T_N f(n) -> R_dis^(k) f(n)` pointwise as `N -> infinity`.

By Fatou’s lemma for counting measure,

```text
||R_dis^(k) f||_p^p
= sum_n |lim_N T_N f(n)|^p
<= liminf_N sum_n |T_N f(n)|^p
<= C_p^p ||f||_p^p.
```

Hence

```text
||R_dis^(k) f||_p <= C_p ||f||_p
```

for every finitely supported `f`, uniformly in `d` and `k`.

Now finitely supported functions are dense in `ell^p(Z^d)` for `1 < p < infinity`. Given arbitrary `f in ell^p(Z^d)`, choose finitely supported `f_j -> f` in `ell^p`. The estimate above gives

```text
||R_dis^(k)(f_j - f_i)||_p <= C_p ||f_j - f_i||_p,
```

so `{R_dis^(k) f_j}` is Cauchy in `ell^p`. Define

```text
R_dis^(k) f := lim_j R_dis^(k) f_j.
```

This definition is independent of the approximating sequence: if `g_j -> f` also, then

```text
||R_dis^(k) f_j - R_dis^(k) g_j||_p
<= C_p ||f_j - g_j||_p -> 0.
```

Finally, passing to the limit in

```text
||R_dis^(k) f_j||_p <= C_p ||f_j||_p
```

gives

```text
||R_dis^(k) f||_p <= C_p ||f||_p.
```

Thus the full operator extends uniquely to a bounded linear operator on `ell^p(Z^d)` with operator norm at most `C_p`. Since the only constant used is the uniform truncation constant, the final bound depends only on `p`, not on `d` or `k`.
