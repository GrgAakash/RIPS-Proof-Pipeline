**Assignment restatement**

Prepare the continuous comparison input needed later: for each `d >= 2` and `k in {1, ..., d}`, define the continuous Riesz transform on `L^p(R^d)` by the principal-value convolution kernel

```text
K_k^cont(x) = c_d x_k / |x|^{d+1},    x != 0,
c_d = Gamma((d+1)/2) / pi^((d+1)/2).
```

State that this operator has an `L^p(R^d)` norm bounded by a constant depending only on `p`, not on `d` or `k`.

**Subproof or failure**

We take as standard background the dimension-free continuous Riesz transform theorem:

For every `1 < p < infinity`, there exists `A_p < infinity`, depending only on `p`, such that for every integer `d >= 2`, every `k in {1, ..., d}`, and every `f in L^p(R^d)`,

```text
|| R_k^cont f ||_{L^p(R^d)} <= A_p || f ||_{L^p(R^d)}.
```

Here

```text
R_k^cont f(x) = p.v. integral_{R^d} c_d (x_k - y_k) / |x-y|^{d+1} f(y) dy.
```

Equivalently, this is principal-value convolution with `K_k^cont(x) = c_d x_k / |x|^{d+1}`.
