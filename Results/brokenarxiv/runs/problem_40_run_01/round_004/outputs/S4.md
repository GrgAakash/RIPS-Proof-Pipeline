`|Gamma(X)| >= |X|`

Thus each `A in B` can be assigned a distinct matched missing star certificate `phi(A) in M`. Therefore `phi : B -> M` is injective, and hence

`|B| <= |M|`.

This is exactly the needed E-step.

## 4. Proof of F: Final Count

`binom(n-1,k-1) = binom(n-1,d)`.

Since `M` is precisely the set of missing star members,

`|S| = binom(n-1,d) - |M|`.

Also `N = B disjoint union E`, so

`|F| = |S| + |N|`
`= binom(n-1,d) - |M| + |B| + |E|`.

Using the injection from E,

`-|M| + |B| <= 0`.

`|F| <= binom(n-1,d) + binom(n-4,d-2)`.
