**1. Assigned Claims**

Let `k=d+1`, and let `F subset binom([n],k)` be shifted with `VCdim(F) <= d`. Assume `n >= 2k`, so all canonical certificates below exist.

For `A in binom([n],k)` and `T subset A`, define `C(A,T)` to be the lexicographically first `k`-set satisfying  
`C(A,T) cap A = T`.

Claims proved here:

1. `T` is realized in the trace of `F` on `A` iff `C(A,T) in F`.
2. Every bad non-star member `A in B = N \ E` has some proper `T subsetneq A` with `C(A,T) in M`, i.e. a missing canonical star certificate.

**2. Certificate Form**

Write `r = k - |T|`. Let `L_A(r)` be the set of the `r` smallest elements of `[n]\A`. Then

```text
C(A,T) = T union L_A(r).
```

This is the lexicographically first feasible `k`-set with intersection exactly `T` with `A`.

Moreover, if `1 notin A` and `T subsetneq A`, then `r >= 1`, so `1 in L_A(r)`, hence `1 in C(A,T)`. Thus every proper canonical certificate for a non-star `A` is a star set.

**3. Proof Of B: Trace-Certificate Lemma**

Use the standard componentwise order on `k`-sets: if  
`X={x_1<...<x_k}` and `Y={y_1<...<y_k}`, then `X <=_s Y` iff `x_i <= y_i` for all `i`. Since `F` is shifted, `Y in F` and `X <=_s Y` imply `X in F`.

Let `D` be any `k`-set with `D cap A = T`. Then `D = T union Y`, where `Y subset [n]\A` and `|Y|=r`. Since `L_A(r)` consists of the first `r` elements of `[n]\A`, for every initial segment `[m]`,

```text
|L_A(r) cap [m]| >= |Y cap [m]|.
```

Adding the same contribution from `T` gives

```text
|C(A,T) cap [m]| >= |D cap [m]|   for every m.
```

For equal-size sets, this initial-segment dominance is equivalent to `C(A,T) <=_s D`. Therefore the canonical certificate is shifted-below every realization of the same trace.

Now:

- If `C(A,T) in F`, then `C(A,T) cap A = T`, so `T` is realized on `A`.
- Conversely, if `T` is realized on `A`, choose `D in F` with `D cap A = T`. Since `C(A,T) <=_s D` and `F` is shifted, `C(A,T) in F`.

Thus

```text
T in F|_A  iff  C(A,T) in F.
```

**4. Proof Of C: Missing Star Certificate**

Let `A in B`. Then `A in F`, `1 notin A`, and `|A|=k=d+1`.

Suppose, for contradiction, that no proper canonical star certificate of `A` is missing. Then for every `T subsetneq A`, we have `C(A,T) in F`. By the trace-certificate lemma, every proper `T subsetneq A` is realized in the trace on `A`.

The remaining trace `A` itself is realized by `A in F`, since `A cap A = A`.

Therefore every subset of `A` is realized, so `A` is shattered. But `|A|=d+1`, contradicting `VCdim(F) <= d`.

Hence there exists some `T subsetneq A` such that `C(A,T) notin F`. Since `1 notin A` and `T` is proper, `1 in C(A,T)`. Therefore

```text
C(A,T) in M = {star k-sets not in F}.
```

So every bad `A in B` has a missing canonical star certificate.
