1. Target decomposition

target_label:
Target theorem

target_type:
Extremal upper bound for uniform finite set systems with fixed VC-dimension.

main_goal:
For fixed integer `d >= 3`, prove that for all sufficiently large `n`, every `(d+1)`-uniform family `F subseteq binom([n], d+1)` with `VCdim(F)=d` satisfies the stated size bound.

variables_and_parameters:
`d >= 3`; `n >= N(d)` sufficiently large; `[n]={1,...,n}`; `k=d+1`; `F subseteq binom([n], k)`.

conclusion_to_prove:
`|F| <= binom(n-1,d)+binom(n-4,d-2)`.

2. Available tools

tool:
VC-dimension/shattering definitions

source_status:
provided definition / notation / assumption

exact_statement_or_fact:
`VCdim(F)=d` means some `d`-set is shattered and no set of size `d+1` is shattered.

intended_role_in_proof:
Only the non-shattering of `(d+1)`-sets is needed for the upper bound.

tool:
Binomial counting of fixed-core uniform families

source_status:
standard background fact

exact_statement_or_fact:
The number of `(d+1)`-sets containing `1` is `binom(n-1,d)`. The number of `(d+1)`-sets not containing `1` but containing `{2,3,4}` is `binom(n-4,d-2)`.

intended_role_in_proof:
Provides the two terms in the final bound.

tool:
Tailored shifted reduction

source_status:
proved inside the current proof

exact_statement_or_fact:
If a counterexample exists for fixed `d` and arbitrarily large `n`, then there is a shifted `(d+1)`-uniform counterexample of the same size and still with no shattered `(d+1)`-set. This must be proved directly for this theorem, not quoted as an ordinary compression reduction.

intended_role_in_proof:
Allows the main counting argument to be carried out for shifted families.

tool:
Shifted charging lemma

source_status:
proved inside the current proof

exact_statement_or_fact:
For shifted `F subseteq binom([n],d+1)` with no shattered `(d+1)`-set, there is an injection
`Phi: {A in F : 1 notin A and {2,3,4} not subseteq A} -> {B in binom([n],d+1) : 1 in B and B notin F}`.

intended_role_in_proof:
Charges every non-star member outside the `{2,3,4}` container to a missing star member.

4. Hardest step prediction

hardest_step_id:
C3

hardest_step_description:
Constructing the canonical charge map from forbidden non-star sets to missing star sets and proving injectivity.

risk_if_wrong:
If the charge map is not injective, the proof only gives a weak covering argument and cannot recover the exact second term `binom(n-4,d-2)`.

how_final_proof_should_handle_it:
Define the charge explicitly, likely by a case split according to `A cap {2,3,4}`. For each case, verify two facts separately: the charged star set is absent, and the charged star set determines `A` uniquely.

5. Failure-mode checks

standard_background_check:

6. Subproblem assignment table

S1:
Prove the tailored shifted reduction for this theorem: elementary shifts preserve `(d+1)`-uniformity, size, and absence of shattered `(d+1)`-sets, giving a shifted counterexample if any counterexample exists.

S2:
For shifted `F`, prove the missing-star certificate lemma for each non-star `A in F` with `{2,3,4} not subseteq A`.

S3:
Define the canonical certificate map `Phi` from S2 and prove it is injective.

S4:
Use the injection to prove `|F| <= |S|+|H|` for shifted families.

S5:
Compute `|S|` and `|H|`, substitute `k=d+1`, and close the contradiction for all sufficiently large `n`.
