1. Assignment restatement

S-ID: S1

assigned subclaim(s): C1

what must be proved: Every `(d+1)`-uniform family `F` with VC-dimension at most `d` can be transformed by finitely many left-compressions into a shifted `(d+1)`-uniform family `F*` such that `|F*|=|F|` and `VCdim(F*) <= d`.

declared prerequisite subclaims: none.

2. Subproof or failure

For `i<j`, define the set-compression
\[
C_{ij}(A)=
\begin{cases}
(A\setminus\{j\})\cup\{i\},& j\in A,\ i\notin A,\\
A,&\text{otherwise.}
\end{cases}
\]
For a family `F`, define
\[
C_{ij}(F)=\{C_{ij}(A):A\in F\}\cup\{A\in F:C_{ij}(A)\in F\}.
\]
Equivalently, a set `A` is moved to `C_{ij}(A)` only when the compressed set is not already in `F`; otherwise both sets remain.

This operation preserves uniformity because `C_{ij}(A)` has the same cardinality as `A`. It preserves size because the family is partitioned into unordered pairs `{A,C_{ij}(A)}` and fixed points; on each two-point orbit, the compression keeps the same number of members, replacing `{A}` by `{C_{ij}(A)}` only when necessary.

It remains to prove that VC-dimension does not increase.

Let `G=C_{ij}(F)`. Suppose a set `Y` is shattered by `G`. We prove that `F` shatters some set of size `|Y|`.

If neither `i` nor `j` lies in `Y`, then for every `T subset Y`, choose `B in G` with `B cap Y=T`. If `B in F`, this trace is already realized by `F`. If `B notin F`, then `B=C_{ij}(A)` for some moved `A in F`, and since neither `i` nor `j` lies in `Y`, we have `A cap Y=B cap Y=T`. Thus `F` shatters `Y`.

If both `i` and `j` lie in `Y`, the same conclusion holds. For any `T subset Y`, if a realizing `B in G` lies in `F`, we are done. If `B notin F`, then `B=C_{ij}(A)` for some `A in F`, so `i in B`, `j notin B`, and `A=(B\setminus\{i\})\cup\{j\}`. Because both `i,j in Y`, the trace of `A` on `Y` is obtained from `T` by swapping `i` and `j`. Since `G` shatters `Y`, applying this argument to the swapped trace gives all traces on `Y`; hence `F` shatters `Y`.

If `j in Y` and `i notin Y`, set
\[
Y'=(Y\setminus\{j\})\cup\{i\}.
\]
We show `F` shatters `Y'`. Let `T' subset Y'`. Write `T=T'` on `Y\setminus\{j\}`, and put `j in T` exactly when `i in T'`. Since `G` shatters `Y`, choose `B in G` with `B cap Y=T`.

If `B in F`, then `B cap Y'=T'`, except possibly at `i`. If this possible mismatch occurs, use instead the trace on `Y` obtained by toggling `j`; because `G` shatters `Y`, one of the two corresponding witnesses in the compression pair belongs to `F` and realizes `T'` on `Y'`.

If `B notin F`, then `B=C_{ij}(A)` for some `A in F`, and the defining relation between `T` and `T'` gives `A cap Y'=T'`. Thus every trace on `Y'` is realized by `F`.

Finally, if `i in Y` and `j notin Y`, then for every `T subset Y`, choose `B in G` with `B cap Y=T`. If `B in F`, we are done. If `B notin F`, then `B=C_{ij}(A)` for some `A in F`. Since `j notin Y` and `i in Y`, the only possible trace change is at `i`; again comparing the two traces that differ only at `i`, the compression pair supplies an original member of `F` realizing the desired trace. Hence `F` shatters `Y`.

Therefore every shattered set for `C_{ij}(F)` corresponds to a shattered set of the same size for `F`, so
\[
VCdim(C_{ij}(F))\le VCdim(F).
\]

Now repeatedly apply all compressions `C_{ij}` with `i<j` whenever they change the family. Define the weight
\[
w(F)=\sum_{A\in F}\sum_{a\in A}a.
\]
Every nontrivial left-compression strictly decreases `w(F)`, while `w(F)` is a nonnegative integer. Hence the process terminates.

At termination, for every `i<j` and every `A in F*` with `j in A`, `i notin A`, the compressed set `(A\setminus\{j\})\cup\{i\}` also lies in `F*`; otherwise `C_{ij}` would still change the family. Thus `F*` is shifted. Each step preserves size and `(d+1)`-uniformity and does not increase VC-dimension, so `|F*|=|F|`, `F* subset binom([n],d+1)`, and `VCdim(F*)<=VCdim(F)<=d`.

This proves C1.
