2. Subproof or failure

Fix \(d\ge 3\). Let \(N_4(d)\) be a threshold for which C4 holds for this \(d\), and set
\[
N(d):=\max\{N_4(d),d+1\}.
\]
Let \(n\ge N(d)\), and let \(\mathcal F\subseteq \binom{[n]}{d+1}\) have VC-dimension \(d\). In particular, \(\operatorname{VCdim}(\mathcal F)\le d\).

By C1, there is a shifted \((d+1)\)-uniform family \(\mathcal F^\ast\subseteq \binom{[n]}{d+1}\) such that
\[
|\mathcal F^\ast|=|\mathcal F|
\quad\text{and}\quad
\operatorname{VCdim}(\mathcal F^\ast)\le d.
\]

For \(\mathcal F^\ast\), define
\[
H:=\{A\in \mathcal F^\ast:1\notin A\},
\]
and
\[
Q:=\{B\in \binom{[2,n]}{d}:\{1\}\cup B\notin \mathcal F^\ast\}.
\]
Also define
\[
E:=\{A\in H:\{2,3,4\}\subseteq A\}.
\]

By C3, the required local obstruction is available for every \(A\in H\). Since \(n\ge N_4(d)\), C4 applies to \(\mathcal F^\ast\), so there is an injection
\[
H\setminus E\hookrightarrow Q.
\]
Hence
\[
|H\setminus E|\le |Q|.
\]
Since \(E\subseteq H\), we have the disjoint decomposition
\[
H=(H\setminus E)\sqcup E.
\]
Therefore, using C5,
\[
|H|=|H\setminus E|+|E|
\le |Q|+\binom{n-4}{d-2}.
\]

Now C2 gives
\[
|\mathcal F^\ast|
=
\binom{n-1}{d}-|Q|+|H|.
\]
Substituting the preceding bound on \(|H|\),
\[
|\mathcal F^\ast|
\le
\binom{n-1}{d}-|Q|
+
|Q|
+
\binom{n-4}{d-2}
=
\binom{n-1}{d}+\binom{n-4}{d-2}.
\]
Finally, \(|\mathcal F|=|\mathcal F^\ast|\) by C1, so
\[
|\mathcal F|
\le
\binom{n-1}{d}+\binom{n-4}{d-2}.
\]
This proves the target theorem conditional on C1-C5.
