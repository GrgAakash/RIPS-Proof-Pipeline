1. Target decomposition

target_label:
Main theorem.

target_type:
Extremal upper bound for uniform set systems with prescribed VC-dimension.

main_goal:
For fixed `d >= 3`, prove that there is `N(d)` such that for every `n >= N(d)` and every `(d+1)`-uniform family `F subset binom([n], d+1)` with VC-dimension `d`, the claimed size bound holds.

variables_and_parameters:
`d >= 3`; `n` sufficiently large depending on `d`; `k = d+1`; ground set `[n] = {1,...,n}`; family `F subset binom([n], k)`.

conclusion_to_prove:
`|F| <= binom(n-1,d) + binom(n-4,d-2)`.

2. Available tools

tool:
Definition of VC-dimension and shattering.

source_status:
provided definition / notation / assumption.

exact_statement_or_fact:
A set `X` is shattered by `F` if every subset of `X` occurs as `Fcap X` for some `F in F`; VC-dimension `d` implies no set of size `d+1` is shattered.

intended_role_in_proof:
The proof only needs the no-shattered-`(d+1)`-set consequence.

tool:
Shifted family notation.

source_status:
provided definition / notation / assumption.

exact_statement_or_fact:
A `(d+1)`-uniform family is shifted if whenever `A in F`, `i < j`, `j in A`, `i notin A`, then `(A \ {j}) union {i} in F`.

intended_role_in_proof:
Used after proving a tailored shifted reduction inside the proof.

tool:
Tailored shifted reduction.

source_status:
proved inside the current proof.

exact_statement_or_fact:
If a counterexample exists, then there is a shifted counterexample of the same size and still with no shattered `(d+1)`-set. This must be proved directly by a minimal-weight or elementary-shift argument, not cited as an ordinary compression theorem.

intended_role_in_proof:
Allows the counting argument to assume shiftedness.

tool:
Star / exceptional / bad partition.

source_status:
proved inside the current proof.

exact_statement_or_fact:
For shifted `F`, partition
`S = {A in F : 1 in A}`,
`E = {A in F : 1 notin A, {2,3,4} subset A}`,
`B = F \ (S union E)`.
Then `|S| <= binom(n-1,d)` and `|E| <= binom(n-4,d-2)`.

intended_role_in_proof:
Reduces the theorem to charging every member of `B` to a distinct missing star set.

tool:
Canonical star certificates.

source_status:
proved inside the current proof.

exact_statement_or_fact:
For each non-star, non-exceptional `A in B`, define a fixed finite set `C(A)` of star sets containing `1`, each designed to realize a required proper trace on `A`. If all members of `C(A)` belonged to `F`, then `A` would be shattered. Hence at least one member of `C(A)` is missing from `F`.

intended_role_in_proof:
Creates the missing-certificate relation needed for the injection or Hall matching.

tool:
Hall’s theorem.

source_status:
standard background fact.

exact_statement_or_fact:
A bipartite graph with left part `B` has a matching saturating `B` if and only if every `X subset B` satisfies `|N(X)| >= |X|`.

intended_role_in_proof:
Used to match bad non-star sets injectively to missing star certificates.

tool:
Hall-type certificate matching lemma.

source_status:
proved inside the current proof.

exact_statement_or_fact:
Let `M = binom([n],d+1)_{1 in .} \ S` be the missing star sets. In the bipartite graph joining `A in B` to `M cap C(A)`, Hall’s condition holds. Therefore `|B| <= |M|`.

intended_role_in_proof:
The main cancellation step: bad non-star sets are paid for by absent star sets.

tool:
Elementary binomial counting.

source_status:
standard background fact.

exact_statement_or_fact:
The number of `(d+1)`-sets containing `1` is `binom(n-1,d)`, and the number of non-star `(d+1)`-sets containing `{2,3,4}` is `binom(n-4,d-2)`.

intended_role_in_proof:
Final assembly of the claimed bound.

4. Hardest step prediction

hardest_step_id:
SC4.

hardest_step_description:
Proving Hall’s condition for the missing-certificate relation. A naive rule choosing the first missing certificate for each bad non-star set can collide many times, so the proof must either verify Hall for all subcollections or define a recoverable reflection/toggle selector and prove both that the selected star set is absent and that different bad sets select different star sets.

risk_if_wrong:
Without SC4, the counting only proves that each bad set has some missing certificate, not that the total number of bad sets is bounded by the number of missing star members.

how_final_proof_should_handle_it:
State the certificate graph precisely, then prove Hall directly. For any `X subset B`, analyze the union of missing canonical certificates forced by `X`; do not rely on arbitrary choices. If using a selector instead, explicitly show recoverability of `A` from its selected missing star set.

5. Failure-mode checks

circularity_check:
Do not assume the desired extremal bound inside the shifted reduction or matching lemma. SC4 must be an independent combinatorial matching statement.

full_theorem_check:
SC1 must handle arbitrary original families, not only shifted ones. The final proof should prove the stronger statement for VC-dimension at most `d`.

source_check:
No supporting theorem is supplied. Compression preservation, canonical certificates, and the matching lemma must be proved inside the proof.

hypothesis_check:
Use `d >= 3` for the `{2,3,4}` exceptional structure. Use “sufficiently large `n`” to guarantee all required certificate fillers and Hall estimates.

notation_check:
Keep `k=d+1`, `[n]`, `S`, `E`, `B`, and `M` fixed throughout. “Star” always means containing vertex `1`.

standard_background_check:
Hall’s theorem, shifted-family definitions, VC definitions, and elementary binomial counts are standard. Sauer-Shelah or external extremal theorems should not be invoked unless proved inside the current proof.

6. Subproblem assignment table

S1:
Prove the tailored shifted reduction: from any counterexample, produce a shifted counterexample of the same size with no shattered `(d+1)`-set, using only elementary shift operations and a direct trace argument.

S2:
For shifted `F`, define the star/exception/bad partition and the canonical certificate set `C(A)` for every `A in B`. Prove that if all certificates for `A` are present, then `A` is shattered; hence `M cap C(A)` is nonempty.

S3:
Prove the Hall-type matching theorem for the certificate graph from `B` to missing star sets `M`. Avoid arbitrary first-missing choices unless a recoverable injective selector is fully proved.

S4:
Assemble the counting: use the matching to show `|B| <= |M|`, count `S union M` as the full star of size `binom(n-1,d)`, count `E` by `binom(n-4,d-2)`, and derive the theorem.

S5:
Check parameter dependencies and edge cases: specify a sufficient threshold `N(d)`, verify `d >= 3` is used correctly, and ensure the proof covers VC-dimension exactly `d` by proving the upper bound under VC-dimension at most `d`.
