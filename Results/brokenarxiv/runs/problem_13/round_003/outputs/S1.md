1. **Subproblem**

Prove the Springer setup statement for \(G=\mathrm{SL}_{n,K}\):

\[
X(K)\neq \varnothing \quad \Longleftrightarrow \quad \eta_X \text{ is neutral},
\]

and if \(X(K_v)\neq\varnothing\) for a completion \(K_v\), then \(\operatorname{res}_v(\eta_X)\) is neutral.

2. **Springer Gerbe**

Let \(\mathscr G_X\) be the Springer gerbe of \(X\). Over an extension \(F/K\), its objects are pairs \((P,\phi)\), where \(P\) is a \(G_F\)-torsor and

\[
\phi:P\to X_F
\]

is \(G_F\)-equivariant. Its band is the usual Springer stabilizer kernel attached to the geometric stabilizer of a geometric point of \(X\), and its class is

\[
\eta_X \in H^2(K,L_X).
\]

The class \(\eta_X\) is neutral exactly when \(\mathscr G_X(K)\) has an object.

3. **Key Input**

For every field \(F\),

\[
H^1(F,\mathrm{SL}_n)=1.
\]

Indeed, from

\[
1\to \mathrm{SL}_n\to \mathrm{GL}_n\xrightarrow{\det}\mathbb G_m\to 1
\]

and Hilbert 90, \(H^1(F,\mathrm{GL}_n)=1\), while \(\det:\mathrm{GL}_n(F)\to F^\times\) is surjective. Hence the connecting obstruction set \(H^1(F,\mathrm{SL}_n)\) is trivial.

4. **Global Equivalence**

If \(x\in X(K)\), then \(G_K\) with the equivariant map

\[
g\mapsto g\cdot x
\]

is an object of \(\mathscr G_X(K)\). Hence \(\eta_X\) is neutral.

Conversely, suppose \(\eta_X\) is neutral. Then there is an object \((P,\phi)\in \mathscr G_X(K)\). Since \(P\) is an \(\mathrm{SL}_n\)-torsor and \(H^1(K,\mathrm{SL}_n)=1\), \(P\) is trivial. Choose a \(K\)-point \(p\in P(K)\). Then

\[
\phi(p)\in X(K),
\]

so \(X(K)\neq\varnothing\).

Thus

\[
X(K)\neq\varnothing \iff \eta_X \text{ is neutral}.
\]

5. **Local Neutrality**

For every completion \(K_v\), base change of \(\mathscr G_X\) gives the Springer gerbe of \(X_{K_v}\), and its class is \(\operatorname{res}_v(\eta_X)\).

If \(x_v\in X(K_v)\), then the same construction gives an object

\[
(\mathrm{SL}_{n,K_v},\ g\mapsto g\cdot x_v)
\]

of \(\mathscr G_X(K_v)\). Hence \(\operatorname{res}_v(\eta_X)\) is neutral.

In fact, since \(H^1(K_v,\mathrm{SL}_n)=1\), one also has

\[
X(K_v)\neq\varnothing \iff \operatorname{res}_v(\eta_X)\text{ is neutral}.
\]
