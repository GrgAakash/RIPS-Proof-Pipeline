**1. S5 Claim**

Assuming S4 proves the central Brauer-Manin/Poitou-Tate compatibility, every central abelian lifting obstruction arising in the nilpotent stabilizer filtration is zero. Hence the stabilizer gerbe is globally neutral, and since `H^1(K, SL_n)=1`, the homogeneous space has a `K`-point.

**2. S4 Input Used**

For each central step
```text
1 -> A -> H -> Hbar -> 1
```
with `A` finite commutative, S4 must supply:

- an obstruction `Delta in Sha^2(K,A)` to lifting a global neutralization through this step;
- for every `chi in Sha^1(K,A^D)`, a class
  `B_chi in Br_nr,alg(X)`;
- the formula, for any adelic point `(x_v) in X(A_K)` inducing the local neutralizations,
```text
sum_v inv_v(B_chi(x_v)) = <Delta, chi>_PT.
```

**3. Killing One Obstruction**

Because `B_chi in Br_nr,alg(X)` and the theorem assumes
```text
Br_nr,alg(X) = im(Br(K) -> Br(X)),
```
there is some `b_chi in Br(K)` whose pullback to `X` is `B_chi`.

Thus for any adelic point `(x_v)`,
```text
sum_v inv_v(B_chi(x_v))
= sum_v inv_v((b_chi)_v)
= 0
```
by global Brauer reciprocity for the number field `K`.

Using the S4 formula,
```text
<Delta, chi>_PT = 0
```
for every `chi in Sha^1(K,A^D)`.

By Poitou-Tate perfectness for finite commutative `K`-group schemes,
```text
Sha^2(K,A) x Sha^1(K,A^D) -> Q/Z
```
is a perfect pairing, so `Delta = 0`.

Therefore the central lifting obstruction vanishes.

**4. Induction**

The finite nilpotent geometric stabilizer has a finite central filtration whose successive kernels are finite commutative central groups `A_i`. Starting from the trivial quotient gerbe, which is neutral, apply the previous step successively.

At each stage:

- local points on `X` give local neutralizations, so the obstruction lies in `Sha^2(K,A_i)`;
- S4 gives the Brauer classes and compatibility formula;
- constancy of `Br_nr,alg(X)` plus reciprocity makes all Poitou-Tate pairings vanish;
- Poitou-Tate perfectness forces the obstruction to vanish;
- hence the neutralization lifts globally to the next stage.

After finitely many steps, the full Springer stabilizer gerbe of `X` is globally neutral.

**5. Rational Point**

By standard Springer theory for homogeneous spaces with finite geometric stabilizer, neutrality of the stabilizer gerbe expresses `X` as a twist of `SL_n/H` by an `SL_n`-torsor. Since
```text
H^1(K, SL_n) = 1,
```
that torsor is trivial. Hence `X ≅ SL_n/H` over `K`, and the image of the identity element gives a `K`-rational point.

Thus `X(K) nonempty`.
