Let \(G=\mathrm{SL}_n\). Choose \(\bar x\in X(\bar K)\), and let \(\bar H=\operatorname{Stab}_{G_{\bar K}}(\bar x)\). Then
\[
X_{\bar K}\simeq G_{\bar K}/\bar H.
\]
The descent datum on \(X\) defines the usual Springer stabilizer kernel/link and the associated Springer gerbe \(\mathcal G_X\). For any field extension \(F/K\), an \(F\)-point of \(X\) neutralizes \(\mathcal G_X\) over \(F\). Conversely, if \(\mathcal G_X\) is neutral over \(K\), the quotient map descends to a \(G\)-torsor \(P\to \operatorname{Spec}K\) equipped with a \(G\)-equivariant map \(P\to X\). Since
\[
H^1(K,\mathrm{SL}_n)=1,
\]
the torsor \(P\) has a \(K\)-point, whose image gives a \(K\)-point of \(X\). Thus it is enough to prove that \(\mathcal G_X\) is globally neutral.

Because \(\bar H\) is finite nilpotent, its upper central series
\[
1=Z_0\subset Z_1\subset \cdots \subset Z_r=\bar H
\]
terminates. Each \(Z_i\) is characteristic, hence stable under the Springer kernel action. Put
\[
A_i=Z_i/Z_{i-1}.
\]
Then each \(A_i\) is a finite abelian \(K\)-group, and each step gives a central extension of \(K\)-kernels
\[
1\to A_i\to \bar H/Z_{i-1}\to \bar H/Z_i\to 1.
\]

Suppose inductively that the gerbe has been neutralized after quotienting by \(Z_i\), and let \(\xi\) denote the corresponding global class for the quotient kernel \(\bar H/Z_i\). The obstruction to lifting \(\xi\) through
\[
1\to A_i\to \bar H/Z_{i-1}\to \bar H/Z_i\to 1
\]
is a class
\[
\Delta_i(\xi)\in H^2(K,A_i).
\]
Concretely, if \(\bar c_\sigma\) is a cocycle representing \(\xi\), and \(c_\sigma\) are arbitrary lifts to \(\bar H/Z_{i-1}\), then
\[
a_{\sigma,\tau}=c_\sigma\,{}^\sigma c_\tau\,c_{\sigma\tau}^{-1}
\]
is an \(A_i\)-valued \(2\)-cocycle. Its cohomology class is \(\Delta_i(\xi)\), independent of the chosen lifts. The class vanishes if and only if the lifts can be corrected by an \(A_i\)-valued \(1\)-cochain to form an actual \((\bar H/Z_{i-1})\)-valued cocycle, equivalently if and only if the neutralization lifts globally.

Since \(X(K_v)\neq\varnothing\) for every completion \(K_v\), the Springer gerbe is locally neutral everywhere. Therefore each central obstruction \(\Delta_i(\xi)\) is locally trivial, so
\[
\Delta_i(\xi)\in \Sha^2(K,A_i).
\]

At this point the required proof needs the following compatibility statement for each central finite abelian step:
for every
\[
\chi\in \Sha^1(K,A_i^D),
\]
one must construct an algebraic unramified Brauer class
\[
B_\chi\in \operatorname{Br}_{nr,\mathrm{alg}}(X)
\]
such that, for every adelic family of local neutralizations \((x_v)\) inducing the local lifting data, one has
\[
\sum_v \operatorname{inv}_v\bigl(B_\chi(x_v)\bigr)
=
\langle \Delta_i(\xi),\chi\rangle_{\mathrm{PT}}.
\]

This is exactly the unresolved SC4 comparison. It is not supplied by S1-S5, and the prompt forbids silently importing it as an established lemma. Without this construction and equality, the remaining argument cannot be completed.

If the SC4 compatibility were proved, then the hypothesis
\[
\ker\bigl(\operatorname{Br}_{nr}(X)\to \operatorname{Br}_{nr}(X_{\bar K})\bigr)
=
\operatorname{im}\bigl(\operatorname{Br}(K)\to \operatorname{Br}(X)\bigr)
\]
would imply that every \(B_\chi\) is constant. For any adelic point \((x_v)\), global reciprocity would then give
\[
\sum_v \operatorname{inv}_v\bigl(B_\chi(x_v)\bigr)=0.
\]
The compatibility formula would imply
\[
\langle \Delta_i(\xi),\chi\rangle_{\mathrm{PT}}=0
\quad
\text{for all }\chi\in \Sha^1(K,A_i^D).
\]
By Poitou-Tate perfectness,
\[
\Delta_i(\xi)=0.
\]
Thus every central lifting obstruction would vanish, the neutralization would lift through the entire nilpotent central filtration, \(\mathcal G_X\) would be globally neutral, and hence \(X(K)\neq\varnothing\).

However, because SC4 is unresolved, this is only a conditional completion, not a proof of the target theorem.
