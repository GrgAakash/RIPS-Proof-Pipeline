assigned subclaim(s): Prove the cluster-size Markov chain representation and its continuous-time Yule/mutation embedding.

what must be proved: In the natural growth coupling, the vector of percolation cluster sizes evolves as a Markov chain where a cluster of size \(x\) is selected for retained growth with probability proportional to \(x\), and new singleton clusters appear when the new edge is not retained. Also, this chain is realized by a continuous-time branching process in which each individual gives same-type births at rate \(p\) and mutant births at rate \(1-p\). Finally, the root-leadership event depends only on these cluster sizes.

declared prerequisite subclaims: None.

2. Subproof or failure

Let \(T_n\) be the recursive tree on vertices \(\{0,\dots,n\}\), with percolation performed during growth. Let the percolation clusters at time \(n\) be indexed by their time of creation, with cluster \(0\) denoting the root cluster. Write
\[
X(n)=(X_0(n),X_1(n),\dots,X_{M(n)}(n)),
\]
where \(X_i(n)\) is the size of cluster \(i\), \(M(n)+1\) is the number of clusters at time \(n\), and \(\sum_i X_i(n)=n+1\).

At step \(n+1\), the new vertex \(n+1\) attaches to a uniformly chosen parent in \(\{0,\dots,n\}\). Conditional on the current percolation cluster sizes, the probability that the parent lies in cluster \(i\) is
\[
\frac{X_i(n)}{n+1}.
\]
If the new edge is retained, which occurs with probability \(p\), then \(n+1\) joins the parent’s cluster, so
\[
X_i(n+1)=X_i(n)+1
\]
for that selected \(i\), while all other cluster sizes are unchanged. Therefore
\[
\mathbb P\bigl(X_i(n+1)=X_i(n)+1 \mid X(n)\bigr)
=
p\frac{X_i(n)}{n+1}.
\]
If the edge is not retained, which occurs with probability \(1-p\), then \(n+1\) forms a new singleton cluster, independent of which parent was chosen. Thus
\[
X(n+1)=(X_0(n),\dots,X_{M(n)}(n),1)
\]
with probability \(1-p\).

Hence the cluster-size process is a Markov chain: from state \((x_0,\dots,x_m)\), with total size \(N=\sum_i x_i\), it moves to
\[
(x_0,\dots,x_i+1,\dots,x_m)
\]
with probability \(p x_i/N\), for each \(0\le i\le m\), and to
\[
(x_0,\dots,x_m,1)
\]
with probability \(1-p\). This is the size-biased birth-with-immigration chain.

The root-leadership event is
\[
\{X_0(n)\ge X_i(n)\text{ for every }i\le M(n)\text{ and every }n\ge0\}.
\]
Since “root cluster remains a largest cluster” permits ties, this event is exactly the event that the root cluster size is at least every other cluster size at every time. It depends only on the cluster-size chain \(X(n)\), not on the internal shape of the recursive tree.

Now construct the continuous-time embedding. Start with one individual of type \(0\). Each individual lives forever and gives births according to an independent rate-\(1\) Poisson process. At each birth, independently, the child has the parent’s type with probability \(p\), and has a new previously unused type with probability \(1-p\). Let \(Y_i(t)\) be the population size of type \(i\) at time \(t\), and observe the process only at its successive birth times \(\tau_n\), where after \(n\) births the total population is \(n+1\).

When the total population is \(N\), all individuals have equal birth rate \(1\), so the next parent is uniformly distributed among the \(N\) individuals. Therefore, conditional on the type sizes \((y_0,\dots,y_m)\), the next parent has type \(i\) with probability \(y_i/N\). With probability \(p\), the child has the same type and type \(i\) increases by one. With probability \(1-p\), the child has a new type of size one. Thus the embedded chain
\[
(Y_0(\tau_n),Y_1(\tau_n),\dots)
\]
has exactly the same transition probabilities as \(X(n)\).

Equivalently, after thinning each individual’s rate-\(1\) birth process, same-type births occur at rate \(p\) per individual and mutant births occur at rate \(1-p\) per individual. Hence a cluster/type of size \(x\) has same-type birth rate \(px\), and the whole population has mutant-birth rate \((1-p)N\). Observed at total-population jump times, this continuous-time Yule process with mutation realizes the cluster-size Markov chain.

This proves the assigned subclaims.
