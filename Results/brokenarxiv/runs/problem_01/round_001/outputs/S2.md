1. Assignment restatement

Define a challenger process whose particles encode non-root clusters by their deficit relative to the root cluster, and prove that a particle crossing the barrier is exactly the event that the root cluster stops being strictly larger than every non-root cluster.

2. Subproof or failure

Let \(R_n\) be the size of the root cluster after vertex \(n\) has been added. For every non-root percolation cluster \(C\) present at time \(n\), write \(|C|_n\) for its size and define its deficit
\[
D_n(C)=R_n-|C|_n.
\]

A non-root cluster is a challenger. The challenger process at time \(n\) is the multiset
\[
\mathcal X_n=\{D_n(C): C \text{ is a non-root cluster at time } n\}.
\]
The barrier is \(0\). A challenger crosses the barrier at time \(n\) if some particle has value \(\le 0\), equivalently if some non-root cluster has size at least \(R_n\).

The dynamics are as follows. Suppose the state at time \(n\) consists of root size \(R_n\) and deficits \(\mathcal X_n\).

When vertex \(n+1\) is added:

- If it attaches by a retained edge to a vertex in the root cluster, then \(R_{n+1}=R_n+1\). Every existing non-root cluster keeps the same size, so every deficit increases by \(1\).

- If it attaches by a retained edge to a vertex in a non-root cluster \(C\), then that cluster grows by \(1\). Its deficit decreases by \(1\), while all other deficits are unchanged and \(R_{n+1}=R_n\).

- If the connecting edge is not retained, then the new vertex starts a new singleton non-root cluster. Its deficit is \(R_n-1\), and all previous deficits are unchanged.

This gives a precise Markovian challenger process once coupled with the usual recursive-tree sampling rule: attachment probabilities are proportional to current cluster sizes.

Now compare the barrier event with root leadership.

At time \(n\), the root cluster is strictly larger than every non-root cluster iff
\[
R_n>|C|_n
\]
for every non-root cluster \(C\). This is equivalent to
\[
D_n(C)=R_n-|C|_n>0
\]
for every challenger \(C\), which is equivalent to every particle in \(\mathcal X_n\) lying in \(\{1,2,3,\dots\}\).

Therefore
\[
\exists n,\ \exists C\ne \text{root}: |C|_n\ge R_n
\]
iff
\[
\exists n,\ \min \mathcal X_n\le 0.
\]
Thus crossing the barrier is exactly root strict-leadership failure.

If the intended target event treats ties as acceptable because the root need only be “a largest cluster,” then the barrier should instead be \(-1\): failure is \(|C|_n>R_n\), equivalently \(D_n(C)<0\). With S0’s instruction that “overtakes or ties” is failure, the correct barrier is \(0\).
