1. Target decomposition

target_label: Problem 01  
target_type: phase-transition theorem / existence of a critical parameter  
main_goal: Show that the all-time leadership probability of the root percolation cluster has a nontrivial threshold in the retention parameter.  
variables_and_parameters: Random recursive tree grown from root 0; fixed retention parameter \(p\in(0,1]\); root cluster \(C_0(n)\); all other percolation clusters at time \(n\); \(P(p)=\mathbb P(C_0(n)\) is a largest cluster for every \(n)\).  
conclusion_to_prove: There is \(p_c\in(0,1)\) such that \(P(p)=0\) for \(p<p_c\), and \(P(p)>0\) for \(p>p_c\).

2. Available tools

tool: Cluster-size Markov chain representation  
source_status: proved inside the current proof  
exact_statement_or_fact: The percolated recursive tree cluster sizes evolve as follows: choose an existing vertex uniformly, equivalently choose a cluster with probability proportional to its size; with probability \(p\) the chosen cluster gains one vertex, and with probability \(1-p\) a new singleton cluster is born.  
intended_role_in_proof: Reduce the tree statement to a size-biased cluster-growth process.

tool: Continuous-time embedding  
source_status: standard background fact / proved inside the current proof  
exact_statement_or_fact: The same cluster process can be embedded in a Yule process where each individual gives birth at rate 1; the child keeps the parent type with probability \(p\), and mutates to a new type with probability \(1-p\).  
intended_role_in_proof: Make independence and branching comparisons available.

tool: Challenger process  
source_status: proved inside the current proof  
exact_statement_or_fact: One can encode non-root clusters that can overtake or tie the root as particles in a multitype branching process, with type recording deficit from the root cluster. Root all-time leadership fails exactly when this process produces a particle crossing the root barrier.  
intended_role_in_proof: Convert the theorem into extinction/survival of an auxiliary branching object.

tool: Spectral-radius criterion  
source_status: proved inside the current proof  
exact_statement_or_fact: For the challenger branching process there is a mean operator \(K_p\) with spectral radius \(\rho(p)\), and \(P(p)>0\) iff \(\rho(p)<1\), while \(P(p)=0\) if \(\rho(p)>1\).  
intended_role_in_proof: Provide the actual threshold mechanism.

tool: Monotonicity and continuity of \(\rho(p)\)  
source_status: proved inside the current proof  
exact_statement_or_fact: \(\rho(p)\) is finite on \((0,1)\), continuous, and strictly decreasing in \(p\).  
intended_role_in_proof: Turn the extinction criterion into a single critical value.

tool: Low-\(p\) supercriticality  
source_status: proved inside the current proof  
exact_statement_or_fact: For all sufficiently small \(p>0\), the challenger process is supercritical, so \(\rho(p)>1\).  
intended_role_in_proof: Show \(p_c>0\).

tool: High-\(p\) subcriticality  
source_status: proved inside the current proof  
exact_statement_or_fact: For all sufficiently large \(p<1\), the challenger process is subcritical, so \(\rho(p)<1\).  
intended_role_in_proof: Show \(p_c<1\).

tool: Galton-Watson / multitype branching-process extinction theorem  
source_status: standard background fact  
exact_statement_or_fact: A multitype branching process with mean spectral radius below 1 dies out with positive probability, while one with spectral radius above 1 survives with positive probability; with the root-barrier encoding, survival corresponds to eventual loss of root leadership.  
intended_role_in_proof: Justify the phase-transition criterion once the auxiliary process is built.

4. Hardest step prediction

hardest_step_id: SC3-SC4  
hardest_step_description: The delicate part is defining the challenger process so that it is neither too weak nor too strong: it must detect exactly the possibility that some non-root cluster overtakes the root, and its extinction criterion must match \(P(p)>0\).  
risk_if_wrong: A one-sided comparison would only prove sufficient or necessary conditions, not the claimed sharp threshold.  
how_final_proof_should_handle_it: Define challenger types explicitly, prove both inclusions between barrier crossing and root leadership failure, then apply the branching-process theorem only after this equivalence is established.

source_check: No web sources or paper-specific lemmas are available; all nonstandard tools must be proved inside the current proof.

6. Subproblem assignment table

S1: Prove the cluster-size Markov chain representation and its continuous-time Yule/mutation embedding. Make clear that root leadership is a statement only about cluster sizes.

S2: Define the challenger process precisely. Its particles should represent non-root clusters by their deficit from the root cluster, and crossing the barrier should be equivalent to root leadership failure.

S3: Prove the mean-operator/spectral-radius criterion for the challenger process, including continuity and monotonicity of \(\rho(p)\).

S4: Prove the two regime estimates: for small \(p\), challengers are supercritical; for \(p\) close to 1, challengers are subcritical.

S5: Assemble the threshold argument by defining \(p_c\), using monotonicity/continuity of \(\rho(p)\), checking \(p_c\in(0,1)\), and translating back to \(P(p)\).
