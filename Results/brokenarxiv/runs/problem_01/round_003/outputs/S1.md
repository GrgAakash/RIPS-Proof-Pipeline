## 1. Model

Let the random recursive tree grow on vertices `1,2,...`, with root `1`. For each `n >= 2`, vertex `n` attaches to a uniformly chosen parent `U_n in {1,...,n-1}`. Independently, the new edge is declared open with probability `p` and closed with probability `1-p`.

At time `n`, let `C_0(n)` be the open cluster containing the root, and let `C_i(n)` be the non-root open clusters. Define

```text
R_n = |C_0(n)|,
M_n = max_i |C_i(n)|,
```

with `M_n = 0` if no non-root clusters exist.

The event of interest is

```text
E = { R_n >= M_n for every n >= 1 }.
```

Ties are allowed. Failure occurs only if some non-root cluster strictly exceeds the root cluster.

Thus

```text
P(p) = P(E).
```

## 2. Cluster Chain

The cluster-size process evolves as follows.

At time `n`, a new vertex chooses a parent uniformly among all `n` existing vertices.

If it attaches to a vertex in the root cluster:

- with probability `p`, the new vertex joins the root cluster, so `R` increases by `1`;
- with probability `1-p`, it creates a new non-root cluster of size `1`.

If it attaches to a vertex in a non-root cluster of size `a`:

- with probability `p`, that cluster grows from `a` to `a+1`;
- with probability `1-p`, a new non-root singleton cluster is born.

Therefore the state can be represented by

```text
(R; A_1,A_2,...,A_m),
```

where `R` is the root cluster size and `A_j` are the sizes of all non-root clusters.

The good region is

```text
G = { (R; A_1,...,A_m) : max_j A_j <= R }.
```

The root remains a largest cluster forever exactly when the cluster chain never leaves `G`.

## 3. Deficit / Challenger Criterion

For a non-root cluster of size `a`, define its deficit against the root cluster by

```text
D = R - a.
```

The cluster is a challenger if it has small deficit, especially `D = 0`.

Because ties are allowed, a challenger of size `a = R` is still harmless. Failure occurs only when some non-root cluster reaches size `R+1`, i.e. deficit `D = -1`.

So the eternal non-overtake condition is equivalently

```text
R_n - A_j(n) >= 0
```

for every non-root cluster `j` and every time `n`.

## 4. Definition of Q_K(p)

For integer `K >= 1`, define `Q_K(p)` as follows.

Start the cluster chain from the deterministic state

```text
(R; non-root clusters) = (K; empty).
```

Equivalently, at the initial time there are exactly `K` vertices, all belonging to the root cluster, and no non-root clusters.

Then

```text
Q_K(p)
=
P_{(K; empty)}(
  root cluster is never strictly overtaken by any non-root cluster
).
```

In notation,

```text
Q_K(p)
=
P_{(K; empty)}(
  R_t >= M_t for all future t
).
```

Here the future evolution is the same recursive-tree/percolation growth rule: each new vertex attaches uniformly to an existing vertex, and its edge is open with probability `p`.

## 5. Early All-Open Bootstrap

Let

```text
B_K = { the first K-1 edges are open }.
```

This means vertices `2,3,...,K` all attach through open edges. Since the tree is connected and all those first `K-1` edges are retained, at time `K` all `K` vertices belong to the root cluster. Hence the cluster state at time `K` is exactly

```text
(K; empty).
```

Also,

```text
P(B_K) = p^(K-1).
```

By the Markov property of the growth process after time `K`, conditional on `B_K`, the future probability of eternal non-overtake is precisely `Q_K(p)`.

Therefore

```text
P(p)
>=
P(B_K and eternal non-overtake after time K)
=
P(B_K) Q_K(p)
=
p^(K-1) Q_K(p).
```

So for every `K >= 1`,

```text
P(p) >= p^(K-1) Q_K(p).
```

This is the desired bootstrap inequality.
