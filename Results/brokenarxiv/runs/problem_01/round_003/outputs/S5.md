**1. S1: Model Reduction**

Let `R_n` be the root open-cluster size at time `n`. Cluster sizes evolve as:

- with probability `p`, the new vertex joins an existing cluster chosen with probability proportional to its size;
- with probability `1-p`, the new vertex starts a new singleton cluster.

The root fails only if some non-root cluster becomes strictly larger than `R_n`. Ties are harmless.

**2. S2: Deficit/Challenger Criterion**

Consider one challenger born when the root cluster has size `r`; the challenger starts with size `1`.

Ignoring all updates to other clusters, the embedded race between root and challenger is a two-color Polya urn starting from `(r,1)`. Conditional on the limiting root fraction `U ~ Beta(r,1)`, the embedded increments are iid: root with probability `U`, challenger with probability `1-U`.

Strict overtake requires

\[
B-A \ge r,
\]

not merely equality, because ties are allowed. Thus the overtake probability is

\[
h_r
=
2^{-r}
+
r\int_{1/2}^1 (1-u)^r u^{-1}\,du
\le 2^{1-r}.
\]

So a singleton born against root size `r` has exponentially small chance to ever strictly overtake.

**3. S3: Finite Bootstrap Survival**

Define `Q_K(p)` as the probability that, starting at time `K` with only one cluster of size `K` containing the root, the root cluster is never strictly overtaken.

For `n >= K`, `R_n >= K`, and

\[
\mathbb E(2^{-R_{n+1}}\mid \mathcal F_n)
=
2^{-R_n}\left(1-\frac{pR_n}{2n}\right)
\le
2^{-R_n}\left(1-\frac{pK}{2n}\right).
\]

Hence

\[
\mathbb E 2^{-R_n}
\le
2^{-K}\left(\frac Kn\right)^{pK/2}.
\]

Let `B` be the number of future challenger clusters that ever strictly overtake the root. By the challenger bound,

\[
\mathbb P(B\ge1)
\le
\mathbb E B
\le
2(1-p)\sum_{n\ge K}\mathbb E 2^{-R_n}.
\]

If `K` is large enough that `pK/2 > 1`, then

\[
\sum_{n\ge K}\mathbb E 2^{-R_n}
\le
2^{-K}\left(1+\frac{K}{pK/2-1}\right),
\]

which tends to `0` as `K -> infinity`. Therefore, for every `p>0`, some finite `K` satisfies

\[
Q_K(p)>0.
\]

**4. S4: Early All-Open Bootstrap**

In the original process, the event that the first `K-1` edges are all open has probability

\[
p^{K-1}>0.
\]

On this event, at time `K` there is exactly one cluster, the root cluster, of size `K`. Therefore

\[
P(p)
\ge
p^{K-1} Q_K(p)
>
0
\]

for every `p in (0,1]`.

**5. S5: Verdict**

The claimed theorem is false as stated. There is no critical value `p_c in (0,1)` such that `P(p)=0` below `p_c` and `P(p)>0` above it.

The finite all-open bootstrap gives the root a large enough early lead with positive probability, and the total future challenger hazard can be made less than `1`. Thus `P(p)>0` for every `p>0`.
