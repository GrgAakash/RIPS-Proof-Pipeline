## 1. S2 Claim

S2 proves the exact embedding needed for later stages:

Bernoulli bond percolation on the naturally grown random recursive tree has the same cluster-size jump chain as a Yule process with mutations, where open births preserve type and closed births create new singleton types.

This solves the embedding component only. It does not by itself prove the claimed threshold \(p_c\).

## 2. Discrete Recursive-Tree Process

At size \(n\), vertex \(n+1\) attaches to a uniformly chosen parent among the \(n\) existing vertices. The new edge is open with probability \(p\), closed with probability \(1-p\), independently.

Let

\[
R_n=\text{root-cluster size},
\qquad
X_{1,n},X_{2,n},\dots = \text{nonroot cluster sizes}.
\]

If the state is

\[
(r;x_1,\dots,x_m),\qquad n=r+\sum_i x_i,
\]

then the next transition is:

\[
(r;x_1,\dots,x_m)\to (r+1;x_1,\dots,x_m)
\]

with probability \(p r/n\);

\[
(r;x_1,\dots,x_i,\dots,x_m)\to (r;x_1,\dots,x_i+1,\dots,x_m)
\]

with probability \(p x_i/n\);

and a new singleton challenger is born,

\[
(r;x_1,\dots,x_m)\to (r;x_1,\dots,x_m,1),
\]

with total probability \(1-p\).

## 3. Yule-Mutation Construction

Start with \(K\) root-type individuals and no other types.

Each individual gives births at total rate \(1\). Equivalently, each individual has:

\[
\text{same-type birth rate }p,
\qquad
\text{mutant birth rate }1-p.
\]

A same-type birth adds one vertex to the parent’s current cluster. A mutant birth creates a new nonroot cluster of size \(1\).

Thus, when the total population is \(n\), the next parent is chosen size-biased by cluster size. From state \((r;x_1,\dots,x_m)\), the rates are:

\[
\text{root growth rate } pr,
\]

\[
\text{challenger }i\text{ growth rate } p x_i,
\]

\[
\text{new-cluster birth rate } (1-p)n.
\]

Dividing by the total event rate \(n\) gives exactly the transition probabilities in Section 2.

## 4. Equivalence Proof

The Yule genealogy observed at birth times is a random recursive tree: when there are \(n\) individuals, each existing individual has birth rate \(1\), so the next parent is uniform among the \(n\) existing vertices.

At that birth, the child inherits the parent’s type with probability \(p\), corresponding to an open edge, and receives a fresh type with probability \(1-p\), corresponding to a closed edge.

Therefore the labeled genealogy plus open/closed edge marks has the same law as the naturally grown Bernoulli-percolated recursive tree. In particular, the cluster-size process has the same law.

Starting from root size \(K\) and no challengers is also valid: it is the same future process as the recursive tree conditioned on the first \(K-1\) added edges being open.

## 5. Deficit Criterion and Bootstrap

Define challenger deficit

\[
D_i=R-X_i.
\]

Root remains a largest cluster iff

\[
D_i\ge 0
\]

for every challenger \(i\) at every jump time. Ties are allowed.

A strict failure can occur only when some challenger with \(D_i=0\) receives an open same-type birth, causing \(D_i\) to become \(-1\). New mutant clusters are born with size \(1\), hence deficit \(R-1\).

For the early all-open bootstrap, let \(A_K\) be the event that the first \(K-1\) edges are open. Then

\[
\mathbb P(A_K)=p^{K-1}.
\]

On \(A_K\), at time \(K\) the root cluster has size \(K\) and there are no challengers. Hence, if \(q_K(p)\) is the no-overtake probability for the Yule-mutation process started from \(K\) root individuals and no challengers, then

\[
P(p)\ge p^{K-1} q_K(p).
\]

So proving \(q_K(p)>0\) for some \(K\) is enough to prove \(P(p)>0\).
