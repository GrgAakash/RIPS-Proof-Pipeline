1. Target decomposition

Let `C_0(n)` be the root-cluster size and let `M(n)` be the largest non-root cluster size after vertex `n` is added. The leadership event is

`L(p) = { C_0(n) >= M(n) for every n }`

because ties are allowed. Failure means `M(n) > C_0(n)` for some `n`.

Key reduction: for each `K >= 1`, let `Q_K(p)` be the probability of eternal non-overtake starting from a state with root cluster size `K` and no non-root cluster. The event that the first `K-1` edges are retained has probability `p^(K-1)`, and on that event the process is exactly in this state. Hence

`P(p) >= p^(K-1) Q_K(p)`.

Therefore any proof of a zero regime must prove `Q_K(p)=0` for every finite `K` when `p<p_c`. If some `Q_K(p)>0` for any `K`, then `P(p)>0` at that `p`, contradicting the claimed subcritical zero regime.

2. Available tools

- Cluster-size Markov chain: a cluster of size `x` grows with probability `p x/n`; with probability `1-p`, the new vertex starts a singleton challenger.
- Continuous-time Yule embedding with mutations: each cluster grows by same-type births at rate `p` per vertex; mutant births create new clusters.
- Equal-rate Yule/Pólya comparison for one challenger versus the root.
- Sharp overtake-tail estimates for a Yule process starting from `1` trying to catch a Yule process with large current size.
- Summability/Borel-Cantelli or thinning over infinitely many future challenger births.
- Tie convention: only strict non-root excess counts as failure.

3. Subclaim support graph

A. Markov/bootstrap reduction  
`first K-1 edges retained` -> root starts with size `K`, no challenger -> `P(p) >= p^(K-1)Q_K(p)`.

B. Finite-head-start survival lemma  
For fixed `p>0`, prove or refute: there exists finite `K` with `Q_K(p)>0`.

C. Challenger hitting bound  
A challenger born when the root has size about `m` has overtake probability at most exponentially small in `m`.

D. Infinite challenger control  
Future challenger births grow roughly like `e^t`, while the root lower envelope grows like `e^{pt}`. If C gives an exponential tail, the dangerous-challenger hazard is summable for every `p>0`.

E. Consequence  
B + A implies `P(p)>0` for every `p>0`, so the target theorem is false as stated.

F. Target-compatible alternative  
To prove the stated theorem, one must instead show `Q_K(p)=0` for every `K` in a small-`p` regime. This is exactly where the bootstrap obstruction must be resolved.

4. Hardest step prediction

The hardest step is the finite-head-start survival lemma. The proof must handle infinitely many challenger clusters born at unbounded future times, including challengers born from other challengers. A weak martingale maximal bound is probably too crude; the needed estimate is the sharp probability that a one-particle equal-rate Yule process ever strictly overtakes a root process already of size `m`.

My prediction: the sharp hitting estimate is exponentially small in `m`, making late challengers summable for every `p>0`. If so, the target theorem cannot be true.

5. Failure-mode checks

- The early all-open bootstrap cannot be ignored: `p^(K-1)>0` for every fixed `p>0`.
- Ties are allowed, so a singleton challenger at size `1` does not immediately defeat the root.
- A claimed small-`p` zero regime must defeat every finite initial root advantage.
- Monotonicity of `P(p)` in `p` is not automatic and should not be assumed.
- “Eventually largest” is weaker than “largest at every time”; both must be separated.
- At `p=0`, if considered, all clusters remain singletons, so strict overtake never occurs.
