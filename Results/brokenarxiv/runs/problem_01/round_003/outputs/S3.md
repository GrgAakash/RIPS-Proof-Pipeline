**1. S1 Role**

I am treating this as the S3 assignment: prove the single-challenger overtake bound. The result needed downstream is solved.

**2. S2 Deficit Criterion**

Suppose a challenger is born as a singleton when the root cluster has size \(m\). Let root size be \(R_0=m\), challenger size \(C_0=1\), so the initial deficit is

\[
D_0=R_0-C_0=m-1.
\]

Ties are allowed, so this challenger causes failure only if eventually

\[
C_k>R_k.
\]

Equivalently, if \(S_k\) is challenger increments minus root increments, then

\[
C_k-R_k = 1-m+S_k,
\]

so strict overtake requires

\[
S_k \ge m.
\]

The threshold is \(m\), not \(m-1\), because equality is only a tie.

**3. S3 Pólya Reduction**

Ignoring all other clusters only changes the clock. When the current root/challenger sizes are \((r,c)\), their open-growth rates are proportional to

\[
pr,\qquad pc.
\]

Thus, conditional on the next growth event affecting one of these two clusters,

\[
\mathbb P(\text{challenger grows})=\frac{c}{r+c},\qquad
\mathbb P(\text{root grows})=\frac{r}{r+c}.
\]

So the embedded process is exactly the two-color Pólya urn started from \((m,1)\). The parameter \(p\) cancels.

**4. S4 Overtake Tail Bound**

Let \(q_m\) be the probability that this challenger ever strictly overtakes the root. For the Pólya urn, condition on the de Finetti limit

\[
U\sim \mathrm{Beta}(1,m),
\]

so future increments are iid with challenger probability \(U\). Given \(U=u\), the walk \(S_k\) has \(+1\) probability \(u\) and \(-1\) probability \(1-u\). The probability it ever hits level \(m\) is

\[
\begin{cases}
\left(\frac{u}{1-u}\right)^m, & u<1/2,\\
1, & u\ge 1/2.
\end{cases}
\]

Since \(U\) has density \(m(1-u)^{m-1}\),

\[
q_m
=
m\int_0^{1/2}\frac{u^m}{1-u}\,du
+
2^{-m}.
\]

Using \(1/(1-u)\le 2\) on \([0,1/2]\),

\[
m\int_0^{1/2}\frac{u^m}{1-u}\,du
\le
2m\int_0^{1/2}u^m\,du
=
\frac{m}{m+1}2^{-m}.
\]

Therefore

\[
q_m \le \left(1+\frac{m}{m+1}\right)2^{-m}<2^{1-m}.
\]

So the required exponential tail holds.

**5. S5 Bootstrap / Threshold Relevance**

If \(N_m\) is the number of challengers born while the root has size \(m\), then the union-bound input is

\[
\mathbb P(\text{some challenger born at root size }m\text{ overtakes})
\le
\mathbb E[N_m]\,2^{1-m}.
\]

Thus the S3 bound is summable against any polynomial or subexponential control of \(N_m\).

The early all-open bootstrap fits cleanly: if the first \(M-1\) edges are open, an event of probability \(p^{M-1}>0\), then at time \(M\) the root has size \(M\) and there are no challengers. Every later challenger starts against root size at least \(M\), hence has exponentially small overtake probability. Combined with the standard root-size-level birth-count estimate, this points to positivity for every \(p>0\), not to a genuine \(p_c\in(0,1)\). The full global count step is outside this S3 assignment.
