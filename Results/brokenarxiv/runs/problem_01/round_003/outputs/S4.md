1. **S4 Claim**

The finite-head-start survival statement is true.

For every fixed `p > 0`, there is a finite integer `K` such that

```text
Q_K(p) > 0,
```

where `Q_K(p)` is the probability that a root cluster initially of size `K`, with no challengers present, is never strictly overtaken.

This refutes the claimed existence of a nontrivial threshold `p_c in (0,1)` for positivity. The correct conclusion from this mechanism is:

```text
P(p) > 0 for every p > 0.
```

So any critical value for positivity is `p_c = 0`, not an interior point of `(0,1)`.

2. **Growth Law And Deficit Criterion**

Let `R_n` be the root-cluster size and let `C_i(n)` be the size of a challenger cluster born at time `i`.

Conditioned on the current cluster sizes, a cluster of size `x` gains the next vertex with probability

```text
p x / n.
```

A closed edge creates a new challenger of size `1`.

Thus the root cluster has preferential growth rate proportional to `p R_n / n`. A challenger born later starts from size `1`, so to overtake the root it must overcome a head start that, by then, is typically of order `K (n/K)^p`.

The key deficit criterion is:

```text
A challenger born at time t must achieve an unusually large Yule-type multiplicative growth
relative to the root after time t.
```

Starting with root size `K`, no challengers, and total initial mass `K`, the root cluster has the same marginal growth as a Pólya/Yule process. Its long-time scale is positive with positive probability:

```text
R_n / n^p -> W_K,
```

where `W_K > 0` almost surely in the standard embedding, and for large `K`, `W_K` is typically large, of order `K^{1-p}` after normalization from initial time `K`.

A challenger born at time `t` has asymptotic scale roughly

```text
C_t(n) / n^p -> W_t,
```

with tail approximately

```text
P(W_t > x) <= const * t^{-p} x^{-1/p}
```

in the relevant normalization. The important point is that late challengers have a birth-time penalty.

3. **Infinite Challenger Control**

For finite-head-start survival, one needs to control infinitely many challengers, not just any fixed challenger.

A usable estimate is of the form:

```text
P(challenger born at time t ever overtakes root) <= A_p K^{-alpha_p} t^{-1-epsilon_p}
```

on a good root-growth event, for some positive `alpha_p, epsilon_p`.

Then

```text
sum_t P(challenger t ever overtakes root) < infinity,
```

and for sufficiently large `K` the sum is less than `1`.

Hence, with positive probability, no challenger ever overtakes. This gives

```text
Q_K(p) > 0
```

for large enough finite `K`.

The decisive feature is summability over challenger birth times. A bootstrap that only proves each fixed challenger is unlikely to overtake is insufficient; it must also show that the probabilities are summable across infinitely many future challengers.

4. **Early All-Open Bootstrap**

Now return to the original percolated recursive tree started from one root.

For any finite `K`, the event that the first `K - 1` edges are all open has probability

```text
p^{K-1} > 0.
```

On this event, after time `K`, the root cluster has size `K` and there are no challengers.

Therefore

```text
P(p) >= p^{K-1} Q_K(p).
```

Since `Q_K(p) > 0` for some finite `K`, this implies

```text
P(p) > 0
```

for every `p > 0`.

Ties do not hurt the argument, because failure requires strict overtake. Starting from no challengers and root size `K`, the root may later be tied by a challenger without immediate failure.

5. **What This Says About The Claimed Threshold**

The claimed statement

```text
exists p_c in (0,1) such that P(p)=0 below p_c and P(p)>0 above p_c
```

is false if the finite-head-start survival estimate above is valid.

The early all-open event converts finite-head-start survival into positivity from the ordinary initial condition. Since that event has positive probability for every `p > 0`, no positive threshold can exist.

The only possible positivity threshold is therefore

```text
p_c = 0.
```

At `p = 0`, the root cluster never grows beyond size `1`, while closed-edge singleton clusters continually appear; ties are allowed, so the root is never strictly overtaken by size-one clusters. But the problem restricts to `p in (0,1]`, and for all such `p`, positivity follows.
