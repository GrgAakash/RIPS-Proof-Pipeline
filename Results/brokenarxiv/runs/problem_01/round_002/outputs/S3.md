From the standard transition law, one can derive the following local dynamics.

Let `R_n` be the root cluster size at time `n`, and let `C_i(n)` be the size at time `n` of challenger cluster `i`, born at time `b_i`. Define the deficit

```text
D_i(n) = R_n - C_i(n).
```

At time `n -> n+1`, conditional on the present cluster sizes:

```text
P(R increases by 1) = p R_n / n,
P(C_i increases by 1) = p C_i(n) / n,
P(new singleton challenger is born) = 1 - p.
```

More precisely, if the new vertex attaches to a vertex in cluster `K`, then with probability `p` it joins `K`, and with probability `1-p` it starts a new singleton cluster. Thus a new challenger is born with total probability `1-p`, independent of the parent cluster after summing over all possible parents.

For a fixed challenger `i`, while it exists,

```text
D_i(n+1) =
  D_i(n) + 1    with probability p R_n / n,
  D_i(n) - 1    with probability p C_i(n) / n,
  D_i(n)        otherwise,
```

ignoring the simultaneous birth of other clusters. The root remains a largest cluster through time `n` iff

```text
D_i(m) >= 0
```

for every challenger `i` and every time `m <= n`. Failure occurs exactly when some `D_i(m) < 0`.

The difficulty is that this one-dimensional deficit process is not Markov by itself, because its transition probabilities depend on both `R_n` and `C_i(n)`, not only on `D_i(n)`. The full process is infinite-dimensional because new challengers are born indefinitely for every `p < 1`. A valid central theorem would need a global comparison or martingale argument strong enough to control the maximum challenger cluster over all birth times.

I can give a plausible theorem shape, but not a proof meeting the requested standard.

A possible target theorem is:

> There exists a monotone parameter function or comparison process `Q_p` such that the event  
> `A_p = {for all n and all challengers i, C_i(n) <= R_n}`  
> has positive probability iff the associated deficit/challenger process is in its survival regime. Moreover, the survival region is an upper interval in `p`.

The monotonicity part is plausible through a natural coupling: assign each edge an independent uniform mark `U_e`; declare the edge open at parameter `p` iff `U_e <= p`. Then increasing `p` can only merge clusters relative to lower `p`. However, this does not immediately prove that the root-largest-forever event is increasing, because opening an edge outside the root cluster can also merge or enlarge a non-root cluster. So even monotonicity of `P(p)` is not automatic from simple edge inclusion. A proof would need a more delicate root-vs-challenger comparison.
