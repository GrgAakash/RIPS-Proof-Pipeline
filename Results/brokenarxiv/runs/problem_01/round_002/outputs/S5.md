## 1. Assignment Restatement

Prove the S5 large-\(p\) direction: using the S3 deficit/challenger theorem, show there is an explicit \(\eta<1\) such that for every \(p>\eta\), the root cluster has positive probability of never being strictly overtaken by any non-root cluster at any time.

Here “failure” means some non-root cluster becomes strictly larger than the root cluster; ties are allowed.

## 2. Subproof Or Failure

Assume the S3 deficit/challenger theorem supplies the following criterion.

**Deficit/challenger theorem.** There exists an explicit constant \(\eta<1\) such that, for every \(p>\eta\), with positive probability every challenger cluster born from a closed edge remains forever at deficit at least \(0\) relative to the root cluster. Equivalently, no non-root cluster ever becomes strictly larger than the root cluster. Moreover, the theorem handles all challenger clusters simultaneously, including infinitely many future challengers and tie states.

Then S5 is immediate but important to state cleanly.

Let \(R_n\) denote the size of the root cluster at time \(n\), and let
\[
M_n=\max\{|C|: C \text{ is a non-root percolation cluster present at time }n\}.
\]
The desired event is
\[
E=\{R_n\ge M_n \text{ for every } n\ge 1\}.
\]
Since ties are acceptable, the event excludes only strict overtake.

By the S3 theorem, for every \(p>\eta\),
\[
\mathbb P_p(E)>0.
\]
Therefore
\[
P(p)=\mathbb P_p(E)>0
\qquad\text{for every }p>\eta.
\]
Because \(\eta<1\), this proves the large-\(p\) half needed for the existence of a nontrivial critical threshold.

If an explicit numerical version is required, S3 may be instantiated with any valid extinction/survival inequality of the form
\[
q=1-p<q_0
\]
for some \(q_0>0\). Then one may take
\[
\eta=1-q_0<1.
\]
For example, if S3 proves the criterion under \(q<1/16\), then S5 gives
\[
P(p)>0 \qquad\text{for all } p>15/16.
\]

Thus S5 is solved conditionally on S3’s advertised theorem. No additional large-\(p\) argument is needed beyond verifying that S3’s event is exactly the eternal non-overtake event with ties allowed.
