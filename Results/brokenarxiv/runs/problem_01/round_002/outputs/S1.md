## 1. Assignment Restatement

Assigned S1 subproblem: derive the conditional transition law for cluster sizes in Bernoulli bond percolation on the naturally grown random recursive tree.

At time `n`, the recursive tree has vertices `{1,...,n}` with root vertex `1`. Vertex `n+1` attaches to a uniformly chosen parent in `{1,...,n}`. The new edge is retained with probability `p` and deleted with probability `1-p`, independently of the parent choice and past history.

We must state the induced Markov chain on cluster sizes, with the root cluster distinguished.

## 2. Subproof Or Failure

Let the state at time `n` be

```text
X_n = (R_n; M_n),
```

where:

- `R_n` is the size of the root cluster,
- `M_n` is the finite multiset of sizes of all non-root clusters,
- `R_n + sum_{s in M_n} s = n`.

Equivalently, write `A_n(k)` for the number of non-root clusters of size `k`. Then

```text
R_n + sum_{k >= 1} k A_n(k) = n.
```

Given `X_n = (r; A)`, the new vertex `n+1` first chooses a parent uniformly among the `n` existing vertices. Therefore the probability that the parent lies in a particular cluster is proportional to that cluster’s size.

There are three possible transition types.

1. Deleted edge.

With probability `1-p`, the edge from `n+1` to its parent is deleted. Then `n+1` forms a new singleton non-root cluster:

```text
(r; A) -> (r; A + e_1)
```

with probability

```text
1 - p.
```

2. Retained edge to the root cluster.

With probability `p`, the edge is retained. Conditional on retention, the parent lies in the root cluster with probability `r/n`. Then the root cluster grows by one:

```text
(r; A) -> (r+1; A)
```

with probability

```text
p r / n.
```

3. Retained edge to a non-root cluster of size `k`.

For each `k >= 1` with `A(k) > 0`, the parent lies in one of the non-root clusters of size `k` with probability `k A(k)/n`. If the edge is retained, that chosen cluster grows from size `k` to size `k+1`:

```text
(r; A) -> (r; A - e_k + e_{k+1})
```

with probability

```text
p k A(k) / n.
```

These probabilities sum to

```text
(1-p) + p r/n + p sum_{k >= 1} k A(k)/n
= (1-p) + p n/n
= 1.
```

Thus `(X_n)_{n >= 1}` is a time-inhomogeneous Markov chain on states `(r; A)` with total mass `n`, started from

```text
X_1 = (1; 0).
```

This transition law is exact and depends on the past only through the current distinguished root size and the multiset of non-root cluster sizes.

For deficit/challenger analysis, if `D_k = R_n - k` for a non-root cluster of size `k`, then:

- root increment increases every challenger deficit by `1`;
- retained growth of a challenger of size `k` decreases that challenger’s deficit by `1`;
- deleted edge creates a new challenger of size `1`, with initial deficit `R_n - 1`.

Failure of the root being largest occurs only when some challenger size becomes strictly larger than `R_n`, i.e. deficit `< 0`. A tie has deficit `0` and is not failure.
