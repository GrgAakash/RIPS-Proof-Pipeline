## 1. Assignment Restatement

Assigned S2 subproblem: define a deficit process for every non-root, or “challenger,” percolation cluster in the growing random recursive tree, and prove that the root cluster remains a largest cluster at every time exactly when every challenger deficit is nonnegative at every time. Ties are allowed, so deficit zero is still success.

## 2. Subproof or Failure

Let \(T_n\) be the recursive tree at time \(n\), rooted at vertex \(1\). Each edge is independently open with probability \(p\). Let \(\mathcal C_0(n)\) denote the open cluster containing the root at time \(n\), and let
\[
R_n := |\mathcal C_0(n)|.
\]

Every other open cluster is a challenger cluster. To index challengers unambiguously, assign each non-root cluster its birth time: when a vertex \(v\) is added and the edge connecting \(v\) to its parent is closed, \(v\) starts a new challenger cluster. If the edge is open, \(v\) joins an existing cluster and no new challenger is born.

For each challenger cluster \(i\), let \(b_i\) be its birth time and define its size at time \(n\) by
\[
C_i(n) :=
\begin{cases}
0, & n < b_i,\\
\text{size of challenger cluster } i \text{ at time } n, & n \ge b_i.
\end{cases}
\]
Because open clusters only grow by newly attached vertices and never merge with one another after birth, this indexing is persistent.

Define the deficit of challenger \(i\) at time \(n\) by
\[
D_i(n) := R_n - C_i(n).
\]

The root cluster remains a largest cluster at every time \(n\) precisely when
\[
R_n \ge C_i(n)
\]
for every challenger \(i\) and every time \(n\). By the definition of \(D_i(n)\), this condition is equivalent to
\[
D_i(n) \ge 0
\]
for every challenger \(i\) and every time \(n\).

Zero deficit corresponds exactly to a tie:
\[
D_i(n)=0 \iff R_n=C_i(n).
\]
Since the target event allows the root cluster to remain “a largest” cluster, ties are successful. Failure occurs only when some challenger becomes strictly larger than the root cluster, namely when
\[
C_i(n)>R_n \iff D_i(n)<0.
\]

Therefore the success event can be written as
\[
\mathcal S_p
=
\left\{
\forall n\ge 1,\ \forall i,\ D_i(n)\ge 0
\right\}.
\]
Equivalently,
\[
P(p)=\mathbb P_p(\mathcal S_p).
\]

This proves the requested equivalence.
