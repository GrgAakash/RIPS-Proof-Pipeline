Sketch of obstruction.

Fix \(p>0\). Let \(K\) be large. With probability \(p^{K-1}>0\), the first \(K-1\) edges are all open, so at time \(K\) the whole tree is the root cluster, of size \(K\), with no challengers.

Now consider any future non-root cluster born when the root cluster has size \(r\ge K\). Comparing only that cluster and the root, their embedded growth chain is a two-color Pólya urn started from \((r,1)\). If \(h_r\) is the probability that this challenger ever becomes strictly larger than the root, then the standard beta-mixture calculation gives

\[
h_r
\le 2^{-r}+r\int_{1/2}^1 \frac{(1-u)^r}{u}\,du
\le 2^{1-r}.
\]

If \(B_r\) is the number of new non-root clusters born while the root has size \(r\), then for \(K\) large enough that \(pr\ge2\),

\[
\mathbb E[B_r]\le \frac{2}{pr}\mathbb E[N_r],
\]

where \(N_r\) is the total tree size when the root first reaches size \(r\). The usual root-growth hazard bound gives

\[
\mathbb E[N_r]\le K\left(\frac rK\right)^{4/p}.
\]

Hence

\[
\mathbb E[\text{future overtaking clusters}\mid \text{first }K-1\text{ edges open}]
\le
\sum_{r\ge K}
\frac{2}{p}K^{1-4/p}r^{4/p-1}2^{1-r}.
\]

For \(K\) sufficiently large, this sum is \(<1\), for example once the exponential tail dominates the polynomial term. Therefore, conditional on the positive-probability initial open run, there is positive probability that no future challenger ever strictly overtakes the root. Thus \(P(p)>0\) for that \(p\).

Since \(p>0\) was arbitrary, the requested small-\(p\) almost-sure overtake conclusion is obstructed under the stated assumptions.
