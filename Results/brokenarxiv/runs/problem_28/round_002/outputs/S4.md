2. Subproof or failure

Assume the declared prerequisites. Let `V=V(C)` and `E=E(C)`. The barycentric subdivision has vertex set `V(B)=V disjoint_union E`; an edge-vertex `e in E` is adjacent in `B` to the two endpoints of the original edge `e`.

For an oriented edge `e`, write `t(e)` for its tail and `h(e)` for its head. Every `f in \ell^2(V(B))` decomposes uniquely as `f=x+a`, where `x in \ell^2(V)` is the old-vertex part and `a in \ell^2(E)` is the edge-vertex part. Define

```text
(Df)(v) = sum_{e: h(e)=v} a(e) - sum_{e: t(e)=v} a(e),      v in V,

(Df)(e) = x(t(e)) + i x(h(e)),                              e in E.
```

Equivalently, `D(x,a)=(partial a, R x)`, where `partial` is the signed divergence and `R x(e)=x(t(e))+i x(h(e))`.

This operator has range one on `B(C)`: at an old vertex it reads only adjacent edge-vertices, and at an edge-vertex it reads only the two adjacent old vertices. Its matrix coefficients are in `{0, +/-1, 1, i}`. Since `deg_C(v) <= d`,

```text
||partial a||_2^2 <= 2d ||a||_2^2,
||R x||_2^2 <= 2d ||x||_2^2.
```

Thus `D` is a bounded finite-range operator.

Now suppose `Df=0`. For every original edge `e`,

```text
x(t(e)) + i x(h(e)) = 0.
```

Hence `|x(t(e))|=|x(h(e))|`. Since `C` is connected, `|x(v)|` is constant over all old vertices. Since `C` is infinite and `x in \ell^2(V)`, this constant must be `0`; hence `x=0`. The remaining equations are exactly

```text
partial a(v)=0 for every v in V.
```

Conversely, if `x=0` and `a in \ell^2(E)` satisfies `partial a=0`, then `D(x,a)=0`. Therefore

```text
ker_{\ell^2} D = {0} direct_sum ker_{\ell^2}(partial),
```

where `ker(partial)` is the space of square-summable divergence-free edge flows.

It remains to compute its dimension. Use the old-vertex normalized trace on `C`. The edge space has dimension

```text
dim_C \ell^2(E) = m/2,
```

because the edge intensity per old vertex is `E deg_C(o)/2 = m/2`. Also

```text
dim_C \ell^2(V) = 1.
```

The adjoint of `partial` is the gradient

```text
partial^* y(e) = y(h(e)) - y(t(e)).
```

If `partial^* y=0`, then `y` is constant on the connected tree `C`. Since `C` is infinite and `y in \ell^2(V)`, this constant is `0`. Thus `ker partial^* = {0}`.

By the standard von Neumann dimension rank-nullity identity for bounded equivariant operators,

```text
dim_C closure(im partial^*) = dim_C \ell^2(V) - dim_C ker partial^* = 1.
```

Also, for bounded operators,

```text
\ell^2(E) = ker partial orthogonal_direct_sum closure(im partial^*).
```

Therefore

```text
dim_C ker partial = dim_C \ell^2(E) - dim_C closure(im partial^*)
                  = m/2 - 1.
```

Since `m>2`, this is strictly positive.

For the normalized barycentric root law, the total vertex intensity is `1 + m/2`. The projection onto `ker D` is zero on old vertices and equals the projection onto `ker partial` on edge-vertices. Hence

```text
dim_B ker D = (m/2 - 1) / (1 + m/2) > 0.
```

Equivalently, with old-vertex intensity normalization for the edge-flow module, the dimension is `m/2 - 1`.
