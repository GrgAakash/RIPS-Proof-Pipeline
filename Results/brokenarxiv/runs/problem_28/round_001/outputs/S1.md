2. Subproof or failure

Let `G` be the deterministic graph with vertex set

\[
V(G)=\mathbb Z\times\{0,1\}.
\]

Write \(b_n=(n,0)\) and \(a_n=(n,1)\). Add edges

\[
\{b_n,b_{n+1}\}\quad(n\in\mathbb Z),
\qquad
\{b_n,a_n\}\quad(n\in\mathbb Z).
\]

Thus \(G\) is the bi-infinite path on the vertices \(b_n\), with one pendant vertex \(a_n\) attached to each base vertex \(b_n\). Mark vertices by their second coordinate, so base vertices have type \(0\) and pendant vertices have type \(1\). Let the root \(o\) be random with

\[
\mathbb P(o=b_0)=\mathbb P(o=a_0)=\frac12.
\]

Equivalently, this is the stationary rooted version of the two-vertex fundamental domain repeated along \(\mathbb Z\).

The degrees are

\[
\deg(b_n)=3,\qquad \deg(a_n)=1,
\]

so the graph is bounded-degree, and

\[
\mathbb E \deg(o)=\frac12\cdot 3+\frac12\cdot 1=2<\infty.
\]

Now prove unimodularity. Let \(f(G,x,y)\ge 0\) be any Borel mass-transport function invariant under rooted network isomorphism. Since the marked graph is periodic under translations \(T_k(n,i)=(n+k,i)\), the value of \(f(G,x,y)\) depends only on the vertex types and the displacement along the \(\mathbb Z\)-coordinate. Define

\[
F_{ij}(m)=f(G,(0,i),(m,j)),
\qquad i,j\in\{0,1\},\ m\in\mathbb Z.
\]

Then

\[
\mathbb E\sum_{v\in V(G)} f(G,o,v)
=
\frac12\sum_{j=0}^1\sum_{m\in\mathbb Z}F_{0j}(m)
+
\frac12\sum_{j=0}^1\sum_{m\in\mathbb Z}F_{1j}(m).
\]

Similarly,

\[
\mathbb E\sum_{v\in V(G)} f(G,v,o)
=
\frac12\sum_{i=0}^1\sum_{m\in\mathbb Z} f(G,(m,i),(0,0))
+
\frac12\sum_{i=0}^1\sum_{m\in\mathbb Z} f(G,(m,i),(0,1)).
\]

By translation invariance,

\[
f(G,(m,i),(0,j))=f(G,(0,i),(-m,j))=F_{ij}(-m).
\]

Since summing over \(m\in\mathbb Z\) is unchanged by \(m\mapsto -m\), the two expected totals are equal. Hence the Mass-Transport Principle holds, so \((G,o)\) is unimodular.

Now prove amenability by explicit Følner sets. For \(N\ge 1\), set

\[
K_N=\{b_n,a_n:-N\le n\le N\}.
\]

Then

\[
|K_N|=2(2N+1).
\]

The only edges from \(K_N\) to its complement are the two base-spine edges

\[
\{b_{-N-1},b_{-N}\},\qquad \{b_N,b_{N+1}\}.
\]

Thus the edge boundary satisfies

\[
|\partial_E K_N|=2.
\]

Therefore

\[
\frac{|\partial_E K_N|}{|K_N|}
=
\frac{2}{2(2N+1)}
=
\frac1{2N+1}
\to 0.
\]

These Følner sets exhaust the graph along the one-dimensional base. Since the rooted network is deterministic up to the finite root choice and the same Følner sequence works for the underlying graph, the unimodular random rooted network is amenable.

This proves the assigned subclaim.
