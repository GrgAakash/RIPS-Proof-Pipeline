1. Target Decomposition

target_label:
Existence theorem for delocalized positive von Neumann eigenspace

target_type:
Existential construction

main_goal:
Construct an amenable unimodular random rooted network with finite expected degree and a finite-range operator `D` having a positive von Neumann dimension eigenspace, while excluding all finitely supported eigenfunctions almost surely.

variables_and_parameters:
- Random rooted network `(G,o)`
- Finite-range operator `D`
- Eigenvalue `lambda in C`
- Von Neumann dimension `dim_G ker(D-lambda)`

conclusion_to_prove:
There exist `(G,o)`, `D`, and `lambda` such that:
1. `(G,o)` is amenable and unimodular.
2. `E deg(o) < infinity`.
3. `D` has finite range.
4. `dim_G ker(D-lambda) > 0`.
5. Almost surely, every `lambda`-eigenfunction of `D` on `G` has infinite support.

4. Hardest Step Prediction

hardest_step_id:
SC4 and SC5 jointly

hardest_step_description:
The construction must leave a positive von Neumann dimension eigenspace while simultaneously making every nonzero eigenfunction delocalized. These requirements pull in opposite directions: too much local freedom creates finitely supported eigenfunctions, while too much coupling can destroy the positive-dimensional eigenspace.

risk_if_wrong:
If the local recurrence is not designed carefully, either the eigenspace may have zero von Neumann dimension, or finitely supported eigenfunctions may survive inside finite decorations.

how_final_proof_should_handle_it:
The final proof should explicitly write the eigenvalue equations, solve the recurrence, and separately prove:
1. a positive expected projection trace, by identifying a positive-density family of independent square-summable eigenvectors or an invariant positive-dimensional solution space;
2. unique continuation from finite support, showing that vanishing outside a finite region forces vanishing everywhere.

6. Subproblem Assignment Table

S1:
Construct the bounded-degree unimodular random rooted network. Prove unimodularity using the Mass-Transport Principle and prove amenability using explicit Følner sets along the one-dimensional base. Also verify finite expected degree.

S2:
Define the finite-range operator `D` and eigenvalue `lambda`. Derive the exact local eigenvalue equations and reduce them to a recurrence or constraint system along the base.

S3:
Prove that the `lambda`-eigenspace has strictly positive von Neumann dimension. Compute or lower-bound `E <P_lambda delta_o, delta_o>` using the explicit solution space from S2.

S4:
Prove the unique-continuation/delocalization lemma: any `lambda`-eigenfunction satisfying the local equations and vanishing outside a finite set must vanish identically.

S5:
Assemble the construction. Combine S1-S4 to conclude the theorem exactly as stated, checking that the no-finite-support statement holds almost surely for every `lambda`-eigenfunction.
