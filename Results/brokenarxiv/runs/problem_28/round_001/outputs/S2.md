2. Subproof or failure

Assume the declared SC1 cell structure. Let the state vector in cell `n` be

`F_n = (f(a_n), f(b_n))^T`.

Define `lambda = 0`. Define `D` on functions `f` on vertices by

```text
(Df)(a_n) = f(a_{n+1}) - f(a_n) - f(b_n),
(Df)(b_n) = f(b_{n+1}) - f(a_n) - 2 f(b_n).
```

Equivalently,

```text
(Df)_n = F_{n+1} - A F_n,
A = [[1, 1],
     [1, 2]].
```

This is finite-range: `(Df)(a_n)` and `(Df)(b_n)` use only values in cells `n` and `n+1`, hence only uniformly bounded graph distance from the output vertex under the SC1 adjacency interface.

The `0`-eigenvalue equation is `Df=0`, so for every `n in Z`,

```text
f(a_{n+1}) = f(a_n) + f(b_n),
f(b_{n+1}) = f(a_n) + 2 f(b_n).
```

Thus the local eigenvalue equations reduce exactly to the first-order transfer recurrence

```text
F_{n+1} = A F_n.
```

Since

```text
det(A) = 1*2 - 1*1 = 1,
```

`A` is invertible, and the same equations may also be propagated backward:

```text
F_n = A^{-1} F_{n+1},
A^{-1} = [[2, -1],
          [-1, 1]].
```

Therefore the assigned SC3 reduction is proved: the finite-range operator and eigenvalue are explicit, and the eigenfunction equation is precisely a local linear recurrence along the base.
