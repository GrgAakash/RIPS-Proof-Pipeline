\[
-v_{tt}-\Delta_{S^{N-1}}v+a^2v=v^p
\quad\text{on }\mathbb R\times S^{N-1}.
\]
The radial homoclinic profile satisfies
\[
-V''+a^2V=V^p,
\]
and S3 gives the explicit profile
\[
V(t)=A\cosh(q(t-t_0))^{-2/(p-1)},
\qquad
A^{p-1}=\frac{a^2(p+1)}2.
\]
For spherical harmonic degree \(\ell\), with
\[
\lambda_\ell=\ell(\ell+N-2),
\]
the linearized angular equation is
\[
-\phi''+(a^2+\lambda_\ell)\phi-pV^{p-1}\phi=0.
\]
The conditional Pöschl-Teller computation supplied by S3 shows that a bounded nonradial zero mode can occur only when
\[
\sqrt{a^2+\lambda_\ell}=a+q.
\]
Since
\[
a^2+\lambda_\ell=(\ell+a)^2,
\]
this implies
\[
\ell=q=\frac{\alpha+2}{2}.
\]
Thus, conditional on the missing rigidity lemma that every nonradial positive decaying solution forces such a bounded nonradial zero mode, one obtains
\[
\alpha=2(\ell-1),
\]
with \(\ell\in\mathbb N\).

The proof blocks at two exact points:

1. Necessity obstruction: no supplied or proved result establishes that an arbitrary nonradial positive decaying cylinder solution must generate a nonzero bounded angular zero mode of the linearized operator about the radial homoclinic.
