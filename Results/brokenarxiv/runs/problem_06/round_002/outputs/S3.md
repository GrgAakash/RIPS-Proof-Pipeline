2. Subproof or failure

I can prove the geometry under the required construction-side interface condition:

For `lambda_k`-almost every rooted diagram `(Gamma,o)`, the underlying non-loop graph has a finite connected core `C` such that `Gamma \ C` has exactly `k` infinite connected components `B_1,...,B_k`, with no edges between distinct `B_i`, and each `B_i` is one-ended. Finite caps and finite decorations may be attached inside the `B_i`.

This is the exact geometric fact that C2/C3 must supply from the finite approximants.

Use the standard definition: an end of a connected locally finite graph is an equivalence class of proper rays, where two rays are equivalent if, after deleting any finite vertex set, their tails eventually lie in the same component.

First, finite decorations do not create ends. More concretely, if a ray or one-ended canopy branch has finite graphs attached along its vertices, then after deleting any finite vertex set, all sufficiently far branch vertices remain in a single infinite tail component; every other remaining component is contained in finitely many finite decorations plus a finite initial segment, hence is finite. Thus the decorated branch is still one-ended. Loops and labels are also end-neutral: loops do not connect distinct vertices, and labels/orientations do not affect the underlying connected components used in the definition of ends.

Now fix a `lambda_k`-typical graph satisfying the interface condition. It is locally finite because the Schreier diagrams have a fixed finite label set, so vertex degree is uniformly bounded up to loops/multiplicity. It is connected because the finite core is connected and every `B_i` attaches to it. It is infinite because each `B_i` is infinite.

There are at least `k` ends: choose one proper ray in each `B_i`. Since the finite core `C` separates the `B_i`, rays lying in different `B_i` are not equivalent.

There are at most `k` ends: every proper ray eventually avoids the finite set `C`, so its tail lies in one component `B_i`; since `B_i` is one-ended, all rays eventually contained in the same `B_i` define the same end.

Therefore every graph in this limiting k-canopy class has exactly `k` ends. Hence, once C2/C3 establish that `lambda_k` is supported on this class, `lambda_k`-almost surely the graph is infinite, locally finite, connected, and has exactly `k` ends.
