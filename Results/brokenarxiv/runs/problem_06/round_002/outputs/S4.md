**1. Assignment restatement**

Prove only the stabilizer-map step: from a stationary probability law `lambda_k` on rooted Schreier diagrams over `G`, define `nu = Stab_* lambda_k` on `Sub(G)`, show the stabilizer map is Borel, show re-rooting corresponds to conjugation, and conclude `nu` is `mu`-stationary.

**2. Subproof or failure**

Let `G` be countable and generated by a finite symmetric set `S`. A rooted Schreier diagram over `G` means a connected rooted labelled graph `(X,o)` in which each label `s in S` defines a bijection `v -> v·s` of the vertex set, the labels satisfy the defining relations of `G`, and hence every `g in G` acts on vertices by choosing any word in `S` representing `g`.

Define

```text
Stab(X,o) = { g in G : o·g = o }.
```

This is a subgroup of `G`: the identity fixes `o`; if `g,h` fix `o`, then `o·gh = (o·g)·h = o·h = o`; and if `g` fixes `o`, then `o = o·g`, so applying `g^{-1}` gives `o·g^{-1} = o`.

Now show Borel measurability. Since `G` is countable discrete, the Chabauty space `Sub(G)` is naturally a closed subspace of `{0,1}^G`, with Borel structure generated by the coordinate membership sets

```text
U_g = { H in Sub(G) : g in H }.
```

It is therefore enough to show that `Stab^{-1}(U_g)` is Borel for each fixed `g in G`.

Choose a word `w = s_1 ... s_m` over `S` representing `g`. Then

```text
Stab(X,o) contains g  iff  o·s_1...s_m = o.
```

This condition is determined by the finite rooted labelled ball of radius `m` around `o`. Hence it is a cylinder condition in the usual local topology on rooted labelled diagrams, so it is clopen, in particular Borel. Thus `Stab` is Borel.

Next prove equivariance. For `a in G`, let `a.(X,o)` denote the same labelled diagram re-rooted at `o·a`. Then

```text
Stab(a.(X,o))
= { g in G : (o·a)·g = o·a }
= { g in G : o·aga^{-1} = o }
= a^{-1} Stab(X,o) a.
```

Equivalently, if the conjugation action on subgroups is written as `g.H = gHg^{-1}`, then re-rooting at `o·a^{-1}` corresponds to conjugation by `a`:

```text
Stab(a^{-1}.(X,o)) = a Stab(X,o) a^{-1}.
```

This is only a convention issue depending on whether the rooted diagram action is written as right re-rooting by `a` or by `a^{-1}`. For the Schreier graphs in the target theorem, vertices are right cosets `H\G` and edges are `Hg -> Hgs`, so the compatible formula is:

```text
Stab(rooted at Ha) = a^{-1}Ha.
```

Therefore conjugation by `a`, namely `H -> aHa^{-1}`, corresponds to re-rooting the Schreier diagram at `Ha^{-1}`.

Now assume `lambda_k` is `mu`-stationary for the rooted-diagram re-rooting convention compatible with the above formula, namely

```text
lambda_k = sum_{a in G} mu(a) (a.lambda_k),
```

where `a` acts by the re-rooting whose stabilizer is conjugated as `H -> aHa^{-1}`. Let `nu = Stab_* lambda_k`. For every Borel set `B subset Sub(G)`,

```text
nu(B)
= lambda_k(Stab^{-1}(B))
= sum_a mu(a) lambda_k(a^{-1} Stab^{-1}(B))
= sum_a mu(a) lambda_k(Stab^{-1}(a^{-1}.B))
= sum_a mu(a) (a.nu)(B).
```

Thus

```text
nu = sum_{a in G} mu(a) (a.nu),
```

so `nu` is a `mu`-stationary random subgroup of `G`.
