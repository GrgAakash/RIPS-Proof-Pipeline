1. Assignment Restatement

Solve only D/E: given an already constructed bounded-degree stationary rooted graphing with exactly \(k\) ends, add a non-atomic stationary decoration and realize it as a rooted Schreier diagram over finitely many involutive generators. I do not prove the canopy construction or its stationarity.

2. Subproof Or Failure

Assume the input is a law \(P\) on rooted connected infinite graphs \((X,o)\), degree \(\leq \Delta\), with exactly \(k\) ends a.s., and assume \(P\) is stationary for a finite involutive root-moving presentation
\[
\tau_1,\ldots,\tau_m,\qquad \tau_i^2=\mathrm{id},
\]
with probabilities \(p_i>0\), \(\sum p_i=1\). Each \(\tau_i(v)\) is either \(v\) or a neighbor of \(v\), and the non-loop \(\tau_i\)-edges generate the connected graph.

Then label \(\tau_i\) by an involutive generator \(a_i\). This gives a Schreier diagram for
\[
G_0=\ast_{i=1}^m C_2
\]
with measure \(\mu_0(a_i)=p_i\). Stationarity is exactly the assumed identity
\[
(X,o)\stackrel{d}= (X,\tau_I(o)),\qquad \mathbb P(I=i)=p_i.
\]
Adding missing \(a_i\)-loops only records fixed points of \(\tau_i\), so it does not change connected components after deleting finite vertex sets; hence it preserves the number of ends.

Now add a finite Schreier decoration. For each base vertex \(v\), sample an independent bit \(\epsilon_v\in\{0,1\}\). Replace \(v\) by a two-point fibre \(\{(v,0),(v,1)\}\). Choose the root \((o,J)\), where \(J\) is uniform on \(\{0,1\}\), independent of everything. Define involutions
\[
a_i(v,j)=(\tau_i v,j),
\]
and add two more involutive generators \(u,t\):
\[
u(v,j)=(v,1-j),
\]
\[
t(v,j)=
\begin{cases}
(v,j), & \epsilon_v=0,\\
(v,1-j), & \epsilon_v=1.
\end{cases}
\]
Thus the decorated diagram is a Schreier diagram for
\[
G=\Big(\ast_{i=1}^m C_2\Big)\ast C_2\ast C_2.
\]
Take any \(\alpha,\beta,\gamma>0\) with \(\alpha+\beta+\gamma=1\), and set
\[
\mu(a_i)=\alpha p_i,\qquad \mu(u)=\beta,\qquad \mu(t)=\gamma.
\]

Stationarity holds. The \(a_i\)-part preserves the law by base stationarity and independence of the iid bits. The \(u\)-move preserves the law because \(J\) is uniform. The \(t\)-move also preserves the law because, conditional on the bit field, \(J\mapsto J\oplus\epsilon_o\) preserves the uniform law. Therefore the full \(\mu\)-mixture is stationary.

The decoration is non-atomic. Fix the ordered word list in the base labels \(a_1,\ldots,a_m\), say shortlex order. From any rooted labelled diagram, this gives a canonical enumeration of base vertices reached from the root, ignoring repeats. Since the base graph is infinite, this list is infinite. The final labelled diagram reveals \(\epsilon_v\) at each enumerated base vertex by comparing the \(t\)-edge with the \(u\)-edge. For any fixed rooted decorated Schreier diagram, matching it forces an infinite prescribed iid bit sequence, which has probability
\[
\lim_{n\to\infty}2^{-n}=0.
\]
So the decorated Schreier law has no atoms.

Ends are preserved. The projection
\[
(v,j)\mapsto v
\]
is a finite-fibre quasi-isometry: base moves change only \(v\), while \(u\) changes only the fibre coordinate. The \(t\)-edges are loops or parallel vertical fibre edges. Finite-fibre quasi-isometries of connected locally finite graphs preserve ends; equivalently, deleting a finite set upstairs corresponds, up to finite error, to deleting its finite projection downstairs. Hence the decorated Schreier graph has exactly \(k\) ends a.s.

If the input is only an unlabelled bounded-degree graphing, one still needs a finite measurable proper edge-colouring to obtain the involutions \(\tau_i\). For a countable graph of degree \(\Delta\), \(2\Delta-1\) colours suffice by the standard greedy/compactness edge-colouring argument. For a measurable random graphing, the required measurable version is a standard Borel edge-colouring theorem; without either that theorem or an explicit colouring from the canopy construction, this interface is unsupported.
