2. Subproof or failure

Let \(S=S_k\) be a finite symmetric alphabet and let \(F=F(S)\). A rooted \(S\)-Schreier diagram means a rooted labelled directed graph \((\Gamma,o)\) in which every vertex has exactly one outgoing and one incoming edge labelled by each \(s\in S\), and the edge labelled \(s^{-1}\) is inverse to the edge labelled \(s\). Thus each \(s\in S\) defines a bijection \(T_s\) of the vertex set, with \(T_{s^{-1}}=T_s^{-1}\). Hence every word \(w=s_1\cdots s_n\) defines
\[
x\cdot w=T_{s_n}\cdots T_{s_1}(x),
\]
and this descends to a right action of \(F\) on the vertices because the only relations in \(F(S)\) are cancellation of adjacent inverse letters.

Define
\[
\Phi(\Gamma,o)=\operatorname{Stab}_F(o)=\{w\in F:o\cdot w=o\}.
\]
This is a subgroup of \(F\). Indeed, the identity fixes \(o\). If \(u,v\in \Phi(\Gamma,o)\), then
\[
o\cdot uv=(o\cdot u)\cdot v=o\cdot v=o.
\]
If \(u\in \Phi(\Gamma,o)\), then \(o\cdot u=o\), so applying \(u^{-1}\) gives \(o=o\cdot uu^{-1}=(o\cdot u)\cdot u^{-1}=o\cdot u^{-1}\). Thus \(u^{-1}\in\Phi(\Gamma,o)\).

Now equip the rooted Schreier diagram space with the usual local rooted topology: a basic cylinder records the finite rooted labelled ball of some radius. Equip \(\operatorname{Sub}(F)\) with the Chabauty topology for a countable discrete group, equivalently the subspace topology inherited from \(\{0,1\}^F\) by identifying a subgroup \(K\) with its indicator function \(1_K\).

To prove \(\Phi\) is Borel, it is enough to prove that for every \(a\in F\), the coordinate set
\[
\{(\Gamma,o):a\in \Phi(\Gamma,o)\}
\]
is Borel. Choose the reduced word \(a=s_1\cdots s_n\). Then
\[
a\in \Phi(\Gamma,o)
\]
holds exactly when the path beginning at \(o\) and following labels \(s_1,\dots,s_n\) ends at \(o\). This condition is determined by the rooted labelled ball of radius \(n\). Therefore the above coordinate set is a finite-radius cylinder, hence Borel, in fact clopen. Since \(F\) is countable and the coordinate maps generate the Borel structure on \(\operatorname{Sub}(F)\subseteq \{0,1\}^F\), \(\Phi\) is Borel.

Finally let \(g\in F\). Reroot \((\Gamma,o)\) at \(o\cdot g\). Then for any \(h\in F\),
\[
h\in \Phi(\Gamma,o\cdot g)
\]
if and only if
\[
(o\cdot g)\cdot h=o\cdot g.
\]
Using the right action law, this is equivalent to
\[
o\cdot gh=o\cdot g,
\]
and after applying \(g^{-1}\) on the right, equivalent to
\[
o\cdot ghg^{-1}=o.
\]
Thus
\[
h\in \Phi(\Gamma,o\cdot g)
\quad\Longleftrightarrow\quad
ghg^{-1}\in \Phi(\Gamma,o),
\]
which means
\[
\Phi(\Gamma,o\cdot g)=g^{-1}\Phi(\Gamma,o)g.
\]

This is precisely the right-coset convention. If \(\Gamma\) is the Schreier graph of right cosets \(H\backslash F\), rooted at \(H\), with edges \(Hx\to Hxs\), then
\[
\Phi(\Gamma,H)=\{w:Hw=H\}=H.
\]
If the same graph is rerooted at \(Hg\), then its stabilizer is
\[
\{h:Hgh=Hg\}=g^{-1}Hg.
\]
So rerooting by right multiplication by \(g\) corresponds to conjugation by \(g^{-1}\), not by \(g\), under the convention \(a.K=aKa^{-1}\).
