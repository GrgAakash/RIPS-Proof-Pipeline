2. Subproof or failure

Let \(u,v:F_*S\to T\) be ring homomorphisms satisfying
\[
u\circ F_{S/R}=v\circ F_{S/R}.
\]

For \(r\in R\), consider the element \(r\otimes 1\in F_*R\otimes_R S\). By the defining formula for the relative Frobenius,
\[
F_{S/R}(r\otimes 1)=f(r)\cdot 1^p=f(r)
\]
inside the underlying ring \(F_*S\). Hence
\[
u(f(r))
=
u(F_{S/R}(r\otimes 1))
=
v(F_{S/R}(r\otimes 1))
=
v(f(r)).
\]
Thus \(u\) and \(v\) agree on \(f(R)\).

Define
\[
h:R\to T,\qquad h(r)=u(f(r)).
\]
This is a ring homomorphism because it is the composite
\[
R\xrightarrow{f}S=F_*S\xrightarrow{u}T.
\]
The preceding equality also gives \(h(r)=v(f(r))\) for all \(r\in R\), so the same \(R\)-algebra structure on \(T\) is obtained from \(v\).

Now view \(u\) and \(v\) as ring maps \(S\to T\), using that \(F_*S\) has the same underlying ring as \(S\). For every \(r\in R\),
\[
u(f(r))=h(r),
\]
so \(u:S\to T\) is an \(R\)-algebra homomorphism with respect to \(h\). Similarly,
\[
v(f(r))=h(r),
\]
so \(v:S\to T\) is also an \(R\)-algebra homomorphism with respect to the same \(R\)-algebra structure \(h\) on \(T\).

This proves C3.
