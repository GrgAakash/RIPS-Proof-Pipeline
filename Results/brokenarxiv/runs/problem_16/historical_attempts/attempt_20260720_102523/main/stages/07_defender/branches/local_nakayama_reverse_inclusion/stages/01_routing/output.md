1. **Target Normalization**

Prove the standalone inclusion:

For finite Galois `L/F` with `D = Gal(L/F)` and finite free `Z[D]`-lattice `Y`, the valuation map
`nu_L : (Y tensor_Z L^x)^D -> Y^D`
has image contained in
`sum_{H <= D} e(L/L^H) N_{D/H}(Y^H)`,

where `N_{D/H}(y) = sum_{sigma in D/H} sigma y`.

Equivalent normalized form for the solver: if `a in Y^D` is the valuation of a `D`-fixed element of `Y tensor L^x`, then `a` must be generated by norm-traces from subgroup-fixed lattices, with ramification-index coefficients.

2. **Task-Adaptive Proof Obligations**

The Main Solver should prove:

- The valuation sequence induces an exact sequence of `D`-modules  
  `0 -> Y tensor O_L^x -> Y tensor L^x -> Y -> 0`.
- The target image equals the kernel of a connecting map  
  `delta : Y^D -> H^1(D, Y tensor O_L^x)`.
- There is a purely internal, non-Tate-Nakayama argument identifying this kernel as contained in the subgroup generated by  
  `e(L/L^H) N_{D/H}(Y^H)`.
- Any use of cohomology must be reduced to explicit cocycles/coboundaries and Hilbert 90, since the target theorem or equivalent valuation-image theorem is disallowed.

3. **Available Tools**

Allowed:

- Definitions of finite Galois extensions of nonarchimedean local fields.
- Fixed fields `L^H`, ramification index `e(L/L^H)`.
- `D`-lattices and tensor notation.
- Local valuation exact sequence  
  `1 -> O_L^x -> L^x -> Z -> 0`.
- Basic Hilbert 90 for finite Galois extensions.
- Standard group action, restriction, corestriction/trace notation if proved or explicitly unpacked.
- Standard finite abelian group/module manipulations.

Not allowed:

- Tate-Nakayama.
- Nakayama valuation image theorem.
- Any equivalent transfer-generation theorem unless proved inside the branch.
