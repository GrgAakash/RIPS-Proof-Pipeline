1. Target decomposition

target_label:
torus_local_global_compact_decomposition

target_type:
theorem

main_goal:
Show every element of `T(Q_p)` differs from an element of `T(Q)` by an element of the maximal compact subgroup `T(Z_p)`.

variables_and_parameters:
`T`: algebraic torus over `Q`; `p`: prime number. In the proof choose a finite Galois splitting field `K/Q`, a place `w|p`, `G = Gal(K/Q)`, `D = Gal(K_w/Q_p)`, and character lattice `X = X^*(T_K)`.

conclusion_to_prove:
`T(Q_p) = T(Z_p)T(Q)`.

4. Hardest step prediction

hardest_step_id:
C4

hardest_step_description:
Proving equality of the global and local valuation images while retaining the hypothesis that the element of `Hom_D(X,Z)` actually comes from a local point in `Hom_D(X,K_w^*)`.

risk_if_wrong:
A tempting but invalid shortcut is to claim that `Hom_D(X,K_w^*) -> Hom_D(X,Z)` is always surjective. This fails in ramified splitting fields, already for `G_m` if `K_w/Q_p` is ramified.

how_final_proof_should_handle_it:
Start with a locally lifted valuation class. Prove directly that this class has a global equivariant lift with the same `w`-valuation, using the finite Galois setup, equivariance, and number-field approximation. The final proof must not cite C4 as external or prove a stronger surjectivity statement.

5. Failure-mode checks

circularity_check:
Do not use the target theorem, weak approximation for tori modulo compact subgroups, or any equivalent torus factorization as an input.

full_theorem_check:
The proof must handle every algebraic torus over `Q`, every prime `p`, and every element of `T(Q_p)`.

source_check:
No formal prior skeleton theorem is available. Only definitions, notation, standard background, and the explicitly proved current-proof subclaims may be used.

hypothesis_check:
The valuation-image equality must be proved only for valuation classes arising from local points in `Hom_D(X,K_w^*)`.

notation_check:
`T(Z_p)` means maximal compact subgroup of `T(Q_p)`, not necessarily points of a prechosen integral model unless that identification is proved.

standard_background_check:
Character lattices, Galois descent for split tori, normalized local valuations, and weak approximation for number fields are acceptable standard background. The key valuation-image equality is not standard background for this run and must be proved.

6. Subproblem assignment table

S1:
Establish the finite Galois splitting setup and prove the identifications `T(Q)=Hom_G(X,K^*)` and `T(Q_p)=Hom_D(X,K_w^*)`.

S2:
Prove that `T(Z_p)` equals the kernel of the valuation map `Hom_D(X,K_w^*) -> Hom_D(X,Z)`.

S4:
Prove the valuation-image equality in the exact setup from the guidance:
`im(Hom_G(X,K^*) -> Hom_D(X,Z)) = im(Hom_D(X,K_w^*) -> Hom_D(X,Z))`.

S5:
Assemble C1-C4 into the final decomposition argument, checking both inclusions and avoiding any stronger surjectivity claim.
