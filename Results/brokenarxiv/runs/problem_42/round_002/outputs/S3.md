**1 Assignment Restatement**

S3 proves SC4:

Assume `R` is an atomic integral domain and has IDF. For every nonzero nonunit `a`, prove `a` has only finitely many factorizations into atoms, up to order and associates. The proof must not assume atoms are prime.

**2 Subproof Or Failure**

Let `a` be a fixed nonzero nonunit of `R`.

By IDF, `a` is divisible by only finitely many atoms up to associates. Choose representatives

```text
p_1, ..., p_n
```

for the associate classes of atoms dividing `a`.

Since `R` is atomic, `a` has at least one factorization into atoms. In any atom factorization

```text
a = u q_1 ... q_m
```

with `u` a unit and each `q_j` an atom, every `q_j` divides `a`, because

```text
a = q_j (u q_1 ... q_{j-1} q_{j+1} ... q_m).
```

Therefore each `q_j` is associate to exactly one of the finitely many representatives `p_i`. Hence every factorization of `a`, up to order and associates, determines an exponent vector

```text
(e_1, ..., e_n) in N^n
```

such that

```text
a is associate to p_1^{e_1} ... p_n^{e_n}.
```

It remains to prove that only finitely many such exponent vectors can occur.

Suppose for contradiction that infinitely many exponent vectors occur. Let

```text
E = { e in N^n : a is associate to p^e }
```

where `p^e := p_1^{e_1} ... p_n^{e_n}`.

We use the standard Dickson lemma: every infinite subset of `N^n` contains two distinct vectors `e, f` with `e_i <= f_i` for all `i`. For completeness, this is a standard elementary well-quasi-ordering fact, proved by induction on `n`.

Thus choose distinct `e, f in E` with `e <= f` componentwise. Since both occur,

```text
p^e is associate to a
p^f is associate to a.
```

So `p^e` is associate to `p^f`. Hence for some unit `u`,

```text
p^f = u p^e.
```

Because `e <= f`, write `f = e + d`, where `d in N^n` and `d != 0`. Then

```text
p^e p^d = u p^e.
```

Since `R` is an integral domain and `p^e != 0`, cancellation gives

```text
p^d = u.
```

But `d != 0`, so `p^d` is a nonempty product of atoms. A nonempty product of nonunits cannot be a unit in an integral domain: if `xy` is a unit, then both `x` and `y` are units, and induction gives the claim. This contradicts that atoms are nonunits.

Therefore `E` is finite.

Each factorization of `a` up to order and associates corresponds to exactly one exponent vector in `E`, and each exponent vector gives at most one such unordered associate-class factorization. Hence `a` has only finitely many atom factorizations up to order and associates.

Thus, under IDF and atomicity, every nonzero nonunit has finitely many atom factorizations.
