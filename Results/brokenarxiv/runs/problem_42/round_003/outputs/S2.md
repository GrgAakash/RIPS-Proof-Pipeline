**1. Claim**

If `R` is an FFD, then `R` has the IDF property.

**2. Inputs Used**

Definitions from the target statement only:

- FFD: every nonzero nonunit has at least one and at most finitely many atom factorizations, up to order and associates.
- IDF: every nonzero element is divisible by only finitely many atoms up to associates.
- Atom: nonzero nonunit irreducible element.

**3. Proof**

Let `x` be a nonzero element of `R`.

If `x` is a unit, then no atom can divide `x`: if `x = py` with `p` an atom, then multiplying by `x^{-1}` gives `1 = p(yx^{-1})`, so `p` is a unit, contradiction. Thus `x` has zero atom divisors.

Now suppose `x` is a nonzero nonunit. Since `R` is an FFD, `x` has finitely many factorizations into atoms, up to order and associates.

Let `p` be any atom dividing `x`. Then `x = py` for some `y ∈ R`. Since `x ≠ 0` and `R` is a domain, `y ≠ 0`.

If `y` is a unit, then `x = py` is already a factorization of `x`, and `p` appears in it.

If `y` is a nonzero nonunit, then by the FFD property, `y` has a factorization into atoms, say

```text
y = q1 ... qn.
```

Hence

```text
x = p q1 ... qn
```

is a factorization of `x` into atoms, and `p` appears in it.

Therefore every atom divisor of `x` appears, up to associates, among the atoms occurring in one of the finitely many factorizations of `x`. Each factorization has finite length, and there are only finitely many such factorization classes. Hence only finitely many atom associate classes can divide `x`.

Thus every nonzero `x ∈ R` is divisible by finitely many atoms up to associates, so `R` is IDF.

**4. Obstruction Check**

No use is made of “atom divides product implies associate to a factor.” The argument instead builds an actual factorization of `x` containing the chosen atom divisor `p`.
