Let \(R\) be an integral domain with the definitions stated in the target
theorem.

The forward implication is available. If \(R\) is an FFD, then every nonzero
nonunit has a factorization into atoms, and units are atomic by definition.
Thus \(R\) is atomic. Hence \(R\) is almost atomic by taking the multiplier
\(s=1\). Also, for any nonzero \(x\), every atom divisor of \(x\) occurs in
some factorization of \(x\); since an FFD has only finitely many factorization
classes of \(x\), only finitely many atom classes can divide \(x\). Therefore
\(R\) is IDF.

The auxiliary fact from S3 is also available: in an IDF domain, any fixed
atomic element has only finitely many factorizations. Indeed, all atoms
appearing in factorizations of a fixed atomic element \(x\) must lie among the
finitely many atom-divisor classes of \(x\). Distinct exponent vectors among
these classes cannot be infinite, since Dickson's lemma would give
\(\alpha \leq \beta\), and cancellation would force a nonempty product of
atoms to be a unit, impossible in a domain.

However, the reverse implication remains unproved. The available conditional
argument is:

\[
\text{IDF} + \text{almost atomic} + \text{length-one clearing lemma}
\Longrightarrow \text{atomic}.
\]

Given nonzero \(r\), almost atomicity gives an atomic \(s\) such that \(rs\)
is atomic. If \(s\) is a unit, then \(r\) is atomic. If
\(s=p_1\cdots p_n\) is a product of atoms, one would need to remove the atoms
\(p_n,\ldots,p_1\) one at a time. Each removal is exactly the missing lemma:
from \(hp\) atomic with \(p\) an atom, conclude \(h\) atomic.

Since that lemma is not proved in the packet, the reverse implication cannot
be completed here.
