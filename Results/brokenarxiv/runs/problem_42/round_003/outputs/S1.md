## 1. Claim
If `R` is an FFD, then `R` is atomic and almost atomic.

## 2. Inputs Used
Definitions from the target statement only:

- Atomic element: a unit or a finite product of atoms.
- Atomic domain: every nonzero element is atomic.
- Almost atomic: for each nonzero `r in R`, there exists an atomic `s in R` such that `rs` is atomic.
- FFD: every nonzero nonunit has at least one factorization into atoms.

## 3. Proof
Assume `R` is an FFD.

Let `r in R` be nonzero.

If `r` is a unit, then `r` is atomic by definition.

If `r` is a nonunit, then since `R` is an FFD, `r` has at least one factorization into atoms. Hence `r` is atomic.

Therefore every nonzero element of `R` is atomic, so `R` is an atomic domain.

Now prove almost atomicity. For any nonzero `r in R`, choose `s = 1`. Since `1` is a unit, `1` is atomic. Also `rs = r`, and we already proved every nonzero `r` is atomic. Hence for every nonzero `r`, there exists an atomic `s`, namely `1`, such that `rs` is atomic.

Thus `R` is almost atomic.

## 4. Dependencies
This proof does not use IDF, cancellation, primality, or any factor-divisibility argument. It uses only the existence part of the FFD definition.
