**1. S4 Verdict**

**2. Lemma Under Test**

Claim: if `R` is IDF and almost atomic, `p` is an atom, and `hp` is atomic, then `h` is atomic.

The tempting invalid step is: from `p | q_1...q_n`, infer that `p` is associate to some `q_i`. That is primality, not irreducibility.

**3. Obstruction Model**

Use additive notation for a reduced cancellative monoid. Let `M` be generated by atoms-to-be

`q, p, a, b, h_0, h_1, h_2, ...`

with relations

```text
h_n = q + h_{n+1}   for all n >= 0
p + h_0 = a + b
```

This can be realized as a submonoid of an abelian group, so cancellation holds.

The atoms are exactly `q, p, a, b`; each `h_n` is reducible since `h_n = q + h_{n+1}`. Hence `M` is IDF because there are only four atom classes total.

`M` is almost atomic: for any element involving finitely many `h_n`, say with total `E` many `h_n` terms and index-weight `N`, adding the atomic element `E p + N q` replaces each `h_n` by

```text
h_n + p + n q = h_0 + p = a + b,
```

so the result is atomic.

But `h_0` is not atomic: it has the infinite descent

```text
h_0 = q + h_1 = 2q + h_2 = ...,
```

and it has no expression as a finite sum of `q,p,a,b`.

Yet

```text
p + h_0 = a + b
```

is atomic, with `p` an atom. This is exactly the length-one clearing pattern with non-atomic cofactor.

**4. Consequence**

IDF blocks infinitely many distinct atom divisors, but it does not block infinite divisibility by the same atom. Almost atomicity can clear every `h_n`, but that still does not force the uncleared cofactor to be atomic.
