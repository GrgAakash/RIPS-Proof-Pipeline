## 1. S5 Claim

Assume `R` is an integral domain satisfying IDF and almost atomic. Using S4, prove `R` is atomic.

## 2. Prerequisite

S4 length-one clearing lemma:

> If `R` is IDF and almost atomic, `p` is an atom, and `hp` is atomic, then `h` is atomic.

This is used as a black box.

## 3. Elementary Facts Used

Atomicity is preserved under associates: if `x` is atomic and `u` is a unit, then `xu` and `xu^{-1}` are atomic, since multiplying one atom factor by a unit preserves irreducibility up to associates.

## 4. Proof

Let `r` be a nonzero element of `R`.

Since `R` is almost atomic, there exists an atomic element `s` such that `rs` is atomic.

If `s` is a unit, then `r` is associate to `rs`, hence `r` is atomic.

Now suppose `s` is not a unit. Since `s` is atomic, write

```text
s = p1 p2 ... pn
```

where each `pi` is an atom.

Set

```text
h_n = r p1 p2 ... p_{n-1}.
```

Then

```text
h_n p_n = r p1 p2 ... pn = rs
```

is atomic. By S4, `h_n` is atomic.

Now set

```text
h_{n-1} = r p1 p2 ... p_{n-2}.
```

Since

```text
h_{n-1} p_{n-1} = h_n
```

is atomic, S4 gives that `h_{n-1}` is atomic.

Repeating this argument, peel off the atoms `p_n, p_{n-1}, ..., p_1` one at a time. After finitely many applications of S4, we obtain that `r` is atomic.

Since every nonzero `r in R` is atomic, `R` is an atomic domain.
