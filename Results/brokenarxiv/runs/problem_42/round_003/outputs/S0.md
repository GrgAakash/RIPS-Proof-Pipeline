1. Target Decomposition

target_label:
FFD iff IDF plus almost atomic

target_type:
Equivalence theorem for integral domains

main_goal:
Prove that an integral domain `R` is a finite factorization domain exactly when it has the IDF property and is almost atomic.

variables_and_parameters:
`R` is an integral domain. Elements are nonzero unless explicitly stated. `R^x` denotes the group of units. Atoms are irreducibles up to associates.

conclusion_to_prove:
`R` is an FFD if and only if:
1. every nonzero element of `R` has only finitely many atom divisors up to associates, and
2. for every nonzero `r in R`, there is an atomic `s in R` such that `rs` is atomic.

tool:
Domain cancellation

source_status:
standard background fact

exact_statement_or_fact:
In an integral domain, if `x != 0` and `xy = xz`, then `y = z`. Also, if a finite product is a unit, then each factor is a unit.

intended_role_in_proof:
Used when comparing factorizations with common atom factors; does not treat atoms as prime.

tool:
FFD implies atomicity

source_status:
follows from provided definition

exact_statement_or_fact:
If `R` is an FFD, then every nonzero nonunit has at least one factorization into atoms, while units are atomic by definition.

intended_role_in_proof:
Gives almost atomicity immediately by choosing multiplier `s = 1`.

tool:
FFD implies IDF

source_status:
proved inside the current proof

exact_statement_or_fact:
If `x` has finitely many factorizations and `p` is an atom dividing `x`, then `x = py`; since `R` is atomic, `y` is atomic, so `p` occurs in some factorization of `x`.

intended_role_in_proof:
Shows only finitely many associate classes of atom divisors can occur.

tool:
Dickson-type finiteness for exponent vectors

source_status:
standard background fact

exact_statement_or_fact:
For a finite set of atom-associate classes, there cannot be infinitely many distinct factorization exponent vectors of one fixed element without two vectors satisfying coordinatewise comparison; cancellation would force a nonempty product of atoms to be a unit.

intended_role_in_proof:
Shows atomic plus IDF implies finite factorization.

tool:
Length-one clearing lemma

source_status:
proved inside the current proof

exact_statement_or_fact:
In an IDF almost atomic domain, if `p` is an atom and `hp` is atomic, then `h` is atomic.

intended_role_in_proof:
Critical non-prime-cancellation step needed to prove almost atomic plus IDF implies atomic.

tool:
Induction on clearing multiplier length

source_status:
proved inside the current proof

exact_statement_or_fact:
If `s` is atomic, `hs` is atomic, and the length-one clearing lemma holds, then `h` is atomic by peeling off the atoms in one fixed factorization of `s`.

intended_role_in_proof:
Converts almost atomicity into full atomicity.

4. Hardest Step Prediction

hardest_step_id:
S4

hardest_step_description:
Proving that `hp` atomic forces `h` atomic without assuming the atom `p` is prime. A factorization of `hp` need not contain an associate of `p`.

risk_if_wrong:
The reverse implication collapses. Any argument that says “since `p` divides a product of atoms, `p` is associate to one of them” is invalid in a general integral domain.

how_final_proof_should_handle_it:
The final proof must isolate this as a separate lemma and prove it using almost atomicity plus IDF. It should argue by contradiction and show that a non-atomic cofactor in a length-one atomic clearing creates the precise finiteness obstruction forbidden by IDF, without prime cancellation.

5. Failure-Mode Checks

circularity_check:
Do not use FFD, atomicity of all elements, or finite factorizations in the reverse implication before they are proved.

full_theorem_check:
Forward direction proves both IDF and almost atomic. Reverse direction proves atomicity first, then finite factorization.

source_check:
No prior theorem, lemma, proposition, or corollary is available. All non-definition tools must be standard background or proved inside this proof.

hypothesis_check:
The length-one clearing lemma must use both IDF and almost atomicity. IDF alone is insufficient for the intended proof route.

notation_check:
Use `R^x` for units and “up to associates” consistently. Treat units as atomic by definition.

standard_background_check:
Only use standard domain cancellation, unit-product facts, and Dickson-style finiteness for `N^k`; state them explicitly if invoked.

6. Subproblem Assignment Table

S1:
Prove that FFD implies atomic and almost atomic. Use the FFD definition and choose `s = 1` for almost atomicity.

S2:
Prove that FFD implies IDF. If atom `p` divides nonzero `x`, write `x = py`; factor `y` using atomicity, so `p` appears in a factorization of `x`. Since `x` has finitely many factorizations, only finitely many atom classes can divide it.

S3:
Prove the finiteness lemma: in an IDF domain, any fixed atomic element has finitely many factorizations. Use the finite set of atom divisors of that element, encode factorizations by exponent vectors, and use cancellation plus Dickson’s lemma to rule out infinitely many distinct vectors.

S4:
Prove the length-one clearing lemma in full detail: if `R` is IDF and almost atomic, `p` is an atom, and `hp` is atomic, then `h` is atomic. The proof must not assume atoms are prime.

S5:
Use S4 to prove IDF plus almost atomic implies atomic. Given nonzero `r`, choose atomic `s` with `rs` atomic. If `s` is a unit, done. Otherwise write `s = p1...pn` and peel off atoms one at a time using S4.
