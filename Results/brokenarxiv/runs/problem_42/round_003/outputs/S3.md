**1. Claim**

In an IDF domain `R`, every fixed atomic element `x != 0` has only finitely many factorizations into atoms, up to order and associates.

**2. Proof**

Let `x` be atomic. If `x` is a unit, it has only the empty factorization, so assume `x` is a nonzero nonunit.

By IDF, `x` is divisible by only finitely many atoms up to associates. Choose representatives

```text
p_1, ..., p_n
```

for the associate classes of atoms dividing `x`.

Every factorization of `x` uses only atoms dividing `x`, hence every atom appearing in any factorization is associate to exactly one `p_i`. Thus each factorization of `x`, up to order and associates, determines an exponent vector

```text
alpha = (alpha_1, ..., alpha_n) in N^n
```

such that

```text
x = u p_1^{alpha_1} ... p_n^{alpha_n}
```

for some unit `u`.

It remains to show that only finitely many such vectors can occur.

Suppose, for contradiction, that infinitely many distinct exponent vectors occur. By Dickson’s lemma, `N^n` has no infinite antichain under componentwise order, so among these vectors there exist distinct vectors `alpha < beta` componentwise, meaning

```text
alpha_i <= beta_i for all i,
```

and `alpha_j < beta_j` for at least one `j`.

For the corresponding factorizations,

```text
x = u p_1^{alpha_1} ... p_n^{alpha_n}
x = v p_1^{beta_1} ... p_n^{beta_n}
```

with units `u, v`. Since `R` is a domain and each `p_i` is nonzero, cancellation gives

```text
u = v p_1^{beta_1-alpha_1} ... p_n^{beta_n-alpha_n}.
```

The right-hand product contains at least one atom factor, since `beta != alpha`. Therefore the product

```text
p_1^{beta_1-alpha_1} ... p_n^{beta_n-alpha_n}
```

is a nonunit: if it were a unit, then any atom factor appearing in it would divide a unit, forcing that atom itself to be a unit, impossible.

Thus the right side is a unit times a nonunit, hence a nonunit, contradicting that `u` is a unit.

Therefore only finitely many exponent vectors occur. Since each exponent vector determines at most one factorization up to order and associates using the chosen representatives, `x` has finitely many factorizations.

**3. Key Point**

No primality of atoms is used. The proof uses only:

```text
finite atom divisors of x + exponent vectors + Dickson’s lemma + cancellation in a domain.
```

**4. Obstruction Check**

The forbidden inference “atom divides a product, hence it is associate to a factor” is not used. We only use that atoms appearing in an actual factorization of `x` are themselves divisors of `x`.
