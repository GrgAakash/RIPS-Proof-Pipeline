**3. S5 Finiteness Claim**

Assume `R` has the IDF property and is almost atomic. Let `r` be a nonzero nonunit of `R`.

By SC4, choose an atomic element `s` such that `rs` is atomic and has only finitely many factorizations into atoms up to order and associates.

If `s` is a unit, then `r` and `rs` are associates. Multiplication by a unit gives a bijection between factorizations of `r` and factorizations of `rs`, up to associates. Hence `r` has only finitely many factorizations.

Now suppose `s` is not a unit. Since `s` is atomic, fix one factorization
\[
s=q_1\cdots q_m
\]
into atoms. Every factorization
\[
r=p_1\cdots p_n
\]
of `r` gives a factorization
\[
rs=p_1\cdots p_nq_1\cdots q_m.
\]
This defines a map from factorizations of `r` to factorizations of `rs`.

This map is injective up to order and associates. Indeed, if two factorizations of `r`,
\[
p_1\cdots p_n
\quad\text{and}\quad
p'_1\cdots p'_{n'}
\]
give the same factorization of `rs` after adjoining the fixed factors `q_1,\dots,q_m`, then the two multisets of associate classes satisfy
\[
\{[p_i]\}_i+\{[q_j]\}_j=\{[p'_i]\}_i+\{[q_j]\}_j.
\]
Cancelling the identical fixed multiset \(\{[q_j]\}_j\) gives
\[
\{[p_i]\}_i=\{[p'_i]\}_i.
\]
Thus the original factorizations of `r` are the same up to order and associates.

Since `rs` has only finitely many factorizations and factorizations of `r` inject into them, `r` has only finitely many factorizations.

**4. Reverse Implication**

Assume `R` is IDF and almost atomic. Let `r` be any nonzero nonunit.

By SC5, `r` has at least one factorization into atoms. By Section 3, `r` has only finitely many such factorizations up to order and associates. Therefore every nonzero nonunit has at least one and at most finitely many factorizations into atoms. Hence `R` is an FFD.

**5. Forward Implication**

Assume `R` is an FFD.

First, `R` is almost atomic: for every nonzero `r`, take `s=1`, which is atomic because units are atomic by definition. If `r` is a unit, then `rs=r` is atomic. If `r` is a nonzero nonunit, then `r` factors into atoms by the FFD property, so `rs=r` is atomic.

Second, `R` is IDF. Let `x` be nonzero. If `x` is a unit, no atom divides `x`; otherwise an atom dividing a unit would itself be a unit, impossible. If `x` is a nonunit, then `x` has only finitely many factorizations. Any atom dividing `x` occurs, up to associates, as one of the atoms in some factorization of `x`: if `x=ay` with `a` an atom, then either `y` is a unit, so `x` is associate to `a`, or `y` is a nonunit and has an atom factorization by the FFD property. Thus only finitely many atom associate classes can divide `x`. Therefore `R` is IDF.

**6. Final Equivalence And Web Confirmation**

The forward implication gives: FFD implies IDF and almost atomic. The reverse implication gives: IDF and almost atomic imply FFD. Therefore `R` is an FFD if and only if it satisfies the IDF property and is almost atomic.
