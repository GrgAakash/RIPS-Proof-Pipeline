2. Subproof or failure

Assume `R` is an FFD.

First, every nonzero element of `R` is atomic. Let `x in R` be nonzero. If `x` is a unit, then `x` is atomic by the definition of atomic element. If `x` is a nonunit, then, because `R` is an FFD, `x` has at least one factorization into atoms. Hence `x` is atomic by definition. Thus every nonzero element of `R` is atomic.

It follows that `R` is almost atomic. Let `r in R` be nonzero. Take `s = 1`. Since `1` is a unit, `s` is atomic. Also `rs = r`, and by the preceding paragraph `r` is atomic. Therefore, for every nonzero `r`, there is an atomic `s` such that `rs` is atomic. Hence `R` is almost atomic.

It remains to prove that `R` has the IDF property. Fix a nonzero element `x in R`.

If `x` is a unit, then no atom divides `x`. Indeed, if an atom `p` divided `x`, then `x = py` for some `y in R`. Since `x` is a unit, multiplying by `x^{-1}` gives `1 = p(yx^{-1})`, so `p` is a unit, contradicting that `p` is an atom. Thus `x` has zero atom divisors up to associates, hence finitely many.

Now suppose `x` is a nonzero nonunit. Since `R` is an FFD, `x` has only finitely many factorizations into atoms, up to order and associates. Choose one representative factorization from each such equivalence class:
`x = u_i a_{i1} ... a_{in_i}`,
where `u_i` is a unit, each `a_{ij}` is an atom, and `i` ranges over a finite index set.

Let `p` be any atom dividing `x`. Then `x = py` for some `y in R`. Since `p` is a nonzero nonunit and `x` is nonzero in a domain, `y` is nonzero. By the first paragraph, `y` is atomic. If `y` is a unit, then `x = py`, so `x` is associate to `p`; this is itself an atom factorization of `x` containing an atom associate to `p`. If `y` is not a unit, then `y = b_1 ... b_m` for atoms `b_k`, and therefore
`x = p b_1 ... b_m`
is a factorization of `x` into atoms containing `p`.

Thus every atom divisor `p` of `x` occurs, up to associate, among the atoms appearing in some atom factorization of `x`. Since the FFD assumption gives only finitely many factorization classes of `x`, and each representative factorization has finite length, only finitely many atom-associate classes occur among all representative factorizations. Therefore only finitely many atom-associate classes can divide `x`.

Hence every nonzero `x in R` is divisible by only finitely many atoms up to associates. So `R` has the IDF property.
