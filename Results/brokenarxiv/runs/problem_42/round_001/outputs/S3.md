## 2. Local Claim

Assume `R` has IDF and is almost atomic. Fix `0 != r in R`. By almost atomicity, choose an atomic element `s in R` such that `rs` is atomic.

Then `s` and `rs` each have only finitely many factorizations into atoms, up to order and associates.

## 3. Prerequisites

Use S2/SC3 as a prerequisite:

If `R` has IDF and `x` is a nonzero atomic element, then `x` has only finitely many factorizations into atoms up to order and associates.

## 4. Proof

Since `s` is atomic, either `s` is a unit or `s` factors into finitely many atoms. In either case, `s != 0`: units are nonzero in an integral domain, and atoms are nonzero by definition, so a finite product of atoms is nonzero.

Thus `s` is a nonzero atomic element. Since `R` has IDF, S2/SC3 applies to `x = s`. Therefore `s` has only finitely many factorizations into atoms up to order and associates.

Also, `r != 0` by choice and `s != 0` as just shown. Because `R` is an integral domain, `rs != 0`. By the almost atomic choice of `s`, the element `rs` is atomic. Hence `rs` is a nonzero atomic element. Applying S2/SC3 again, now to `x = rs`, shows that `rs` has only finitely many factorizations into atoms up to order and associates.

This establishes the assigned claim.
