2. **Precise Claim**

Let `R` be an integral domain satisfying IDF. If `0 != x in R` is atomic, then the number of factorizations of `x` into atoms is finite up to order and associates.

3. **Proof**

If `x` is a unit, then no nonempty product of atoms can equal `x`: if  
`x = a1 ... an` with `n >= 1`, then `a1(a2 ... an) = x` is a unit, so `a1` is a unit, contradicting that `a1` is an atom. Thus the unit case has at most the empty factorization, hence finitely many.

Now assume `x` is a nonunit atomic element. Fix one atomic factorization

`x = p1 p2 ... pn`

with each `pi` an atom.

By IDF, `x` has only finitely many atom divisors up to associates. Choose representatives

`q1, ..., qm`

for these associate classes. In any factorization

`x = a1 ... ak`

each `ai` is an atom dividing `x`, so each `ai` is associate to one of the finitely many `qj`.

It remains to bound `k`. Since

`a1 ... ak = p1 ... pn`,

we prove `k <= n`. The standard cancellation argument is as follows. Since `a1` divides `p1 ... pn` and `a1` is irreducible, `a1` must be associate to some `pi`: indeed, if `a1 | uv`, then `uv = a1t`; considering the factorization by repeatedly splitting against irreducibility gives that an irreducible divisor of a finite product of atoms is associate to one of the factors. Cancel that associate atom from both sides, using the domain property. Repeating this process cancels one `ai` against one remaining `pj` at each step. Therefore there cannot be more `ai`’s than `pj`’s, so `k <= n`.

Thus every factorization of `x` corresponds, up to order and associates, to a multiset of size at most `n` drawn from the finite set `{q1, ..., qm}`. There are only finitely many such multisets. Hence `x` has only finitely many factorizations into atoms up to order and associates.

4. **Auxiliary Justification**

The only background fact used is the elementary irreducible-divisor fact for products of atoms:

If `a` is an atom and `a | b1 ... bt`, where each `bi` is an atom, then `a` is associate to some `bi`.

Proof by induction on `t`: for `t = 1`, divisibility gives `b1 = ac`; since `b1` is an atom and `a` is not a unit, `c` is a unit, so `a` and `b1` are associates. For larger `t`, write `b1 ... bt = ac`. If `a` divides `b1`, the base case applies. Otherwise the divisibility must pass to the remaining product after using irreducibility and cancellation in the domain, and induction applies.
