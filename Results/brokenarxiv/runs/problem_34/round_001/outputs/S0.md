1. Target decomposition

target_label: Problem 34

target_type: uniqueness theorem for local square-integrable fractional Brownian rough path lifts

main_goal: prove that every local, square-integrable, translation/scaling/coordinate-permutation invariant eta-Hölder rough path lift of X equals the canonical lift.

variables_and_parameters: d >= 2; H in (1/4,1/2]; N = floor(1/H), so N in {2,3}; eta in (0,H) with 1/eta < N+1; X a d-dimensional fBM on canonical path space; Xbold an arbitrary admissible lift; Xcan the canonical lift.

conclusion_to_prove: Xbold = Xcan as a G^N(R^d)-valued eta-Hölder rough path, almost surely.
