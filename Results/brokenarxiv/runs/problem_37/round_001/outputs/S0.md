1. Target decomposition

target_label:
Problem 37

target_type:
eventual equality of saturation numbers for a fixed graph family

main_goal:
Show that for each fixed integer `p >= 4`, with `F = K_{p-1}^- ∪ K_1` and `H = K_1 ∨ F`, the minimum number of edges in an `H`-saturated `n`-vertex graph equals the universal-vertex construction value for all sufficiently large `n`.

variables_and_parameters:
`p >= 4` fixed; `n` sufficiently large; `F = K_{p-1}^- ∪ K_1`; `H = K_1 ∨ F`.

conclusion_to_prove:
`sat(n,H) = n - 1 + sat(n - 1,F)` for all `n >= N_p`, for some threshold depending only on `p`.

4. Hardest step prediction

hardest_step_id:
C3

hardest_step_description:
The key difficulty is proving that a near-extremal `H`-saturated graph must contain a universal vertex. The proof should analyze saturation witnesses for missing edges, use the special structure of `H = K_1 ∨ (K_{p-1}^- ∪ K_1)`, and show that absence of a universal vertex forces too many edges compared with the construction bound.

risk_if_wrong:
If this lemma is false or too weak, the lower bound cannot be derived from deletion of a universal vertex.

how_final_proof_should_handle_it:
The final proof should isolate this as a standalone structural lemma with an explicit threshold `N_p`. It should carefully distinguish whether the added edge in a witness copy is incident to the apex, lies inside the `K_{p-1}^-` part, or supplies the pendant-to-apex edge.

5. Failure-mode checks

circularity_check:
Do not use the target equality to prove the extremal universal-vertex lemma. C3 must be proved independently, using only saturation-witness analysis and edge counting.

full_theorem_check:
The upper bound comes from C2. The lower bound comes from applying C3 to an extremal graph and then C4. Together they prove equality.

source_check:
No outside lemmas are available. Every nonstandard lemma listed above must be proved inside the final proof.

hypothesis_check:
The proof must keep `p >= 4` fixed and allow the threshold for “sufficiently large” to depend on `p`.

notation_check:
Remember that `K_m^-` means one deleted edge from `K_m`, and `K_1 ∨ F` adds one universal apex to all vertices of `F`.

standard_background_check:
Only basic facts about subgraphs, joins, edge counts, and saturation witnesses are being treated as standard.

6. Subproblem assignment table

S1:
Prove the basic facts about `F = K_{p-1}^- ∪ K_1`, especially how the isolated component behaves in non-induced subgraphs, and verify the sparse `F`-saturated clique-joined-to-matching model for sufficiently large order.

S2:
Prove the universal-join lifting lemma: for an `F`-saturated graph `Q` on `n-1` vertices, show `K_1 ∨ Q` is `H`-free and that every missing edge creates `H`.

S3:
Prove the extremal universal-vertex lemma. Assume an `H`-saturated graph has no universal vertex and derive an edge lower bound strictly larger than `n - 1 + sat(n-1,F)` for sufficiently large `n`.

S4:
Prove the universal deletion lemma. Given an `H`-saturated graph `G` with universal vertex `v`, prove `G-v` is `F`-free and that adding any missing edge to `G-v` creates `F`.

S5:
Assemble the final theorem from C2, C3, and C4, choosing one threshold `N_p` large enough for all previous subclaims.
