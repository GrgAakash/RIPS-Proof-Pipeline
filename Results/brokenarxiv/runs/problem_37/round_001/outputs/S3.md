2. Subproof or failure

SUBPROBLEM UNSOLVED. The obstacle is that the assigned subclaim is false as stated.

Fix p >= 4. For arbitrarily large q, put n = pq + 1 and let G_q be the disjoint union of q copies of K_p and one isolated vertex.

First, G_q is H-free. The graph H is connected, because its join vertex is adjacent to every vertex of F, and |V(H)| = p + 1. Every connected subgraph of G_q lies inside one connected component, but every component of G_q has order p or 1. Hence no component contains H.

Second, G_q is H-saturated. Any missing edge xy has endpoints in different components. Since there is only one isolated component, at least one endpoint, say x, lies in a K_p component C. In G_q + xy, take x as the join vertex of H, take C \ {x} as the K_{p-1}^- component of F, and take y as the isolated K_1 component of F. The set C \ {x} is a K_{p-1}, hence contains K_{p-1}^- as a subgraph. Also x is adjacent to all vertices of C \ {x} and to y by the added edge. Thus G_q + xy contains H.

Third, G_q has no universal vertex and
e(G_q) = q * binom(p,2) = (p - 1)(n - 1)/2.

It remains to compare this with the claimed lower bound. Let N = n - 1 = pq. I record a simple lower bound: for sufficiently large q,
sat(N,F) >= (p - 3)N/2.

Indeed, let Q be any F-saturated graph on N vertices. Since N >= p, Q is K_{p-1}^--free; otherwise a K_{p-1}^- together with any extra vertex gives F. For any missing edge ab, Q + ab contains a K_{p-1}^- using ab as a required edge; otherwise the same F-copy would already have existed in Q.

Every vertex of Q has degree at least p - 4. If some vertex v had degree at most p - 5, then adding an edge from v to a nonneighbor would have to place v in a K_{p-1}^-, where every vertex has degree at least p - 3, impossible since v gains only one edge.

If delta(Q) >= p - 3, then e(Q) >= (p - 3)N/2. Otherwise choose x with degree p - 4. Let A = N_Q(x), so |A| = p - 4, and let B = V(Q) \ (A union {x}). For every y in B, the edge xy is missing. In Q + xy, the K_{p-1}^- using xy must use all vertices of A plus y as the neighbors of x inside that copy, and it has one further vertex z_y in B. Therefore y is adjacent to every vertex of A and to z_y. Hence A is complete to B and Q[B] has minimum degree at least 1. Thus, with b = |B| = N - p + 3,
e(Q) >= (p - 4)b + (p - 4) + b/2.
For p = 4 and N = 4q, this gives e(Q) >= ceil((N - 1)/2) = N/2. For p >= 5, the displayed bound is at least (p - 3)N/2 once q is large enough.

Therefore
n - 1 + sat(n - 1,F) = N + sat(N,F) >= N + (p - 3)N/2 = (p - 1)N/2 = e(G_q).

So G_q is an H-saturated graph with no universal vertex whose edge count is not strictly larger than n - 1 + sat(n - 1,F). This directly contradicts the assigned S3 claim for infinitely many arbitrarily large n.
