2. Subproof or failure

Let `Q = G - v`. We prove that `Q` is `F`-saturated.

First, `Q` is `F`-free. Suppose not. Then `Q` contains a subgraph isomorphic to `F`. Since `v` is universal in `G`, `v` is adjacent in `G` to every vertex of that `F`-copy. Therefore, adding `v` as the joined vertex gives a subgraph of `G` isomorphic to `K_1 ∨ F = H`, contradicting that `G` is `H`-free. Hence `Q` is `F`-free.

Now let `xy` be any non-edge of `Q`. Since `v` is universal in `G`, the non-edges of `Q` are exactly the non-edges of `G` not involving `v`; in particular, `xy` is also a non-edge of `G`.

Because `G` is `H`-saturated, the graph `G + xy` contains a copy `J` of `H`. Since `G` itself is `H`-free, this copy uses the added edge `xy`.

We claim that `Q + xy` contains a copy of `F`. In the copy `J ≅ H = K_1 ∨ F`, choose the joined vertex, say `a`, whose removal leaves a copy of `F` inside `J - a`.

If `a = v`, then `J - v` is an `F`-copy contained entirely in `Q + xy`, as required.

If `a ≠ v`, then `v` is one of the vertices in the `F`-part of `J`. Since `v` is universal in `G + xy`, it is adjacent to every other vertex of `J`. The vertex set `V(J) \ {v}` therefore still contains the joined vertex `a`, adjacent to all remaining vertices of the original `F`-part except `v`.

It remains to check that `V(J) \ {v}` contains an `F`-copy inside `Q + xy`. Since `F = K_{p-1}^- ∪ K_1`, an `F`-copy as a non-induced subgraph consists of a copy of `K_{p-1}^-` together with one additional distinct vertex; the additional vertex may have extra ambient edges.

Inside `J`, the `F`-part consists of a `K_{p-1}^-` component together with one isolated vertex, call it `z`. There are two cases.

If `v = z`, then the other `p-1` vertices of the `F`-part form a `K_{p-1}^-`, and `a` is an additional distinct vertex. Thus `V(J) \ {v}` contains `F`.

If instead `v` lies in the `K_{p-1}^-` component, then let `B` be the remaining vertices of that component after deleting `v`. The set `B ∪ {a}` has `p-1` vertices. The vertex `a` is adjacent to every vertex of `B`, and the graph on `B` contains all edges inherited from a `K_{p-1}^-` after deleting one vertex. Hence `B ∪ {a}` contains a copy of `K_{p-1}^-`: if the deleted vertex `v` was incident to the missing edge of the original `K_{p-1}^-`, then `B` is a clique of size `p-2`, so deleting any edge incident to `a` gives a `K_{p-1}^-` subgraph; if not, then `B` already contains a `K_{p-2}^-`, and joining `a` to all of `B` gives a `K_{p-1}^-`. The original isolated vertex `z` is distinct from `B ∪ {a}` and supplies the extra `K_1` vertex. Thus `V(J) \ {v}` again contains `F`.

Therefore, in every case, `Q + xy` contains `F`. Since every non-edge `xy` of `Q` creates an `F`-copy and `Q` is `F`-free, `Q = G-v` is `F`-saturated.
