2. Subproof or failure

Let `u` be the new vertex joined to every vertex of `Q`, so `G = u ∨ Q`.

First note the following elementary consequence of the non-induced subgraph convention. If a graph contains a copy of `K_{p-1}^-` on some vertex set `A` and has any further vertex `y ∉ A`, then it contains `F = K_{p-1}^- ∪ K_1` as a subgraph: map the `K_{p-1}^-` component to `A` and the isolated vertex of `F` to `y`. Any extra edges incident with `y` are irrelevant for ordinary subgraphs.

We prove that `G` is `H`-free. Suppose, for contradiction, that `G` contains a copy of `H = K_1 ∨ F`. Let `c` denote the join vertex of this abstract copy of `H`. Inside the abstract `F`, let `A` be the `p - 1` vertices spanning `K_{p-1}^-`, and let `b` be the isolated vertex.

Let `φ` be an embedding of this copy of `H` into `G`.

If `φ(c) = u`, then `φ(A ∪ {b})` lies in `Q` and forms a copy of `F`, contradicting that `Q` is `F`-free.

Now suppose `φ(c) = q ∈ V(Q)`. If `u` is not in `φ(A ∪ {b})`, then again the image of `F` lies entirely in `Q`, a contradiction. Hence `u` lies in the image of the `F`-part.

If `φ(b) = u`, then `φ(A) ⊆ V(Q)` contains a `K_{p-1}^-`; using the distinct vertex `q ∈ V(Q) \ φ(A)` as the isolated vertex gives a copy of `F` in `Q`, contradiction.

It remains that `u = φ(a_0)` for some `a_0 ∈ A`. Put `A' = A \ {a_0}`. The vertices `φ(A')` lie in `Q`, and the vertex `q` is adjacent in `Q` to every vertex of `φ(A')`, because `c` is joined to all vertices of `F` in `H`. Also, the edges required among `A'` by the `K_{p-1}^-` component are present among `φ(A')`. Therefore `{q} ∪ φ(A')` contains a copy of `K_{p-1}^-`: deleting one vertex from `K_{p-1}^-` leaves either `K_{p-2}` or `K_{p-2}^-`, and joining `q` to all those vertices supplies the required `K_{p-1}^-` edges. The distinct vertex `φ(b) ∈ Q` can serve as the isolated vertex of `F`. Thus `Q` contains `F`, contradiction.

So `G` is `H`-free.

Now let `xy` be any missing edge of `G`. Since `u` is universal in `G`, both `x,y` lie in `Q`, and `xy` is a missing edge of `Q`. Since `Q` is `F`-saturated, `Q + xy` contains a copy of `F`. In `G + xy`, the vertex `u` is adjacent to every vertex of that `F`-copy, so `u` together with that copy forms `K_1 ∨ F = H`.

Thus every missing edge of `G` creates an `H`-copy, while `G` itself is `H`-free. Hence `G = K_1 ∨ Q` is `H`-saturated. This proves the assigned lemma, in fact without needing a large-`n` condition.
