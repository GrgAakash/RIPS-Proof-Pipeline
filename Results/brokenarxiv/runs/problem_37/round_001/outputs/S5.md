declared prerequisite subclaims:

C2. For every \(q\) in the relevant range, if \(Q\) is an \(F\)-saturated graph on \(q\) vertices, then \(K_1\vee Q\) is \(H\)-saturated.

C3. There is a threshold \(N_3(p)\) such that for every \(n\ge N_3(p)\), every \(H\)-saturated graph \(G\) on \(n\) vertices with no universal vertex satisfies
\[
e(G)>n-1+\operatorname{sat}(n-1,F).
\]

C4. If \(G\) is an \(H\)-saturated graph with a universal vertex \(v\), then \(G-v\) is \(F\)-saturated.

2. Subproof or Failure

Fix \(p\ge 4\), and set \(F=K_{p-1}^{-}\cup K_1\) and \(H=K_1\vee F\).

Assume C2, C3, and C4 hold with threshold \(N_3(p)\) for C3 and with C2 available for all \(q=n-1\) under consideration. Let \(N_p\) be large enough that \(n\ge N_p\) implies both \(n\ge N_3(p)\) and that an \(F\)-saturated graph on \(n-1\) vertices realizing \(\operatorname{sat}(n-1,F)\) exists.

We prove both inequalities for every \(n\ge N_p\).

First, let \(Q\) be an \(F\)-saturated graph on \(n-1\) vertices with
\[
e(Q)=\operatorname{sat}(n-1,F).
\]
By C2, \(K_1\vee Q\) is \(H\)-saturated. Its number of edges is
\[
e(K_1\vee Q)=(n-1)+e(Q)=n-1+\operatorname{sat}(n-1,F).
\]
Therefore
\[
\operatorname{sat}(n,H)\le n-1+\operatorname{sat}(n-1,F).
\]

For the reverse inequality, let \(G\) be any \(H\)-saturated graph on \(n\) vertices. If \(G\) has no universal vertex, then by C3,
\[
e(G)>n-1+\operatorname{sat}(n-1,F),
\]
so certainly
\[
e(G)\ge n-1+\operatorname{sat}(n-1,F).
\]

Otherwise, \(G\) has a universal vertex \(v\). By C4, \(G-v\) is \(F\)-saturated. Hence
\[
e(G-v)\ge \operatorname{sat}(n-1,F).
\]
Since \(v\) is adjacent to all other \(n-1\) vertices,
\[
e(G)=e(G-v)+(n-1)\ge \operatorname{sat}(n-1,F)+n-1.
\]
Thus every \(H\)-saturated graph \(G\) on \(n\) vertices satisfies
\[
e(G)\ge n-1+\operatorname{sat}(n-1,F).
\]
Taking the minimum over all such \(G\) gives
\[
\operatorname{sat}(n,H)\ge n-1+\operatorname{sat}(n-1,F).
\]

Combining the upper and lower bounds yields
\[
\operatorname{sat}(n,H)=n-1+\operatorname{sat}(n-1,F)
\]
for all \(n\ge N_p\), conditional on C2, C3, and C4.
