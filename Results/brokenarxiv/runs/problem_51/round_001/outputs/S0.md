1. Target decomposition

target_label:
Problem 51

target_type:
Existential asymptotic lower bound for a graph edge-coloring parameter.

main_goal:
Show that every sufficiently large graph \(G\) on \(n\) vertices with
\[
e(G)=\binom n2-\lfloor n^{2-\epsilon}\rfloor
\]
requires at least \(c(\epsilon)n^2\) colors in any edge-coloring in which every copy of \(P_4\) is rainbow.

variables_and_parameters:
\(\epsilon>0\); sufficiently large integer \(n\); \(m=\lfloor n^{2-\epsilon}\rfloor\); graph \(G\) with \(n\) vertices and \(\binom n2-m\) edges; complement \(H=\overline G\), so \(e(H)=m\).

conclusion_to_prove:
There exists \(c(\epsilon)>0\) such that every valid \(P_4\)-rainbow edge-coloring of \(G\) uses more than \(c(\epsilon)n^2\) colors.

2. Available tools

tool:
Complement viewpoint

source_status:
proved inside the current proof

exact_statement_or_fact:
Let \(H=\overline G\). Then \(H\) has \(m=\lfloor n^{2-\epsilon}\rfloor\) edges. If two edges of \(G\) receive the same color, then they are not contained together in any copy of \(P_4\) in \(G\). This noncontainment can be translated into required missing edges in \(H\).

intended_role_in_proof:
Turn the coloring restriction into structural constraints forced by the sparse complement.

tool:
Same-color adjacent edge constraint

source_status:
proved inside the current proof

exact_statement_or_fact:
If \(ab,bc\in E(G)\) have the same color, then every vertex \(x\notin\{a,b,c\}\) must miss at least one of the edges \(ax,cx\) in \(G\). Equivalently, in \(H\), every such \(x\) is adjacent to at least one of \(a,c\).

intended_role_in_proof:
Show that a same-colored adjacent pair forces degree mass in the complement.

tool:
Same-color disjoint edge constraint

source_status:
proved inside the current proof

exact_statement_or_fact:
If \(ab,cd\in E(G)\) are disjoint and have the same color, then at least one of the four possible connecting edges
\[
ac,ad,bc,bd
\]
must be absent from \(G\). Equivalently, at least one of these four edges lies in \(H\).

intended_role_in_proof:
Control repeated colors on disjoint edges using missing edges in the complement.

tool:
High-degree exceptional set in sparse complement

source_status:
standard background / proved inside the current proof

exact_statement_or_fact:
For any threshold \(T>0\), the number of vertices of \(H\) with degree at least \(T\) is at most \(2e(H)/T\), by the handshake lemma.

intended_role_in_proof:
Choose a large set \(U\subseteq V(G)\) of vertices whose complement-degrees are small.

tool:
Induced almost-complete subgraph on low complement-degree vertices

source_status:
proved inside the current proof

exact_statement_or_fact:
For a suitable threshold \(T=n^{1-\epsilon/2}\), all but \(O(n^{1-\epsilon/2})\) vertices have complement-degree less than \(T\). Let \(U\) be this set. Then \(|U|=n-o(n)\), and every vertex in \(U\) is adjacent in \(G\) to all but fewer than \(T\) vertices.

intended_role_in_proof:
Restrict the coloring to a very large induced subgraph where every vertex has large \(G\)-degree.

tool:
No same-color adjacent pairs inside \(G[U]\)

source_status:
proved inside the current proof

exact_statement_or_fact:
For sufficiently large \(n\), no two adjacent edges of \(G[U]\) can have the same color. Indeed, if \(ab,bc\) had the same color with \(a,c\in U\), then the adjacent-edge constraint would imply
\[
d_H(a)+d_H(c)\ge n-3,
\]
contradicting \(d_H(a),d_H(c)<T\) once \(2T<n-3\).

intended_role_in_proof:
Show that each color class inside \(G[U]\) is a matching.

tool:
Bound on same-color disjoint pairs inside \(G[U]\)

source_status:
proved inside the current proof

exact_statement_or_fact:
For each missing edge \(xy\in E(H)\), it can certify only \(O(n)\) unordered disjoint edge-pairs of \(G[U]\): pairs \(ab,cd\) whose endpoints include \(x,y\) as one of the four cross pairs. Therefore the total number of same-color disjoint edge-pairs in \(G[U]\) is at most \(O(mn)=O(n^{3-\epsilon})\).

intended_role_in_proof:
Bound the possible amount of color reuse inside the large induced subgraph.

tool:
Color-class pair counting

source_status:
standard background / proved inside the current proof

exact_statement_or_fact:
If color classes on \(E(G[U])\) have sizes \(s_1,\dots,s_k\), and each class is a matching, then
\[
\sum_i \binom{s_i}{2}
\]
counts all unordered same-color edge-pairs in \(G[U]\). Also,
\[
\sum_i (s_i-1)=|E(G[U])|-k
\]
is at most \(\sum_i \binom{s_i}{2}\), since \(s_i-1\le \binom{s_i}{2}\) for \(s_i\ge 1\).

intended_role_in_proof:
Convert the bound on repeated same-color pairs into a lower bound on the number of colors.

tool:
Edge count inside \(U\)

source_status:
proved inside the current proof

exact_statement_or_fact:
Since \(|U|=n-o(n)\) and \(G\) misses only \(m=o(n^2)\) edges, one has
\[
e(G[U])=\binom{|U|}{2}-e(H[U])=\frac12n^2-o(n^2).
\]

intended_role_in_proof:
Ensure that the subgraph being counted still has quadratically many edges.

4. Hardest step prediction

hardest_step_id:
SC5

hardest_step_description:
The final proof must carefully count how many same-color disjoint edge-pairs can be charged to missing edges of \(G\). For every same-color pair \(ab,cd\), SC2 gives at least one missing cross-edge among \(ac,ad,bc,bd\). One must then bound how many edge-pairs can be charged to a fixed missing edge \(xy\). A fixed missing edge \(xy\) can appear as a cross-edge only by choosing one extra endpoint paired with \(x\) and one extra endpoint paired with \(y\), giving at most \(O(|U|)\), not \(O(|U|^2)\), possibilities because the two \(G\)-edges must be \(x a\) and \(y b\), or the symmetric orientation.

risk_if_wrong:
If a fixed missing edge is allowed to certify too many pairs, the bound may become \(O(mn^2)\), which is too weak and does not imply a quadratic color lower bound for small \(\epsilon\).

how_final_proof_should_handle_it:
Define an explicit charging rule: for each same-color disjoint pair, choose one missing cross-edge witnessing SC2. Then prove directly that for a fixed missing edge \(xy\), a charged pair is determined by choosing one edge incident to \(x\) in \(G[U]\) and one edge incident to \(y\) in \(G[U]\) with the other endpoints matched across the pair in one of at most two orientations. This gives at most \(2(|U|-2)\) or another explicit \(O(|U|)\) bound.

5. Failure-mode checks

circularity_check:
No subclaim assumes the target lower bound. The argument proceeds from local \(P_4\)-avoidance constraints to complement-degree bounds, then to color-class counting.

full_theorem_check:
The proof must handle every graph \(G\) with exactly \(\binom n2-\lfloor n^{2-\epsilon}\rfloor\) edges and every valid coloring of \(G\). Since the lower bound is proved for an arbitrary such \(G\) and coloring, it implies the minimum defining \(\chi_S\) also exceeds \(c(\epsilon)n^2\).

source_check:
No external sources or unsupported task-specific results are used. All graph-theoretic claims beyond definitions are elementary and must be proved inside the final proof, except the handshake lemma and basic counting identities.

hypothesis_check:
The proof uses \(\epsilon>0\), \(m=\lfloor n^{2-\epsilon}\rfloor=o(n^2)\), and sufficiently large \(n\). If \(\epsilon\ge 2\), then \(m\le 1\) eventually, and the same proof still works after noting \(m=o(n^2)\); the threshold \(T=n^{1-\epsilon/2}\) may fall below \(1\), so the final proof should instead set \(T=n/4\) or \(T=\max(n^{1-\epsilon/2}, n/4)\) if needed. A cleaner route is to split: for \(\epsilon\ge 1\), use any fixed \(T=o(n)\) larger than average complement degree, such as \(T=n^{1/2}\).

notation_check:
\(P_4\) is the 4-vertex path with 3 edges. “Rainbow” means its three edges receive pairwise distinct colors. \(H=\overline G\) should be introduced explicitly.

standard_background_check:
The only standard facts used are the handshake lemma, elementary asymptotic notation, and basic binomial/color-class counting. These should be stated when used.

6. Subproblem assignment table

S1:
Prove the two local constraints. First, if adjacent same-colored edges \(ab,bc\) exist and some \(x\notin\{a,b,c\}\) has both \(ax,cx\in E(G)\), then either \(xabc\) or \(abcx\) gives a \(P_4\) containing both same-colored edges, contradiction. Second, if disjoint same-colored edges \(ab,cd\) exist and all four cross-edges \(ac,ad,bc,bd\) are present, then one of \(a-c-d-b\), \(a-d-c-b\), \(b-c-d-a\), or \(b-d-c-a\) is a \(P_4\) containing both same-colored edges, contradiction. Choose one clean path and verify distinct vertices.

S2:
Using \(H=\overline G\), prove the low complement-degree set claim. Pick a threshold \(T=o(n)\) satisfying \(e(H)/T=o(n)\) and \(2T<n-3\), for example \(T=n^{1-\epsilon/2}\) when \(0<\epsilon<2\), with a harmless separate choice such as \(T=n^{1/2}\) for \(\epsilon\ge 2\). Show \(|V\setminus U|\le 2m/T=o(n)\). Then use S1’s adjacent-edge constraint to prove no same-colored adjacent edges occur in \(G[U]\).

S3:
Prove the charging bound for same-colored disjoint pairs in \(G[U]\). For each such pair, S1 gives a missing cross-edge in \(H\). Charge the pair to one chosen missing cross-edge. For a fixed missing edge \(xy\), count the charged pairs for which \(xy\) is one cross-edge between the two \(G\)-edges. Show there are at most \(2(|U|-2)\) or another explicit \(O(|U|)\) such unordered pairs. Conclude the total is \(O(e(H)|U|)=O(n^{3-\epsilon})\).

S4:
Prove the color-class counting step on \(E(G[U])\). Since S2 shows each color class is a matching, all repeated same-color pairs are disjoint and are counted by S3. If the color-class sizes are \(s_i\), prove
\[
\sum_i \binom{s_i}{2}\le Cn^{3-\epsilon}.
\]
Then use \(s_i-1\le \binom{s_i}{2}\) for \(s_i\ge1\) to get
\[
k\ge e(G[U])-Cn^{3-\epsilon}.
\]

S5:
Finish the theorem. Prove \(e(G[U])=\binom{|U|}{2}-e(H[U])=\frac12n^2-o(n^2)\), hence \(e(G[U])\ge n^2/3\) for large \(n\). Since \(n^{3-\epsilon}=o(n^2)\) only when \(\epsilon>1\), check the exponent issue. If \(\epsilon\le1\), the SC5-to-SC7 route is insufficient. Strengthen the counting by combining with low complement-degree matching structure, or adjust the blueprint before finalization. The final proof must ensure the repeated-color surplus is \(o(n^2)\) or at most \((1/2-c)n^2\) for every \(\epsilon>0\).
