1. Assignment restatement

S-ID: S4

assigned subclaim(s): Color-class counting step on \(E(G[U])\).

what must be proved: Assuming prior subclaims give that every color class on \(E(G[U])\) is a matching and that same-color disjoint edge pairs in \(G[U]\) are bounded by \(C n^{3-\epsilon}\), prove
\[
\sum_i \binom{s_i}{2}\le C n^{3-\epsilon},
\]
where \(s_i\) are the color-class sizes in \(E(G[U])\). Then prove
\[
k\ge e(G[U])-C n^{3-\epsilon},
\]
where \(k\) is the number of colors used on \(E(G[U])\). Finally determine the strength of this bound in \(\epsilon\).

declared prerequisite subclaims:

- Prerequisite A: On \(G[U]\), each color class is a matching.
- Prerequisite B: The number of same-color disjoint pairs of edges in \(G[U]\) is at most \(C n^{3-\epsilon}\).

2. Subproof or failure

Let the colors appearing on \(E(G[U])\) be indexed by \(i=1,\dots,k\), and let \(s_i\) be the number of edges of \(G[U]\) receiving color \(i\). Thus
\[
\sum_{i=1}^k s_i=e(G[U]).
\]

By Prerequisite A, each color class is a matching. Therefore, for any fixed color \(i\), every unordered pair of distinct edges in that color class is a disjoint pair of edges. The number of such pairs is exactly
\[
\binom{s_i}{2}.
\]
Summing over all colors, the total number of same-color pairs of distinct edges in \(G[U]\) is
\[
\sum_{i=1}^k \binom{s_i}{2}.
\]
Since each of these pairs is disjoint by Prerequisite A, Prerequisite B applies and gives
\[
\sum_{i=1}^k \binom{s_i}{2}\le C n^{3-\epsilon}.
\]

Now, for every integer \(s\ge 1\),
\[
s-1\le \binom{s}{2}.
\]
Indeed, for \(s=1\) both sides are \(0\), and for \(s\ge2\),
\[
\binom{s}{2}=\frac{s(s-1)}2\ge s-1.
\]
Hence
\[
s_i\le 1+\binom{s_i}{2}
\]
for every color class. Summing over \(i\),
\[
e(G[U])=\sum_{i=1}^k s_i
\le \sum_{i=1}^k \left(1+\binom{s_i}{2}\right)
= k+\sum_{i=1}^k\binom{s_i}{2}.
\]
Using the previous bound,
\[
e(G[U])\le k+C n^{3-\epsilon},
\]
so
\[
k\ge e(G[U])-C n^{3-\epsilon}.
\]

This counting step is strong enough to force a quadratic lower bound only when \(\epsilon>1\), assuming \(e(G[U])=\Theta(n^2)\). Indeed, then \(n^{3-\epsilon}=o(n^2)\). For \(0<\epsilon\le1\), the error term \(C n^{3-\epsilon}\) is at least order \(n^2\), so this estimate alone does not imply \(k\ge c n^2\) with \(c>0\).
