1. Assignment restatement

S-ID: S1

assigned subclaim(s): sparse integer-tail construction lemma

what must be proved: Construct \(\varepsilon_m\in\{0,1\}\) and positive integers \(T_m\) such that \(T_0=1\),
\[
T_m=2T_{m-1}-m\varepsilon_m,
\]
\(1\le T_m\le m+2\), the support \(\{m:\varepsilon_m=1\}\) is infinite, and its counting function is \(O(N/\log N)\).

declared prerequisite subclaims: none

2. Subproof or failure

SUBPROBLEM UNSOLVED. Missing obstacle: an allowed construction of an infinite sparse set \(A\subset \mathbb N\) with
\[
\#(A\cap[1,N])=O(N/\log N)
\quad\text{and}\quad
\sum_{m\in A} m2^{-m}=1.
\]

Useful conditional reduction: suppose such a set \(A\) is available. Define
\[
\varepsilon_m=\mathbf 1_{m\in A},\qquad
S_m=\sum_{j=1}^m j\varepsilon_j2^{-j},\qquad
T_m=2^m(1-S_m).
\]
Then \(T_0=1\), and
\[
T_m=2^m-\sum_{j=1}^m j\varepsilon_j2^{m-j},
\]
so \(T_m\) is an integer. Since \(\sum_{m\in A}m2^{-m}=1\),
\[
T_m=2^m\sum_{\substack{j>m\\ j\in A}} j2^{-j}.
\]
The set \(A\) is infinite, hence unbounded, so the last tail is strictly positive for every \(m\); thus \(T_m\ge1\). Also
\[
T_m\le 2^m\sum_{j=m+1}^{\infty}j2^{-j}=m+2,
\]
using the elementary geometric-tail identity
\[
\sum_{j=m+1}^{\infty}j2^{-j}=\frac{m+2}{2^m}.
\]
Finally,
\[
T_m
=2^m(1-S_{m-1}-m\varepsilon_m2^{-m})
=2T_{m-1}-m\varepsilon_m.
\]
The support and counting bound are exactly those of \(A\). Thus the unresolved sparse exact subsum lemma would prove the assigned construction lemma.
