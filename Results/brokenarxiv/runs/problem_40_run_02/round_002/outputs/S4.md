1. Assignment restatement

Assume a block construction has produced disjoint finite sets \(B_k\) supported in consecutive integer intervals with local counting bounds. Prove that for \(A=\bigcup_k B_k\), the global counting function
\[
A(N):=\#\{a\in A:a\le N\}
\]
satisfies
\[
A(N)=O(N/\log N).
\]
State the endpoint growth assumptions needed.

2. Subproof or failure

Let
\[
1\le M_0<M_1<M_2<\cdots
\]
be increasing integers, and suppose
\[
B_k\subseteq (M_{k-1},M_k]\cap \mathbb Z
\]
are pairwise disjoint finite sets. Put \(A=\bigcup_{k\ge1}B_k\).

A sufficient set of assumptions is:

There is a constant \(C>0\) such that for every \(k\),
\[
|B_k|\le C\,\frac{M_k-M_{k-1}}{\log M_k}.
\]
There is a constant \(D>0\) such that for every \(k\ge1\),
\[
\sum_{i=1}^{k-1}|B_i|\le D\,\frac{M_{k-1}}{\log M_k}.
\]
The second condition is the needed growth/sparsity condition on the endpoints. For example, it follows if the endpoints grow fast enough that earlier accumulated block counts are negligible on the logarithmic scale of the next block.

Now fix \(N\). If \(N\le M_0\), then \(A(N)=0\), so the estimate is trivial. Otherwise choose \(k\ge1\) such that
\[
M_{k-1}<N\le M_k.
\]
Then
\[
A(N)\le \sum_{i=1}^{k-1}|B_i|+\#(B_k\cap[1,N]).
\]
The first term is bounded by assumption:
\[
\sum_{i=1}^{k-1}|B_i|
\le D\,\frac{M_{k-1}}{\log M_k}.
\]
Since \(M_{k-1}<N\le M_k\), we have \(\log N\le \log M_k\), hence
\[
\frac{M_{k-1}}{\log M_k}\le \frac{N}{\log N}.
\]
Thus
\[
\sum_{i=1}^{k-1}|B_i|\le D\,\frac{N}{\log N}.
\]

For the current block, the local estimate gives
\[
\#(B_k\cap[1,N])\le |B_k|
\le C\,\frac{M_k-M_{k-1}}{\log M_k}.
\]
This full-block bound alone is not enough if \(N\) lies very close to \(M_{k-1}\). Therefore the required local count bound should be stated in the stronger prefix form:
\[
\#(B_k\cap(M_{k-1},N])\le C\,\frac{N-M_{k-1}+1}{\log N}
\]
for all \(M_{k-1}<N\le M_k\), after enlarging \(C\) to handle small \(N\).

Then
\[
\#(B_k\cap[1,N])
=\#(B_k\cap(M_{k-1},N])
\le C\,\frac{N-M_{k-1}+1}{\log N}
\le C'\frac{N}{\log N}
\]
for an absolute constant \(C'\).

Combining the two estimates,
\[
A(N)\le (D+C')\frac{N}{\log N}.
\]
Hence
\[
A(N)=O(N/\log N).
\]

Thus the global counting estimate follows provided the block construction supplies:

1. Consecutive supports \(B_k\subseteq(M_{k-1},M_k]\).
2. A uniform prefix-local bound inside each block:
\[
\#(B_k\cap(M_{k-1},N])=O((N-M_{k-1}+1)/\log N).
\]
3. Endpoint growth strong enough that previous blocks satisfy:
\[
\sum_{i<k}|B_i|=O(M_{k-1}/\log M_k).
\]
