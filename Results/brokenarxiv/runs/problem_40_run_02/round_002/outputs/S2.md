\Delta(M,N)=\sum_{m=M}^{N-1}2^{-m}=2^{1-M}-2^{1-N}.
\]

\[
B(M)\subseteq [M,\Phi(M))
\]

\[
c\log_2 M\le \Phi(M)-M\le C\log_2 M,\qquad |B(M)|\le K,
\]
and the block identity
\[
\sum_{b\in B(M)} b2^{-b}=\Delta(M,\Phi(M)).
\]
This is the only external subclaim used.

Choose any integer \(M_0\ge \max(M_\ast,2)\). Define recursively
\[
M_{k+1}=\Phi(M_k),\qquad I_k=[M_k,M_{k+1}),\qquad B_k=B(M_k)
\]
for \(k\ge 0\). Since \(M_{k+1}>M_k\), the intervals \(I_k\) are consecutive and pairwise disjoint. Also \(M_k\to\infty\), because a strictly increasing integer sequence cannot remain bounded. Hence the intervals cover every integer \(\ge M_0\).

Since \(B_k\subseteq I_k\), the sets \(B_k\) are pairwise disjoint. Define
\[
A=\bigcup_{k=0}^\infty B_k.
\]
Each \(B_k\) is nonempty because \(\Delta(M_k,M_{k+1})>0\), so \(A\) is infinite.

For \(K_0\ge 1\),
\[
\sum_{a\in \bigcup_{k=0}^{K_0-1}B_k} a2^{-a}
=\sum_{k=0}^{K_0-1}\Delta(M_k,M_{k+1})
=\sum_{m=M_0}^{M_{K_0}-1}2^{-m}
=2^{1-M_0}-2^{1-M_{K_0}}.
\]
Letting \(K_0\to\infty\) gives
\[
\sum_{a\in A} a2^{-a}=2^{1-M_0}.
\]
Thus, conditional on S1.FBC, S2 constructs an infinite set \(A\) with exact positive rational block-sum value \(r=2^{1-M_0}\).
