what must be proved: For the integer profile taken from an existing equilibrium, the set of continuous profiles satisfying feasibility and same-integer-profile best-response optimality is a rational polyhedron.

2. Subproof or failure

SC2 as stated is false.

Counterexample with rational data and \(Q_{ii}=0\). Take \(n=2\). Let each player have one continuous and one integer variable:
\[
x_i=(u_i,z_i)\in \mathbb R_+\times \mathbb Z_+.
\]
Force \(z_i=0\) by the rational constraint \(-z_i\ge 0\). Thus \(z_i\ge0\) and \(-z_i\ge0\) imply \(z_i=0\).

Let
\[
Q_{11}=Q_{22}=0,\qquad
Q_{12}=Q_{21}=\begin{pmatrix}1&0\\0&0\end{pmatrix},\qquad d_1=d_2=0.
\]
Then player 1 minimizes \(u_2u_1\), and player 2 minimizes \(u_1u_2\). All data are rational and both own quadratic blocks vanish.

The profile \((u_1,u_2,z_1,z_2)=(0,0,0,0)\) is a Nash equilibrium. Fix its integer profile \(z_1=z_2=0\).

For this fixed integer profile, player 1’s continuous best responses are:
\[
u_1=0 \text{ if } u_2>0,\quad \text{and any } u_1\ge0 \text{ if } u_2=0.
\]
Equivalently, \(u_1\) is a best response iff \(u_1=0\) or \(u_2=0\). The same condition holds symmetrically for player 2. Therefore the continuous profiles satisfying feasibility and best-response optimality are
\[
P=\{(u_1,u_2)\in\mathbb R_+^2: u_1u_2=0\},
\]
the union of the two nonnegative coordinate axes.

This set is not convex, since \((1,0),(0,1)\in P\) but \((1/2,1/2)\notin P\). Every polyhedron is convex. Hence \(P\) is not a polyhedron, rational or otherwise.

Thus SC2 cannot be proved as stated.

5. Interface notes for S6

Do not rely on SC2 as stated. The obstruction is cross-player bilinear objective dependence: even though each player’s problem is linear in its own continuous variables after opponents are fixed, the joint best-response set can be nonconvex.

A plausible repair is to fix, in addition to the equilibrium integer profile, a primal-dual LP active pattern/certificate at the given equilibrium. That gives a rational polyhedron containing the original equilibrium, but it is a different and weaker statement than SC2.
