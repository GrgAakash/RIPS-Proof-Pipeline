2. Subproof or failure

Construct a 2-player instance.

Player 1 has continuous variables `(a,u,v,h,r) in R_+^5` and integer variables `(zA,zB,zC) in Z_+^3`. Player 2 has one continuous variable `y in R_+`.

Player 1 minimizes
\[
f_1=-2a^2-u^2+v^2-4h.
\]
Player 2 minimizes
\[
f_2=y^2-2ry.
\]
Thus `Q_11` is nonzero, with rational entries only.

Player 1 constraints, besides nonnegativity, are:
\[
z_A+z_B+z_C=1,\quad a=z_A,\quad h=z_C,
\]
\[
u\le y,\quad u\le 2z_B,
\]
\[
v\le y,\quad v\le 2z_C,\quad v\ge y-2+2z_C,
\]
\[
r\le 2,\quad r\le 2-2z_B,\quad r\ge 2z_C,
\]
\[
r-y\le 2(1-z_A),\quad y-r\le 2(1-z_A).
\]
Player 2 constraint is
\[
y\le 2.
\]
All equalities and upper bounds are equivalent to pairs/sign changes of rational linear inequalities of the required form.

Fix any feasible `y in [0,2]`. Since the `z` variables are nonnegative integers and sum to 1, exactly one mode is active.

Mode A: `zA=1`. Then `a=1`, `u=v=h=0`, `r=y`, and Player 1’s value is `-2`.

Mode B: `zB=1`. Then `a=v=h=r=0`, `0<=u<=y`, and minimizing `-u^2` gives `u=y`, with value `-y^2`.

Mode C: `zC=1`. Then `a=u=0`, `h=1`, `v=y`, `r=2`, and value `y^2-4`.

Therefore Player 1’s best value is
\[
\min\{-2,-y^2,y^2-4\}.
\]
Mode A is optimal iff
\[
-2\le -y^2 \quad\text{and}\quad -2\le y^2-4,
\]
i.e. iff `y^2=2`. Mode B is uniquely optimal for `y^2>2`, and Mode C is uniquely optimal for `y^2<2`.

For Player 2, because Player 1’s constraints always give `0<=r<=2`, minimizing
\[
y^2-2ry=(y-r)^2-r^2
\]
over `0<=y<=2` has the unique solution `y=r`.

Now analyze equilibria.

If Mode A is used, Player 1’s constraints give `r=y`, so Player 2 is satisfied automatically; Player 1 is optimal only when `y^2=2`, hence `y=r=sqrt(2)`.

If Mode B is used, then `r=0`, so Player 2 forces `y=0`; but at `y=0`, Mode C has value `-4`, strictly better than Mode B’s value `0`. So no equilibrium uses Mode B.

If Mode C is used, then `r=2`, so Player 2 forces `y=2`; but at `y=2`, Mode B has value `-4`, strictly better than Mode C’s value `0`. So no equilibrium uses Mode C.

Thus the instance has a Nash equilibrium:
\[
z_A=1,\ z_B=z_C=0,\ a=1,\ u=v=h=0,\ y=r=\sqrt2.
\]
At this point all constraints hold, Player 1 is optimal because all three mode values equal `-2`, and Player 2 is optimal because `y=r`.

Every equilibrium must have `y=r=sqrt(2)`. Since `sqrt(2)` is irrational, no equilibrium of this rational-data instance is rational.
