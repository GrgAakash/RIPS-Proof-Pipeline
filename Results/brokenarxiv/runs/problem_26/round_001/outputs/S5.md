2. Subproof or failure

Assume SC1-SC4 have established the following sufficient-condition result: if \(Q_{ii}=0\) for every player \(i\), then every rational-data MI-LQ-GNEP in the stated class that has a Nash equilibrium also has a rational Nash equilibrium.

This proves the “if” direction of the target theorem.

For the converse, use SC5 as prerequisite: there exists a rational-data MI-LQ-GNEP with at least one nonzero own quadratic block \(Q_{ii}\), with at least one Nash equilibrium, but with no rational Nash equilibrium.

It remains only to check that such a counterexample fits the theorem’s notation for a general player set \(N=\{1,\dots,n\}\). If the SC5 counterexample already has a player set of this form, no embedding is needed: relabel its players as \(1,\dots,m\), and it is already an instance in the stated class.

If the theorem is being read for a larger fixed number of players \(n>m\), embed the \(m\)-player counterexample by adding dummy players \(m+1,\dots,n\). For each dummy player \(r\), take a one-dimensional continuous variable \(x_r\in \mathbb R_+\), impose the rational constraints
\[
x_r\ge 0,\qquad -x_r\ge 0,
\]
equivalently forcing \(x_r=0\), and give that player the zero objective. Set all coupling matrices and quadratic blocks involving dummy players to zero except for the dummy player’s own constraints forcing \(x_r=0\). These data are rational.

Then every feasible profile of the enlarged game has all dummy variables equal to \(0\). The active players’ feasible sets and objectives are exactly those of the original SC5 counterexample, because the dummy variables do not enter their objectives or constraints. Hence Nash equilibria of the enlarged game are precisely the Nash equilibria of the original counterexample, together with dummy coordinates equal to \(0\). Therefore the enlarged game has a Nash equilibrium, but it has no rational Nash equilibrium: a rational equilibrium of the enlarged game would restrict to a rational equilibrium of the active SC5 counterexample, contradicting SC5.

Thus, once nonzero own quadratic terms are allowed, the claimed rational-equilibrium guarantee fails. Combining this with the sufficient-condition direction from SC1-SC4 gives exactly:
\[
\text{Every rational-data MI-LQ-GNEP with an equilibrium has a rational equilibrium}
\quad\Longleftrightarrow\quad
Q_{ii}=0\ \text{for all } i.
\]
