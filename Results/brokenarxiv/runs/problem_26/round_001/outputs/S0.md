1. Target decomposition

target_label:
Rational-equilibrium characterization for MI-LQ-GNEPs

target_type:
If-and-only-if existence theorem, with a sufficiency direction and a sharp counterexample direction.

main_goal:
Show that, for rational-data MI-LQ-GNEPs that have at least one Nash equilibrium, rational equilibrium existence is guaranteed exactly in the subclass with no player-own quadratic term.

variables_and_parameters:
Players \(N=\{1,\dots,n\}\); variables \(x_i\in \mathbb R_+^{l_i}\times \mathbb Z_+^{k_i}\); rational data \(Q_{ij},A_{ij},d_i,b_i\); objectives
\[
\sum_{j\in N}x_j^TQ_{ij}x_i+d_i^Tx_i;
\]
constraints
\[
\sum_{j\in N}A_{ij}x_j\ge b_i.
\]

conclusion_to_prove:
A rational-data MI-LQ-GNEP with at least one Nash equilibrium is guaranteed to admit a rational Nash equilibrium if and only if \(Q_{ii}=0\) for every player \(i\).

2. Available tools

tool:
Fixed-integer reduction

source_status:
standard background fact

exact_statement_or_fact:
For a mixed-integer feasible set \(x_i=(y_i,z_i)\in \mathbb R_+^{l_i}\times \mathbb Z_+^{k_i}\), once the integer vector \(z_i\) is fixed, the remaining feasible region in \(y_i\) defined by rational linear inequalities is a rational polyhedron.

intended_role_in_proof:
Used to reduce equilibrium verification locally to finitely described rational polyhedral conditions for each fixed integer profile.

tool:
Linear programming rational optimal face

source_status:
standard background fact

exact_statement_or_fact:
For a linear program with rational objective and rational polyhedral feasible region, if the optimal value is finite and attained, then the optimal face is a rational polyhedron and contains a rational point.

intended_role_in_proof:
Core sufficiency tool when \(Q_{ii}=0\), because each player’s objective becomes linear in its own decision after fixing opponents.

tool:
Polyhedral description of best-response optimality for linear programs

source_status:
standard background fact

exact_statement_or_fact:
For rational linear programs, the set of parameters and decisions satisfying feasibility plus optimality can be expressed by rational linear inequalities, for example using primal feasibility and dual feasibility with equality of primal and dual objective values.

intended_role_in_proof:
Turns the Nash equilibrium conditions, for fixed integer profile, into a rational polyhedral system.

tool:
Rational point in nonempty rational polyhedron

source_status:
standard background fact

exact_statement_or_fact:
Every nonempty rational polyhedron contains a rational point.

intended_role_in_proof:
After showing that the equilibrium set associated with an integer profile is a nonempty rational polyhedron, this gives a rational equilibrium.

tool:
Existence of an equilibrium selects one integer profile

source_status:
proved inside the current proof

exact_statement_or_fact:
If a mixed-integer Nash equilibrium \(x^*\) exists, then its integer components \(z^*\) define a fixed integer profile. Restricting attention to that profile, \(x^*\)’s continuous components satisfy the corresponding fixed-profile Nash conditions.

intended_role_in_proof:
Avoids needing compactness or global finiteness over all integer profiles; the proof only follows the integer profile realized by one existing equilibrium.

tool:
Counterexample from irrational quadratic minimizer

source_status:
must be proved inside the current proof

exact_statement_or_fact:
There is a rational-data one-player MI-LQ-GNEP with nonzero own quadratic coefficient that has a Nash equilibrium but no rational Nash equilibrium; for example minimize
\[
x^2-2x
\]
over \(x\ge 0\), whose unique minimizer is \(x=1\), is not enough because it is rational. A valid counterexample must use rational quadratic data whose unique minimizer is irrational, such as minimizing
\[
x^2-2
\]
does not work because the objective is constant-shifted and minimized at \(0\). The final proof must construct the irrational minimizer using cross-variable linear constraints or a higher-dimensional quadratic form with rational coefficients.

intended_role_in_proof:
Establishes necessity by showing that once own quadratic terms are allowed, rational equilibrium existence is not guaranteed.

tool:
Quadratic minimization over rational polyhedron may have irrational unique minimizer

source_status:
standard background fact, but must be instantiated explicitly

exact_statement_or_fact:
A convex quadratic program with rational coefficients over a rational polyhedron can have an irrational optimizer. Example template: minimize \((y-\sqrt 2)^2\) is not allowed directly because \(\sqrt2\) is irrational data; the proof must instead encode irrationality through rational quadratic KKT equations, e.g. minimize \(u\) subject to rational constraints whose quadratic first-order condition forces \(u^2=2\).

intended_role_in_proof:
Needed for the “only if” direction. This is the riskiest part and must be made fully explicit.

4. Hardest step prediction

hardest_step_id:
SC5

hardest_step_description:
The hard step is constructing a valid rational-data MI-LQ-GNEP with a nonzero own quadratic term whose equilibrium set is nonempty but contains no rational point. The construction must not sneak irrational coefficients into the data. It must force irrationality through rational constraints and quadratic optimality, not by writing an irrational target directly into the objective.

risk_if_wrong:
If the counterexample has even one rational equilibrium, the “only if” direction fails. If it uses irrational data, it violates the theorem hypotheses. If it relies on unsupported nonlinear constraints, it leaves the MI-LQ-GNEP class.

how_final_proof_should_handle_it:
The final proof should give the counterexample explicitly, list all matrices/vectors, solve the player problems directly, and prove uniqueness or prove that every equilibrium satisfies an equation such as \(t^2=2\). It should then conclude irrationality from elementary real algebra.

5. Failure-mode checks

circularity_check:
The sufficiency proof must not assume rational equilibrium existence. It may assume existence of some equilibrium only to select an integer profile and prove nonemptiness of a rational polyhedron.

full_theorem_check:
Both directions must be addressed: zero own quadratic terms imply rational equilibrium existence; allowing a nonzero own quadratic term destroys any general guarantee.

source_check:
Only definitions from the packet and standard facts from LP, rational polyhedra, and elementary algebra are used. No external paper lemmas or web sources are used.

hypothesis_check:
All input data in both directions must be rational. The proof must respect \(x_i\in\mathbb R_+^{l_i}\times\mathbb Z_+^{k_i}\) and linear coupling constraints.

notation_check:
The term \(Q_{ii}=0\) means the full own quadratic matrix for player \(i\) is the zero matrix, not merely its diagonal or symmetric part.

standard_background_check:
The LP duality and rational-polyhedron facts are standard. Any special quadratic counterexample must be proved explicitly rather than treated as standard.

6. Subproblem assignment table

S1:
Prove SC1 carefully. Show that if \(Q_{ii}=0\), then for fixed \(x_{-i}\) and fixed integer part of \(x_i\), player \(i\)’s objective is linear in its continuous decision variables and the feasible region is a rational polyhedron.

S2:
Prove SC2. For the integer profile taken from an existing equilibrium, write feasibility and best-response optimality using rational linear inequalities, preferably via LP duality for each player. Show the resulting set of continuous profiles is a rational polyhedron.

S3:
Prove SC3 and SC4. Use the theorem that a nonempty rational polyhedron contains a rational point, then verify that this rational point with the fixed integer profile is still feasible and still satisfies every player’s best-response condition in the original game.

S4:
Construct and verify SC5. Find an explicit rational-data MI-LQ-GNEP with some \(Q_{ii}\neq0\), at least one Nash equilibrium, and no rational Nash equilibrium. The verification must solve the equilibrium conditions directly and prove irrationality without using irrational data.

S5:
Handle SC6 and final assembly. Explain how the counterexample fits the theorem’s player-set notation, including dummy-player embedding if needed, and assemble the two directions into the stated iff conclusion.
