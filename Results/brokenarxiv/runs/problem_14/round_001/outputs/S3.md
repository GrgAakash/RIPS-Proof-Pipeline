2. Subproof or failure

Let `G` be an `n`-vertex graph attaining `h_F(n,1)`. By the definition of `h_F(n,1)`, the graph `G` has exactly `ex(n,F)+1` edges.

Assume SC2. Then there is an edge `e ∈ E(G)` such that every copy of `F` in `G` contains `e`.

We claim that `G-e` is `F`-free. Suppose otherwise that `G-e` contains a copy `H` of `F`. Since `G-e` is a subgraph of `G`, the same subgraph `H` is also a copy of `F` in `G`. But `H` does not contain `e`, because `e` is not an edge of `G-e`. This contradicts SC2, which says every copy of `F` in `G` contains `e`. Hence `G-e` is `F`-free.

Finally,
`|E(G-e)| = |E(G)| - 1 = (ex(n,F)+1)-1 = ex(n,F)`.

Thus `G-e` is an `n`-vertex `F`-free graph with exactly `ex(n,F)` edges. By the definition of `ex(n,F)` as the maximum number of edges in an `n`-vertex `F`-free graph, `G-e` is an extremal `n`-vertex `F`-free graph.
