1. Target decomposition

target_label:
S0 target theorem

target_type:
eventual equality theorem in extremal graph theory

main_goal:
Show that for every fixed graph \(F\) containing a cycle, the least possible number of copies of \(F\) among \(n\)-vertex graphs with \(\operatorname{ex}(n,F)+1\) edges is attained by adding one edge to an extremal \(F\)-free graph, once \(n\) is large enough.

variables_and_parameters:
Fixed graph \(F\) with at least one cycle; integer \(n\); \(q=1\); \(n\)-vertex graphs \(G\); \(\operatorname{ex}(n,F)\); \(h_F(n,1)\); \(c(n,F)\).

conclusion_to_prove:
There exists \(n_0(F)\) such that for all \(n\ge n_0(F)\),
\[
h_F(n,1)=c(n,F).
\]

2. Available tools

tool:
Definition of \(h_F(n,q)\)

source_status:
provided definition / notation / assumption

exact_statement_or_fact:
\(h_F(n,q)\) is the minimum number of copies of \(F\), counted as subgraphs, in an \(n\)-vertex graph with \(\operatorname{ex}(n,F)+q\) edges.

intended_role_in_proof:
Identifies \(h_F(n,1)\) as the optimum over all \(n\)-vertex graphs with one more edge than the extremal \(F\)-free number.

tool:
Definition of \(c(n,F)\)

source_status:
provided definition / notation / assumption

exact_statement_or_fact:
\(c(n,F)\) is the minimum number of copies of \(F\) in a graph obtained by adding one edge to an extremal \(n\)-vertex \(F\)-free graph.

intended_role_in_proof:
Provides the canonical construction giving the upper bound \(h_F(n,1)\le c(n,F)\).

tool:
Extremal definition of \(\operatorname{ex}(n,F)\)

source_status:
provided definition / notation / assumption

exact_statement_or_fact:
\(\operatorname{ex}(n,F)\) is the maximum number of edges in an \(n\)-vertex graph containing no copy of \(F\).

intended_role_in_proof:
Used to show any graph with \(\operatorname{ex}(n,F)+1\) edges contains at least one copy of \(F\), and that deleting a suitable edge from an optimal graph may produce an extremal \(F\)-free graph.

tool:
Monotonicity under deleting edges

source_status:
standard background fact

exact_statement_or_fact:
Deleting edges from a graph cannot create new copies of a fixed graph \(F\), and every copy of \(F\) in the smaller graph is also a copy in the original graph.

intended_role_in_proof:
Used when comparing a graph \(G\) with \(G-e\).

tool:
Finite edge-cover reduction

source_status:
proved inside the current proof

exact_statement_or_fact:
If an \(n\)-vertex graph \(G\) with \(\operatorname{ex}(n,F)+1\) edges minimizes the number of \(F\)-copies, then for sufficiently large \(n\), there is an edge \(e\in E(G)\) meeting every copy of \(F\) in \(G\).

intended_role_in_proof:
This is the key reduction: it implies \(G-e\) is \(F\)-free.

tool:
Extremality after deleting the universal edge

source_status:
proved inside the current proof

exact_statement_or_fact:
If \(G\) has \(\operatorname{ex}(n,F)+1\) edges and \(e\) meets every copy of \(F\), then \(G-e\) is an extremal \(F\)-free graph with exactly \(\operatorname{ex}(n,F)\) edges.

intended_role_in_proof:
Converts an arbitrary minimizer into a graph counted in the definition of \(c(n,F)\).

tool:
Canonical comparison

source_status:
proved inside the current proof

exact_statement_or_fact:
If every extremal minimizer \(G\) is obtained from an extremal \(F\)-free graph by adding one edge, then the number of \(F\)-copies in \(G\) is at least \(c(n,F)\).

intended_role_in_proof:
Gives \(h_F(n,1)\ge c(n,F)\).

tool:
Upper-bound construction

source_status:
standard background fact from definitions

exact_statement_or_fact:
Any graph formed by adding one edge to an extremal \(F\)-free graph has \(\operatorname{ex}(n,F)+1\) edges, so it is admissible for \(h_F(n,1)\).

intended_role_in_proof:
Gives \(h_F(n,1)\le c(n,F)\).

3. Subclaim support graph

id:
SC1

statement:
For every sufficiently large \(n\), \(h_F(n,1)\le c(n,F)\).

uses_prior_subclaims:
None.

purpose:
Establishes the easy direction using the construction in the definition of \(c(n,F)\).

status:
standard background / follows from definitions.

suggested_solver:
S1.

id:
SC2

statement:
Let \(G\) be an \(n\)-vertex graph with \(\operatorname{ex}(n,F)+1\) edges minimizing the number of copies of \(F\). For sufficiently large \(n\), some edge \(e\in E(G)\) belongs to every copy of \(F\) in \(G\).

uses_prior_subclaims:
None.

purpose:
This is the structural heart of the proof. It says an optimal one-extra-edge graph has all \(F\)-copies concentrated on one added edge.

status:
must be proved in final proof.

suggested_solver:
S2.

id:
SC3

statement:
With \(G\) and \(e\) as in SC2, the graph \(G-e\) is \(F\)-free.

uses_prior_subclaims:
SC2.

purpose:
Turns the universal edge into an edge whose removal destroys all \(F\)-copies.

status:
standard background / immediate from SC2.

suggested_solver:
S3.

id:
SC4

statement:
With \(G\) and \(e\) as in SC2, \(G-e\) has exactly \(\operatorname{ex}(n,F)\) edges and is therefore an extremal \(n\)-vertex \(F\)-free graph.

uses_prior_subclaims:
SC3.

purpose:
Shows that \(G\) is obtained by adding one edge to an extremal \(F\)-free graph.

status:
must be proved in final proof, but short from definitions.

suggested_solver:
S3.

id:
SC5

Every minimizing graph \(G\) has at least \(c(n,F)\) copies of \(F\).

4. Hardest step prediction

hardest_step_id:
SC2

hardest_step_description:
Prove that an \(F\)-copy-minimizing graph with \(\operatorname{ex}(n,F)+1\) edges has a single edge contained in every copy of \(F\), for all sufficiently large \(n\).

risk_if_wrong:
If SC2 fails, the graph minimizing \(F\)-copies need not be obtainable by adding one edge to an extremal \(F\)-free graph, and the claimed lower bound \(h_F(n,1)\ge c(n,F)\) would not follow.

how_final_proof_should_handle_it:
The final proof must give a genuine structural argument, not just assert minimizers have this form. It should likely argue by contradiction: assume every edge deletion leaves a copy of \(F\), then use the cyclicity of \(F\), extremality, and a replacement/deletion comparison to build another graph with \(\operatorname{ex}(n,F)+1\) edges but fewer copies of \(F\), contradicting minimality.

5. Failure-mode checks

circularity_check:
Do not use the target theorem or any equivalent “one extra edge is minimized by adding to an extremal graph” statement while proving SC2 or SC5.

full_theorem_check:
Both inequalities are needed: \(h_F(n,1)\le c(n,F)\) from the canonical construction and \(h_F(n,1)\ge c(n,F)\) from the structural reduction.

source_check:
No formal supporting statements are available. Every non-definitional structural claim, especially SC2, must be proved inside the current proof.

hypothesis_check:
The assumption that \(F\) contains a cycle is essential. It must be used in the proof of SC2 or any structural replacement lemma supporting SC2.

notation_check:
Copies of \(F\) are counted as subgraphs, not necessarily induced subgraphs. Adding one edge to an extremal \(F\)-free graph means adding an edge absent from that extremal graph.

standard_background_check:
Only basic graph facts should be treated as standard: edge deletion cannot create copies, extremal graphs have exactly \(\operatorname{ex}(n,F)\) edges, and finite minimizers exist. Any stability, supersaturation, or special extremal theorem must be proved if needed.

6. Subproblem assignment table

S1:
Prove the easy upper bound. Show that a graph counted by \(c(n,F)\) has exactly \(\operatorname{ex}(n,F)+1\) edges, hence is admissible for \(h_F(n,1)\), so \(h_F(n,1)\le c(n,F)\).

S2:
Prove the structural concentration claim SC2. Let \(G\) minimize the number of \(F\)-copies among all \(n\)-vertex graphs with \(\operatorname{ex}(n,F)+1\) edges. Show, using only the assumption that \(F\) has a cycle and arguments proved inside the proof, that for all sufficiently large \(n\), some edge of \(G\) lies in every copy of \(F\).

S3:
Assuming SC2, prove that deleting the universal edge \(e\) gives an \(F\)-free graph with exactly \(\operatorname{ex}(n,F)\) edges, hence an extremal \(F\)-free graph.

S4:
Assuming S2 and S3, prove the lower bound. Since \(G\) is obtained by adding one edge to an extremal \(F\)-free graph, the number of \(F\)-copies in \(G\) is at least \(c(n,F)\). Conclude \(h_F(n,1)\ge c(n,F)\).

S5:
Assemble the final theorem. Combine the upper and lower bounds, track the sufficiently-large threshold \(n_0(F)\), and verify all uses of the hypothesis that \(F\) contains a cycle occur inside the structural step.
