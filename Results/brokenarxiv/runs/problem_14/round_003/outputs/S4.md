**S1. Assignment Restatement**

Prove SC5 and SC6 for fixed cyclic \(F\): if \(G\) realizes \(h_F(n,1)\), then for all sufficiently large \(n\), some edge \(e\in E(G)\) has \(G-e\) \(F\)-free; consequently \(h_F(n,1)\ge c(n,F)\).

**S2. Subproof Or Failure**

Let \(N_F(G)\) denote the number of copies of \(F\) in \(G\). Fix \(F\) containing a cycle, and take \(n\) large enough that SC1, SC3, and SC4 apply.

Let \(G\) be an \(n\)-vertex graph with \(\operatorname{ex}(n,F)+1\) edges realizing \(h_F(n,1)\). By SC1,

\[
N_F(G)=h_F(n,1)\le c(n,F).
\]

Suppose, toward contradiction, that deleting every single edge of \(G\) still leaves a copy of \(F\). Then \(G\) satisfies the hypothesis of SC4, so

\[
N_F(G)>c(n,F),
\]

contradicting \(N_F(G)\le c(n,F)\). Hence there exists an edge \(e\in E(G)\) such that \(G-e\) contains no copy of \(F\). This proves SC5.

Now apply SC3 to this edge \(e\). Since \(G-e\) is \(F\)-free and has exactly \(\operatorname{ex}(n,F)\) edges, SC3 gives

\[
N_F(G)\ge c(n,F).
\]

Because \(G\) realizes \(h_F(n,1)\), this is

\[
h_F(n,1)\ge c(n,F).
\]

This proves SC6.
