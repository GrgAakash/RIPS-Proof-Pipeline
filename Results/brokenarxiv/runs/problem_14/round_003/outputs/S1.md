Let `T` be an extremal `n`-vertex `F`-free graph and let `e` be an added edge such that `T+e` realizes this minimum. Then

`e(T+e) = ex(n,F)+1`.

`h_F(n,1) <= c(n,F)`.

For existence, there are only finitely many simple graphs on a fixed `n`-vertex set. Hence there are finitely many `n`-vertex graphs with exactly `ex(n,F)+1` edges. The number of copies of `F` in each such graph is a nonnegative integer, so the finite set of possible values has a minimum. Thus some graph attains `h_F(n,1)`.
