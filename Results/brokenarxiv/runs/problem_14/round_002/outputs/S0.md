1. Target decomposition

target_label:
q=1 extremal supersaturation identity

target_type:
eventual equality theorem for finite graphs

main_goal:
Show that for every fixed graph \(F\) containing a cycle, every sufficiently large \(n\)-vertex graph with \(\operatorname{ex}(n,F)+1\) edges and the fewest possible copies of \(F\) is obtainable by adding one edge to an extremal \(F\)-free graph.

variables_and_parameters:
\(F\): fixed graph containing at least one cycle.  
\(n\): sufficiently large integer.  
\(\operatorname{ex}(n,F)\): maximum number of edges in an \(n\)-vertex \(F\)-free graph.  
\(h_F(n,1)\): minimum number of copies of \(F\) in an \(n\)-vertex graph with \(\operatorname{ex}(n,F)+1\) edges.  
\(c(n,F)\): minimum number of copies of \(F\) obtained by adding one edge to an extremal \(n\)-vertex \(F\)-free graph.

conclusion_to_prove:
\[
h_F(n,1)=c(n,F)
\]
for all sufficiently large \(n\).

2. Available tools

tool:
Definition of \(h_F(n,1)\)  
source_status: provided definition / notation / assumption  
exact_statement_or_fact:
\(h_F(n,1)\) is the minimum number of copies of \(F\) among all \(n\)-vertex graphs with \(\operatorname{ex}(n,F)+1\) edges.  
intended_role_in_proof:
Choose a minimizing graph \(G\) and compare its number of \(F\)-copies to \(c(n,F)\).

tool:
Definition of \(c(n,F)\)  
source_status: provided definition / notation / assumption  
exact_statement_or_fact:
\(c(n,F)\) is the minimum number of \(F\)-copies in a graph obtained by adding one edge to an extremal \(n\)-vertex \(F\)-free graph.  
intended_role_in_proof:
Gives the immediate upper bound \(h_F(n,1)\le c(n,F)\), and the lower bound once a minimizer is shown to have the required form.

tool:
Extremal graph definition  
source_status: provided definition / notation / assumption  
exact_statement_or_fact:
An extremal \(n\)-vertex \(F\)-free graph has exactly \(\operatorname{ex}(n,F)\) edges and contains no copy of \(F\).  
intended_role_in_proof:
Used after deleting a suitable edge from a minimizer.

tool:
Edge-deletion hitting claim  
source_status: proved inside the current proof  
exact_statement_or_fact:
For fixed cyclic \(F\), for all sufficiently large \(n\), if \(G\) is an \(n\)-vertex graph with \(\operatorname{ex}(n,F)+1\) edges minimizing the number of copies of \(F\), then there exists an edge \(e\in E(G)\) such that every copy of \(F\) in \(G\) contains \(e\).  
intended_role_in_proof:
This is the central structural step. It implies \(G-e\) is \(F\)-free.

tool:
Nontriviality of \(c(n,F)\)  
source_status: standard background fact  
exact_statement_or_fact:
If \(T\) is extremal \(F\)-free and \(xy\notin E(T)\), then \(T+xy\) contains at least one copy of \(F\), because otherwise \(T+xy\) would be \(F\)-free with more than \(\operatorname{ex}(n,F)\) edges.  
intended_role_in_proof:
Confirms that added-edge constructions are legitimate witnesses for \(h_F(n,1)\).

tool:
Finite minimizer existence  
source_status: standard background fact  
exact_statement_or_fact:
Among finitely many \(n\)-vertex graphs with a fixed number of edges, a graph minimizing the number of copies of \(F\) exists.  
intended_role_in_proof:
Allows choosing a minimizer \(G\) for \(h_F(n,1)\).

tool:
Basic copy deletion fact  
source_status: standard background fact  
exact_statement_or_fact:
If every copy of \(F\) in \(G\) contains an edge \(e\), then \(G-e\) contains no copy of \(F\).  
intended_role_in_proof:
Converts the structural hitting claim into \(F\)-freeness of \(G-e\).

4. Hardest step prediction

hardest_step_id:
SC2

hardest_step_description:
Prove that an \(F\)-copy-minimizing graph with \(\operatorname{ex}(n,F)+1\) edges has an edge meeting every copy of \(F\).

risk_if_wrong:
Without this, deleting an arbitrary edge from the minimizer leaves only \(\operatorname{ex}(n,F)\) edges, but it may still contain \(F\). The final proof must not infer \(F\)-freeness merely from having exactly \(\operatorname{ex}(n,F)\) edges.

how_final_proof_should_handle_it:
The final proof should isolate SC2 as a separate lemma. It must explicitly use the minimizing property of \(G\), the assumption that \(F\) contains a cycle, and the phrase “for sufficiently large \(n\).” Only after finding the hitting edge \(e\) may the proof conclude that \(G-e\) is \(F\)-free.

5. Failure-mode checks

circularity_check:
Do not use the target theorem to prove SC2. SC2 must be established independently from the minimizing property and standard extremal reasoning.

full_theorem_check:
Both inequalities are needed. The upper bound is immediate from the definition of \(c(n,F)\); the lower bound requires the structural hitting-edge claim.

source_check:
No allowed supporting statements are available. Every non-definitional graph-theoretic claim specific to this theorem must be proved inside the final proof.

hypothesis_check:
The assumption that \(F\) contains a cycle must be used in SC2. The theorem is not being asserted for forests.

notation_check:
Copies of \(F\) are counted as subgraphs. The proof should distinguish \(G\), the minimizer for \(h_F(n,1)\), from \(T=G-e\), the extremal \(F\)-free graph obtained after deletion.

standard_background_check:
Permitted standard facts are only finite minimizer existence, elementary edge deletion behavior, and the definition-level extremal observation that adding an edge to an extremal \(F\)-free graph must create a copy of \(F\).

6. Subproblem assignment table

S1:
Prove the upper bound \(h_F(n,1)\le c(n,F)\) directly from the definitions.

S2:
Prove the structural hitting-edge lemma: for fixed cyclic \(F\) and all sufficiently large \(n\), any minimizer \(G\) for \(h_F(n,1)\) has an edge contained in every copy of \(F\).

S3:
Assuming S2, prove that deleting the hitting edge \(e\) gives an \(F\)-free graph with exactly \(\operatorname{ex}(n,F)\) edges.

S4:
Assuming S3, prove that the original minimizer \(G\) is one of the graphs counted in the definition of \(c(n,F)\), so its number of \(F\)-copies is at least \(c(n,F)\).

S5:
Assemble S1 and S4 into the final equality for sufficiently large \(n\), checking that all hypotheses and quantifiers match the theorem.
