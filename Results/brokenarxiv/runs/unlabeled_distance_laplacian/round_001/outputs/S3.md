1. Assignment restatement

S-ID: S3

assigned subclaim(s): C5

what must be proved: Let \(H\) be a graph on \(n\) vertices with \(m=e(H)\), such that \(\overline H\) is connected of diameter \(2\). If \(\lambda_1\ge \cdots \ge \lambda_n\) are the ordinary Laplacian eigenvalues of \(H\), then for every \(1\le r\le n\),
\[
nr+\sum_{i=1}^r\lambda_i(H)\le \binom n2+m+\binom{r+2}{3},
\]
except exactly for \(H=K_3\cup K_1,r=2\), and \(H=K_4\cup K_1,r=3\).

declared prerequisite subclaims: none.

2. Subproof or failure

Use the standard ordinary Laplacian partial-sum bound:
\[
\sum_{i=1}^r\lambda_i(F)\le e(F)+\binom{r+1}{2}
\tag{LPS}
\]
for every finite simple graph \(F\) and \(1\le r\le |V(F)|\).

Applying (LPS) to \(H\), it is enough, outside small parameter pairs, to prove
\[
nr+m+\binom{r+1}{2}\le \binom n2+m+\binom{r+2}{3}.
\]
After cancellation this is
\[
g(n,r):=\binom n2-nr+\binom{r+1}{3}\ge 0.
\tag{1}
\]

We check when (1) holds. Since
\[
g(n+1,r)-g(n,r)=n-r,
\]
for fixed \(r\), \(g(n,r)\) is nondecreasing for \(n\ge r\).

For \(r=1\),
\[
g(n,1)=\frac{n(n-3)}2\ge 0
\]
because \(\overline H\) has diameter \(2\), so \(n\ge 3\).

For \(r=2\),
\[
g(n,2)=\frac{n^2-5n+2}{2}\ge 0
\]
for \(n\ge 5\), leaving \(n=3,4\).

For \(r=3\),
\[
g(n,3)=\frac{n^2-7n+8}{2}\ge 0
\]
for \(n\ge 6\), leaving \(n=3,4,5\).

For \(r\ge 4\), monotonicity gives
\[
g(n,r)\ge g(r,r)=\frac{r(r-4)(r+1)}6\ge 0.
\]
Thus (LPS) proves the desired inequality except possibly for
\[
(n,r)\in \{(3,2),(3,3),(4,2),(4,3),(5,3)\}.
\]

Now handle these directly.

If \(n=3\), then the only connected diameter-\(2\) complement is \(P_3\), so \(H=K_2\cup K_1\), \(m=1\), and the Laplacian spectrum of \(H\) is \((2,0,0)\). Hence:
\[
r=2:\quad 6+2=8=\binom32+1+\binom43,
\]
and
\[
r=3:\quad 9+2=11\le 3+1+\binom53=14.
\]

Let \(q=e(\overline H)\). Since \(m=\binom n2-q\), and since the sum of all Laplacian eigenvalues of \(H\) is \(2m\), we use
\[
\sum_{i=1}^r\lambda_i(H)\le 2m.
\tag{2}
\]

For \(n=4,r=2\), the desired residual bound is
\[
\sum_{i=1}^2\lambda_i(H)\le m+2.
\]
If \(q\ge 4\), then \(m\le 2\), so by (2),
\[
\sum_{i=1}^2\lambda_i(H)\le 2m\le m+2.
\]
If \(q=3\), then \(\overline H\) is a connected tree on four vertices. Diameter \(2\) forces \(\overline H=K_{1,3}\), so \(H=K_3\cup K_1\). Its Laplacian spectrum is \((3,3,0,0)\), and
\[
4\cdot 2+(3+3)=14>6+3+\binom43=13.
\]
Thus this is exactly the listed \(n=4,r=2\) failure.

For \(n=4,r=3\), the desired residual bound is
\[
\sum_{i=1}^3\lambda_i(H)\le m+4.
\]
Here \(q\ge 3\), so \(m\le 3\). By (2),
\[
\sum_{i=1}^3\lambda_i(H)\le 2m\le m+4.
\]
So no failure occurs for \(n=4,r=3\).

For \(n=5,r=3\), the desired residual bound is
\[
\sum_{i=1}^3\lambda_i(H)\le m+5.
\]
If \(q\ge 5\), then \(m\le 5\), so by (2),
\[
\sum_{i=1}^3\lambda_i(H)\le 2m\le m+5.
\]
If \(q=4\), then \(\overline H\) is a connected tree on five vertices. Diameter \(2\) forces \(\overline H=K_{1,4}\), so \(H=K_4\cup K_1\). Its Laplacian spectrum is \((4,4,4,0,0)\), and
\[
5\cdot 3+(4+4+4)=27>10+6+\binom53=26.
\]
Thus this is exactly the listed \(n=5,r=3\) failure.

Therefore C5 holds for every \(r\), except exactly for \(H=K_3\cup K_1,r=2\) and \(H=K_4\cup K_1,r=3\).
