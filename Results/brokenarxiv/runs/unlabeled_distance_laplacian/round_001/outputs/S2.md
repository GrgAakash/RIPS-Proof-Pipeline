2. Subproof or failure

Let `C = binom(n,2)`, `B_r = binom(r+2,3)`, and `Q = W(G)-C`.

By C1,
\[
\sum_{i=1}^r \partial_i^L(G)
\le nr+\min\{(D-1)nr,2Q\}.
\]

We want
\[
\sum_{i=1}^r \partial_i^L(G)\le W(G)+B_r=C+Q+B_r.
\]

There are two sufficient cases.

If
\[
Q\le C+B_r-nr,
\]
then using the `2Q` branch of C1 gives
\[
\sum_{i=1}^r \partial_i^L(G)
\le nr+2Q
\le C+Q+B_r
= W(G)+B_r.
\]

If
\[
Q\ge Dnr-C-B_r,
\]
then using the `(D-1)nr` branch gives
\[
\sum_{i=1}^r \partial_i^L(G)
\le nr+(D-1)nr
= Dnr
\le C+Q+B_r
= W(G)+B_r.
\]

Thus it remains only to know that these two cases cover all possible `Q`. This is equivalent to
\[
Dnr-C-B_r\le C+B_r-nr,
\]
or
\[
C+B_r\ge \frac{D+1}{2}nr.
\]
That is exactly C2 under the hypothesis
\[
n\ge \left\lceil \frac49(D+1)^3\right\rceil.
\]
Therefore C1 and C2 imply class (1).

Now assume `diam(G)=2`. For distinct vertices `u,v`,
\[
d_G(u,v)=
\begin{cases}
1,& uv\in E(G),\\
2,& uv\notin E(G).
\end{cases}
\]
Hence, with `\bar G` the complement,
\[
D(G)=J-I+A(\bar G).
\]
The transmission of vertex `v` is
\[
\operatorname{Tr}_G(v)=n-1+d_{\bar G}(v).
\]
Therefore
\[
L_D(G)
=\operatorname{Tr}(G)-D(G)
=((n-1)I+\operatorname{Deg}(\bar G))-(J-I+A(\bar G))
=nI-J+L(\bar G).
\]

Since `L(\bar G)1=0` and `(nI-J)1=0`, while `nI-J` acts as scalar `n` on `1^\perp`, the distance Laplacian eigenvalues are
\[
\partial_i^L(G)=n+\lambda_i(L(\bar G)),\qquad 1\le i\le n-1,
\]
and `\partial_n^L(G)=0`, where Laplacian eigenvalues are ordered nonincreasingly with `\lambda_n(L(\bar G))=0`.

Also,
\[
W(G)=\binom n2+e(\bar G),
\]
because every unordered pair contributes `1`, plus one extra contribution exactly for each nonedge of `G`.

Thus for diameter-2 graphs the target inequality becomes
\[
nr+\sum_{i=1}^r\lambda_i(L(\bar G))
\le
\binom n2+e(\bar G)+\binom{r+2}{3},
\]
with the harmless convention that the zero eigenvalue contributes when `r=n`.

Exceptional checks:

For `G=K_{1,3}`, we have `n=4`, `diam(G)=2`, and `\bar G=K_3\cup K_1`. Thus
\[
e(\bar G)=3,\qquad W(G)=\binom42+3=9.
\]
The Laplacian spectrum of `K_3\cup K_1` is
\[
3,3,0,0.
\]
Hence the distance Laplacian spectrum of `K_{1,3}` is
\[
7,7,4,0.
\]
For `r=2`,
\[
7+7=14>9+\binom43=13.
\]
For the other relevant values:
`r=1`: `7 <= 9+1`;  
`r=3`: `18 <= 9+10`;  
`r=4`: `18 <= 9+20`.  
So `K_{1,3}` fails exactly at `r=2`.

For `G=K_{1,4}`, we have `n=5`, `diam(G)=2`, and `\bar G=K_4\cup K_1`. Thus
\[
e(\bar G)=6,\qquad W(G)=\binom52+6=16.
\]
The Laplacian spectrum of `K_4\cup K_1` is
\[
4,4,4,0,0.
\]
Hence the distance Laplacian spectrum of `K_{1,4}` is
\[
9,9,9,5,0.
\]
For `r=3`,
\[
9+9+9=27>16+\binom53=26.
\]
For the other relevant values:
`r=1`: `9 <= 16+1`;  
`r=2`: `18 <= 16+4`;  
`r=4`: `32 <= 16+20`;  
`r=5`: `32 <= 16+35`.  
So `K_{1,4}` fails exactly at `r=3`.
