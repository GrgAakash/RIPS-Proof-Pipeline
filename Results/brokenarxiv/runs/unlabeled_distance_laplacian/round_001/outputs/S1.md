2. Subproof or failure

Let `V(G)={1,...,n}`. For each `j=1,...,D`, let `H_j` be the graph on vertex set `V(G)` whose edges are exactly the unordered pairs `{u,v}` with `d_G(u,v)=j`. Since `diam(G)<=D`, the graphs `H_1,...,H_D` partition the edge set of the complete graph on `V(G)`.

For any vector `x`,
```text
x^T L_D(G)x = sum_{u<v} d_G(u,v)(x_u-x_v)^2.
```
Also,
```text
x^T L(K_n)x = sum_{u<v}(x_u-x_v)^2,
```
and
```text
x^T L(H_j)x = sum_{d_G(u,v)=j}(x_u-x_v)^2.
```
Therefore
```text
L_D(G) = L(K_n) + R,
where
R = sum_{j=2}^D (j-1)L(H_j).
```

Let `S_r(M)` denote the sum of the largest `r` eigenvalues of a real symmetric matrix `M`. By Ky Fan’s inequality,
```text
S_r(L_D(G)) <= S_r(L(K_n)) + S_r(R).
```
The Laplacian spectrum of `K_n` is `n` with multiplicity `n-1` and `0` with multiplicity `1`, hence
```text
S_r(L(K_n)) <= nr.
```

Now `R` is positive semidefinite. Its trace is
```text
tr R = sum_{j=2}^D (j-1) tr L(H_j)
     = sum_{j=2}^D (j-1) 2|E(H_j)|
     = 2 sum_{u<v}(d_G(u,v)-1)
     = 2(W(G)-binom(n,2))
     = 2Q.
```
Since `R` is positive semidefinite,
```text
S_r(R) <= tr R = 2Q.
```

Also, because `0 <= d_G(u,v)-1 <= D-1`,
```text
x^T R x
= sum_{u<v}(d_G(u,v)-1)(x_u-x_v)^2
<= (D-1) sum_{u<v}(x_u-x_v)^2
= (D-1)x^T L(K_n)x.
```
Thus `R <= (D-1)L(K_n)` in Loewner order. Hence every eigenvalue of `R` is at most `(D-1)n`, so
```text
S_r(R) <= (D-1)nr.
```
Combining the two estimates for `S_r(R)` gives
```text
S_r(R) <= min{(D-1)nr, 2Q}.
```
Therefore
```text
sum_{i=1}^r partial_i^L(G)
= S_r(L_D(G))
<= nr + min{(D-1)nr, 2Q}.
```
This proves C1.

Now prove C2. Put
```text
m = D+1.
```
We need
```text
binom(n,2)+binom(r+2,3) >= (m/2)nr.
```

If `D=0`, then a connected graph of diameter at most `0` has `n=1`, and the inequality is immediate. Assume henceforth `D>=1`, so `m>=2`. Since
```text
n >= ceil(4m^3/9),
```
we have `n >= 4m^3/9`, and in particular `n>=4`.

First record the AM-GM estimate
```text
n^2/2 + r^3/6 >= c n^(4/3) r,
where c = (1/2)(9/4)^(1/3).
```
Indeed, minimizing `n^2/(2r)+r^2/6` over `r>0` gives exactly the lower bound `c n^(4/3)`. Since `n >= 4m^3/9`,
```text
c n^(1/3) >= (1/2)(9/4)^(1/3)(4/9)^(1/3)m = m/2.
```
Thus
```text
n^2/2 + r^3/6 >= (m/2)nr.        (*)
```

Now split into two cases.

Case 1: `r^2 + (2/3)r >= n`.

Then
```text
binom(n,2)+binom(r+2,3)
= n^2/2 + r^3/6 + (r^2/2 + r/3 - n/2)
>= n^2/2 + r^3/6.
```
By `(*)`,
```text
binom(n,2)+binom(r+2,3) >= (m/2)nr.
```

Case 2: `r^2 + (2/3)r < n`.

Then `r < sqrt(n)`. Define, for real `t>0`,
```text
h(t)= n(n-1)/(2t) + (t+1)(t+2)/6.
```
Since
```text
binom(n,2)+binom(r+2,3) = r h(r),
```
it suffices to show `h(r) >= mn/2`.

For `0<t<=sqrt(n)`,
```text
h'(t)= -n(n-1)/(2t^2) + (2t+3)/6
     <= -(n-1)/2 + (2sqrt(n)+3)/6
     = (-3n+2sqrt(n)+6)/6 < 0,
```
because `n>=4`. Hence `h` is decreasing on `(0,sqrt(n)]`, so `r<sqrt(n)` implies
```text
h(r) > h(sqrt(n)).
```
Now
```text
h(sqrt(n))
= n(n-1)/(2sqrt(n)) + (sqrt(n)+1)(sqrt(n)+2)/6
= n^(3/2)/2 + n/6 + 1/3
= (n/2)(sqrt(n)+1/3+2/(3n)).
```
It remains to show `sqrt(n)+1/3 >= m`. This follows from
```text
n >= 4m^3/9 >= (m-1/3)^2,
```
because
```text
4m^3/9 - (m-1/3)^2
= (4m^3 - 9m^2 + 6m - 1)/9 >= 0
```
for every `m>=2`; the cubic has value `7` at `m=2` and derivative
```text
12m^2-18m+6 = 6(2m-1)(m-1) >= 0
```
for `m>=2`.

Therefore
```text
h(r) >= mn/2,
```
and hence
```text
binom(n,2)+binom(r+2,3) >= (m/2)nr.
```
This proves C2.
