1. Target decomposition

target_label: Distance-Laplacian Brouwer-type inequality for three graph classes

target_type: multi-class spectral graph inequality

main_goal: Prove that for each listed graph class and every admissible integer `r`,
\[
\sum_{i=1}^{r}\partial_i^L(G)\le W(G)+\binom{r+2}{3}.
\]

variables_and_parameters:
`G`: finite simple connected graph  
`n`: order of `G`  
`r`: integer with `1 <= r <= n`  
`D`: diameter upper bound in class (1)  
`k`: parameter in class (3), with `Delta(G)=n-k`  
`W(G)`: Wiener index  
`\partial_i^L(G)`: distance Laplacian eigenvalues in nonincreasing order

conclusion_to_prove:
The target inequality holds for:
(1) `diam(G)<=D` and `n >= ceil(4/9 (D+1)^3)`;  
(2) every diameter-2 graph except `K_{1,3}` at `r=2` and `K_{1,4}` at `r=3`;  
(3) every graph with `Delta(G)=n-k` and `n>=N(k)`, where `N(2)=10`, `N(k)=ceil(5(k-1)^{3/2})` for `k>=3`.

2. Available tools

tool: Distance-Laplian as weighted Laplacian  
source_status: standard background fact  
exact_statement_or_fact: For weights `w_uv=d_G(u,v)`, `L_D(G)` is the weighted Laplacian of the complete graph with edge weights `w_uv`; hence
\[
x^TL_D(G)x=\sum_{\{u,v\}}d_G(u,v)(x_u-x_v)^2.
\]
intended_role_in_proof: Enables PSD comparisons, trace identities, and Ky Fan bounds.

tool: Trace identity  
source_status: standard background fact  
exact_statement_or_fact:
\[
\operatorname{tr}L_D(G)=2W(G),
\]
and for any weighted Laplacian with total edge weight `M`, its trace is `2M`.
intended_role_in_proof: Gives crude but useful upper bounds on partial eigenvalue sums.

tool: Ky Fan maximum principle / Ky Fan inequality  
source_status: standard background fact  
exact_statement_or_fact: For Hermitian matrices,
\[
\sum_{i=1}^r\lambda_i(A+B)\le \sum_{i=1}^r\lambda_i(A)+\sum_{i=1}^r\lambda_i(B).
\]
Also, if `0 <= A <= B` in Loewner order, then partial sums of top eigenvalues of `A` are bounded by those of `B`.
intended_role_in_proof: Main spectral comparison tool.

tool: Complete graph Laplacian spectrum  
source_status: standard background fact  
exact_statement_or_fact: `L(K_n)=nI-J`, with eigenvalues `n` of multiplicity `n-1` and `0` once.
intended_role_in_proof: Provides the base `nr` contribution in decompositions of `L_D`.

tool: Diameter-layer decomposition  
source_status: proved inside the current proof  
exact_statement_or_fact: If `H_j` is the graph on `V(G)` whose edges are pairs at distance `j`, then
\[
L_D(G)=L(K_n)+\sum_{j=2}^{D}(j-1)L(H_j),
\]
and
\[
W(G)=\binom n2+\sum_{j=2}^{D}(j-1)e(H_j).
\]
intended_role_in_proof: Core for class (1).

tool: Diameter-2 complement identity  
source_status: proved inside the current proof  
exact_statement_or_fact: If `diam(G)=2` and `\bar G=H`, then
\[
L_D(G)=nI-J+L(H),\qquad W(G)=\binom n2+e(H).
\]
intended_role_in_proof: Converts class (2) into an ordinary Laplacian inequality for `\bar G`.

tool: Grone-Merris/Bai Laplacian majorization  
source_status: standard background fact  
exact_statement_or_fact: For a graph `H` with Laplacian eigenvalues `\lambda_i(H)` and conjugate degree sequence `d_i^*`,
\[
\sum_{i=1}^r\lambda_i(H)\le \sum_{i=1}^r d_i^*.
\]
intended_role_in_proof: Candidate main tool for the finite/exact diameter-2 classification.

3. Subclaim support graph

id: C1  
statement: For every connected graph with `diam(G)<=D`, writing `C=binom n2`, `B_r=binom{r+2}{3}`, and `Q=W(G)-C`,
\[
\sum_{i=1}^r\partial_i^L(G)
\le nr+\min\{(D-1)nr,\,2Q\}.
\]
uses_prior_subclaims: none  
purpose: Gives the universal diameter-bounded estimate needed for class (1).  
status: must be proved in final proof.  
suggested_solver: S1.

id: C2  
statement: If
\[
n\ge \left\lceil \frac49(D+1)^3\right\rceil,
\]
then for all `1<=r<=n`,
\[
\binom n2+\binom{r+2}{3}\ge \frac{D+1}{2}nr.
\]
uses_prior_subclaims: none  
purpose: Numeric gap lemma allowing the two branches in C1 to cover all possible `Q`.  
status: must be proved in final proof.  
suggested_solver: S1.

id: C3  
statement: C1 and C2 imply class (1). Namely, if `Q <= C+B_r-nr`, use the trace branch; if `Q >= Dnr-C-B_r`, use the spectral branch; C2 guarantees these intervals overlap.  
uses_prior_subclaims: C1, C2  
purpose: Completes the large-order bounded-diameter case.  
status: must be proved in final proof.  
suggested_solver: S2.

id: C4  
statement: For diameter-2 graphs,
\[
L_D(G)=nI-J+L(\bar G),\qquad W(G)=\binom n2+e(\bar G),
\]
so the target inequality is equivalent to
\[
nr+\sum_{i=1}^r\lambda_i(L(\bar G))
\le \binom n2+e(\bar G)+\binom{r+2}{3}.
\]
Also verify directly that `K_{1,3}` fails only at `r=2`, and `K_{1,4}` fails only at `r=3`.  
uses_prior_subclaims: none  
purpose: Reduces class (2) to an ordinary Laplacian statement and identifies the exceptions.  
status: must be proved in final proof.  
suggested_solver: S2.

id: C5  
statement: Let `H` be any graph whose complement is connected of diameter 2. Then
\[
nr+\sum_{i=1}^r\lambda_i(L(H))
\le \binom n2+e(H)+\binom{r+2}{3}
\]
for every `r`, except exactly when `H=K_3\cup K_1, r=2` or `H=K_4\cup K_1, r=3`.  
uses_prior_subclaims: C4  
purpose: Main exact diameter-2 classification.  
status: must be proved in final proof.  
suggested_solver: S3.

id: C6  
statement: If `Delta(G)=n-k`, choose a vertex `v` of degree `n-k` and let `B=V(G)\setminus N_G[v]`, so `|B|=k-1`. Add all missing edges from `v` to `B` to obtain a graph `G_0` with a universal vertex. Then `diam(G_0)<=2`, `W(G_0)<=W(G)`, and
\[
L_D(G)=L_D(G_0)+P,
\]
where `P` is a PSD weighted Laplacian supported only on pairs with at least one endpoint in `B`.  
uses_prior_subclaims: none  
purpose: Structural reduction for high maximum degree.  
status: must be proved in final proof.  
suggested_solver: S4.

id: C7  
statement: With notation from C6, for `n>=N(k)` and every `r`,
\[
\sum_{i=1}^r\lambda_i(P)
\le \bigl(W(G)-W(G_0)\bigr)
+\Bigl(W(G_0)+\binom{r+2}{3}
-\sum_{i=1}^r\partial_i^L(G_0)\Bigr).
\]
Consequently, Ky Fan plus the diameter-2 result for `G_0` proves class (3).  
uses_prior_subclaims: C4, C5, C6  
purpose: Main perturbation estimate for the high-degree case.  
status: must be proved in final proof.  
suggested_solver: S5.

4. Hardest step prediction

hardest_step_id: C7

hardest_step_description: Proving the vertex-cover perturbation estimate for `P`, using only that the distance defect is supported on the `k-1` nonneighbors of a maximum-degree vertex and that `n` is at least `N(k)`.

risk_if_wrong: The proof of class (3) collapses. A crude trace bound gives `2(W(G)-W(G_0))`, which is generally too weak; the missing factor must be recovered from the slack in the diameter-2 inequality for `G_0` and the small support of `P`.

how_final_proof_should_handle_it: Treat C7 as a dedicated technical lemma. Do not hide it inside prose. State the support, trace, and eigenvalue estimates for `P` explicitly, then prove the needed inequality by splitting ranges of `r` relative to `k-1` and using the numeric threshold `N(k)`.

full_theorem_check: The final proof must cover all `r=1,...,n`, all three graph classes, and explicitly verify the two listed exceptions in class (2).

source_check: Only definitions from the prompt and standard named spectral facts are allowed. No web sources, prior memory, or external paper statements.

hypothesis_check: Class (1) uses `diam(G)<=D`; class (2) uses exact diameter 2; class (3) uses `Delta(G)=n-k` and the specified `N(k)` including the special value `N(2)=10`.

notation_check: Keep ordinary Laplacian eigenvalues distinct from distance-Laplacian eigenvalues. Use `\lambda_i(L(H))` for ordinary Laplacian eigenvalues and `\partial_i^L(G)` for distance-Laplacian eigenvalues.

6. Subproblem assignment table

S1: Prove C1 and C2. Give a complete derivation of the diameter-layer decomposition, the estimate
\[
S_r\le nr+\min\{(D-1)nr,2(W-\binom n2)\},
\]
and the numeric inequality
\[
\binom n2+\binom{r+2}{3}\ge \frac{D+1}{2}nr
\]
under `n>=ceil(4/9(D+1)^3)`.

S2: Prove C3 and C4. Turn S1’s estimates into the class (1) proof. Then derive the diameter-2 complement identity and compute the spectra/Wiener indices for `K_{1,3}` and `K_{1,4}` to confirm the exact failures.

S3: Prove C5. Work entirely with the complement formulation for diameter-2 graphs. Use Grone-Merris/Bai majorization or an equally standard Laplacian bound, reduce to a degree-sequence inequality, and isolate exactly the two exceptional complements `K_3∪K_1` and `K_4∪K_1`.

S4: Prove C6. For `Delta(G)=n-k`, build `G_0` by making a maximum-degree vertex universal. Prove `diam(G_0)<=2`, identify where distances can decrease, prove `P=L_D(G)-L_D(G_0)` is PSD, and show its weighted support has vertex cover size `k-1`.

S5: Prove C7. Establish the perturbation inequality for the PSD weighted Laplacian `P` supported on the `k-1` exceptional vertices. Split into `k=2` with `n>=10` and `k>=3` with `n>=ceil(5(k-1)^{3/2})`. Combine Ky Fan, C5 for `G_0`, and the perturbation estimate to finish class (3).
