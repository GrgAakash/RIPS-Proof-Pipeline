## 1. Assignment Restatement

For fixed `n >= 1`, define the finite-system class `K_p^n` for the two-sorted ultrametric Fraisse class `K`. An object should be a finite two-sorted ultrametric space equipped with `n` partial automorphisms, where each partial automorphism has both a point-sort component and a distance-sort component. I also spell out morphisms/extensions and check that this is the standard class appearing in the KR/HHLS ample-generics criterion.

## 2. Subproof Or Failure

Fix notation. For `A in K`, write

`A = (X_A, D_A, 0_A, <=_A, d_A)`,

where `X_A` is the point sort and `D_A` is the finite linearly ordered distance sort.

A finite substructure `B <= A` consists of subsets `X_B subseteq X_A` and `D_B subseteq D_A` such that:

- `0_A in D_B`;
- for all `x,y in X_B`, `d_A(x,y) in D_B`;
- the order and distance map are inherited from `A`.

Thus inclusions of substructures are dc-embeddings.

A partial dc-automorphism `p` of `A` is an isomorphism between two finite substructures of `A`. Equivalently, it consists of:

- point sets `dom_X(p), rng_X(p) subseteq X_A`;
- distance sets `dom_D(p), rng_D(p) subseteq D_A`;
- substructures  
  `A^-_p = (dom_X(p), dom_D(p)) <= A` and  
  `A^+_p = (rng_X(p), rng_D(p)) <= A`;
- bijections  
  `p^X: dom_X(p) -> rng_X(p)` and  
  `p^D: dom_D(p) -> rng_D(p)`;

such that:

- `p^D` is an order isomorphism between the induced finite linear orders;
- `p^D(0_A) = 0_A`;
- for all `x,y in dom_X(p)`,

```text
d_A(p^X(x), p^X(y)) = p^D(d_A(x,y)).
```

The distance-domain may contain distances not realized among `dom_X(p)`; those are still moved by the distance-sort partial map, subject only to order and `0` preservation.

Now define `K_p^n`.

An object of `K_p^n` is a tuple

```text
S = (A, p_1, ..., p_n),
```

where `A in K` and each `p_i` is a partial dc-automorphism of `A`. The maps `p_i` are independent; no commutation or compatibility between different indices is required.

A morphism

```text
alpha: (A, p_1, ..., p_n) -> (B, q_1, ..., q_n)
```

is a dc-embedding `alpha = (alpha^X, alpha^D): A -> B` such that, for every `i <= n`,

```text
alpha^X[dom_X(p_i)] subseteq dom_X(q_i),
alpha^D[dom_D(p_i)] subseteq dom_D(q_i),
```

and the partial maps commute with `alpha` on their domains:

```text
q_i^X(alpha^X(x)) = alpha^X(p_i^X(x))
```

for all `x in dom_X(p_i)`, and

```text
q_i^D(alpha^D(r)) = alpha^D(p_i^D(r))
```

for all `r in dom_D(p_i)`.

Equivalently, sortwise,

```text
alpha p_i alpha^{-1} subseteq q_i
```

as partial maps on the image of `A`.

A concrete extension `S subseteq T` means the morphism is inclusion on both sorts: the underlying two-sorted ultrametric space of `S` is a substructure of that of `T`, and each partial map of `T` extends the corresponding partial map of `S` on both the point sort and the distance sort.

This is a genuine category: identities satisfy the compatibility condition, and composition preserves it.

Standard background used here: the KR/HHLS criterion says that if `K` is a Fraisse class with limit `U`, then `Aut(U)` has ample generics iff, for every `n >= 1`, the category `K_p^n` of finite `K`-structures with `n` partial automorphisms has JEP and WAP.

This definition is exactly the one needed for that criterion. Basic open conditions in `Aut(U)^n` are finite specifications saying that each automorphism extends a finite partial automorphism of `U`. In the two-sorted setting, such a finite partial automorphism must specify both point-sort and distance-sort behavior, preserving order, `0`, and the distance map. Conversely, every object of `K_p^n`, once embedded into `U`, gives such a finite basic condition; by standard Fraisse ultrahomogeneity, each finite partial dc-automorphism extends to an automorphism of `U`.

Thus the remaining class-specific work for the target is precisely to prove JEP and WAP for these `K_p^n`.
