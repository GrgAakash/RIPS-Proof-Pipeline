## 2. Subproof Or Failure

### Free Ultrametric Amalgamation

Let \(A\subseteq B,C\) be finite ultrametric spaces, with \(A\) nonempty on the point sort. Assume the embeddings over \(A\) are dc-embeddings. Also assume the distance sorts \(D_B,D_C\) have been embedded into a common finite linearly ordered distance sort \(D_E\), preserving \(0\), and agreeing on \(D_A\). Identify the distance sorts with their images in \(D_E\).

Define the point set

\[
E=B\cup_A C.
\]

For pairs both in \(B\) or both in \(C\), keep the old distance. For \(b\in B\), \(c\in C\), define the bridge distance by

\[
d_E(b,c)=\min_{a\in A}\max\{d_B(b,a),d_C(a,c)\}.
\]

The minimum exists because \(A\) is finite and nonempty, and the value lies in \(D_E\).

If \(b\in A\), then this bridge formula agrees with the old distance in \(C\). Indeed, for every \(a\in A\), the ultrametric inequality in \(C\) gives

\[
d_C(b,c)\leq \max\{d_C(b,a),d_C(a,c)\},
\]

and taking \(a=b\) gives equality. The same argument applies if \(c\in A\). Thus the definition is compatible on overlaps.

Symmetry is immediate. Also \(d_E(x,y)=0\) iff \(x=y\): this is inherited inside \(B\) and \(C\), while if \(b\in B\setminus A\) and \(c\in C\setminus A\), then for every \(a\in A\), both \(d_B(b,a)\) and \(d_C(a,c)\) are nonzero, so the bridge value is nonzero.

It remains to prove the ultrametric inequality. The only nontrivial case has two points on one side and one on the other. Let \(x,y\in B\) and \(z\in C\). Write

\[
\alpha=d_E(x,y),\quad \beta=d_E(x,z),\quad \gamma=d_E(y,z).
\]

Choose \(a,b\in A\) such that

\[
\beta=\max\{d_B(x,a),d_C(a,z)\},
\]
\[
\gamma=\max\{d_B(y,b),d_C(b,z)\}.
\]

First,

\[
d_B(x,y)\leq \max\{d_B(x,a),d_B(a,b),d_B(b,y)\}.
\]

Since \(a,b\in A\), \(d_B(a,b)=d_C(a,b)\), and in \(C\),

\[
d_C(a,b)\leq \max\{d_C(a,z),d_C(z,b)\}.
\]

Each term on the right is bounded by \(\max\{\beta,\gamma\}\). Hence

\[
\alpha\leq \max\{\beta,\gamma\}.
\]

Second, using \(b\) as a candidate in the bridge formula for \(\beta\),

\[
\beta\leq \max\{d_B(x,b),d_C(b,z)\}.
\]

But

\[
d_B(x,b)\leq \max\{d_B(x,y),d_B(y,b)\}\leq \max\{\alpha,\gamma\},
\]

and \(d_C(b,z)\leq \gamma\). Therefore

\[
\beta\leq \max\{\alpha,\gamma\}.
\]

Swapping \(x\) and \(y\) gives

\[
\gamma\leq \max\{\alpha,\beta\}.
\]

Thus every mixed triple satisfies the ultrametric inequality. All other triples lie inside \(B\) or inside \(C\), so \(E\) is a finite ultrametric space. The inclusions \(B\hookrightarrow E\) and \(C\hookrightarrow E\) are dc-embeddings.

### JEP For \(K_p^n\)

Use the standard convention that an object of \(K_p^n\) is a finite two-sorted ultrametric space equipped with \(n\) finite partial automorphisms, each having a point part and a distance-sort part.

Let \(P,Q\in K_p^n\). Rename their point sets disjointly. Add a fresh point \(*\) and a fresh distance value \(\tau\) to each, with \(\tau\) above all old distances. Set

\[
d(*,x)=\tau
\]

for every old point \(x\), and \(d(*,*)=0\). Extend each of the \(n\) partial automorphisms by fixing \(*\) on the point sort and fixing \(\tau\) on the distance sort. This remains a partial automorphism because all new distances involving \(*\) are \(\tau\), and \(\tau\mapsto\tau\).

Now both expanded systems share the common subspace with point set \(\{*\}\) and distance sort \(\{0,\tau\}\), with all partial automorphisms fixing it.

Amalgamate the distance sorts over \(\{0,\tau\}\) by placing the nonzero old distances of \(P\) and \(Q\) as disjoint finite blocks below \(\tau\), preserving their internal orders. The union of the corresponding distance partial automorphisms is still order-preserving, since each stays inside its own block and fixes \(0,\tau\).

Apply the free ultrametric amalgamation lemma over \(\{*\}\). For \(p\in P\), \(q\in Q\),

\[
d(p,q)=\max\{d(p,*),d(*,q)\}=\max\{\tau,\tau\}=\tau.
\]

The point partial automorphisms also amalgamate by union, since they agree on \(*\). Cross-distances are preserved because every cross-distance is \(\tau\), and every distance partial automorphism fixes \(\tau\).

Thus the resulting finite \(K_p^n\)-object contains embeddings of both \(P\) and \(Q\). Therefore \(K_p^n\) has JEP.
