### Standard Background Used

**KR/HHLS criterion.** Let `K` be a Fraisse class with limit `U`. If, for every `n >= 1`, the class `K_p^n` of finite systems with `n` partial automorphisms has JEP and WAP, then `Aut(U)` has ample generics.

Here `K_p^n` denotes finite `K`-structures equipped with `n` partial automorphisms, with embeddings preserving the partial automorphisms.

### Explicit Prerequisites From S2-S4

For fixed `n >= 1`, assume the following have been proved.

**P1. Free ultrametric point amalgamation.**  
If two finite ultrametric structures `B` and `C` share a common substructure `A` and have already been amalgamated on the ordered distance sort, then their point sorts can be freely amalgamated over `A` by defining cross-distances using the usual ultrametric free-amalgam formula, and the result is again a finite two-sorted ultrametric structure.

Concretely, once the distance set is a common ordered amalgam `D_E`, for `b in B \ A` and `c in C \ A`, define

```text
d_E(b,c) = min_{a in A_X} max{d_B(b,a), d_C(a,c)}
```

with distances read inside `D_E`. If `A_X` is empty, choose a sufficiently large distance in `D_E` above all existing distances. This gives a valid ultrametric amalgam.

**P2. Prepared extension.**  
For every object `A = (A, p_1, ..., p_n)` in `K_p^n`, there is an extension

```text
e : A -> A*
```

in `K_p^n`

such that the distance-sort partial automorphisms in `A*` are prepared for equivariant finite amalgamation.

**P3. Ordered-distance equivariant amalgamation.**  
If `A*` is prepared and

```text
f : A* -> B,
g : A* -> C
```

are embeddings in `K_p^n`, then the finite ordered distance systems of `B` and `C` admit an equivariant amalgam over `A*`.

That is, there is a finite linearly ordered distance set `D_E` with least element `0`, order-preserving embeddings

```text
D_B -> D_E,
D_C -> D_E
```

agreeing on `D_{A*}`, and the induced partial automorphisms on distances are compatible with all `p_1, ..., p_n`.

**P4. JEP for `K_p^n`.**  
For every `n >= 1`, `K_p^n` has JEP.

### WAP For `K_p^n`

Fix `n >= 1`. Let

```text
A = (A, p_1, ..., p_n)
```

be an object of `K_p^n`.

By P2, choose a prepared extension

```text
e : A -> A*.
```

I claim that `e` is a WAP witness for `A`.

Take arbitrary embeddings in `K_p^n`

```text
f : A* -> B,
g : A* -> C.
```

We must find an object `E in K_p^n` and embeddings

```text
r : B -> E,
s : C -> E
```

such that

```text
r ∘ f ∘ e = s ∘ g ∘ e.
```

Indeed, since `f` and `g` already agree on the copy of `A*` only up to the chosen embeddings, we amalgamate over `A*`.

First apply P3 to the ordered distance sorts of `B` and `C` over `A*`. This gives a finite ordered distance set `D_E`, with least element `0`, and order-preserving embeddings of `D_B` and `D_C` into `D_E` agreeing on `D_{A*}`. Moreover, these embeddings are equivariant for the distance parts of the partial automorphisms `p_1, ..., p_n`.

Now amalgamate the point sorts over `A*_X`. Identify the common copy of `A*_X`, keep the old distances inside `B` and inside `C`, and for cross-pairs define the free ultrametric distance as in P1:

```text
d_E(b,c) = min_{a in A*_X} max{d_B(b,a), d_C(a,c)}.
```

If `A*_X` is empty, use a new or already available sufficiently large distance in `D_E` above all existing distances. By P1, this produces a finite two-sorted ultrametric structure `E`, and the natural maps

```text
r : B -> E,
s : C -> E
```

are dc-embeddings agreeing on `A*`.

It remains only to check that the `n` partial automorphisms extend to the amalgam. On the copies of `B` and `C`, define each partial automorphism `p_i^E` to agree with the corresponding partial automorphism from `B` and `C`. This is well-defined on the overlap because `f` and `g` are embeddings over `A*`, and the distance-sort amalgam was chosen equivariantly by P3.

For old pairs inside `B` or inside `C`, preservation of distances is inherited. For a cross-pair `b in B`, `c in C` lying in the domain of `p_i^E`, the free distance is computed by a minimum of expressions

```text
max{d_B(b,a), d_C(a,c)}
```

over `a in A*_X`. Since `p_i` is an isometry on each side and the prepared distance amalgam is equivariant, applying `p_i` sends this set of candidate values to the corresponding set for the pair `(p_i b, p_i c)`. Hence the minimum is preserved. Therefore

```text
d_E(p_i b, p_i c) = p_i^D(d_E(b,c))
```

whenever both sides are defined.

Thus each `p_i^E` is a partial automorphism of `E`, and `E` is an object of `K_p^n`. The embeddings `r` and `s` preserve all partial automorphisms and agree on `A*`, hence in particular

```text
r ∘ f ∘ e = s ∘ g ∘ e.
```

So `e : A -> A*` witnesses WAP for `A`.

Since `A` was arbitrary, `K_p^n` has WAP.

### Application To Ample Generics

By P4, `K_p^n` has JEP for every `n >= 1`.

By the WAP argument above, using P2 and P3, `K_p^n` has WAP for every `n >= 1`.

Therefore, by the KR/HHLS criterion, the automorphism group of the Fraisse limit `U` has ample generics.
