**2. Subproof Or Failure**

I use the standard KR convention that an extension of a partial-automorphism system may enlarge the domains of the partial point and distance maps while extending the old maps.

It is enough to consider `n=1`. Let `S` have distance sort

`0 < r < s`

and points `x0,x1,y0,y1`, with

`d(x0,x1)=r`

and every other nonzero distance equal to `s`. Define one partial automorphism `p=(pi,rho)` by

`pi(x0)=y0`, `pi(x1)=y1`, and `rho(0)=0`, `rho(r)=s`.

This is a valid finite two-sorted ultrametric partial automorphism.

Now let `T` be any finite extension of this `S`. The point map of `p` in `T` cannot be total on `X_T`. If it were total, then since `X_T` is finite it would be a permutation. Hence every realized distance in `T` would lie in the domain of `rho`, and `rho` would induce an order-preserving injection from the finite set of realized distances into itself. That injection would be a bijection, hence the identity on a finite linear order. But it sends `r` to `s`, with `r<s`, contradiction.

So choose `t in X_T \ Dom(pi)`.

I now show why min-max bridge equivariance fails for arbitrary extensions of `T`. Choose a new distance `epsilon` below every positive element of `D_T`. Build two extensions `A` and `B` of `T`.

In `A`, add two new domain points `a0,a1`, both `epsilon`-close clones of `t` over `T`:

`d(a_j,t)=epsilon`, and `d(a_j,z)=d(t,z)` for `z != t`, with `d(a0,a1)=epsilon`.

Extend the distance partial map so that `epsilon` is in its domain, say `rho_A(epsilon)=eta_A`, with `eta_A>0` chosen below all positive target values needed below. Add image points `a0+,a1+` realizing the transformed type over `Range(pi)`, and set `d(a0+,a1+)=eta_A`. Define `pi_A(a_j)=a_j+`.

The usual finite ultrametric one-point/two-point extension check applies: the transformed type over `Range(pi)` is Katetov because `rho_A` is order-preserving and extends `rho`.

Construct `B` similarly, with points `b0,b1,b0+,b1+`, distance `epsilon_B`, and image `eta_B`.

Now consider any attempted free/min-max amalgam over `T` whose distance-sort union map is order-preserving. The bridge distance between `a0` and `b0` is

`delta(a0,b0)=max(epsilon_A,epsilon_B)`,

because `t` witnesses this value, while every other base point has old positive distance from `t`, hence is farther.

Let `eta_*` be the image of this maximum under the union distance map. Since each image point type was chosen strictly above its corresponding `eta`, every base witness `z in X_T` gives

`max(d(a0+,z), d(b0+,z)) > eta_*`.

Thus

`delta(a0+,b0+) > eta_* = rho(delta(a0,b0))`.

So the min-max bridge is not equivariant. This obstruction occurs for every finite extension `T` of the displayed `S`.

Therefore the requested S3 construction cannot exist under the stated arbitrary-extension min-max requirement.
