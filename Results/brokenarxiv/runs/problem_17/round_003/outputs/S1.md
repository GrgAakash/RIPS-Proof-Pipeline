**2. Subproof/Failure**

Fix \(n\geq 1\). Let \(K\) be the finite two-sorted ultrametric structures from the prompt, with dc-embeddings.

A finite object is written
\[
A=(X_A,D_A,0,<_{A},d_A).
\]

A substructure \(B\leq A\) means:

- \(X_B\subseteq X_A\),
- \(D_B\subseteq D_A\), with \(0\in D_B\),
- the order and distance map are inherited,
- \(d_A(x,y)\in D_B\) for all \(x,y\in X_B\).

Thus the inclusion \(B\hookrightarrow A\) is a dc-embedding.

A partial dc-isomorphism \(p\) of \(A\) is a dc-isomorphism
\[
p:A_0\to A_1
\]
between substructures \(A_0,A_1\leq A\). Equivalently,
\[
p=(p_X,p_D)
\]
where \(p_X:X_{A_0}\to X_{A_1}\) is a bijection, \(p_D:D_{A_0}\to D_{A_1}\) is an order-preserving bijection with \(p_D(0)=0\), and
\[
d_A(p_Xx,p_Xy)=p_D(d_A(x,y))
\]
for all \(x,y\in X_{A_0}\).

A finite \(n\)-system is a tuple
\[
S=(A^S,p_1^S,\dots,p_n^S),
\]
where \(A^S\in K\) and each \(p_i^S\) is a partial dc-isomorphism of \(A^S\). The class of these systems is \(K_p^n\).

An embedding of systems
\[
e:S\to T
\]
is a dc-embedding \(e=(e_X,e_D):A^S\to A^T\) such that for each \(i\leq n\),
\[
e(\operatorname{dom} p_i^S)\leq \operatorname{dom} p_i^T
\]
and
\[
p_i^T\!\upharpoonright e(\operatorname{dom} p_i^S)
=
e\circ p_i^S\circ e^{-1}.
\]
Componentwise:
\[
p_{i,X}^T(e_Xx)=e_X(p_{i,X}^Sx),
\qquad
p_{i,D}^T(e_Dr)=e_D(p_{i,D}^Sr).
\]

An extension of \(S\) is a system embedding \(S\to T\). When convenient, we identify it with an inclusion \(S\leq T\), meaning \(A^S\leq A^T\) and each \(p_i^T\) extends \(p_i^S\) on both sorts.

JEP for \(K_p^n\): for all \(S,T\in K_p^n\), there are \(R\in K_p^n\) and embeddings
\[
S\to R,\qquad T\to R.
\]

WAP for \(K_p^n\): for every \(S\in K_p^n\), there is an extension
\[
e:S\to T
\]
such that whenever
\[
f:T\to A,\qquad g:T\to B
\]
are embeddings in \(K_p^n\), there are \(C\in K_p^n\) and embeddings
\[
h:A\to C,\qquad k:B\to C
\]
with
\[
h\circ f\circ e=k\circ g\circ e.
\]
So the two extensions of \(T\) need only amalgamate over the original \(S\), not necessarily over all of \(T\).

Standard background used: elementary facts about finite linear orders, namely that order-preserving injections compose, an order-preserving bijection between finite linear orders has an order-preserving inverse, and restrictions of order-preserving injections remain order-preserving.

Closure checks:

- Dc-embeddings compose. If \(e:A\to B\) and \(f:B\to C\), then
\[
(f\circ e)_X=f_X\circ e_X,\qquad (f\circ e)_D=f_D\circ e_D
\]
is again injective, order-preserving on distances, fixes \(0\), and preserves distances.

- Partial dc-isomorphisms invert. If \(p:A_0\to A_1\) is partial, then \(p^{-1}:A_1\to A_0\) is partial, because \(p_D^{-1}\) is order-preserving and the distance equation reverses.

- Partial dc-isomorphisms restrict. If \(p:A_0\to A_1\) and \(B_0\leq A_0\), then \(p[B_0]\leq A_1\), and
\[
p\!\upharpoonright B_0:B_0\to p[B_0]
\]
is again a partial dc-isomorphism.

- Partial dc-isomorphisms compose on their natural domain. If \(p:A_0\to A_1\) and \(q:B_0\to B_1\), define the domain of \(q\circ p\) by
\[
X=\{x\in X_{A_0}:p_X(x)\in X_{B_0}\},
\]
\[
D=\{r\in D_{A_0}:p_D(r)\in D_{B_0}\}.
\]
This is a substructure of \(A_0\). On it, \(q\circ p\) is a partial dc-isomorphism, since
\[
d(qp(x),qp(y))
=q_D(d(p(x),p(y)))
=q_Dp_D(d(x,y)).
\]

- System embeddings compose. If \(e:S\to T\) and \(f:T\to R\), then \(f\circ e:S\to R\), because each partial map commutes with the embeddings on both point and distance sorts.

Therefore \(K_p^n\) is a well-defined category of finite \(n\)-systems with system embeddings.
