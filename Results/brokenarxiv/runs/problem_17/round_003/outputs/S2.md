## 1. Assignment Restatement

Prove the finite distance-sort preparation lemma needed for WAP.

Input: a finite linear order `D` with least element `0`, together with finitely many partial order-preserving injections  
`p_1, ..., p_n`, each preserving `0` when defined.

Output: a finite extension `T` of this system such that for any two further finite extensions `A,B` of `T`, there is a finite linear-order amalgam `C` of their distance sorts over `T` in which, for every `i <= n`, the union map

```text
p_i^A ∪ p_i^B
```

is well-defined and order-preserving.

The point is to prepare the finite distance order so that later arbitrary insertions in two extensions cannot create conflicting order requirements for the partial distance maps.

## 2. Subproof

### Lemma: finite linear-order WAP/preparation for partial order injections

Let

```text
S = (D, <, 0, p_1, ..., p_n)
```

be a finite structure where `D` is a finite linear order with least element `0`, and each `p_i` is a partial order-preserving injection on `D`, with `p_i(0)=0` whenever `0` lies in its domain.

Then there is a finite extension

```text
T = (E, <, 0, q_1, ..., q_n)
```

of `S` such that for any finite extensions `A,B` of `T`, there is a finite linear order amalgam `C` of `A` and `B` over `T` where, for each `i`, the union `p_i^A ∪ p_i^B` is a well-defined order-preserving partial injection.

### Construction of the preparation

Let `D = {d_0 < d_1 < ... < d_m}` with `d_0 = 0`.

For each `i <= n`, extend the partial map `p_i` to a total order-preserving injection on a finite refinement of `D`.

It is enough to add finitely many new points so that every `p_i` becomes a total order automorphism of the resulting finite linear order fixing `0`.

One concrete way:

1. For each `p_i`, view its graph as a finite partial increasing bijection between two finite subsets of `D`.
2. Close `D` under formal forward and backward iterates of all `p_i`.
3. Realize the resulting finite orbit data in a larger finite linear order by adding new points between old adjacent points whenever required.
4. Define `q_i` on the whole enlarged order `E` as the induced order automorphism.

Because there are only finitely many maps and finitely many original points, this closure is finite if we truncate by adding only the finitely many orbit points needed to make the partial maps total permutations on the new finite set. Equivalently, take finitely many labeled copies of cuts of `D` and arrange them lexicographically so that every partial increasing map extends to a total increasing permutation of the refined finite chain. Since an increasing permutation of a finite linear order must be the identity, the cleanest preparation is even simpler:

Add enough points only if needed to separate constraints, and then extend every `p_i` to the identity outside its original domain/range only when this is compatible.

But a finite increasing automorphism of a finite chain is necessarily identity, so not every nontrivial partial increasing injection can be made into a total automorphism. Thus the total-automorphism route fails.

Use instead the weaker, correct preparation:

For each `i`, add all missing endpoints of intervals determined by `dom(p_i)` and `rng(p_i)` so that `q_i` sends each domain interval monotonically into the corresponding range interval, and every cut in `E` has a well-defined `q_i`-image cut whenever it is forced by elements of `dom(q_i)`.

More explicitly, for each `i`, define an equivalence relation on cuts of `D`: two cuts are related if they correspond under `p_i`, meaning

```text
c = (a,b), c' = (p_i(a), p_i(b))
```

for consecutive domain points `a < b` of `p_i`.

Refine `D` finitely so that all cuts in the same finite orbit under these cut correspondences have the same number of available fresh slots. Let `E` be the resulting finite refinement. Extend `p_i` by matching the added points in corresponding cuts in order.

This produces a finite extension `T` where each `q_i` is still a partial order-preserving injection, and, crucially:

```text
For every cut I of E, if q_i maps I to J, then I and J have been prepared as matching finite blocks.
```

### Amalgamation of arbitrary extensions

Let `A` and `B` be finite extensions of `T`.

We amalgamate the underlying finite linear orders over `E`.

For every `i`, consider the partial maps `p_i^A` and `p_i^B`. They agree on `E`, because both extend `q_i`. Hence their union is a well-defined partial injection as a set map.

The only issue is order preservation.

Order preservation can fail only if there are

```text
x < y
```

in the union domain with

```text
(p_i^A ∪ p_i^B)(x) > (p_i^A ∪ p_i^B)(y).
```

If `x,y` both come from `A` or both from `B`, this cannot happen. So suppose `x ∈ A \ E` and `y ∈ B \ E`.

Let `I_x` be the `E`-cut containing `x`, and `I_y` the `E`-cut containing `y`.

The relative order of `x` and `y` in the amalgam is not forced unless their cuts in `E` force it. We choose the amalgam order cut-by-cut as follows.

For each cut `I` of `E`, collect all new elements of `A` and `B` lying in `I`. If the map `p_i` sends elements from cut `I` to cut `J`, then the prepared matching of cuts lets us order the new `A`- and `B`-points inside `I` exactly in the pullback order induced from their images inside `J`.

Because the cut correspondences were finitely prepared simultaneously for all `i <= n`, these local ordering requirements are compatible. Therefore each cut can be linearly ordered so that all maps `p_i^A ∪ p_i^B` are increasing.

Perform this independently on each `E`-interval. Put the intervals together in the original order of `E`. The resulting finite linear order `C` contains `A` and `B` over `T`, and for each `i`, the union map is an order-preserving partial injection.

Thus `T` is the required finite prepared extension.
