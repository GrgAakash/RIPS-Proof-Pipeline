## 1. Assignment Restatement

Prove the fresh-top ultrametric amalgamation lemma for S3:

Given two finite ultrametric systems over a common base, and assuming their distance sorts have already been compatibly amalgamated with the relevant partial distance maps, form the point amalgam by disjoint union over the base. Add one new largest distance `M`, require every partial distance map to fix `M`, and set every genuinely cross-side point distance to `M`. Verify:

- the result is a finite two-sorted ultrametric space;
- both original systems embed by dc-embeddings;
- the partial point maps remain dc-embeddings;
- the construction is equivariant for the partial maps.

## 2. Subproof

### Fresh-Top Ultrametric Amalgamation Lemma

Let `B` and `C` be finite two-sorted ultrametric spaces with common finite subspace `A`, where the inclusions are dc-embeddings and we identify `A` inside both point sorts.

Assume their distance sorts have been amalgamated into a finite linear order `E` extending the images of `D_B` and `D_C` over `D_A`, with least element `0`.

Assume also that for each partial map index `i`, the distance-sort partial maps from `B` and `C` have compatible union on `E`: that union is a well-defined order-preserving partial injection.

Now adjoin a fresh element `M` to `E`, greater than every element of `E`. Let

```text
E^+ = E ∪ {M}
```

with `M` the new maximum.

Extend each partial distance map by declaring

```text
ρ_i(M) = M
```

whenever `M` is included in its domain; equivalently, for the amalgamated system we may include `M` in both domain and range and make it fixed by every `ρ_i`.

Define the point set

```text
X = B ∪_A C
```

as the disjoint union of the point sets of `B` and `C` over their shared copy of `A`.

Define the distance `d_X` as follows:

- if `x,y ∈ B`, set `d_X(x,y)` equal to the image of `d_B(x,y)` in `E^+`;
- if `x,y ∈ C`, set `d_X(x,y)` equal to the image of `d_C(x,y)` in `E^+`;
- if `x ∈ B \ A` and `y ∈ C \ A`, set

```text
d_X(x,y) = M.
```

This is well-defined because the two definitions agree on `A`: both embeddings preserve the old distances through the common copy of `D_A`.

### Metric Axioms

Symmetry is immediate from symmetry in `B` and `C`, and from the symmetric cross-distance definition.

Also `d_X(x,y)=0` iff `x=y`:

- inside one side this holds because `B` and `C` are ultrametric spaces;
- if `x ∈ B \ A` and `y ∈ C \ A`, then `d_X(x,y)=M`, and `M ≠ 0`.

### Ultrametric Inequality

We must show

```text
d_X(x,z) ≤ max{d_X(x,y), d_X(y,z)}
```

for all `x,y,z ∈ X`.

If all three points lie in `B`, this is true because `B` is ultrametric. The same holds if all three lie in `C`.

Otherwise, the triple uses both sides. If one of the two distances on the right is a genuine cross-distance, it is `M`, hence the right side is `M`, the largest element of `E^+`, and the inequality is automatic.

The only remaining mixed case is when `x,z` are on opposite non-base sides but both `d_X(x,y)` and `d_X(y,z)` are not genuine cross-distances. That forces `y ∈ A`, `x ∈ B \ A`, and `z ∈ C \ A`, or symmetrically. Then

```text
d_X(x,z) = M,
```

while `d_X(x,y), d_X(y,z) ∈ E`, so their maximum is below `M`. But this case cannot avoid having a cross-distance on the right: if `x ∈ B \ A`, `z ∈ C \ A`, and `y ∈ A`, then both `x,y` lie in `B` and `y,z` lie in `C`, so the right side is below `M`.

Thus the inequality in the displayed orientation may fail for the ordered triple `(x,y,z)`.

The corrected fresh-top construction therefore sets

```text
d_X(b,c) = M
```

for every pair with `b ∈ B \ A` and `c ∈ C \ A`, but this alone is not sufficient unless every bridge through `A` also has right-hand maximum `M`.

So the usable fresh-top amalgamation must instead make all cross-side distances from either non-base side to the opposite side equal to `M`, including base bridges when needed. But distances from a base point to a side point are already fixed by the side metric and cannot be changed without losing the embeddings.

Therefore, as stated with ordinary amalgamation over a nonempty base, the pure “set only new cross-distances to a fresh top” construction does **not** prove ultrametricity.

### Counterexample

Let the base `A` have one point `a`. Let `B` add one point `b` with

```text
d_B(a,b)=r
```

and let `C` add one point `c` with

```text
d_C(a,c)=s
```

where `r,s < M`.

The fresh-top construction sets

```text
d_X(b,c)=M.
```

For the triple `(b,a,c)` the ultrametric inequality requires

```text
d_X(b,c) ≤ max{d_X(b,a), d_X(a,c)}.
```

That is

```text
M ≤ max{r,s},
```

which is false because `M` is strictly largest.

Hence the assignment’s proposed lemma is false in this naive form.

### Salvage Condition

The fresh-top method is valid in either of the following stronger forms:

1. **Free disjoint amalgamation over empty base.**  
   If `A` is empty, every mixed triangle contains a cross edge on the right whenever needed, so the top-distance argument works.

2. **Top-separated extensions over the base.**  
   If every point outside `A` is already at distance `M` from every base point, then for any mixed triangle `b,a,c` with `a ∈ A`, the right-hand side is already `M`, so ultrametricity holds.

Under this top-separated hypothesis, the previous verification goes through: any mixed triangle has at least one right-hand edge equal to `M`, or all three points lie on one side.
