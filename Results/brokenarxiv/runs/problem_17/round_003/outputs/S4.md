**2. Subproof**

Fix `n >= 1` and a finite system

```text
S = (X_S, D_S, d_S, p_1, ..., p_n)
```

in `K_p^n`, where each `p_i` consists of a finite partial point dc-isomorphism together with its associated finite partial order-preserving distance map.

By S2, extend the distance-sort part of `S` to a prepared finite distance system

```text
D_S <= D_T
```

with partial maps extended accordingly, and with a fresh top distance `M in D_T` fixed by every prepared partial distance map. Extend the point sort trivially, or by adding no new points, obtaining a finite two-sorted system

```text
T = (X_S, D_T, d_T, p_1^T, ..., p_n^T),
```

where `d_T` is just `d_S` followed by the inclusion `D_S <= D_T`. Since the distance inclusion is order-preserving and preserves `0`, `T` is again in `K_p^n`, and `S <= T`.

Now let

```text
A, B
```

be arbitrary finite extensions of `T` in `K_p^n`.

Apply S2 to the distance-sort systems of `A` and `B` over the prepared base `D_T`. We get a finite linear order `D_C` amalgamating `D_A` and `D_B` over the base required by WAP, with each union

```text
p_i^A ∪ p_i^B
```

on the distance sort a well-defined order-preserving partial injection. In particular, the chosen top cross-distance `M` remains identified on both sides and is fixed by each distance partial map.

Define the point set of the amalgam by taking the disjoint union over the point part of the original base:

```text
X_C = X_A ∪_{X_S} X_B.
```

The distances inside `A` and inside `B` are preserved, interpreted in `D_C`. For cross pairs

```text
a in X_A \ X_S,   b in X_B \ X_S,
```

set

```text
d_C(a,b) = M.
```

Also set the same value for any remaining non-base cross pair if needed. Distances involving identified base points are already determined by the corresponding side.

By S3, this fresh-top construction is a valid ultrametric: triangles internal to one side hold because `A` and `B` are ultrametric, and triangles using points from both sides hold because every cross-distance is the top value `M`. Symmetry and separation are immediate, since `M > 0` and only identical points have distance `0`.

For each `i <= n`, define the partial point map on `C` by

```text
p_i^C = p_i^A ∪ p_i^B.
```

This is well-defined over the base because `A` and `B` are extensions of `T`, and the only identifications in `X_C` are base identifications. Its associated distance map is the already amalgamated union on `D_C`.

It remains to check equivariance for cross pairs. If `p_i^C(a)` and `p_i^C(b)` are both defined and `a,b` lie on opposite sides, then their images also lie on opposite sides or in the common base according to the prepared compatibility. In the genuine cross case,

```text
d_C(p_i^C(a), p_i^C(b)) = M = p_i^C_D(M) = p_i^C_D(d_C(a,b)).
```

The base/internal cases hold because they hold in `A` or `B`, and the distance-sort maps agree on the prepared base. Hence each `p_i^C` is a partial dc-automorphism of `C`.

Thus `A` and `B` have a finite amalgam after passing through the prepared extension `T`. More precisely, the embeddings of `A` and `B` into `C` agree on the original `S`, which is exactly the weak amalgamation requirement. Therefore `K_p^n` has WAP, conditional on S2 and S3.
