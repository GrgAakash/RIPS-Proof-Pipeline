**1. Assignment Restatement**

S5 task: prove JEP for each finite partial-system class `K_p^n`, then assemble the final theorem. WAP is not proved here; it is used as the S4 prerequisite.

**2. Subproof**

Fix `n >= 1`. Let

`A = (X_A, D_A, d_A, p_1^A, ..., p_n^A)` and  
`B = (X_B, D_B, d_B, p_1^B, ..., p_n^B)`

be two finite members of `K_p^n`, where each `p_i` is a finite partial dc-automorphism.

Construct a joint extension `C`.

First replace `A` and `B` by disjoint isomorphic copies on the point sort. On the distance sort, take a finite linear order `D_C` containing order-preserving copies of `D_A` and `D_B`, identifying only `0`, and add a new greatest element `rho` above every old distance. Extend each distance-sort partial map from `A` and `B` by keeping its original action on its own copied distance sort; since the two copied distance sorts are disjoint over `0`, these actions do not conflict.

Let `X_C = X_A disjoint-union X_B`. Define

- inside `X_A`, distances are copied from `A`;
- inside `X_B`, distances are copied from `B`;
- for `a in X_A`, `b in X_B`, set `d_C(a,b) = rho`.

This is an ultrametric. The only nontrivial triangle is one meeting both sides. If two points lie on one side and the third on the other, then two sides have distance `rho`, so

`d_C(x,z) <= max(d_C(x,y), d_C(y,z))`

holds immediately because `rho` is greatest.

Each `p_i^A` and `p_i^B` now combine into one partial dc-automorphism `p_i^C` on `C`: it acts as `p_i^A` on the copied `A` part and as `p_i^B` on the copied `B` part. Cross-distances are all `rho`; either no cross-distance is relevant to a partial map’s original preservation condition, or, if the combined partial map compares one domain point from each side, the image points again lie on opposite sides and the distance remains `rho`. Put `rho` fixed on the distance sort whenever needed.

Thus both `A` and `B` embed into `C` as `K_p^n`-systems. Therefore `K_p^n` has JEP.

Now assemble the theorem. By S4, for every `n >= 1`, `K_p^n` has WAP. By the JEP proof above, for every `n >= 1`, `K_p^n` also has JEP. The Kechris-Rosendal / Hodges-Hodkinson-Lascar-Shelah criterion says: if `K` is a Fraisse class and, for every `n >= 1`, the corresponding finite partial-automorphism class `K_p^n` has JEP and WAP, then the automorphism group of the Fraisse limit has ample generics.

Applying this criterion to the Fraisse limit `U` of `K`, we conclude:

`Aut(U)` has ample generics.
