## 1. Assignment Restatement

## 2. Subproof/Failure

Let `(A,p_1,...,p_n)` and `(B,q_1,...,q_n)` be two objects of `K_p^n`.

We may replace them by isomorphic copies, so assume their point sets are disjoint and their distance sorts are disjoint except for the identified zero element. Write the common zero as `0`.

Construct a finite two-sorted ultrametric space `C` as follows. Its point set is the disjoint union

`X_C = X_A ⊔ X_B`.

Its distance sort is

`D_C = {0} ∪ (D_A \ {0}) ∪ (D_B \ {0}) ∪ {τ}`,

where `τ` is fresh, with linear order extending those of `D_A` and `D_B` and satisfying

`0 < D_A \ {0} < D_B \ {0} < τ`.

Define the metric on `C` by keeping the original distances inside `A` and inside `B`, and setting

`d_C(a,b) = τ`

whenever `a ∈ X_A` and `b ∈ X_B`.

This is a finite two-sorted ultrametric space. Inside each side, ultrametricity is inherited. For a mixed triple, at least two cross-distances are `τ`, so the ultrametric inequality is immediate. The inclusions of `A` and `B` into `C` are dc-embeddings.

Now fix `i <= n`. Let `p_i` have domain substructure `P_i^-` and range substructure `P_i^+` inside `A`; similarly let `q_i` have domain `Q_i^-` and range `Q_i^+` inside `B`.

Define `r_i` on points by

`r_i^X = p_i^X ∪ q_i^X`.

Define its distance-sort map by

`r_i^D = p_i^D ∪ q_i^D ∪ {τ ↦ τ}`.

This is well-defined because the two distance sorts overlap only at `0`, and both partial automorphisms preserve `0`.

The domain of `r_i` is the finite substructure generated by `P_i^- ∪ Q_i^- ∪ {τ}` on the distance sort, and the range is similarly generated by `P_i^+ ∪ Q_i^+ ∪ {τ}`. These are finite substructures of `C`.

The map `r_i` is a dc-isomorphism. On each component, this is true because `p_i` and `q_i` are dc-isomorphisms. For a cross pair `a ∈ X_A`, `b ∈ X_B` in the domain,

`d_C(r_i(a), r_i(b)) = τ = r_i^D(d_C(a,b))`.

The distance-sort map is order-preserving: it preserves order inside the `A` part and inside the `B` part, sends `0` to `0`, fixes the new maximum `τ`, and the whole `A`-positive block remains below the whole `B`-positive block.

Thus each `r_i` is a finite partial automorphism of `C`, and `(C,r_1,...,r_n)` is an object of `K_p^n`.

The inclusions `A -> C` and `B -> C` preserve all partial automorphisms componentwise, since each `r_i` extends both `p_i` and `q_i`. Therefore the two original systems jointly embed into `(C,r_1,...,r_n)`.

Hence `K_p^n` has JEP.
