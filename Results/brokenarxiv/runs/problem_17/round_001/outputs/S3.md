## 1. Assignment Restatement

S3 must prove a finite preparation/orbit-extension lemma for any finite system  
`(A,p_1,...,p_n)` where each `p_i` is a finite partial dc-automorphism of `A`.

The needed output is a finite extension `(B,q_1,...,q_n)` such that, relative to the original core `A`, every old point and every old distance value is internal to its `q_i`-orbit: it has both a `q_i`-predecessor and a `q_i`-successor in `B`.

This subproof uses the explicit prerequisite:

**Prerequisite SC1:** finite strong dc-amalgamation for finite two-sorted ultrametric spaces over common dc-subspaces.

## 2. Subproof/Failure

Call an extension `A <= B` **A-prepared** for `(q_1,...,q_n)` if for every `i`:

- `X_A ⊆ dom(q_i^X) ∩ rng(q_i^X)`;
- `D_A ⊆ dom(q_i^D) ∩ rng(q_i^D)`.

Equivalently, no point or distance from the old core `A` is an endpoint of its partial `q_i`-orbit.

### One-map extension lemma

Let `(A,p)` be a finite one-partial-automorphism system. We construct a finite extension `(B,q)` such that `q` extends `p` and `A ⊆ dom(q) ∩ rng(q)` on both sorts.

Take an isomorphic copy `A^+` of `A`, with copy map `s:A -> A^+`. Let `P=dom(p)` and `R=rng(p)`. Since `p:P -> R` is a dc-isomorphism, amalgamate `A` and `A^+` over `P` by identifying `s(a)` with `p(a)` for every `a in P`, on both point and distance sorts. By SC1, this gives a finite two-sorted ultrametric space `C^+`. The map `s:A -> C^+` is a dc-embedding extending `p`.

Now take an isomorphic copy `C^-` of `C^+`, with isomorphism `t:C^- -> C^+`. Inside `C^-`, the preimage `t^{-1}(s(A))` is a copy of `A`. Amalgamate `C^-` and `C^+` over this copy and the original copy of `A` in `C^+`, identifying  
`t^{-1}(s(a))` with `a` for every `a in A`. Again by SC1, obtain a finite two-sorted ultrametric space `B`.

Define `q` to be the dc-isomorphism `t:C^- -> C^+`, viewed as a partial automorphism of `B`.

For `a in dom(p)`, the old element `a` is identified with `t^{-1}(s(a))`, hence  
`q(a)=t(t^{-1}(s(a)))=s(a)=p(a)`. Thus `q` extends `p`.

For every old `a in A`, `q(a)=s(a)` exists, so `a in dom(q)`. Also `t^{-1}(a)` exists and maps to `a`, so `a in rng(q)`. The same argument applies verbatim to distance-sort elements. Hence `A ⊆ dom(q) ∩ rng(q)` on both sorts.

### Finite n-map preparation

Start with `A^0=A` and `p_i^0=p_i`.

Inductively, for `k=1,...,n`, apply the one-map extension lemma to the current finite structure `A^{k-1}` and the current partial automorphism `p_k^{k-1}`. This yields a finite extension `A^k` and an extension `p_k^k` with  
`A^{k-1} ⊆ dom(p_k^k) ∩ rng(p_k^k)` on both sorts.

For `j≠k`, keep `p_j^k=p_j^{k-1}` as the same partial automorphism, now considered inside the larger ambient structure. This remains valid because dc-embeddings preserve all distances and the relative order on the old distance-domain/range.

After finitely many steps, set `B=A^n` and `q_i=p_i^n`.

Since the original `A` is contained in every intermediate `A^{k-1}`, each `q_i` has every point and every distance of `A` in both its domain and range. Therefore `(B,q_1,...,q_n)` is `A`-prepared.

### Orbit control

For a finite partial bijection, each orbit component is a finite directed path or a cycle. Since every old element of `A` has both a predecessor and a successor under each `q_i`, no old element is an endpoint of such a path. Therefore every path component meeting `A` has endpoints outside `A`; cyclic components meeting `A` are already closed.

On the distance sort, because each `q_i^D` is order-preserving, any finite cycle is a fixed singleton: if `r<q_i^D(r)`, iterates strictly increase; if `q_i^D(r)<r`, iterates strictly decrease; either contradicts return to `r`. Thus non-fixed distance orbits meeting `D_A` are finite paths whose endpoints lie outside `D_A`.

This is the required finite preparation/orbit-extension lemma.
