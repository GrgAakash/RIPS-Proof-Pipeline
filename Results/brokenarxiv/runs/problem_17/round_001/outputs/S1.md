2. Subproof or failure

We prove the amalgamation statement.

Let

\[
\alpha:A\to B,\qquad \beta:A\to C
\]

be dc-embeddings. Replacing `B` and `C` by isomorphic copies if necessary, we may assume that `A` is literally a common dc-substructure of `B` and `C`, that

\[
X_B\cap X_C=X_A,\qquad D_B\cap D_C=D_A,
\]

and that the inclusions are the given embeddings. It is enough to construct an amalgam in this situation, since composing with the chosen isomorphisms gives the general case.

First amalgamate the distance sorts. Let `E` be the disjoint union of `D_B` and `D_C` over their common subset `D_A`. Put the partial order on `E` generated by the two linear orders on `D_B` and `D_C`. This partial order is acyclic: any strict cycle would, after deleting repeated adjacent points from the same side, have to alternate between `D_B\D_A` and `D_C\D_A`; but comparability between the two sides is introduced only through elements of `D_A`, and the two orders agree on `D_A`, so such a cycle would force a strict cycle already in either `D_B` or `D_C`. Hence the generated relation is a partial order. Since `E` is finite, extend it to a finite linear order `D_D`. Its least element is the common `0`, because `0` is least in both `D_B` and `D_C`. Thus the inclusions

\[
D_B\hookrightarrow D_D,\qquad D_C\hookrightarrow D_D
\]

are order-preserving injections agreeing on `D_A`.

Let

\[
X_D=X_B\cup X_C
\]

with intersection `X_A`. Define `d_D` as follows. For pairs inside `X_B` or inside `X_C`, keep the old distances. For `b\in X_B\setminus X_A` and `c\in X_C\setminus X_A`, if `X_A` is nonempty, set

\[
d_D(b,c)=d_D(c,b)
=\min_{a\in X_A}\max\{d_B(b,a),d_C(a,c)\},
\]

where the max and min are taken in the linear order `D_D`. If `X_A` is empty, add, if necessary, one new element `\top` above every element of the previously constructed distance order and set

\[
d_D(b,c)=d_D(c,b)=\top
\]

for every `b\in X_B`, `c\in X_C`. In this empty-base case, replace `D_D` by the resulting finite linear order. In both cases set `d_D(x,x)=0`.

The inclusions of point sorts and distance sorts from `B` and `C` into `D` clearly preserve `0`, are injective, and preserve all old distances. It remains to verify that `d_D` is an ultrametric.

Symmetry is immediate from the definition. Also `d_D(x,y)=0` iff `x=y`: this holds inside `B` and `C`; for a cross pair with nonempty `A`, if

\[
d_D(b,c)=0,
\]

then for some `a\in A`,

\[
\max\{d_B(b,a),d_C(a,c)\}=0,
\]

so `b=a=c`, contradicting that the pair is genuinely cross unless both are the same point of `A`. In the empty-base case cross-distances equal `\top>0`.

Now check the ultrametric inequality. If all three points lie in `B` or all lie in `C`, it is inherited. If `A` is empty and the triple uses both sides, every cross-distance is `\top`, so the inequality is immediate.

Assume now that `A` is nonempty. It suffices by symmetry to check triples involving both sides.

First let `b,b'\in X_B` and `c\in X_C`. Choose `a\in X_A` such that

\[
d_D(b',c)=\max\{d_B(b',a),d_C(a,c)\}.
\]

Then, using the ultrametric inequality in `B`,

\[
d_B(b,a)\le \max\{d_B(b,b'),d_B(b',a)\}.
\]

Therefore

\[
\begin{aligned}
d_D(b,c)
&\le \max\{d_B(b,a),d_C(a,c)\}\\
&\le \max\{d_B(b,b'),d_B(b',a),d_C(a,c)\}\\
&=\max\{d_D(b,b'),d_D(b',c)\}.
\end{aligned}
\]

So the inequality holds for the pattern `B,B,C`. The pattern `C,C,B` is identical.

It remains to check a mixed triple `b\in X_B`, `c\in X_C`, and `a_0\in X_A`; this is already included in the previous argument if one allows `b'=a_0`, but explicitly:

\[
d_D(b,c)\le \max\{d_B(b,a_0),d_C(a_0,c)\}
=\max\{d_D(b,a_0),d_D(a_0,c)\}.
\]

The other two ultrametric inequalities in the same triple follow from the same estimate and the old ultrametric inequalities in `B` or `C`.

Thus `D` is a finite two-sorted ultrametric space, and the inclusions `B -> D` and `C -> D` are dc-embeddings agreeing on `A`. This proves finite dc-amalgamation for `K`.
