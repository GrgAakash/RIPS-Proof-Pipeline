## 2. Subproof / Failure

The prompt does not give the intrinsic S3 definition of “prepared,” so I state the exact S4 interface needed.

A finite system
\[
\mathcal A=(A,p_1,\ldots,p_n)
\]
is S4-prepared if, whenever
\[
\mathcal B=(B,q_1,\ldots,q_n),\qquad \mathcal C=(C,r_1,\ldots,r_n)
\]
are finite extensions of \(\mathcal A\), after replacing them by isomorphic copies over \(\mathcal A\), their distance sorts admit a finite ordered amalgam \(D_E\) over \(D_A\) such that each
\[
s_i^D:=q_i^D\cup r_i^D
\]
is a well-defined order-preserving partial injection, and the bridge values defined below are \(s_i^D\)-equivariant.

Assume \(B,C\) are disjoint over \(A\). Let
\[
X_E=X_B\cup_{X_A}X_C.
\]
The distance sort is the prepared compatible ordered amalgam \(D_E\). If \(X_A=\varnothing\), add one new top distance \(\rho>0\), fixed by every \(s_i^D\).

Define \(d_E\) by keeping the old distances on \(B\) and \(C\). For \(b\in X_B\), \(c\in X_C\), if \(X_A\neq\varnothing\), set
\[
d_E(b,c)=\min_{a\in X_A}\max\{d_B(b,a),d_C(a,c)\}.
\]
If \(X_A=\varnothing\), set \(d_E(b,c)=\rho\).

This agrees with the old distance when \(b\) or \(c\) lies in \(A\): for example, if \(b=a_0\in A\), then choosing \(a=a_0\) gives \(d_E(a_0,c)\le d_C(a_0,c)\), while the ultrametric inequality in \(C\) gives the reverse inequality for every \(a\in A\).

For \(X_A\neq\varnothing\), the key witness equivalence is:
\[
d_E(b,c)\le t
\]
iff there is \(a\in X_A\) such that
\[
d_B(b,a)\le t \quad\text{and}\quad d_C(a,c)\le t.
\]

Now check ultrametricity. The only nontrivial case is a mixed triple, say \(b_1,b_2\in X_B\), \(c\in X_C\). Let
\[
t=\max\{d_B(b_1,b_2),d_E(b_2,c)\}.
\]
Choose \(a\in X_A\) witnessing \(d_E(b_2,c)\le t\). Then
\[
d_B(b_1,a)\le \max\{d_B(b_1,b_2),d_B(b_2,a)\}\le t,
\]
and \(d_C(a,c)\le t\), so \(d_E(b_1,c)\le t\).

For the other mixed inequality, let
\[
t=\max\{d_E(b_1,c),d_E(b_2,c)\}.
\]
Choose witnesses \(a_1,a_2\in X_A\). Then
\[
d_A(a_1,a_2)\le \max\{d_C(a_1,c),d_C(c,a_2)\}\le t,
\]
so
\[
d_B(b_1,b_2)\le \max\{d_B(b_1,a_1),d_A(a_1,a_2),d_B(a_2,b_2)\}\le t.
\]
The case with two points from \(C\) and one from \(B\) is symmetric. If \(X_A=\varnothing\), every mixed distance is the new top \(\rho\), so the ultrametric inequality is immediate.

Define
\[
s_i^X=q_i^X\cup r_i^X,\qquad s_i^D=q_i^D\cup r_i^D
\]
and, in the empty-base case, also \(s_i^D(\rho)=\rho\). By prepared compatibility, \(s_i^D\) is order-preserving. Same-side distance preservation holds inside \(B\) and \(C\). For a mixed pair \(b\in\operatorname{dom}(q_i)\), \(c\in\operatorname{dom}(r_i)\), S4-prepared equivariance gives
\[
d_E(s_i^X b,s_i^X c)=s_i^D(d_E(b,c)).
\]
Thus each \(s_i\) is a partial automorphism of \(E\), extending both \(q_i\) and \(r_i\). Therefore prepared systems have AP in \(K_p^n\).

For WAP: assume the S3 preparation lemma says every \(\mathcal S\in K_p^n\) embeds into an S4-prepared finite system \(\mathcal A\). Given two extensions of \(\mathcal A\), prepared AP amalgamates them over all of \(\mathcal A\), hence certainly over the original copy of \(\mathcal S\). Therefore \(\mathcal A\) witnesses weak amalgamation for \(\mathcal S\). Since \(\mathcal S\) was arbitrary, \(K_p^n\) has WAP.
