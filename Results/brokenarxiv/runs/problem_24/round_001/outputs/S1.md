2. Subproof or failure

Assume \(G\) is a discrete group with Kazhdan’s property (T), as in the target theorem’s group-theoretic setting.

First, \(G\) is finitely generated. By the standard Kazhdan-pair characterization of property (T) for discrete groups, there are a finite set \(Q\subseteq G\) and \(\varepsilon>0\) such that every unitary representation with a unit vector moved by less than \(\varepsilon\) by every element of \(Q\) has a nonzero \(G\)-invariant vector. Let \(H=\langle Q\rangle\). If \(H\ne G\), consider the quasi-regular representation of \(G\) on \(\ell^2(G/H)\). The vector \(\delta_H\) is fixed by every element of \(Q\), since \(Q\subseteq H\). If \(G/H\) is infinite, this representation has no nonzero \(G\)-invariant vector, contradicting that \(Q\) is Kazhdan. If \(G/H\) is finite and \(H\ne G\), restrict to the orthogonal complement of the constant vectors; the nonzero vector \(\delta_H-|G/H|^{-1}\mathbf{1}\) is still \(Q\)-fixed but there is no nonzero \(G\)-invariant vector there. Again contradiction. Hence \(H=G\), so \(G\) is generated by the finite set \(Q\).

Now let \(S\) be a finite generating set and suppose \(a,b\in B_S(N)\) generate a free semigroup. For each \(k\ge 1\), the \(2^k\) positive words of length \(k\) in the alphabet \(\{a,b\}\) represent distinct elements of \(G\). Since \(|a|_S,|b|_S\le N\), each such word has \(S\)-length at most \(kN\). Therefore
\[
|B_S(kN)|\ge 2^k.
\]
Using the standard definition
\[
\omega(G,S)=\lim_{r\to\infty}|B_S(r)|^{1/r},
\]
whose existence follows from submultiplicativity of ball growth, we get along the subsequence \(r=kN\)
\[
\omega(G,S)
=\lim_{k\to\infty}|B_S(kN)|^{1/(kN)}
\ge \lim_{k\to\infty}(2^k)^{1/(kN)}
=2^{1/N}.
\]
Thus SC1 and SC2 are proved.
