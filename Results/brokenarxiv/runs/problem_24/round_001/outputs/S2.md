2. Subproof or failure

Let \(G\) be acylindrically hyperbolic. By the definition of acylindrical hyperbolicity used in this packet, \(G\) admits an acylindrical action on a Gromov-hyperbolic space \(X\) whose action is non-elementary, equivalently whose limit set in \(\partial X\) is infinite.

For an isometric action on a hyperbolic space, an element is loxodromic if it has exactly two fixed points on the boundary and acts with positive translation length. Two loxodromic elements are independent if their pairs of fixed points in \(\partial X\) are disjoint. A standard theorem for non-elementary acylindrical actions on hyperbolic spaces says that such an action contains independent loxodromic elements. Applying this to the non-elementary acylindrical action \(G\curvearrowright X\), there exist \(a,b\in G\) that are loxodromic for this action and whose fixed point pairs in \(\partial X\) are disjoint. This proves the dynamical setup required in SC3.

Now assume \(G\) has property (T). Property (T) passes to quotients. Also, groups with property (T) have finite abelianization. Therefore \(G\) cannot have an infinite cyclic quotient: if \(\pi:G\twoheadrightarrow \mathbb Z\), then \(\mathbb Z\) would have property (T), contradicting the fact that \(\mathbb Z\) has infinite abelianization and hence does not have property (T).

More generally, \(G\) has no infinite virtually cyclic quotient. Suppose for contradiction that \(q:G\twoheadrightarrow V\), where \(V\) is infinite virtually cyclic. Since property (T) passes to quotients, \(V\) has property (T). Every infinite virtually cyclic group has a finite-index subgroup isomorphic to \(\mathbb Z\), or at least admits an infinite virtually cyclic structure with an infinite cyclic subgroup of finite index after passing to an index-two subgroup in the dihedral case. Property (T) passes to finite-index subgroups, so this infinite cyclic subgroup would have property (T), impossible because \(\mathbb Z\) does not have property (T). Thus no such quotient \(V\) exists.

Taking the quotient map to be the identity also shows that \(G\) itself cannot be infinite virtually cyclic. Since an acylindrically hyperbolic group is non-elementary for some hyperbolic action, it is already not finite in the relevant elementary sense; in any case, property (T) rules out the infinite virtually cyclic alternative. This proves SC4.
