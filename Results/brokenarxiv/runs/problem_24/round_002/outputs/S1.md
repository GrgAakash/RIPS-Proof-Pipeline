More generally, a locally compact group with property `(T)` is compactly generated; for a discrete group, compact subsets are finite, so compact generation is exactly finite generation. Therefore the given group `G` is finitely generated.

Hence there exists a Gromov-hyperbolic space `X` and a non-elementary acylindrical action `G -> Isom(X)`.

Thus both setup facts are verified.
