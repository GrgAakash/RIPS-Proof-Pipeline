2. Subproof Or Failure

Let

\[
a=\alpha,\qquad b=T\alpha,\qquad k=a+b=(T+1)\alpha .
\]

The sampling densities are

\[
p_x(x\mid \beta)=\frac{x^{a-1}}{\beta^a\Gamma(a)}e^{-x/\beta},
\qquad
p_y(y\mid \beta)=\frac{y^{b-1}}{\beta^b\Gamma(b)}e^{-y/\beta}.
\]

With Jeffreys prior \(\pi_J(\beta)\propto \beta^{-1}\),

\[
\pi_J(\beta\mid x)
\propto \beta^{-a-1}e^{-x/\beta}.
\]

Using

\[
\int_0^\infty \beta^{-a-1}e^{-x/\beta}\,d\beta
=\Gamma(a)x^{-a},
\]

the posterior is

\[
\pi_J(\beta\mid x)
=
\frac{x^a}{\Gamma(a)}\beta^{-a-1}e^{-x/\beta},
\qquad \beta>0.
\]

Thus

\[
q_J(y\mid x)
=
\int_0^\infty p_y(y\mid \beta)\pi_J(\beta\mid x)\,d\beta .
\]

Compute:

\[
q_J(y\mid x)
=
\frac{x^a y^{b-1}}{\Gamma(a)\Gamma(b)}
\int_0^\infty \beta^{-k-1}e^{-(x+y)/\beta}\,d\beta .
\]

Again,

\[
\int_0^\infty \beta^{-k-1}e^{-(x+y)/\beta}\,d\beta
=
\Gamma(k)(x+y)^{-k}.
\]

Therefore

\[
\boxed{
q_J(y\mid x)
=
\frac{\Gamma(k)}{\Gamma(a)\Gamma(b)}
\frac{x^a y^{b-1}}{(x+y)^k},
\qquad y>0.
}
\]

It is normalized since

\[
\int_0^\infty \frac{y^{b-1}}{(x+y)^k}\,dy
=
x^{-a}B(b,a)
=
x^{-a}\frac{\Gamma(b)\Gamma(a)}{\Gamma(k)}.
\]

Now define KL loss and risk by

\[
L(\beta,q;x)
=
\int_0^\infty p_y(y\mid \beta)
\log\frac{p_y(y\mid \beta)}{q(y\mid x)}\,dy,
\]

\[
R(\beta,q)
=
\int_0^\infty p_x(x\mid \beta)L(\beta,q;x)\,dx.
\]

Equivalently,

\[
R(\beta,q)
=
E_\beta\left[
\log\frac{p_y(Y\mid \beta)}{q(Y\mid X)}
\right],
\]

where \(X\sim \mathrm{Ga}(a,\beta)\), \(Y\sim \mathrm{Ga}(b,\beta)\), independently.

For any two predictive densities \(q_1,q_2\),

\[
\boxed{
R(\beta,q_1)-R(\beta,q_2)
=
E_\beta\left[
\log\frac{q_2(Y\mid X)}{q_1(Y\mid X)}
\right].
}
\]

In particular,

\[
R(\beta,q)-R(\beta,q_J)
=
E_\beta\left[
\log\frac{q_J(Y\mid X)}{q(Y\mid X)}
\right].
\]

Now let \(\Pi\) be a proper prior on \(\beta\). Define the marginal densities

\[
m_\Pi(x)=\int_0^\infty p_x(x\mid \beta)\,d\Pi(\beta),
\]

\[
m_\Pi(x,y)
=
\int_0^\infty p_x(x\mid \beta)p_y(y\mid \beta)\,d\Pi(\beta).
\]

The Bayes predictive density is

\[
\boxed{
q_\Pi(y\mid x)
=
\frac{m_\Pi(x,y)}{m_\Pi(x)}
=
\int_0^\infty p_y(y\mid \beta)\,d\Pi(\beta\mid x).
}
\]

For any predictive density \(q\),

\[
\begin{aligned}
B_\Pi(q)-B_\Pi(q_\Pi)
&=
\int R(\beta,q)\,d\Pi(\beta)
-
\int R(\beta,q_\Pi)\,d\Pi(\beta)\\
&=
\int_0^\infty m_\Pi(x)
\int_0^\infty q_\Pi(y\mid x)
\log\frac{q_\Pi(y\mid x)}{q(y\mid x)}\,dy\,dx.
\end{aligned}
\]

Hence

\[
\boxed{
B_\Pi(q)-B_\Pi(q_\Pi)
=
\int m_\Pi(x)\,
D_{\mathrm{KL}}\!\left(q_\Pi(\cdot\mid x)\,\|\,q(\cdot\mid x)\right)\,dx
\ge 0.
}
\]

So \(q_\Pi\) is the proper-prior Bayes predictive density under KL loss.

Also, for two priors \(\Pi_1,\Pi_2\),

\[
\boxed{
R(\beta,q_{\Pi_1})-R(\beta,q_{\Pi_2})
=
E_\beta\left[
\log
\frac{
m_{\Pi_2}(X,Y)m_{\Pi_1}(X)
}{
m_{\Pi_2}(X)m_{\Pi_1}(X,Y)
}
\right].
}
\]
