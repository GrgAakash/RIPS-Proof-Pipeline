1. Assignment restatement

Prove SC3: in the rate parametrization `lambda = 1/beta`, derive `A_r^h`, show

```math
q_{\epsilon,h}(y\mid x)
=
q_J(y\mid x)
\frac{1+\epsilon A_k^h(x+y)}
{1+\epsilon A_\alpha^h(x)},
\qquad k=(T+1)\alpha,
```

is the posterior predictive density under the perturbed prior

```math
\pi_{\epsilon,h}(\lambda)\propto \lambda^{-1}(1+\epsilon h(\lambda)),
```

where `h:(0,\infty)->[-1,1]` is bounded and `0<epsilon<1`, and verify normalization.

2. Subproof

Write the gamma density with rate `lambda=1/beta` as

```math
p_a(z\mid\lambda)=\frac{\lambda^a z^{a-1}}{\Gamma(a)}e^{-\lambda z},
\qquad z>0.
```

For `r>0`, define

```math
A_r^h(z)
=
\frac{z^r}{\Gamma(r)}
\int_0^\infty \lambda^{r-1}e^{-z\lambda}h(\lambda)\,d\lambda,
\qquad z>0.
```

This is well-defined since `|h|<=1`, and

```math
|A_r^h(z)|
\le
\frac{z^r}{\Gamma(r)}
\int_0^\infty \lambda^{r-1}e^{-z\lambda}\,d\lambda
=1.
```

Thus `1+\epsilon A_r^h(z)>0`.

Under Jeffreys prior in rate form, `\pi_J(\lambda)\propto \lambda^{-1}`. The marginal of `x` is proportional to

```math
m_J(x)
=
\int_0^\infty p_\alpha(x\mid\lambda)\lambda^{-1}\,d\lambda
=
\frac{x^{\alpha-1}}{\Gamma(\alpha)}
\int_0^\infty \lambda^{\alpha-1}e^{-x\lambda}\,d\lambda.
```

For the perturbed prior,

```math
m_{\epsilon,h}(x)
=
\int_0^\infty p_\alpha(x\mid\lambda)\lambda^{-1}(1+\epsilon h(\lambda))\,d\lambda.
```

Using the definition of `A_\alpha^h`,

```math
m_{\epsilon,h}(x)
=
m_J(x)\{1+\epsilon A_\alpha^h(x)\}.
```

Similarly, the joint marginal for `(x,y)` under the perturbed prior is

```math
M_{\epsilon,h}(x,y)
=
\int_0^\infty
p_\alpha(x\mid\lambda)p_{T\alpha}(y\mid\lambda)
\lambda^{-1}(1+\epsilon h(\lambda))\,d\lambda.
```

The product likelihood is

```math
p_\alpha(x\mid\lambda)p_{T\alpha}(y\mid\lambda)
=
\frac{x^{\alpha-1}y^{T\alpha-1}}{\Gamma(\alpha)\Gamma(T\alpha)}
\lambda^k e^{-(x+y)\lambda},
\qquad k=(T+1)\alpha.
```

Multiplying by `lambda^{-1}` gives the kernel `lambda^{k-1}e^{-(x+y)\lambda}`. Hence

```math
M_{\epsilon,h}(x,y)
=
M_J(x,y)\{1+\epsilon A_k^h(x+y)\}.
```

Therefore the posterior predictive density is

```math
q_{\epsilon,h}(y\mid x)
=
\frac{M_{\epsilon,h}(x,y)}{m_{\epsilon,h}(x)}
=
\frac{M_J(x,y)}{m_J(x)}
\frac{1+\epsilon A_k^h(x+y)}
{1+\epsilon A_\alpha^h(x)}
=
q_J(y\mid x)
\frac{1+\epsilon A_k^h(x+y)}
{1+\epsilon A_\alpha^h(x)}.
```

This proves the displayed perturbation formula.

Normalization follows immediately from the marginal identity:

```math
\int_0^\infty q_{\epsilon,h}(y\mid x)\,dy
=
\frac{1}{m_{\epsilon,h}(x)}
\int_0^\infty M_{\epsilon,h}(x,y)\,dy.
```

Since `p_{T\alpha}(y|lambda)` integrates to `1`,

```math
\int_0^\infty M_{\epsilon,h}(x,y)\,dy
=
\int_0^\infty p_\alpha(x\mid\lambda)\lambda^{-1}(1+\epsilon h(\lambda))\,d\lambda
=
m_{\epsilon,h}(x).
```

Thus

```math
\int_0^\infty q_{\epsilon,h}(y\mid x)\,dy=1.
```

Also, positivity holds because `|A_r^h|\le1` and `0<epsilon<1`, so numerator and denominator are strictly positive. Hence `q_{\epsilon,h}` is a valid predictive density.
