1. Assignment Restatement

Prove the strong amalgamation property for the class of finite two-sorted ultrametric spaces with dc-embeddings.

Concretely: given finite two-sorted ultrametric spaces \(A,B,C\) and dc-embeddings
\[
i_B:A\to B,\qquad i_C:A\to C,
\]
construct a finite two-sorted ultrametric space \(D\) and dc-embeddings
\[
j_B:B\to D,\qquad j_C:C\to D
\]
such that \(j_B\circ i_B=j_C\circ i_C\), and the amalgam is strong: the point sorts and distance sorts of \(B\) and \(C\) meet in \(D\) exactly along the image of \(A\).

2. Subproof or Failure

We prove strong amalgamation.

By replacing \(B\) and \(C\) by isomorphic copies over \(A\), assume without loss of generality that \(A\) is a common substructure of \(B\) and \(C\), that
\[
X_B\cap X_C=X_A,
\]
and that the distance sorts \(D_B,D_C\) contain a common copy of \(D_A\) with the same order and the same \(0\). We now build a finite ordered distance sort \(D_D\), then define the point metric.

First amalgamate the finite ordered distance sorts. Since \(D_B\) and \(D_C\) are finite linear orders with common ordered suborder \(D_A\), form a finite linear order \(D_D\) containing order-preserving copies of \(D_B\) and \(D_C\) over \(D_A\), with intersection exactly \(D_A\).

One explicit construction is this. For each interval cut determined by consecutive elements of \(D_A\), including the initial and final external intervals, place the elements of \(D_B\setminus D_A\) and \(D_C\setminus D_A\) that belong to that cut into a single finite linear order extending their original internal orders, keeping the two sides disjoint. Put these finite interval orders between the corresponding adjacent elements of \(D_A\). The least element remains \(0\), since both embeddings preserve \(0\), and \(0\in D_A\). This gives a finite linear order \(D_D\) and order-preserving inclusions
\[
D_B\hookrightarrow D_D,\qquad D_C\hookrightarrow D_D
\]
whose images meet exactly in \(D_A\).

We identify \(D_B,D_C\) with their images in \(D_D\).

Let
\[
X_D:=X_B\cup X_C
\]
with \(X_B\cap X_C=X_A\). Define \(d_D\) on pairs from the same side by the old distances:
\[
d_D(x,y)=d_B(x,y)\quad(x,y\in X_B),
\]
\[
d_D(x,y)=d_C(x,y)\quad(x,y\in X_C).
\]

It remains to define cross-distances \(d_D(b,c)\) for
\[
b\in X_B\setminus X_A,\qquad c\in X_C\setminus X_A.
\]

If \(X_A\neq\varnothing\), set
\[
d_D(b,c):=\min_{a\in X_A}\max\{d_B(b,a),d_C(a,c)\}.
\]
The minimum exists because \(X_A\) is finite and \(D_D\) is linearly ordered.

If \(X_A=\varnothing\), choose an element \(M\in D_D\) above every element of \(D_B\cup D_C\), adding one new top element if necessary, and set
\[
d_D(b,c):=M
\]
for every cross pair \(b,c\).

The map \(d_D\) is symmetric by definition, and \(d_D(x,x)=0\). Also \(d_D(x,y)=0\) implies \(x=y\): this is true on each side because \(B,C\) are ultrametric spaces, while a cross-distance is nonzero. In the nonempty-base case, for \(b\notin A\), \(c\notin A\), and any \(a\in A\),
\[
d_B(b,a)>0,\qquad d_C(a,c)>0,
\]
so each \(\max\{d_B(b,a),d_C(a,c)\}\) is positive, hence so is the minimum.

Now verify the ultrametric inequality:
\[
d_D(x,z)\leq \max\{d_D(x,y),d_D(y,z)\}.
\]

If \(x,y,z\) all lie in \(B\), or all lie in \(C\), this is exactly the ultrametric inequality in \(B\) or \(C\).

If \(X_A=\varnothing\), then every mixed triangle has at least one cross-distance equal to the chosen top value \(M\), and no distance exceeds \(M\), so the inequality is immediate.

Assume now \(X_A\neq\varnothing\). It suffices to check mixed triples. The only nontrivial case, up to symmetry, is
\[
b,b'\in X_B,\qquad c\in X_C.
\]
We must show
\[
d_D(b,c)\leq \max\{d_D(b,b'),d_D(b',c)\}.
\]
Choose \(a\in X_A\) such that
\[
d_D(b',c)=\max\{d_B(b',a),d_C(a,c)\}.
\]
Such \(a\) exists by the definition of the minimum.

By definition of \(d_D(b,c)\),
\[
d_D(b,c)\leq \max\{d_B(b,a),d_C(a,c)\}.
\]
Since \(B\) is ultrametric,
\[
d_B(b,a)\leq \max\{d_B(b,b'),d_B(b',a)\}.
\]
Therefore
\[
\max\{d_B(b,a),d_C(a,c)\}
\leq
\max\{d_B(b,b'),d_B(b',a),d_C(a,c)\}.
\]
But
\[
\max\{d_B(b',a),d_C(a,c)\}=d_D(b',c),
\]
so
\[
d_D(b,c)\leq \max\{d_D(b,b'),d_D(b',c)\}.
\]
The case \(c,c'\in X_C\), \(b\in X_B\) is symmetric.

The remaining mixed inequality in the same triangle,
\[
d_D(b,b')\leq \max\{d_D(b,c),d_D(b',c)\},
\]
also follows. Pick \(a,a'\in X_A\) realizing the minima:
\[
d_D(b,c)=\max\{d_B(b,a),d_C(a,c)\},
\]
\[
d_D(b',c)=\max\{d_B(b',a'),d_C(a',c)\}.
\]
In \(C\),
\[
d_C(a,a')\leq \max\{d_C(a,c),d_C(c,a')\}
\leq \max\{d_D(b,c),d_D(b',c)\}.
\]
Because \(A\) is embedded into both \(B\) and \(C\) by dc-embeddings over the same distance copy, the distance between \(a,a'\) computed in \(B\) equals the one computed in \(C\). Hence
\[
d_B(a,a')\leq \max\{d_D(b,c),d_D(b',c)\}.
\]
Using the ultrametric inequality in \(B\),
\[
d_B(b,b')\leq \max\{d_B(b,a),d_B(a,a'),d_B(a',b')\}.
\]
Each term on the right is bounded by \(\max\{d_D(b,c),d_D(b',c)\}\). Hence
\[
d_D(b,b')=d_B(b,b')
\leq \max\{d_D(b,c),d_D(b',c)\}.
\]
The symmetric case for \(d_D(c,c')\) is identical.

Thus \(D=(X_D,D_D,d_D)\) is a finite two-sorted ultrametric space.

The inclusions \(B\hookrightarrow D\) and \(C\hookrightarrow D\), together with the constructed inclusions of distance sorts, are dc-embeddings: they are injective on points, order-preserving injective on distance sorts, preserve \(0\), and preserve all old distances by construction.

Finally, the amalgam is strong. We arranged
\[
X_B\cap X_C=X_A
\]
inside \(X_D\), and the ordered distance-sort amalgam was constructed so that
\[
D_B\cap D_C=D_A
\]
inside \(D_D\). Therefore the class has strong amalgamation.
