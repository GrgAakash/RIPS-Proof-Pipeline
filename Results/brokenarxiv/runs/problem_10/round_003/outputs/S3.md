## 1. Assignment Restatement

For a fixed finite object  
\[
A=(X_A,D_A,d_A,p_1,\dots,p_n)\in K_p^n,
\]
construct a finite extension  
\[
e:A\hookrightarrow B
\]
inside \(K_p^n\) which can serve as the WAP witness.

The construction must not totalize the partial automorphisms \(p_i\). It should add only finite “orbit-interface” data needed later so that arbitrary \(K_p^n\)-extensions of \(B\) can be amalgamated coherently, including when the distance-sort parts of the partial automorphisms move distance elements.

## 2. Subproof

Write each partial automorphism as  
\[
p_i=(p_i^X,p_i^D),
\]
where \(p_i^X\) is a partial bijection on points and \(p_i^D\) is a partial order-isomorphism between finite distance suborders, preserving \(0\), with the usual compatibility:
\[
d_A(p_i^Xx,p_i^Xy)=p_i^D(d_A(x,y))
\]
whenever both sides are defined.

### Step 1: Finite distance orbit closure

Let
\[
E_0=D_A.
\]

For each \(i\le n\), close \(E_0\) under all already defined forward and backward applications of \(p_i^D\). Since \(D_A\) is finite and each \(p_i^D\) is a finite partial bijection, this closure is finite. Call the resulting set
\[
E_A.
\]

Equivalently, \(E_A\) is the union of all finite \(p_i^D\)-orbit fragments meeting \(D_A\). It contains every distance value of \(A\), and whenever \(r\in E_A\) and \(p_i^D(r)\) is defined in \(A\), then \(p_i^D(r)\in E_A\); likewise for inverse applications.

This is the protected distance interface.

### Step 2: Finite point orbit closure

Let
\[
P_0=X_A.
\]

For each \(i\le n\), close \(P_0\) under all already defined forward and backward applications of \(p_i^X\). Since \(X_A\) is finite and each \(p_i^X\) is a finite partial bijection, this gives a finite set
\[
P_A.
\]

Thus \(P_A\) is the union of all finite point-orbit fragments meeting \(X_A\).

Because \(A\) already contains all points in \(X_A\), this step adds no genuinely new points unless the chosen presentation of \(A\) omitted some domain/range elements of the partial maps. In the usual \(K_p^n\) convention, domains and ranges are already substructures of \(A\), so \(P_A=X_A\). The notation is still useful because the later interface property refers to these orbit fragments.

### Step 3: Add missing distance values forced by protected point pairs

Let
\[
F_A=\{d_A(x,y):x,y\in P_A\}.
\]

Now enlarge the protected distance interface to
\[
I_A=\operatorname{cl}_{p_1^D,\dots,p_n^D}(E_A\cup F_A),
\]
again taking only closure under already defined forward and backward partial distance maps.

Since everything is finite, \(I_A\) is finite.

It satisfies:

1. \(D_A\subseteq I_A\).
2. Every distance between protected points belongs to \(I_A\).
3. If \(r\in I_A\) and \(p_i^D(r)\) is defined, then \(p_i^D(r)\in I_A\).
4. If \(r\in I_A\) and \((p_i^D)^{-1}(r)\) is defined, then \((p_i^D)^{-1}(r)\in I_A\).

### Step 4: Construct \(B\)

Let \(B\) have the same point sort as \(A\):
\[
X_B=X_A.
\]

Let its distance sort be the finite ordered set obtained from \(D_A\) by adjoining all elements of \(I_A\), preserving the existing order on \(D_A\) and placing the additional elements according to the order already inherited from the partial distance maps.

If two elements are not order-comparable from the existing data, choose any finite linear extension. This is legitimate because the distance sort in a finite two-sorted ultrametric structure is only required to be linearly ordered with least element \(0\), and the construction does not alter any old order relation.

Define
\[
d_B(x,y)=d_A(x,y)
\]
for all \(x,y\in X_A\).

Thus \(B\) adds no new point distances; it only enlarges the distance sort by protected interface values.

Extend each \(p_i\) to \(q_i\) on \(B\) as follows:

- On points, \(q_i^X=p_i^X\).
- On distances, \(q_i^D\) is the restriction of the closure relation on \(I_A\) generated by the original \(p_i^D\).

Because \(I_A\) was defined by closing under already defined distance moves, \(q_i^D\) is again a finite partial order-isomorphism preserving \(0\). Since no point distances were changed, compatibility with the metric remains exactly the compatibility already present in \(A\).

Therefore
\[
B=(X_B,D_B,d_B,q_1,\dots,q_n)\in K_p^n
\]
and \(A\hookrightarrow B\) is a \(K_p^n\)-embedding.

### Step 5: Interface property supplied to later stages

The construction gives the following finite protected interface.

Define
\[
\mathcal I_B=(P_B,I_B)
\]
where
\[
P_B=X_B
\]
and
\[
I_B=I_A\subseteq D_B.
\]

This interface has the exact properties needed by the later WAP amalgamation argument:

1. **Point-distance protection.**  
   For all \(x,y\in P_B\),
   \[
   d_B(x,y)\in I_B.
   \]

2. **Distance-move protection.**  
   For every \(i\le n\), if \(r\in I_B\) and \(q_i^D(r)\) is defined, then \(q_i^D(r)\in I_B\). The same holds backward.

3. **Point-move protection.**  
   For every \(i\le n\), if \(x\in P_B\) and \(q_i^X(x)\) is defined, then \(q_i^X(x)\in P_B\). The same holds backward.

4. **Compatibility on protected distances.**  
   Whenever \(x,y,q_i^Xx,q_i^Xy\in P_B\),
   \[
   d_B(q_i^Xx,q_i^Xy)=q_i^D(d_B(x,y)).
   \]

5. **No totalization.**  
   No \(q_i^X\) or \(q_i^D\) is defined outside the finite orbit fragments forced by the original partial maps on \(A\). In particular, the construction does not make the partial automorphisms total on \(B\).

This is precisely the finite orbit-interface witness needed for S4/S5: any later extension of \(B\) must preserve the protected finite set \(I_B\), so formulas defining cross-distances over the interface can be checked only against these finitely many protected distance-sort orbit fragments, including fragments moved by the partial distance maps.
