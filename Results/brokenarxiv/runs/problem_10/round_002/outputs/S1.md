Let `K` be the class of finite two-sorted ultrametric spaces with dc-embeddings.

**Lemma 1: finite linear-order amalgamation over a common suborder.**

Suppose `D_A, D_B, D_C` are finite linear orders with least element `0`, and `D_A` embeds into `D_B,D_C` by order-preserving injections preserving `0`. After identifying the two copies of `D_A`, there is a finite linear order `D_E` and order-preserving injections

`i_B : D_B -> D_E`, `i_C : D_C -> D_E`

which agree on `D_A` and preserve `0`.

Proof. Define a partial order on the disjoint union of `D_B` and `D_C` over identified `D_A` by keeping the original orders and additionally forcing every comparison implied by the common order: for `b in D_B`, `c in D_C`, set

`b < c` if there is `a in D_A` with `b <= a < c`,  
and `c < b` if there is `a in D_A` with `c <= a < b`.

Equivalently, place elements of `D_B \ D_A` and `D_C \ D_A` inside the intervals cut out by consecutive elements of `D_A`, then choose any finite linear extension inside each interval. Since the original orders agree on `D_A`, no cycle is created. Any finite partial order has a linear extension, a standard background fact. This gives the required `D_E`.

**Lemma 2: base amalgamation for finite two-sorted ultrametric spaces.**

Let `A,B,C in K`, and let `A -> B`, `A -> C` be dc-embeddings. Then there is `E in K` and dc-embeddings `B -> E`, `C -> E` agreeing on `A`.

Proof. By replacing `B,C` by isomorphic copies, assume `A` is a common substructure of both and the embeddings are inclusions on both point and distance sorts.

Use Lemma 1 to amalgamate the finite distance orders over `D_A`, obtaining a finite linear order `D_E` with least element `0` and order embeddings of `D_B,D_C`.

For the point sort, take the disjoint union over `A`:

`X_E := X_B union_{X_A} X_C`.

Distances inside `B` and inside `C` are inherited, with values transported into `D_E`.

It remains to define cross-distances. If `b in X_B \ X_A` and `c in X_C \ X_A`, define

`d_E(b,c) := min_{a in X_A} max(d_B(b,a), d_C(a,c))`

when `X_A` is nonempty.

If `X_A` is empty, choose any positive element `r in D_E`, adding one if necessary above `0`, and set all cross-distances between `B` and `C` equal to `r`. This still gives a finite linearly ordered distance sort.

Symmetry is imposed by `d_E(c,b)=d_E(b,c)`, and `d_E(x,x)=0`.

The minimum exists because `X_A` is finite and `D_E` is linearly ordered.

Now verify the ultrametric inequality. The only nontrivial cases involve points from both sides. Let `b,b' in X_B` and `c in X_C`. We show

`d_E(b,c) <= max(d_E(b,b'), d_E(b',c))`.

If `b' in X_A`, this is immediate from the definition of cross-distance using `a=b'`.

Otherwise, choose `a in X_A` witnessing the minimum for `d_E(b',c)`, so

`d_E(b',c)=max(d_B(b',a), d_C(a,c))`.

By the ultrametric inequality in `B`,

`d_B(b,a) <= max(d_B(b,b'), d_B(b',a))`.

Therefore

`max(d_B(b,a), d_C(a,c)) <= max(d_B(b,b'), d_E(b',c))`.

Since `d_E(b,c)` is the minimum over all `a in X_A` of the left-hand expression, the desired inequality follows.

The case with two points in `C` and one in `B` is symmetric. The cases entirely inside `B` or entirely inside `C` hold by assumption. Thus `E` is a finite two-sorted ultrametric space.

Finally, the inclusions `B -> E` and `C -> E` are dc-embeddings by construction: the point maps are injective, the distance-sort maps are order-preserving injections preserving `0`, and all internal distances are preserved exactly.

So `K` has amalgamation.

**Definition: `K_p^n`.**

For fixed `n >= 1`, an object of `K_p^n` is a tuple

`(A, p_1, ..., p_n)`

where `A in K`, and each `p_i` is a finite partial automorphism of the two-sorted structure `A`.

Concretely, each `p_i` consists of:

- a partial injective map on points,  
  `p_i^X : dom_X(p_i) -> ran_X(p_i)`;
- a partial order-preserving bijection on distance-sort elements,  
  `p_i^D : dom_D(p_i) -> ran_D(p_i)`;

such that `0` is preserved whenever it lies in the domain, and for all `x,y in dom_X(p_i)` with `d_A(x,y) in dom_D(p_i)`,

`d_A(p_i^X(x), p_i^X(y)) = p_i^D(d_A(x,y))`.

Equivalently, `p_i` is an isomorphism between two finite generated two-sorted substructures of `A`, with separate point-sort and distance-sort components.

A morphism

`h : (A,p_1,...,p_n) -> (B,q_1,...,q_n)`

in `K_p^n` is a dc-embedding `h : A -> B`, consisting of point map `h_X` and distance map `h_D`, such that for each `i` it intertwines the partial automorphisms:

- if `x in dom_X(p_i)`, then `h_X(x) in dom_X(q_i)` and  
  `q_i^X(h_X(x)) = h_X(p_i^X(x))`;
- if `r in dom_D(p_i)`, then `h_D(r) in dom_D(q_i)` and  
  `q_i^D(h_D(r)) = h_D(p_i^D(r))`.

Thus morphisms are ordinary dc-embeddings that preserve the named partial automorphisms.
