1. **Assignment Restatement**

Prove JEP for `K_p^n`: given two finite two-sorted ultrametric spaces equipped with `n` partial automorphisms, construct a finite two-sorted ultrametric space into which both embed, so that the corresponding partial automorphisms jointly form partial automorphisms and the two input systems are not unintentionally identified.

2. **Subproof Or Failure**

Let

`(A, p_1, ..., p_n)` and `(A', q_1, ..., q_n)`

be finite objects of `K_p^n`. Here each `p_i` and `q_i` is a partial dc-automorphism: it has a finite point-domain and point-range, and a finite distance-domain and distance-range, with an order-preserving bijection on the relevant distance elements preserving `0` and all distances between points in its point-domain.

We prove JEP by building a common finite extension.

First replace `A` and `A'` by isomorphic disjoint copies, except that their least distance element `0` is identified. This causes no point identifications. We now construct a finite linearly ordered distance set `D_C` and order-preserving embeddings

`e_D : D_A -> D_C`,  
`e'_D : D_{A'} -> D_C`

such that, for each `i`, the two finite partial order-isomorphisms induced by `p_i` and `q_i` are compatible inside `D_C`.

Concretely, take the finite partial order data consisting of:

- the ordered set `D_A`,
- the ordered set `D_{A'}`,
- the identifications forced only by `0`,
- and, for each `i`, the requirement that if `δ` is in the distance-domain of `p_i`, then its image under the joint partial map is `p_i^D(δ)`, and similarly for `q_i`.

Because each `p_i^D` and `q_i^D` is already an order-isomorphism between finite suborders, this finite diagram embeds into some finite linear order extending all given orders and all required images. If necessary, take disjoint labeled copies of all nonzero distance elements before forming the linear extension, so no additional equality is imposed. Thus we obtain a finite ordered distance set `D_C` with least element `0`.

Now set the point set of `C` to be the disjoint union

`X_C = X_A ⊔ X_{A'}`.

The embeddings on points are the two inclusions. On distances they are `e_D` and `e'_D`.

Define distances inside each copy by transport:

`d_C(x,y) = e_D(d_A(x,y))` for `x,y in A`,  
`d_C(x',y') = e'_D(d_{A'}(x',y'))` for `x',y' in A'`.

For cross distances, choose a single distance value `M in D_C` strictly above every embedded distance from `A` and `A'`. If `D_C` does not yet have such an element, add a new greatest element `M`. Then put

`d_C(x,x') = M`

for every `x in X_A` and `x' in X_{A'}`.

This is a finite two-sorted ultrametric space. The only nontrivial ultrametric check is for triangles meeting both copies. Such a triangle has two cross distances equal to `M`, while the remaining internal distance is `<= M`; hence

`d(u,w) <= max{d(u,v), d(v,w)}`

holds.

Each input embeds into `C` by a dc-embedding, and the point images are disjoint, so no unintended point identifications occur. The distance embeddings impose only the forced common `0` and whatever equalities are deliberately chosen in the common finite order; by using labeled disjoint copies before the linear extension, no extra nonzero distance identifications are forced.

For each `i`, define a partial automorphism `r_i` of `C` as the union of the transported copies of `p_i` and `q_i`:

- on points, `r_i^X = p_i^X ∪ q_i^X`,
- on distances, `r_i^D = p_i^D ∪ q_i^D`, interpreted through the embeddings into `D_C`.

These unions are well-defined because the point domains are disjoint and the distance maps were embedded compatibly into `D_C`. They are injective partial maps. The distance component is order-preserving by construction. Distance preservation holds inside each original copy because `p_i` and `q_i` were partial dc-automorphisms. For a cross pair `x in A`, `x' in A'` lying in the point-domain of `r_i`, both its image points again lie one in the `A` copy and one in the `A'` copy, so

`d_C(r_i x, r_i x') = M = r_i^D(M)`

provided `M` is included as a fixed point of each `r_i^D`. Add this convention when defining the finite distance-domain/range of each `r_i`. Since `M` is greatest, fixing it preserves order.

Thus `(C, r_1, ..., r_n)` is an object of `K_p^n` receiving embeddings from both given systems. Therefore `K_p^n` has JEP.
