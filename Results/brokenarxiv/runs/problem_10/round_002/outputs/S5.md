```text
(A, p_1, ..., p_n)
```

where `A in K` and each `p_i` is a finite partial automorphism of the two-sorted structure `A`, meaning a partial isomorphism preserving both sorts, the distance order, `0`, and the distance map wherever defined. Morphisms

```text
(A, p_1, ..., p_n) -> (B, q_1, ..., q_n)
```

are dc-embeddings `e: A -> B` such that, for each `i`, `e` carries the graph of `p_i` into the graph of `q_i`; equivalently,

```text
e(p_i(a)) = q_i(e(a))
```

whenever `p_i(a)` is defined.

The Kechris-Rosendal criterion says:

For a Fraisse limit `M` of a countable Fraisse class `K`, the diagonal conjugation action of `Aut(M)` on `Aut(M)^n` has a comeager orbit iff `K_p^n` has the joint embedding property and the weak amalgamation property. Consequently, `Aut(M)` has ample generics iff, for every `n >= 1`, `K_p^n` has JEP and WAP.

Here the action is

```text
g · (h_1, ..., h_n) = (g h_1 g^{-1}, ..., g h_n g^{-1}).
```

Apply this with `M = U`. Thus, for each fixed `n >= 1`, it is enough to know:

1. `K_p^n` has JEP.
2. `K_p^n` has WAP.

Hence, for every `n >= 1`, `Aut(U)^n` has a comeager conjugacy class under diagonal conjugation.

Therefore `Aut(U)` has ample generics.
