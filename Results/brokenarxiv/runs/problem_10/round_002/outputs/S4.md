By the prerequisite, amalgamate their distance sorts over `I_D` into a finite linear order `D_E`, with each distance-sort partial map `p_i^E` extending the corresponding maps from `C` and `D`.

Define the point sort

```text
E_X = C_X ∪_{I_X} D_X.
```

Distances inside `C_X` and inside `D_X` are inherited. For `c in C_X \ I_X` and `d in D_X \ I_X`, define

```text
d_E(c,d) = min_{a in I_X} max(d_C(c,a), d_D(a,d)).
```

This value lies in `D_E`, since the maximum is one of the two displayed existing distance values, and the minimum is taken over a finite nonempty set.

Separation is clear: if `c` and `d` are from different sides and not both in `I_X`, then no bridge point `a in I_X` can make both distances zero, so `d_E(c,d) > 0`.

The ultrametric inequality is inherited on each side. For a mixed triangle, say `c1,c2 in C_X` and `d in D_X`, choose any `a in I_X`. In `C`,

```text
d_C(c1,a) <= max(d_C(c1,c2), d_C(c2,a)).
```

Therefore

```text
max(d_C(c1,a), d_D(a,d))
<= max(d_C(c1,c2), max(d_C(c2,a), d_D(a,d))).
```

Taking the minimum over `a` gives

```text
d_E(c1,d) <= max(d_C(c1,c2), d_E(c2,d)).
```

The other mixed cases are symmetric.

Now check partial automorphisms. The point map `p_i^E` is the union of the point maps from `C` and `D`; it is well-defined because `I_X` is closed and the two sides agree there. It is injective because no new outside point can map into a point of `I_X` already having its prescribed preimage in `I_X`.

```text

= p_i^E(min_a max(d_C(c,a), d_D(a,d)))
= min_a max(d_C(p_i c,p_i a), d_D(p_i a,p_i d))
= d_E(p_i c,p_i d).
```

This proves compatibility for moved distance-sort elements as well: no fixed-distance assumption is used; only injective order preservation is used.
