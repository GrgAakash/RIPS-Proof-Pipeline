## 1. Assignment Restatement

Given an arbitrary finite object  
\[
A=(X_A,D_A,d_A,p_1,\dots,p_n)\in K_p^n,
\]
where each \(p_i\) is a partial automorphism with a point-sort part and a distance-sort part, construct a finite extension  
\[
A\hookrightarrow B
\]
intended to serve as the WAP witness in the Kechris-Rosendal criterion.

The construction must not totalize the partial automorphisms. It must instead record enough finite orbit and interface data around the point and distance elements already appearing in the domains and ranges of the partial automorphisms, including distance-sort elements moved by the partial maps.

## 2. Subproof Or Failure

I describe a finite extension \(B\) of \(A\). This is only the witness construction, not the full WAP proof.

Let
\[
p_i=(p_i^X,p_i^D)
\]
where \(p_i^X\) is the point-sort partial bijection and \(p_i^D\) is the distance-sort partial order-isomorphism, preserving \(0\), and preserving all distances on the point-domain.

Define the finite point support
\[
P_A:=X_A.
\]

Define the finite distance support
\[
R_A:=D_A.
\]

For each \(i\), let
\[
\operatorname{dom}_X(p_i),\operatorname{rng}_X(p_i)\subseteq X_A
\]
and
\[
\operatorname{dom}_D(p_i),\operatorname{rng}_D(p_i)\subseteq D_A.
\]

Although these are already subsets of \(X_A\) and \(D_A\), we distinguish them because the construction records which elements participate in partial orbits.

### Step 1: Finite partial-orbit closure inside \(A\)

For the point sort, define an equivalence relation \(\equiv_X\) on \(X_A\) generated by
\[
x\equiv_X p_i^X(x)
\]
whenever \(p_i^X(x)\) is defined.

For the distance sort, define an equivalence relation \(\equiv_D\) on \(D_A\) generated by
\[
r\equiv_D p_i^D(r)
\]
whenever \(p_i^D(r)\) is defined.

Thus each \(\equiv_X\)-class and \(\equiv_D\)-class is a finite partial orbit under the existing partial automorphisms.

The important point is that distance-sort orbits are recorded separately. A moved distance value is not treated merely as a label appearing between points; it has its own partial orbit data.

### Step 2: Add endpoint markers for partial orbit classes

For every \(\equiv_X\)-class \(C\subseteq X_A\), add two fresh points
\[
c^- , c^+
\]
unless one chooses to omit them when unnecessary. These are orbit-interface markers for the point class \(C\).

For every \(\equiv_D\)-class \(E\subseteq D_A\), add two fresh distance elements
\[
e^- , e^+
\]
with
\[
0<e^-<r<e^+
\]
for every nonzero \(r\in E\), and with the ordering chosen so that all newly added distance elements remain linearly ordered.

If \(E=\{0\}\), do not add elements below \(0\); instead record that \(0\) is fixed and has no lower marker.

Let
\[
D_B
\]
be the finite linear order obtained from \(D_A\) by inserting these finitely many new distance markers.

The purpose of \(e^-,e^+\) is to isolate the finite distance orbit \(E\) from possible later extensions. Any later embedding of \(B\) must preserve the relative position of \(E\) in the distance order.

### Step 3: Add distance-interface values for point-orbit classes

For every pair of point partial-orbit classes
\[
C,C'\in X_A/{\equiv_X},
\]
define the finite set
\[
\Delta(C,C'):=\{d_A(x,y):x\in C,\ y\in C'\}\subseteq D_A.
\]

For every such pair, add fresh distance markers
\[
\delta^-_{C,C'},\delta^+_{C,C'}
\]
with
\[
\delta^-_{C,C'}\le r\le \delta^+_{C,C'}
\]
for every \(r\in \Delta(C,C')\), respecting the already existing order.

If \(\Delta(C,C')=\{0\}\), take \(\delta^-_{C,C'}=\delta^+_{C,C'}=0\).

These markers record all distance values realized between point elements lying in partial point-orbits. This is part of the finite interaction data needed later: when two extensions of \(B\) are compared, they cannot freely reinterpret the scale on which the old point-orbit distances sit.

### Step 4: Add formal point witnesses realizing orbit interfaces

For every point partial-orbit class \(C\subseteq X_A\), add a fresh point \(u_C\).

Define its distances to old points by
\[
d_B(u_C,x)=\max\{d_A(c,x):c\in C\}
\]
for \(x\in X_A\).

Define distances between new witnesses by
\[
d_B(u_C,u_{C'})=\max\{d_A(c,c'):c\in C,\ c'\in C'\}.
\]

These values lie in \(D_A\subseteq D_B\). The ultrametric inequality is preserved because each assigned value is a maximum of old ultrametric distances.

The point \(u_C\) is not placed into the domain or range of any \(p_i\). It is a passive marker. It records the external metric profile of the whole partial point-orbit class \(C\) without forcing any automorphism to be extended.

### Step 5: Extend the partial automorphisms without totalizing

For each \(i\le n\), define \(q_i\) on \(B\) as follows.

On old points:
\[
q_i^X\upharpoonright X_A=p_i^X.
\]

On old distances:
\[
q_i^D\upharpoonright D_A=p_i^D.
\]

The new point markers \(c^-,c^+,u_C\) are left outside the domain and range of \(q_i^X\), unless they were deliberately identified with old elements, which they are not.

The new distance markers \(e^-,e^+,\delta^-_{C,C'},\delta^+_{C,C'}\) are also left outside the domain and range of \(q_i^D\).

Thus
\[
q_i
\]
is exactly the old partial automorphism on \(A\), regarded inside \(B\), with no forced totalization.

This directly handles moved distance-sort elements: if \(r\in D_A\) and \(p_i^D(r)=s\ne r\), then both \(r\) and \(s\) remain in the recorded finite distance orbit \(E\), and the surrounding markers for \(E\) are part of \(B\). But \(q_i^D\) is not extended beyond its old finite domain.

### Step 6: The resulting finite object

Let
\[
X_B:=X_A\cup\{u_C:C\in X_A/{\equiv_X}\}
\]
together with any optional named endpoint markers if one chooses to realize them as points.

Let \(D_B\) be the finite linear order extending \(D_A\) by the finitely many inserted marker distances described above.

Let \(d_B\) extend \(d_A\), with values involving new points defined by the maximum formulas above.

Let
\[
B=(X_B,D_B,d_B,q_1,\dots,q_n).
\]

Then \(B\) is finite, contains \(A\) as a dc-substructure, and each \(q_i\) is a partial automorphism of \(B\). The embedding
\[
A\hookrightarrow B
\]
is the identity on both sorts.

This is the desired S3 construction.
