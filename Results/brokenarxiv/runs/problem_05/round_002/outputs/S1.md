2. Subproof or failure.

Let `T_i` be the boundary torus corresponding to the `i`th link component. Fix the standard oriented meridian-longitude basis `(μ_i, λ_i)` for `H_1(T_i)`. A slope `α_i = a_i/p_i` denotes the primitive unoriented class

```text
[α_i] = a_i μ_i + p_i λ_i,
```

with `p_i ≥ 0`.

The geometric intersection distance between slopes represented by primitive classes `a μ + p λ` and `b μ + q λ` is

```text
Δ(a/p, b/q) = |a q - b p|.
```

The meridian slope is `μ_i = 1/0`. Therefore

```text
Δ(α_i, μ_i)
= Δ(a_i/p_i, 1/0)
= |a_i · 0 - 1 · p_i|
= |p_i|.
```

Since `p_i ≥ 0`, this is just `p_i`. Thus:

- `p_i = 0` means `α_i` is meridional.
- `p_i = 1` means `α_i` is integral.
- If `α_i` is neither meridional nor integral, then `p_i ≥ 2`, equivalently `Δ(α_i, μ_i) ≥ 2`.

This proves C1.

For C2, fill each boundary torus `T_i` along the slope `α_i`. That is, attach a solid torus `V_i` to `T_i` so that the meridian disk boundary of `V_i` is identified with slope `α_i`.

Since `P` is spanning planar, it has exactly one boundary component on each `T_i`, and that boundary component has slope `α_i`. After the `α_i`-filling, the boundary curve `∂_i P ⊂ T_i` bounds a meridian disk `D_i ⊂ V_i`. Attach all these disks to `P`:

```text
\widehat P = P ∪ D_1 ∪ ... ∪ D_N.
```

Because `P` is planar with exactly `N` boundary components, capping all boundary components by disks gives a closed planar surface, hence a sphere. Thus `\widehat P` is a sphere in the filled manifold.

Let `c_i` be the core circle of the filling solid torus `V_i`. A meridian disk of a solid torus intersects its core transversely in exactly one point. Since `\widehat P ∩ V_i = D_i`, it follows that

```text
|c_i ∩ \widehat P| = 1
```

for every `i`.

So the precise filling configuration passed forward is: the capped surface `\widehat P` is a sphere, and every filling core `c_i` intersects it exactly once.
