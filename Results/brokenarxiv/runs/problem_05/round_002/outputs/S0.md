1. Target decomposition

target_label: Problem 5

target_type: boundary-slope obstruction theorem for hyperbolic link exteriors

main_goal: Show that the boundary slopes of an incompressible spanning planar surface cannot all be nonmeridional nonintegral.

variables_and_parameters:  
N >= 3; L = K_1 union ... union K_N subset S^3; X_L = S^3 \ int(N(L)); boundary tori T_i = ∂N(K_i); standard meridian-longitude coordinates (mu_i, lambda_i); P subset X_L incompressible planar with exactly one boundary curve on each T_i; boundary slope alpha_i = a_i/p_i.

conclusion_to_prove:  
There exists i such that alpha_i is meridional or integral, equivalently p_i in {0,1} after standard denominator normalization.

2. Available tools

tool: slope-distance normalization  
source_status: notation / standard background fact  
exact_statement_or_fact: For alpha_i = a_i/p_i in meridian-longitude coordinates, alpha_i is meridional iff p_i = 0 and integral iff p_i = 1; if p_i notin {0,1}, then Delta(alpha_i, mu_i) = |p_i| >= 2.  
intended_role_in_proof: Converts the desired conclusion into the contradiction assumption that every boundary slope has distance at least 2 from the meridian.

tool: meridian filling restores S^3  
source_status: provided definition / notation  
exact_statement_or_fact: Filling every boundary torus of X_L along the meridian slope mu_i recovers S^3.  
intended_role_in_proof: Supplies the comparison filling used in the denominator obstruction.

tool: boundary-slope filling and capping  
source_status: standard background fact  
exact_statement_or_fact: If X_L is filled along alpha_i = slope(∂P ∩ T_i), then P caps off by one meridian disk in each filling solid torus to an embedded 2-sphere \widehat P.  
intended_role_in_proof: Produces the closed sphere whose existence drives the contradiction.

tool: one-intersection configuration  
source_status: additional guidance item  
exact_statement_or_fact: In the boundary-slope filling, each filling core intersects the capped planar sphere \widehat P exactly once. The proof must use this actual configuration and must not assume at least two intersections or use a separating-sphere argument.  
intended_role_in_proof: Controls the correct filling model for the hard obstruction step.

tool: nonseparating sphere criterion  
source_status: standard background fact  
exact_statement_or_fact: An embedded sphere intersecting a closed curve transversely in exactly one point is nonseparating and does not bound a ball.  
intended_role_in_proof: Shows \widehat P is an essential sphere in the alpha-filling.

tool: hyperbolicity consequences  
source_status: standard background fact  
exact_statement_or_fact: A finite-volume hyperbolic link exterior is irreducible, boundary-irreducible, atoroidal, and contains no essential non-boundary-parallel annuli.  
intended_role_in_proof: Rules out the graph/handle-addition alternatives produced by the hard obstruction lemma.

tool: one-intersection reducible-surgery denominator obstruction  
source_status: proved inside the current proof  
exact_statement_or_fact: In the present setup, if the alpha-filling contains an essential sphere meeting each alpha-filling core exactly once and the meridian filling gives S^3, then not all Delta(alpha_i, mu_i) can be >= 2.  
intended_role_in_proof: This is the central internal lemma; it converts the capped-sphere configuration into the existence of a meridional or integral boundary slope.

4. Hardest step prediction

hardest_step_id: C5

hardest_step_description:  
The proof must establish the one-intersection denominator obstruction without replacing the actual configuration by the usual “reducing sphere meets a surgery core at least twice” setup. The final proof should use the cut-open sphere-and-arcs model, or an equivalent intersection-graph/handle-addition argument, with exactly one arc per filling core.

risk_if_wrong:  
If the proof assumes \widehat P separates, or assumes some core intersects \widehat P at least twice, it proves a different statement and does not apply to this target. If it cites a reducible-surgery denominator theorem externally, it violates the source restrictions unless that theorem is proved inside the current proof.

how_final_proof_should_handle_it:  
Prove the obstruction directly: put the meridian filling disks/handles in minimal position relative to the cut-open one-intersection model, build the labeled graph, use Delta >= 2 to force a bigon/Scharlemann-type configuration, and show that configuration yields one of the forbidden objects in X_L.
