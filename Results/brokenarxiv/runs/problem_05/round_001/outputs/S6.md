FINAL PROOF NOT COMPLETED.

1. Suppose, for contradiction, that every boundary component of \(P\) has slope \(a_i/p_i\) with \(p_i\notin\{0,1\}\).

2. Let the boundary tori of \(X_L\) be \(T_1,\dots,T_N\), and let \(\gamma_i=P\cap T_i\). Since \(P\) has exactly one boundary component on each boundary torus, each \(\gamma_i\) is a primitive slope on \(T_i\), written in standard meridian-longitude coordinates as
\[
\gamma_i=a_i\mu_i+p_i\lambda_i.
\]

3. Perform Dehn filling on each \(T_i\) along \(\gamma_i\), attaching a solid torus \(V_i\). Let \(D_i\subset V_i\) be a meridian disk with \(\partial D_i=\gamma_i\). Then
\[
\widehat P=P\cup D_1\cup\cdots\cup D_N
\]
is an embedded closed surface in the filled manifold \(M\).

4. Since \(P\) is connected and planar, capping all of its boundary components with disks gives a 2-sphere. Hence \(\widehat P\cong S^2\).

5. For each \(i\), the core \(C_i\) of the attached solid torus \(V_i\) intersects \(D_i\) transversely exactly once, is disjoint from \(P\), and is disjoint from \(D_j\) for \(j\ne i\). Therefore
\[
|C_i\cap \widehat P|=1.
\]

6. It follows that \(\widehat P\) is nonseparating in \(M\): if a two-sided embedded sphere separated \(M\), then every closed curve would have algebraic intersection number zero with it, whereas \(C_i\) has odd, indeed one-point, intersection with \(\widehat P\).
