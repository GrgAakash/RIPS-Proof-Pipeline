1. Target decomposition

target_label:  
Problem 5

target_type:  
Obstruction theorem for boundary slopes of incompressible spanning planar surfaces in hyperbolic link exteriors.

main_goal:  
Show that an incompressible planar spanning surface in an `N >= 3` component hyperbolic link exterior cannot have all boundary slopes strictly nonmeridional and nonintegral.

variables_and_parameters:  
`N >= 3`; an `N`-component hyperbolic link `L subset S^3`; exterior `X_L = S^3 \ int(N(L))`; boundary tori `T_1, ..., T_N`; incompressible spanning planar surface `P subset X_L`; boundary slope on `T_i` written `a_i / p_i` in standard meridian-longitude coordinates.

conclusion_to_prove:  
At least one boundary component of `P` has slope `a_i/p_i` with `p_i in {0,1}`, i.e. meridional or integral.

source_status: provided definition / assumption

exact_statement_or_fact:  
`P` is planar and has exactly one boundary component on each boundary torus of `X_L`.

intended_role_in_proof:

Incompressibility of `P`

source_status: provided definition / assumption

intended_role_in_proof:

tool:  
Hyperbolicity of `L`

source_status: provided assumption

`X_L` is a finite-volume hyperbolic 3-manifold with torus boundary.

intended_role_in_proof:  
Supplies standard consequences: irreducibility, boundary irreducibility, atoroidality, and no essential spheres or disks in `X_L`.

tool:  
Dehn filling along the boundary slopes of `P`

source_status: standard background fact

exact_statement_or_fact:  
If each boundary torus is filled along the slope represented by `partial P`, then each component of `partial P` bounds a meridian disk in the corresponding attached solid torus.

intended_role_in_proof:  
Produces a closed sphere `\widehat P` in the filled manifold.

tool:  
Homology calculation for multi-component Dehn filling of a link in `S^3`

source_status: must be proved inside the current proof

exact_statement_or_fact:  
For surgery coefficients `a_i/p_i`, the first homology of the filled manifold is presented by the linking matrix with diagonal entries `a_i` and off-diagonal entries determined by pairwise linking numbers, with the denominators `p_i` entering through the chosen longitude-meridian relation.

intended_role_in_proof:  
Used to derive a contradiction if every `|p_i| > 1`, likely by showing the capped sphere forces a decomposition incompatible with the homology/surgery data.

tool:  
Sphere separation in closed orientable 3-manifolds

source_status: standard background fact

exact_statement_or_fact:  
Every embedded 2-sphere in a closed orientable 3-manifold separates if and only if it is null-homologous over `Z`.

intended_role_in_proof:  
Used to analyze whether the capped planar surface can separate after filling.

tool:  
Intersection pairing between capped sphere and surgery-core curves

source_status: must be proved inside the current proof

exact_statement_or_fact:  
The capped sphere intersects each attached solid torus in one meridian disk, so it has algebraic/geometric intersection one with the corresponding filling core, after orientations are chosen appropriately.

intended_role_in_proof:  
If the capped sphere separates, intersection constraints on core curves and arcs crossing the sphere produce restrictions on the surgery denominators.

tool:  
Contrapositive strategy

source_status: standard proof method

exact_statement_or_fact:

intended_role_in_proof:

4. Hardest step prediction

hardest_step_id:  
SC4

hardest_step_description:  
The difficult point is converting the capped sphere and its intersections with the filling cores into a precise contradiction when all boundary slopes are nonmeridional and nonintegral.

risk_if_wrong:  
If this step only shows that a sphere exists after filling, the proof is incomplete; closed Dehn fillings can contain spheres. The argument must explain why the particular sphere coming from a spanning planar incompressible surface forces forbidden topology back in the original hyperbolic exterior.

how_final_proof_should_handle_it:  
The final proof should give an explicit cut-and-paste or intersection-minimization argument. It should cut the filled manifold along `\widehat P`, track the attached solid-torus meridian disks and core arcs, then pull the resulting structure back into `X_L`. The contradiction must be stated concretely: either a compression of `P`, a boundary compression inconsistent with the slopes, or an essential sphere/annulus/torus in the hyperbolic exterior.

5. Failure-mode checks

circularity_check:  
Do not assume the target theorem or any special theorem about spanning planar surfaces in hyperbolic links. Every nonstandard obstruction must be proved inside the current proof.

full_theorem_check:  
The proof must handle every `N >= 3` hyperbolic link and every incompressible spanning planar surface, not only examples such as pretzel, Montesinos, or alternating links.

source_check:  
No external classification theorem, no paper-specific lemma, and no hidden result may be cited. Hyperbolic exterior consequences such as irreducibility and boundary irreducibility are acceptable standard background.

hypothesis_check:  
Use all necessary hypotheses: `N >= 3`, hyperbolicity of `L`, planarity of `P`, exactly one boundary component on each boundary torus, and incompressibility of `P`.

notation_check:  
Clarify that slope `a/p` is in meridian-longitude coordinates, with meridional corresponding to `p = 0` and integral corresponding to `p = 1`.

standard_background_check:  
Acceptable standard tools include Dehn filling definitions, capping boundary curves by meridian disks under matching filling, basic irreducibility consequences of hyperbolic 3-manifolds, and elementary surface intersection/cut-and-paste arguments.

6. Subproblem assignment table

S1:  
Set up the contradiction. Define boundary slopes `a_i/p_i`, assume all `p_i notin {0,1}`, perform Dehn filling along these slopes, and prove that `P` caps off to an embedded sphere `\widehat P`.

S2:  
Analyze the capped sphere in the filled manifold. Prove separation properties and describe exactly how each attached solid-torus core intersects `\widehat P`.

S3:  
Prove the main geometric obstruction: under the assumption that all denominators avoid `{0,1}`, the sphere/core configuration forces a compression, boundary compression, or forbidden essential surface in the original exterior.

S4:  
Use hyperbolicity of `X_L` and incompressibility of `P` to rule out the forbidden object produced by S3.

S5:  
Assemble the contradiction and conclude that at least one boundary slope has `p in {0,1}`. Check that all cases, including signs and possible nonprimitive notation, are normalized correctly.
