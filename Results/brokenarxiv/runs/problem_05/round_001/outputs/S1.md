2. Subproof or failure

Let `T_1, ..., T_N` be the boundary tori of `X_L`, indexed by the components of `L`. Since `P` is a spanning planar surface, its boundary consists of exactly one simple closed curve on each `T_i`; write this curve as `γ_i`.

Fix standard meridian-longitude coordinates `(μ_i, λ_i)` on `T_i`. The slope of `γ_i` is written `a_i/p_i`, meaning that, up to sign, `γ_i` represents the primitive class

`\[
a_i \mu_i + p_i \lambda_i \in H_1(T_i;\mathbb Z).
\]`

With the convention in the target theorem, `p_i = 0` is the meridional case and `p_i = 1` is the integral case. For the contradiction setup, assume

`\[
p_i \notin \{0,1\}
\quad\text{for every } i=1,\dots,N.
\]`

For each `i`, attach a solid torus `V_i` to `T_i` so that the meridian curve of `V_i` is identified with the slope represented by `γ_i`. Denote the resulting simultaneous Dehn filling by

`\[
M = X_L(a_1/p_1,\dots,a_N/p_N).
\]`

By construction of Dehn filling, each `γ_i` bounds a meridian disk `D_i` inside the attached solid torus `V_i`. The solid tori `V_i` are pairwise disjoint, so the disks `D_i` may be chosen pairwise disjoint, with interiors disjoint from `X_L`.

Now define

`\[
\widehat P = P \cup_{\gamma_1} D_1 \cup_{\gamma_2} \cdots \cup_{\gamma_N} D_N \subset M.
\]`

Since `P` is properly embedded in `X_L`, each `D_i` is embedded in the corresponding attached solid torus, and the only intersections occur along the common boundary curves `γ_i`, this union is an embedded closed surface in `M` after the usual smoothing along the seams.

Topologically, `\widehat P` is obtained from the connected planar surface `P` by attaching one disk to each boundary component. Thus all boundary components are capped, no genus is introduced, and the resulting closed connected genus-zero surface is homeomorphic to `S^2`.

Therefore, under the contradiction assumption that all `p_i notin {0,1}`, the Dehn-filled manifold `M` contains the capped embedded sphere `\widehat P`.
