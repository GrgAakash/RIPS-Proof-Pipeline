## 1. Claim

For the assigned S2 subproblem: after Dehn filling each boundary torus of \(X_L\) along the slope \(\alpha_i\) carried by \(\partial P \cap T_i\), the surface \(P\) caps off to an embedded sphere \(\widehat P\), and each filling core intersects \(\widehat P\) exactly once.

## 2. Setup

Let \(T_i\) be the \(i\)-th boundary torus of \(X_L\). Since \(P\) is a spanning planar surface with exactly one boundary component on each \(T_i\), write

\[
\partial P \cap T_i = \gamma_i,
\]

where \(\gamma_i\) is an essential simple closed curve of slope \(\alpha_i\).

Perform \(\alpha_i\)-Dehn filling on each \(T_i\), attaching a solid torus \(V_i\) so that \(\gamma_i\) bounds a meridian disk in \(V_i\). Let \(c_i\) denote the core circle of \(V_i\).

## 3. Construction

For each \(i\), choose a meridian disk \(D_i \subset V_i\) with

\[
\partial D_i = \gamma_i = \partial P \cap T_i.
\]

The solid tori \(V_i\) are pairwise disjoint, and \(P\) lies in the original exterior \(X_L\), so the disks \(D_i\) are disjoint from one another and meet \(P\) only along their boundary circles.

Define

\[
\widehat P = P \cup_{\partial P} \bigcup_{i=1}^N D_i.
\]

After the usual smoothing along the glued boundary circles, \(\widehat P\) is an embedded closed surface in the filled manifold.

Because \(P\) is planar with exactly \(N\) boundary components, capping every boundary component by a disk produces a closed genus-zero surface. Hence

\[
\widehat P \cong S^2.
\]

So \(\widehat P\) is an embedded sphere.

## 4. Core Intersections

Inside each attached solid torus \(V_i\), the filling core \(c_i\) intersects any meridian disk \(D_i\) transversely in exactly one point. Since \(c_i\) is contained in \(V_i\) and \(\widehat P \cap V_i = D_i\), we get

\[
|c_i \cap \widehat P| = |c_i \cap D_i| = 1.
\]

Thus every filling core intersects the capped sphere \(\widehat P\) exactly once, not at least twice.
