2. Subproof or failure

Let \(\eta\in \operatorname{Lip}_c(M)\), \(\eta\ge 0\). Let \(K=\operatorname{spt}\eta\). Since \(u\in W^{1,n}_{\mathrm{loc}}(M)\cap L^\infty_{\mathrm{loc}}(M)\), \(u\) is essentially bounded on a relatively compact open set containing \(K\). The map \(t\mapsto e^{-t}\) has bounded derivative on the essential range of \(u\) over this set, so the Sobolev chain rule gives \(e^{-u}\in W^{1,n}_{\mathrm{loc}}\), with
\[
\nabla(e^{-u})=-e^{-u}\nabla u.
\]
Hence
\[
\phi=\eta^n e^{-u}\in W^{1,n}_0(M)\cap L^\infty_c(M)
\]
and is an admissible nonnegative compactly supported test function in the weak formulation. Substituting \(\phi\) gives
\[
\int_M |\nabla u|^{n-2}g(\nabla u,\nabla(\eta^n e^{-u}))\,dV_g
=
\int_M e^u\eta^n e^{-u}\,dV_g
=
\int_M \eta^n\,dV_g.
\]
Using the product and chain rules,
\[
\nabla(\eta^n e^{-u})
=
n\eta^{n-1}e^{-u}\nabla\eta-\eta^n e^{-u}\nabla u.
\]
Therefore
\[
\int_M \eta^n\,dV_g
=
n\int_M \eta^{n-1}e^{-u}|\nabla u|^{n-2}g(\nabla u,\nabla\eta)\,dV_g
-
\int_M \eta^n e^{-u}|\nabla u|^n\,dV_g.
\]
Set
\[
A:=\left(\int_M \eta^n e^{-u}|\nabla u|^n\,dV_g\right)^{(n-1)/n},
\qquad
B:=\left(\int_M e^{-(n-1)u}|\nabla\eta|^n\,dV_g\right)^{1/n}.
\]
By Hölder,
\[
\int_M \eta^{n-1}e^{-u}|\nabla u|^{n-1}|\nabla\eta|\,dV_g
\le AB,
\]
because
\[
\eta^{n-1}e^{-u}|\nabla u|^{n-1}|\nabla\eta|
=
(\eta^n e^{-u}|\nabla u|^n)^{(n-1)/n}
(e^{-(n-1)u}|\nabla\eta|^n)^{1/n}.
\]
Thus
\[
\int_M \eta^n\,dV_g + A^{n/(n-1)}
\le nAB.
\]
Using Young’s inequality in the sharp form
\[
nAB\le A^{n/(n-1)}+(n-1)B^n,
\]
we obtain cancellation of the \(A^{n/(n-1)}\) terms and hence
\[
\boxed{
\int_M \eta^n\,dV_g
\le
(n-1)\int_M e^{-(n-1)u}|\nabla\eta|^n\,dV_g.
}
\]
This is the core \(n\)-Caccioppoli estimate. Equivalently,
\[
\boxed{
\|\eta\|_{L^n(M)}^n
\le
(n-1)\|e^{-u/n'}\nabla\eta\|_{L^n(M)}^n,
\qquad n'=\frac n{n-1}.
}
\]
The estimate is homogeneous of degree \(n\) in the cutoff: replacing \(\eta\) by \(c\eta\) multiplies both sides by \(c^n\). This is the scale-invariant structure associated with the \(n\)-Laplacian.

In particular, if \(K=\operatorname{spt}\eta\), then local boundedness of \(u\) gives
\[
e^{-(n-1)u}\le \exp\bigl((n-1)\|u\|_{L^\infty(K)}\bigr)
\quad\text{a.e. on }K,
\]
so the unweighted consequence
\[
\boxed{
\int_M \eta^n\,dV_g
\le
(n-1)e^{(n-1)\|u\|_{L^\infty(K)}}
\int_M |\nabla\eta|^n\,dV_g
}
\]
also holds. The sharper form is the weighted estimate above.
