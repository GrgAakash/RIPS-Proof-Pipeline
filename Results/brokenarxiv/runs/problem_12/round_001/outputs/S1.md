2. Subproof or failure

Let `X` be a finite set. Define

`A_X := Z[E_x : x in X]`,

the polynomial ring over `Z` with one indeterminate `E_x` for each element `x in X`. This is a commutative ring.

For each `x in X`, let `e_x := E_x in A_X`. These elements are the initial formal representatives of the points of `X`.

Define the preliminary map

`i_X : X -> A_X`,  
`i_X(x) = e_x`.

We claim that `i_X` is injective. If `X` is empty or has one element, this is immediate. Otherwise, let `x,y in X` with `x != y`. In the polynomial ring `A_X`, the indeterminates `E_x` and `E_y` are distinct formal monomials. Equivalently, as elements of the free abelian group underlying `A_X`, they are distinct basis monomials, so `E_x - E_y != 0`. Hence `e_x != e_y`, and therefore `i_X` is injective.

Now suppose a later subproblem forms a quotient ring `R = A_X/I`, or a quotient of a larger polynomial ring containing these same symbols, and lets `q` denote the quotient map. The intended embedding map would have the form

`j : X -> R`,  
`j(x) = q(e_x)`.

For this `j` to be injective, it is necessary and sufficient that

`q(e_x) != q(e_y)` for every pair `x,y in X` with `x != y`.

In the quotient-ring case `R = A_X/I`, this is equivalently the condition

`e_x - e_y notin I` for every `x != y`.

Thus the precise preservation requirement for later quotient constructions is: no imposed relation may force `e_x = e_y` for distinct `x,y in X`.
