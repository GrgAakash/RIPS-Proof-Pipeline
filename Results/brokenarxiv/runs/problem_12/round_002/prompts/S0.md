Target theorem:
Let X be a finite set. A function f : X^k -> X is said to embed into a polynomial of total degree d over a commutative ring R if there is an injection j : X -> R and a polynomial g in R[x_1, ..., x_k] of total degree at most d such that j(f(v_1, ..., v_k)) = g(j(v_1), ..., j(v_k)) for all (v_1, ..., v_k) in X^k. There exists a universal integer d >= 1 such that for every finite set X and every binary function f : X^2 -> X, f embeds into a polynomial of total degree at most d over some commutative ring R.

Additional mathematical guidance:
1. Do not use the commutative quotient with g=x_1 x_2 for arbitrary binary functions; in any commutative ring it forces j(f(a,b))=j(f(b,a)), so with injective j it can only represent symmetric binary functions.
