**1. Assignment Restatement**

Construct a concrete commutative ring `R` for a finite set `X`, define an injection `j : X -> R`, and prove that `j` is injective.

**2. Subproof or Failure**

If `X` is empty, take any commutative ring, for example `R = Z`, and let `j : emptyset -> R` be the unique empty function. It is injective vacuously.

Assume now that `X` is nonempty. Let

`R = Z^X`

with coordinatewise addition and multiplication. Thus an element of `R` is a function `r : X -> Z`, and

`(r+s)(x)=r(x)+s(x)`,  
`(rs)(x)=r(x)s(x)`.

This is a commutative ring.

For each `a in X`, define `j(a) in R` by

`j(a)(x) = 1` if `x=a`, and `j(a)(x)=0` otherwise.

So `j(a)` is the characteristic function of the singleton `{a}`.

To prove injectivity, let `a,b in X` and suppose `j(a)=j(b)`. Evaluating both sides at `a`, we get

`j(a)(a)=j(b)(a)`.

The left side is `1`. If `b != a`, then `j(b)(a)=0`, contradiction. Hence `b=a`. Therefore `j` is injective.
