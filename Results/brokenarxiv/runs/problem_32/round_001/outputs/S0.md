1. Target decomposition

target_label: Problem 32  
target_type: if and only if classification  
main_goal: Classify exactly when the Terwilliger algebra \(T\) of the association scheme from the orbit Schur ring \(S(G,H)\) is almost commutative.  
variables_and_parameters: \(p\) prime; \(n\ge 1\); \(G\) finite cyclic of order \(p^n\); \(H\le \operatorname{Aut}(G)\); \(S(G,H)\) the orbit Schur ring; \(T\) the Terwilliger algebra of the derived association scheme.  
conclusion_to_prove: \(T\) is almost commutative if and only if \(H=\{1\}\) or \(H=\operatorname{Aut}(G)\).

2. Available tools

tool: Orbit Schur ring basic sets  
source_status: provided definition / notation / assumption  
exact_statement_or_fact: The basic sets of \(S(G,H)\) are the \(H\)-orbits on \(G\), and the associated Cayley relations are indexed by those orbits.  
intended_role_in_proof: Identifies the dual idempotents and adjacency matrices used in \(T\).

tool: Cyclic \(p\)-group automorphism layers  
source_status: standard background fact  
exact_statement_or_fact: If \(G=\langle g\rangle\), then \(\operatorname{Aut}(G)\cong(\mathbb Z/p^n\mathbb Z)^\times\), acting by \(g^a\mapsto g^{ua}\). Its orbits are the \(p\)-adic layers \(L_i=\{g^{p^iu}:u\in(\mathbb Z/p^{n-i}\mathbb Z)^\times\}\), \(0\le i<n\), plus \(\{1_G\}\).  
intended_role_in_proof: Reduces the endpoint \(H=\operatorname{Aut}(G)\) to a layer scheme and shows every \(H\)-orbit refines a layer.

tool: Generator-layer orbit test  
source_status: standard background fact  
exact_statement_or_fact: The action of \(\operatorname{Aut}(G)\) on the generators \(L_0\) is regular. Thus \(H\cdot g\) is singleton iff \(H=\{1\}\), and equals \(L_0\) iff \(H=\operatorname{Aut}(G)\).  
intended_role_in_proof: Converts “proper nontrivial \(H\)” into the existence of a nontrivial proper orbit in the generator layer.

tool: Almost-commutative Terwilliger criterion  
source_status: provided definition / notation / assumption  
exact_statement_or_fact: Use the standard definition: \(T\) is almost commutative iff every irreducible \(T\)-module other than the primary module is one-dimensional.  
intended_role_in_proof: Gives the module-theoretic condition to prove or disprove.

tool: Primary module  
source_status: standard background fact  
exact_statement_or_fact: The primary \(T\)-module is spanned by the characteristic vectors of the basic sets containing the basepoint relation classes.  
intended_role_in_proof: Separates the allowed higher-dimensional primary component from forbidden higher-dimensional nonprimary components.

tool: Trivial-\(H\) matrix-unit computation  
source_status: proved inside the current proof  
exact_statement_or_fact: If \(H=\{1\}\), all basic sets are singletons, and \(E_x^*A_{x^{-1}y}E_y^*\) gives matrix units; hence \(T=\operatorname{Mat}_{|G|}(\mathbb C)\) and its unique irreducible module is the primary module.  
intended_role_in_proof: Proves the first sufficiency branch.

tool: Full-automorphism layer decomposition  
source_status: proved inside the current proof  
exact_statement_or_fact: If \(H=\operatorname{Aut}(G)\), then \(V\) decomposes as the primary module plus, for each nonidentity layer \(L_i\), the zero-sum subspace on \(L_i\); cross-layer blocks kill these zero-sum subspaces, and each layer’s restricted algebra is simultaneously diagonalizable, giving only one-dimensional nonprimary irreducibles.  
intended_role_in_proof: Proves the second sufficiency branch.

tool: Intermediate-\(H\) obstruction  
source_status: proved inside the current proof  
exact_statement_or_fact: If \(\{1\}<H<\operatorname{Aut}(G)\), then using two distinct \(H\)-orbits in the generator layer and a nontrivial character of the finite abelian group \(H\), some adjacency block sends a nonprimary character vector in one orbit to a nonzero vector in another orbit. Therefore a nonprimary irreducible \(T\)-module has dimension at least \(2\).  
intended_role_in_proof: Proves necessity.

4. Hardest step prediction

hardest_step_id: SC5  
hardest_step_description: Constructing the nonprimary higher-dimensional module for every proper nontrivial \(H\), especially for \(p=2\) and for subgroups acting trivially on some lower quotients.  
risk_if_wrong: The proof could accidentally show only that a nonprimary invariant subspace has dimension \(>1\), without proving that an irreducible constituent has dimension \(>1\).  
how_final_proof_should_handle_it: Use explicit \(H\)-character vectors on the free generator-layer orbits. Show an actual off-diagonal Terwilliger block acts nontrivially on a nontrivial \(H\)-character component; since a one-dimensional \(T\)-module must lie in a single dual-idempotent fiber, this forces a nonprimary irreducible constituent of dimension at least \(2\).

6. Subproblem assignment table

S1: Prove the cyclic \(p\)-group orbit facts: describe \(\operatorname{Aut}(G)\), its \(p\)-adic layers, and the generator-layer test for \(H=\{1\}\) and \(H=\operatorname{Aut}(G)\).

S2: State the Terwilliger setup and almost-commutative criterion. Prove the \(H=\{1\}\) case by matrix units and identify the standard module with the primary module.

S3: Prove the \(H=\operatorname{Aut}(G)\) case. Use the \(p\)-adic layers, show cross-layer adjacency blocks are constant, show zero-sum layer subspaces are killed by cross-layer blocks, and diagonalize the within-layer algebra into one-dimensional modules.

S4: Prove the intermediate-\(H\) obstruction. Work on the generator layer, use nontrivial characters of \(H\), find a nonzero off-diagonal block between two generator-layer \(H\)-orbits on a nontrivial character component, and conclude a nonprimary irreducible has dimension at least \(2\).

S5: Assemble the iff proof from S1-S4, explicitly checking edge cases \(n=1\), \(p=2\), and the case \(\operatorname{Aut}(G)=\{1\}\).
