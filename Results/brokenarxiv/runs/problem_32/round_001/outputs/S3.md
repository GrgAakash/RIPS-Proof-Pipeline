2. Subproof or failure

Let `G=<g>` have order `p^n`. For `0 <= i < n`, define
`L_i={g^{p^i u}: p does not divide u}`, and define `L_n={1_G}`. The automorphisms of `G` are given by `g -> g^a` with `a` a unit modulo `p^n`. Hence they preserve the exact `p`-adic valuation of the exponent, and conversely act transitively on each `L_i`; therefore the basic sets for `H=Aut(G)` are exactly `L_0,...,L_n`.

Let `V=C^G`, with basis vectors `e_x`. Let `A_i` be the adjacency matrix for the Cayley relation indexed by `L_i`, so `(A_i)_{x,y}=1` exactly when `xy^{-1} in L_i`. Let `E_i^*` be the diagonal projection onto `V_i=C^{L_i}`. Put
`1_i=sum_{x in L_i} e_x`, and for `0 <= i < n`,
`W_i={sum_{x in L_i} c_x e_x : sum_{x in L_i} c_x=0}`.
Also set `W_n=0`.

The primary module is
`M=span{1_0,...,1_n}`:
indeed, with basepoint `1_G`, we have `A_i e_{1_G}=1_i`, so the primary module contains all `1_i`; conversely, the block computations below show every generator `A_i` and `E_i^*` sends layer-constant vectors to layer-constant vectors.

First compute cross-layer blocks. If `x in L_a`, `y in L_b`, and `a != b`, then `xy^{-1} in L_min(a,b)`. For example, if `a<b<n`, then
`x=g^{p^a u}`, `y=g^{p^b v}`, so
`xy^{-1}=g^{p^a(u-p^{b-a}v)}`,
and the parenthesized factor is a unit. The other case is symmetric, and the identity layer is immediate. Thus
`E_a^* A_r E_b^*`
is the all-one rectangular block from `V_b` to `V_a` if `r=min(a,b)`, and is zero otherwise. Consequently every cross-layer block kills `W_b`, because an all-one block sends a vector to a multiple of the sum of its coordinates.

Now fix `i<n` and identify `L_i` with `U=(Z/p^{n-i}Z)^x` by `u -> g^{p^i u}`. Let `m=n-i`. For `0 <= s <= m`, define `N_s` on `C^U` by
`(N_s)_{u,v}=1` iff `u congruent v mod p^s`;
thus `N_0` is the all-one matrix and `N_m` is the identity matrix. Inside `V_i`,
`E_i^* A_{i+s} E_i^*=N_s-N_{s+1}` for `0 <= s<m`,
and `E_i^* A_n E_i^*=N_m`.
This follows because
`g^{p^i u}(g^{p^i v})^{-1}=g^{p^i(u-v)}`,
so the layer is determined by the exact `p`-adic valuation of `u-v`, with equality giving the identity layer.

The matrices `N_s` commute. Indeed, `(N_sN_t)_{u,w}` counts units `v` satisfying
`v congruent u mod p^s` and `v congruent w mod p^t`. This count is zero unless `u congruent w mod p^min(s,t)`, and if nonzero it depends only on `max(s,t)`, not on `u,w`. Hence `N_sN_t=cN_min(s,t)=N_tN_s` for the relevant constant `c`. Since the `N_s` are also symmetric, they are simultaneously diagonalizable over `C`. Therefore the within-layer algebra generated by the blocks `E_i^*A_rE_i^*` has a basis of common eigenvectors on `W_i`.

Each `W_i` is `T`-invariant. The dual idempotents either fix it or kill it. The cross-layer blocks kill it by the preceding all-one-block computation. The within-layer blocks preserve the total coordinate sum, hence preserve `W_i`. Therefore each simultaneous eigenline in `W_i` is a one-dimensional `T`-submodule. Thus
`W_i` is a direct sum of one-dimensional `T`-modules.

Finally,
`V=M direct_sum W_0 direct_sum ... direct_sum W_{n-1}`.
The module `M` is irreducible: if a nonzero `T`-submodule of `M` contains some nonzero layer component `c 1_i`, then applying `E_i^*` isolates it. If `i<n`, applying `E_n^*A_iE_i^*` gives a nonzero multiple of `1_n`; from `1_n`, the vectors `A_j1_n=1_j` generate all of `M`. If `i=n`, the same last step applies directly.

So the standard module decomposes as the primary irreducible module `M` plus one-dimensional nonprimary modules. Hence, for `H=Aut(G)`, every nonprimary irreducible Terwilliger module is one-dimensional.
